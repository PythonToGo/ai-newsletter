## 지금 이 논문을 읽어야 하는 이유

2012년 AlexNet이 풀려던 문제는 단순한 이미지 분류가 아니었다. 핵심은 'hand-crafted feature 없이 raw data에서 직접 표현을 학습할 수 있는가'였다. ReLU activation으로 vanishing gradient를 억제하고, dropout으로 overfitting을 제어하며, GPU 병렬 연산으로 대규모 학습을 현실화한 이 조합은, 당시 지배적이던 shallow model 패러다임 전체를 뒤흔들었다. 오늘날 시각으로 보면 이 논문은 'scale이 곧 성능'이라는 현대 deep learning의 핵심 철학을 처음으로 대규모 벤치마크에서 증명한 문서다.

AlexNet 이후 탄생한 VGGNet, ResNet의 residual connection, 그리고 Vision Transformer(ViT)까지, 현대 컴퓨터 비전 파이프라인의 뿌리는 모두 이 논문으로 거슬러 올라간다. PyTorch나 TensorFlow로 image classification 모델을 fine-tuning할 때 당연하게 쓰는 ReLU, dropout, data augmentation 조합은 AlexNet이 실전에서 검증한 레시피다. GPU를 활용한 대규모 neural network 훈련이라는 방법론은 이후 NLP, 음성 인식, 강화학습 전 분야로 확산되어 오늘날 LLM 훈련 인프라의 직접적인 조상이 되었다.

지금 이 논문을 읽으면 두 가지 실질적 통찰을 얻는다. 첫째, 하드웨어와 알고리즘의 co-design 사고방식이다. AlexNet의 성공은 모델 구조만이 아니라 GPU 메모리 제약에 맞춰 network를 두 GPU에 분산 설계한 엔지니어링 결정에서 비롯됐다. 오늘날 edge device 배포나 TPU 최적화 설계에서도 동일한 사고가 요구된다. 둘째, regularization 선택의 근거다. dropout이 왜 fully connected layer에 집중 적용되었는지 원문을 읽으면 parameter 수와 overfitting 리스크의 관계를 직관적으로 재정립할 수 있다.

## [ImageNet Classification with Deep Convolutional Neural Networks (AlexNet)](https://papers.nips.cc/paper/2012/hash/c399862d3b9d6b76c8436e924a68c45b-Abstract.html)

> 2012년  ·  Alex Krizhevsky, Ilya Sutskever, Geoffrey E. Hinton  ·  NeurIPS 2012  ·  인용 120,000회

### 한 줄 요약

2012년 ImageNet Large Scale Visual Recognition Challenge(ILSVRC)에서 기존 방식으로는 해결하기 어려웠던 대규모 이미지 분류 문제를 다루기 위해, Alex Krizhevsky, Ilya Sutskever, Geoffrey Hinton은 5개의 convolutional layer와 2개의 fully connected layer로 구성된 깊은 convolutional neural network(AlexNet)를 제안했다. 핵심 아이디어는 ReLU activation, dropout regularization, GPU 병렬 학습을 결합하여 60만 개의 parameter를 가진 대형 모델을 효율적으로 훈련하는 것이었다. 그 결과 top-5 error rate 18.9%를 달성하며 당시 2위와 10%p 이상의 격차로 압도적인 우승을 기록했다.

### 역사적 배경

2012년 이전까지 머신러닝 커뮤니티는 kernel method와 shallow model이 이론적으로 충분하다는 믿음이 강했고, neural network는 1990년대 backpropagation 이후 두 번째 침체기를 겪고 있었다. AlexNet은 이러한 분위기 속에서 대규모 데이터와 GPU 연산, 그리고 정교한 regularization 기법을 결합함으로써 deep learning의 실용성을 처음으로 대규모 벤치마크에서 증명해 보였다.

### 왜 혁신적이었는가

기존의 hand-crafted feature 기반 pipeline 대신 end-to-end로 학습되는 deep convolutional neural network를 GPU로 훈련함으로써, 당시 2위 대비 top-5 error rate를 10%p 이상 낮추는 성능 도약을 달성했다.

### 이 논문이 만들어낸 변화

AlexNet의 등장은 deep learning이 컴퓨터 비전의 새로운 표준 패러다임으로 자리잡는 결정적 계기가 되었으며, 이후 VGGNet, GoogLeNet, ResNet 등 더 깊은 아키텍처 연구의 물꼬를 텄다. GPU를 활용한 대규모 neural network 훈련이라는 방법론은 자연어 처리, 음성 인식 등 AI 전 분야로 확산되어 현대 deep learning 붐의 실질적인 출발점이 되었다.

### 오늘날 배울 수 있는 것

1. ReLU activation의 실용적 가치: sigmoid나 tanh 대신 ReLU를 사용하면 non-saturating 특성 덕분에 backpropagation 시 gradient 소실을 줄이고 훈련 속도를 크게 높일 수 있으며, 이는 오늘날에도 대부분의 deep learning 모델 설계의 기본 원칙으로 남아 있다.
2. Dropout regularization의 중요성: fully connected layer에서 dropout을 적용하면 co-adaptation을 방지하고 overfitting을 효과적으로 억제할 수 있으며, 데이터가 제한된 실무 환경에서도 여전히 유효한 regularization 전략이다.
3. 하드웨어와 알고리즘의 공진화: AlexNet의 성공은 단순히 모델 구조의 혁신이 아니라 GPU 병렬 연산이라는 하드웨어 활용 전략과의 결합에서 비롯되었으며, 오늘날 실무에서도 모델 설계 시 가용 연산 자원과 아키텍처를 함께 고려하는 co-design 사고방식이 필수적이다.

### 한계 및 이후 발전

AlexNet은 모델 깊이가 제한적이고 convolutional layer 설계가 직관에 의존했으며, 이후 batch normalization, residual connection, attention mechanism 등의 기법이 등장하면서 더 깊고 안정적인 학습이 가능해졌다.

## [Neural Machine Translation by Jointly Learning to Align and Translate](https://arxiv.org/abs/1409.0473)

> 2014년  ·  Dzmitry Bahdanau, Kyunghyun Cho, Yoshua Bengio  ·  ICLR 2015  ·  인용 25,000회

### 한 줄 요약

기존 encoder-decoder 모델은 입력 문장 전체를 하나의 fixed-length vector로 압축해야 했기 때문에 긴 문장에서 성능이 급격히 저하되는 문제가 있었다. Bahdanau 등은 이를 해결하기 위해 decoder가 매 출력 단계마다 입력 시퀀스의 어느 부분에 집중할지 자동으로 학습하는 soft attention mechanism을 제안했다. 그 결과 특히 긴 문장에서 번역 품질이 크게 향상되었으며, 이 alignment 시각화를 통해 모델의 내부 동작을 직관적으로 해석할 수 있게 되었다.

### 역사적 배경

2014년에는 Sutskever et al.의 sequence-to-sequence 모델이 발표된 직후로, RNN과 LSTM 기반의 encoder-decoder 패러다임이 machine translation의 새로운 표준으로 자리 잡기 시작하던 시기였다. 이 논문은 당시 지배적이었던 '입력 전체를 하나의 벡터로 요약한다'는 패러다임에 정면으로 도전하며, 모델이 출력 생성 시 입력의 특정 부분을 동적으로 선택적으로 참조할 수 있어야 한다는 새로운 설계 철학을 제시했다.

### 왜 혁신적이었는가

기존의 fixed-length context vector 방식 대신 decoder의 각 time step마다 입력 시퀀스 전체에 대한 동적 가중합(soft attention)을 계산하는 방식을 도입함으로써, 긴 문장에서도 성능 저하 없이 번역 품질을 유지하고 동시에 alignment를 자동으로 학습하는 end-to-end 훈련을 가능하게 했다.

### 이 논문이 만들어낸 변화

이 논문이 제안한 attention mechanism은 이후 NLP 전반으로 확산되어 Transformer 아키텍처의 self-attention 및 multi-head attention의 직접적인 토대가 되었다. 또한 모델이 예측 시 입력의 어느 부분을 참조했는지 attention matrix를 통해 시각화할 수 있게 됨으로써, 딥러닝 모델의 interpretability 연구에도 중요한 방향을 제시했다.

### 오늘날 배울 수 있는 것

1. bottleneck 진단의 중요성: fixed-length vector라는 구조적 병목을 명확히 식별하고 이를 해소하는 방향으로 아키텍처를 설계한 접근법은, 실무에서도 모델 성능 한계의 원인을 추상적으로 탓하지 않고 정보 흐름 관점에서 구체적으로 분석하는 습관이 얼마나 중요한지를 보여준다.
2. soft vs. hard의 선택: hard attention(이산적 선택)이 아닌 soft attention(연속적 가중치)을 선택함으로써 backpropagation이 가능한 end-to-end 학습 구조를 유지했다는 점은, 미분 가능성(differentiability)을 설계 원칙으로 삼는 것이 학습 안정성과 실용성에 얼마나 큰 영향을 미치는지를 보여주는 교훈이다.
3. interpretability는 부산물이 아닌 설계 목표: attention matrix 시각화를 통해 source-target alignment를 직관적으로 확인할 수 있게 된 것은 의도된 설계의 결과였으며, 오늘날 실무에서도 모델의 내부 동작을 설명할 수 있는 구조를 처음부터 고려하는 것이 디버깅과 신뢰 확보 모두에 유리하다는 점을 시사한다.

### 한계 및 이후 발전

soft attention은 모든 입력 토큰에 대해 가중치를 계산하므로 시퀀스 길이에 따라 계산 비용이 O(n²)으로 증가하는 한계가 있었으며, 이는 이후 Transformer의 efficient attention 변형들(예: sparse attention, linear attention)과 positional encoding 개선 연구들로 극복되었다.
