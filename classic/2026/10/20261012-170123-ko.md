## 1. Batch Normalization: Accelerating Deep Network Training by Reducing Internal Covariate Shift

- 저자: Sergey Ioffe, Christian Szegedy
- 최초 공개: arXiv v1, 2015-02-11
- 검토 버전: v3, 2015-03-02
- 학회: ICML 2015
- 정규 URL: https://arxiv.org/abs/1502.03167
- 공식 저자 코드: 원문·arXiv 페이지에서 별도 공식 저장소 링크를 확인하지 못했다.

### 왜 고전인가

Batch Normalization(BN)은 mini-batch에서 각 feature의 평균과 분산을 구해 정규화한 뒤, 학습 가능한 scale γ와 shift β로 표현력을 되돌린다. 논문의 설명은 각 층 입력 분포가 학습 중 변하는 “internal covariate shift”를 줄이면 높은 learning rate와 덜 민감한 초기화가 가능하다는 것이다. 이후 CNN 학습의 기본 부품이 됐지만, 핵심은 단순히 식 하나가 아니라 training에서는 batch 통계, inference에서는 고정 population 추정치를 쓴다는 두 동작 모드다.

### 방법

feature (x^{(k)})에 대해 batch 평균 μ와 분산 σ²을 계산하고, `(x-μ)/sqrt(σ²+ε)`로 정규화한다. 그 뒤 `y=γx_hat+β`를 학습해 필요하면 원래 affine 표현도 복원할 수 있게 한다. 완전 whitening 대신 각 scalar feature를 독립적으로 정규화하는 계산 가능한 근사다.

합성곱 층에서는 같은 feature map의 batch·공간 위치에 걸쳐 통계를 공유하고, affine transform 뒤 nonlinearity 전에 BN을 둔다. 추론에서는 훈련 중 여러 mini-batch에서 모은 평균·분산을 고정하고, BN과 γ/β를 하나의 선형 변환으로 합칠 수 있다. 따라서 `model.train()`과 `model.eval()`의 차이는 구현 세부사항이 아니라 논문의 알고리즘 자체다.

### 실험과 조건

MNIST 진단에서는 28×28 이진 이미지, sigmoid 100-unit hidden layer 3개, batch 60, 50,000 step을 사용했다. 목적은 최고 성능 경쟁이 아니라 BN 유무에 따른 수렴과 sigmoid 입력 분포 변화를 비교하는 것이었다.

ImageNet 실험은 1,000-class ILSVRC2012와 13.6M parameter Inception 변형을 사용했다. 원 Inception의 초기 learning rate 0.0015에 비해 BN-x5는 0.0075, BN-x30은 0.045를 사용했다.

| 조건 | 원문 결과 | 해석 |
| --- | ---: | --- |
| Inception | 31M step에서 validation accuracy 72.2% | 비교 기준 |
| BN-Baseline | 절반 미만 step에서 72.2% 도달 | BN만 추가 |
| BN-x5 | 14배 적은 step으로 72.2% | BN 외 LR·decay·shuffle·distortion 변경도 포함 |
| BN-x30 | 6M step에서 74.8% | 높은 LR, 더 높은 최종 정확도 |
| BN-x5-Sigmoid | 69.8% | BN 없는 sigmoid Inception은 1/1000보다 낫지 않음 |
| BN ensemble | validation top-5 error 4.9%, test 4.8% | 단일 모델 결과와 구분 필요 |

“14배 빠르다”는 wall-clock 보편값이 아니다. BN-x5에는 learning rate 5배 증가, decay 6배 가속, Local Response Normalization 제거, 더 강한 shuffle, photometric distortion 감소가 함께 들어갔다. 비교 대상도 2015년 Inception 계열이다.

### 오늘 다시 읽을 때의 주의점

논문이 제시한 internal covariate shift 설명은 역사적 동기다. 이 원문만으로 BN의 모든 효과가 그 원인에서 나온다고 확정할 수 없다. 작은 batch, 시계열·온라인 학습, 참여자별 EEG처럼 batch 안 샘플이 독립·동일분포가 아닌 조건에서는 통계 잡음과 leakage가 커질 수 있다. train/eval 전환을 놓치거나 validation·test 데이터로 running statistics를 갱신하면 성능이 과대평가될 수 있다.

BN의 stochastic batch 통계는 정규화이자 잡음원으로 작동한다. gradient accumulation은 effective optimizer batch를 키우지만 BN이 실제로 보는 micro-batch 통계를 자동으로 키워주지 않는다. 분산 학습에서 GPU별 BN과 SyncBatchNorm도 서로 다른 모델 동작이다. 그래서 “batch size”를 기록할 때 global batch만 쓰면 재현 정보가 부족하다.

공식 저자 코드가 확인되지 않았고, 현대 프레임워크 구현은 논문을 바탕으로 발전한 후대 구현이다. 라이브러리 기본 momentum 정의, unbiased variance 처리, epsilon, channel 축을 확인해야 한다.

### FP/EEG와 일반 ML 실무 적용

- 대상: 참여자 수가 적고 trial correlation이 큰 EEG 또는 시계열 모델을 학습하는 연구팀.
- 실행: BN, LayerNorm/GroupNorm, normalization 없음 세 조건을 같은 seed·분할·optimizer budget으로 비교한다. participant 단위 train/validation/test 분리를 먼저 고정하고, 평가 전 반드시 eval mode로 바꾸며 running mean/variance가 test에서 갱신되지 않는지 hook 또는 unit test로 검증한다.
- 기록: 실제 micro-batch size, global batch, SyncBN 여부, momentum, epsilon, 채널 축, train/eval 전환 위치, 마지막 batch 처리 규칙.
- 완료 기준: unseen-subject 성능뿐 아니라 seed 분산, calibration, train/eval 출력 차이, batch size 민감도를 표로 남기고 어떤 정규화가 선택됐는지 근거를 적는다.
- 읽는 순서: §3 Algorithm 1–2 → §3.2 CNN 적용 → §4.1 MNIST 진단 → §4.2 ImageNet → Conclusion. 초록의 14배 수치보다 조건표를 먼저 확인한다.

### 캡션
Batch Normalization을 한 줄짜리 정규화 공식으로만 기억하면 가장 중요한 부분을 놓칩니다. 학습 때는 mini-batch 통계, 추론 때는 고정 통계를 사용하기 때문에 mode 전환·micro-batch·분산 학습 설정이 결과를 바꿉니다. 원문의 “14배 적은 step”도 BN 하나의 보편적 속도가 아니라 당시 Inception과 함께 바꾼 학습 설정 안에서 나온 결과입니다. 작은 EEG 데이터에서는 참가자 분할과 running statistics 누수를 먼저 검증하세요.
