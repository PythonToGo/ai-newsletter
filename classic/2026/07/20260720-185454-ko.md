## 지금 이 논문을 읽어야 하는 이유

2014년 DeepMind 연구진이 던진 질문은 단순했다. 신경망이 Von Neumann 아키텍처처럼 외부 memory를 읽고 쓸 수 있다면 어떨까? NTM은 이 질문에 답하기 위해 external memory matrix에 soft attention 기반 read/write 연산을 결합했다. 핵심은 모든 연산을 end-to-end differentiable하게 유지한 것이다. Hard discrete operation 대신 soft attention으로 memory에 접근함으로써 backpropagation이 전체 시스템을 관통할 수 있었고, 그 결과 sorting과 copying 같은 알고리즘적 task를 학습으로 습득하는 데 성공했다.

이 논문의 직계 후손들은 지금 우리 주변에 있다. Differentiable Neural Computer(DNC)는 NTM의 직접적 진화이며, retrieval-augmented generation(RAG) 시스템이 외부 knowledge base를 attention으로 조회하는 방식은 NTM의 content-based addressing 철학과 구조적으로 동일하다. LLM이 tool을 호출하고 외부 memory를 참조하는 agent 아키텍처 역시 NTM이 열어놓은 패러다임의 연장선이다.

지금 이 논문을 읽으면 두 가지 설계 원칙이 눈에 들어온다. 첫째, 새로운 모듈을 추가할 때 gradient flow를 끊지 않는 것이 얼마나 강력한 제약 조건인지 체감할 수 있다. RAG나 agent 시스템 설계 시 differentiability를 기준으로 컴포넌트를 평가하는 시각이 생긴다. 둘째, content-based addressing과 location-based addressing의 조합은 현대 Transformer의 attention 설계를 근본부터 이해하는 데 직접적인 통찰을 제공한다. 이 논문은 역사가 아니라 현재 시스템의 설계도다.

## [Neural Turing Machines](https://arxiv.org/abs/1410.5401)

> 2014년  ·  Alex Graves, Greg Wayne, Ivo Danihelka  ·  arXiv 2014  ·  인용 5,000회

### 한 줄 요약

당시 neural network는 복잡한 알고리즘적 task를 수행하기에 내부 memory 용량이 제한적이었다. 이 논문은 neural network를 외부 memory matrix에 연결하고, attention mechanism을 통해 read/write 연산을 수행하는 Neural Turing Machine(NTM)을 제안했다. 전체 시스템이 end-to-end differentiable하게 설계되어 backpropagation으로 학습 가능하며, sorting이나 copying 같은 알고리즘적 task를 학습으로 습득할 수 있음을 보였다.

### 역사적 배경

2014년은 deep learning이 image recognition에서 두각을 나타내던 시기였으나, 신경망은 여전히 Von Neumann 아키텍처가 기본으로 갖추는 random access memory나 명시적 저장소 없이 작동했다. Alex Graves 등 DeepMind 연구진은 Turing Machine의 개념을 신경망에 접목함으로써, 당시 지배적이던 'neural network는 고정된 크기의 hidden state만 가진다'는 패러다임에 정면으로 도전했다.

### 왜 혁신적이었는가

기존의 LSTM처럼 고정된 크기의 internal hidden state에만 의존하는 방식 대신, 외부 memory matrix에 대한 soft attention 기반 read/write 연산을 도입함으로써, 전체 시스템을 end-to-end differentiable하게 유지하면서도 임의 길이의 정보를 저장하고 검색하는 능력을 neural network에 부여했다.

### 이 논문이 만들어낸 변화

NTM은 이후 Differentiable Neural Computer(DNC), Memory-Augmented Neural Network 등 memory 기반 아키텍처 연구의 직접적인 출발점이 되었다. 또한 neural network가 단순한 패턴 매칭을 넘어 알고리즘적 절차를 학습할 수 있다는 가능성을 열어, program synthesis와 neural reasoning 분야 전반에 큰 영향을 미쳤다.

### 오늘날 배울 수 있는 것

1. Differentiability를 설계 원칙으로 삼아라: NTM의 핵심은 memory 접근 연산을 hard discrete operation이 아닌 soft attention으로 구현하여 gradient가 흐를 수 있게 한 것이다. 실무에서 새로운 모듈을 설계할 때도 end-to-end gradient flow를 최우선으로 고려해야 한다.
2. Inductive bias를 구조로 표현하라: 알고리즘적 task를 풀기 위해 데이터만 늘리는 대신, Turing Machine이라는 계산 이론적 inductive bias를 아키텍처 자체에 내재화했다. 문제의 구조적 특성을 모델 설계에 반영하는 것이 여전히 유효한 전략이다.
3. Content-based addressing과 location-based addressing의 조합을 이해하라: NTM은 memory를 내용(content)으로도, 위치(location)로도 접근할 수 있게 설계했는데, 이 두 가지 addressing 방식의 조합은 현대 Transformer의 attention 설계와 retrieval-augmented generation(RAG) 시스템을 이해하는 데 직접적인 통찰을 제공한다.

### 한계 및 이후 발전

NTM은 학습이 불안정하고 실제 복잡한 task로 확장하기 어려웠으며, 이후 DeepMind의 Differentiable Neural Computer(2016)가 memory addressing 메커니즘을 개선하고 더 복잡한 graph 기반 task에서의 일반화 성능을 높이는 방향으로 극복되었다.

## [Graph Attention Networks (GAT)](https://arxiv.org/abs/1710.10903)

> 2017년  ·  Petar Velickovic, Guillem Cucurull, Arantxa Casanova  ·  ICLR 2018  ·  인용 12,000회

### 한 줄 요약

당시 graph-structured data를 다루는 기존 방법들은 neighbor node들에 동일한 가중치를 부여하거나, graph의 전체 구조 정보(Laplacian eigenvector 등)를 미리 알아야 하는 한계가 있었다. GAT는 masked self-attentional layer를 도입하여 각 node가 이웃 node들에 대해 서로 다른 attention coefficient를 동적으로 학습할 수 있게 했다. 그 결과 Cora, Citeseer, PPI 등 주요 benchmark에서 당시 state-of-the-art를 달성하며 graph neural network 설계의 새로운 방향을 제시했다.

### 역사적 배경

2017년은 NLP 분야에서 Transformer의 self-attention이 막 등장하던 시기였으며, vision과 NLP 중심으로 발전하던 deep learning을 non-Euclidean 구조인 graph에 적용하려는 시도가 본격화되고 있었다. 당시 지배적이던 GCN 계열 방법들은 graph의 spectral 특성에 의존하거나 고정된 aggregation 방식을 사용하여 유연성이 부족하다는 비판을 받고 있었다.

### 왜 혁신적이었는가

기존의 GCN 방식이 모든 neighbor node에 균일하거나 degree 기반의 고정 가중치를 적용하던 것과 달리, GAT는 학습 가능한 masked self-attention을 통해 각 node pair의 feature로부터 동적으로 attention coefficient를 계산함으로써, graph 구조 정보 없이도 inductive하게 중요한 이웃을 선별하는 능력을 달성했다.

### 이 논문이 만들어낸 변화

GAT는 attention mechanism을 graph domain으로 확장함으로써, node classification, link prediction, graph classification 등 다양한 downstream task에서 neighbor의 중요도를 학습하는 패러다임을 확립했다. 이후 Graph Transformer, heterogeneous graph attention network 등 수많은 후속 연구의 기반이 되었으며, 분자 구조 예측, 추천 시스템, 지식 그래프 등 실제 산업 응용에도 폭넓게 채택되었다.

### 오늘날 배울 수 있는 것

1. attention mechanism은 특정 domain(NLP, vision)에 종속된 기법이 아니라, '어떤 입력에 얼마나 집중할 것인가'라는 범용적 inductive bias로 graph 등 비정형 구조에도 그대로 적용 가능하다는 설계 철학을 실무에서 내재화할 것.
2. GAT의 multi-head attention 적용 방식처럼, 단일 attention score에 의존하지 않고 여러 독립적인 attention head를 병렬로 학습시켜 representation의 안정성과 다양성을 확보하는 전략은 graph 외 다른 도메인의 모델 설계에도 유효하다.
3. spectral method처럼 전체 데이터 구조에 의존하는 transductive 방식 대신, node feature만으로 attention을 계산하는 inductive 설계를 채택함으로써 새로운 node나 graph에 대한 일반화 성능을 확보할 수 있으며, 실무에서 동적으로 변하는 graph(소셜 네트워크, 거래 그래프 등)를 다룰 때 이 원칙이 특히 중요하다.

### 한계 및 이후 발전

GAT의 attention 계산은 각 edge마다 독립적으로 수행되어 global structural information(graph 전체의 위상적 특성)을 반영하지 못하며, 이는 이후 Graph Transformer나 positional encoding을 결합한 연구들에 의해 부분적으로 극복되었다.
