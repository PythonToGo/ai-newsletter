## 지금 이 논문을 읽어야 하는 이유

활성화 함수는 사소한 구현 기본값처럼 보이지만 모델의 표현과 학습을 바꾼다. 전체 classic 제목·URL과 대조해 미수록인 GELU를 읽는다. 이전의 SELU 리뷰와는 다른 함수이며, 자동으로 같은 안정성 성질을 갖는다고 가정하지 않는다.

## [Gaussian Error Linear Units (GELUs)](https://arxiv.org/abs/1606.08415)

> Dan Hendrycks, Kevin Gimpel · 최초 연구 2016년, arXiv 프리프린트  
> 분석한 PDF v5: 2023-06-06 · 확인 2026-11-09 · 발견 경로: 활성화 함수 고전 후보 → 원문·저자 코드

### 한 줄 요약

GELU는 입력 x에 표준정규 누적분포 Φ(x)를 곱해, 부호만으로 끊지 않고 크기에 따라 연속적으로 가중한다.

### 역사적 배경

ReLU는 음수를 버리는 단순한 관문이고 dropout은 확률적으로 출력을 가린다. GELU는 입력에 의존하는 확률적 관문의 기대값에서 결정론적 함수를 동기화한다. 실제 추론 때 반드시 난수를 뽑는 함수가 아니다.

### 왜 혁신적이었는가

함수는 xΦ(x)이며 음수도 일부 통과시키고 부드럽게 변한다. 원문은 근사식도 제시한다. 따라서 GELU라는 이름이 같아도 정확식과 근사 구현의 수치가 완전히 같다고 가정하면 안 된다.

### 이 논문이 만들어낸 변화

활성화를 부호 기반 선택 대신 입력 크기의 가중으로 보는 관점을 제공한다. 원문 TIMIT 프레임 분류에서 검증 손실로 선택한 중앙 테스트 오류는 GELU 29.3%, ReLU 29.5%, ELU 29.6%다. 5층·층당 2048뉴런, 설정당 5회 실행 조건이며 음성 문장 전체 인식률이 아니다. 작은 차이를 모든 구조의 큰 향상으로 일반화하지 않는다.

### 오늘날 배울 수 있는 것

모델 담당자는 초기화·학습률 탐색·시드 수를 고정해 활성화만 비교하자. 완료 기준은 여러 시드의 품질과 실제 장치 지연을 함께 보고하고, 학습·추론의 정확식 또는 근사식 설정을 일치시키는 것이다.

[저자 코드 README](https://github.com/hendrycks/GELUs)를 확인했다. sigmoid 근사는 빠르지만 더 부정확하고 tanh 근사는 더 정확하다고 구분한다. TensorFlow·Lasagne 의존 안내는 오래된 재현 환경이므로 현재 환경에서 바로 실행 가능하다고 단정하지 않는다. 함수 유도 → 작업별 실험 조건 → 구현 순서로 읽자.

### 한계 및 이후 발전

원 논문의 소규모 작업 결과가 현대 대형 모델의 최적 함수를 결정하지는 않는다. 정규분포에 기반한 동기를 모든 층의 입력 분포가 정확히 정규라는 보장으로 읽지 않는다. 이번에는 코드를 실행하지 않았으며 독립 재현도 하지 않았다.
