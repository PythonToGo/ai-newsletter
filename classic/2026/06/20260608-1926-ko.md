## 지금 이 논문을 읽어야 하는 이유

1997년 Hochreiter와 Schmidhuber가 LSTM으로 풀려 했던 문제는 단순했다. recurrent network가 긴 시퀀스를 학습할 때 gradient가 소멸하거나 폭발하는 vanishing gradient 문제였다. 이들의 해법은 constant error carousel과 input gate, forget gate, output gate라는 구조로 '무엇을 기억하고 무엇을 버릴지'를 네트워크 스스로 학습하게 만드는 것이었다. 오늘날의 시각으로 보면, 이는 단순한 RNN 개선이 아니라 정보 흐름을 선택적으로 제어한다는 패러다임의 탄생이었다.

LSTM이 없었다면 지금 우리가 매일 쓰는 기술들의 계보가 달라졌을 것이다. encoder-decoder 기반 sequence-to-sequence 모델, 초기 기계 번역 시스템, 음성 인식 파이프라인이 모두 LSTM 위에서 자랐다. 그리고 결정적으로, gate 메커니즘이라는 개념 자체가 GRU를 거쳐 Transformer의 self-attention 설계에까지 이어졌다. attention matrix가 어떤 token에 얼마나 집중할지를 학습하는 방식은, LSTM의 gate가 어떤 정보를 통과시킬지를 학습하는 방식과 같은 철학적 뿌리를 공유한다.

지금 이 논문을 읽어야 하는 이유는 두 가지다. 첫째, architecture를 설계할 때 backpropagation 시 gradient가 어떻게 흐르는지를 사전에 분석하고 보장하는 접근법은 residual connection, layer normalization 설계에도 그대로 이어지는 실무 원칙이다. 둘째, 현상의 근본 원인을 수학적으로 먼저 규명한 뒤 architecture로 해결한 이 논문의 방법론은, 오늘날 LLM의 학습 불안정성이나 long-context 처리 문제를 다룰 때도 유효한 사고 프레임을 제공한다.

## [Long Short-Term Memory](https://www.bioinf.jku.at/publications/older/2604.pdf)

> 1997년  ·  Sepp Hochreiter, Jurgen Schmidhuber  ·  Neural Computation 1997  ·  인용 100,000회

### 한 줄 요약

기존 recurrent neural network는 recurrent backpropagation 과정에서 gradient가 소멸하거나 폭발하는 문제로 인해 장기 의존성(long-term dependency)을 학습하지 못했다. 이 논문은 Hochreiter의 vanishing gradient 분석을 바탕으로, constant error carousel과 gate(input gate, output gate, forget gate) 구조를 갖춘 long short-term memory(LSTM) unit을 제안했다. 그 결과 수백 스텝 이상의 시간적 의존성을 효과적으로 학습할 수 있음을 실험으로 입증했다.

### 역사적 배경

1997년 당시 딥러닝이라는 용어조차 보편화되지 않았던 시기에, 신경망 연구는 shallow network와 support vector machine(SVM)에 밀려 침체기를 겪고 있었다. Hochreiter와 Schmidhuber는 이 논문에서 RNN의 근본적 결함인 vanishing gradient 문제를 정면으로 다루며, 단순한 경험적 개선이 아닌 수학적 분석에 기반한 아키텍처 설계를 제시했다.

### 왜 혁신적이었는가

기존의 standard RNN이 backpropagation 과정에서 gradient를 그대로 흘려보내는 방식 대신, constant error carousel(CEC)과 multiplicative gate를 도입하여 gradient를 일정하게 유지함으로써 100스텝 이상의 long-term dependency 학습을 처음으로 실용적으로 가능하게 했다.

### 이 논문이 만들어낸 변화

LSTM은 이후 자연어 처리, 음성 인식, 기계 번역 등 거의 모든 시퀀스 모델링 태스크의 표준 아키텍처로 자리잡았으며, encoder-decoder 구조와 결합되어 sequence-to-sequence 학습의 핵심 구성 요소가 되었다. 또한 gate 메커니즘이라는 개념 자체가 이후 GRU, Transformer의 attention matrix 설계에 이르기까지 정보 흐름을 선택적으로 제어하는 패러다임의 원형이 되었다.

### 오늘날 배울 수 있는 것

1. Gate를 통한 정보 흐름 제어: input gate, forget gate, output gate라는 개념은 '무엇을 기억하고 무엇을 버릴지'를 네트워크가 스스로 학습하게 만드는 설계 철학으로, 오늘날 attention mechanism 설계 시에도 동일한 원리가 적용된다.
2. Gradient flow의 명시적 설계: 아키텍처를 설계할 때 backpropagation 시 gradient가 어떻게 흐르는지를 사전에 분석하고 보장하는 접근법은, residual connection이나 layer normalization 설계에도 이어지는 핵심 실무 원칙이다.
3. 이론적 분석 선행의 중요성: Hochreiter의 1991년 vanishing gradient 분석이 6년 후 LSTM이라는 실용적 해법으로 이어진 사례는, 현상의 근본 원인을 수학적으로 규명하는 작업이 장기적으로 가장 큰 실용적 가치를 만들어낸다는 교훈을 준다.

### 한계 및 이후 발전

LSTM은 순차적 계산 구조 때문에 병렬화가 어렵고 매우 긴 시퀀스에서는 여전히 성능 한계가 있었으며, 이는 이후 attention mechanism과 Transformer 아키텍처의 등장으로 상당 부분 극복되었다.

## [Learning Transferable Visual Models From Natural Language Supervision (CLIP)](https://arxiv.org/abs/2103.00020)

> 2021년  ·  Alec Radford, Jong Wook Kim, Chris Hallacy  ·  ICML 2021  ·  인용 18,000회

### 한 줄 요약

기존 computer vision 모델들은 고정된 category set에 대해서만 학습되어 일반화 능력이 제한적이었다. CLIP은 인터넷에서 수집한 4억 쌍의 (image, text) 데이터를 활용해 'contrastive learning' 방식으로 image encoder와 text encoder를 동시에 학습시키는 방법을 제안했다. 그 결과, 별도의 fine-tuning 없이 'zero-shot transfer'만으로도 다양한 downstream task에서 기존 supervised 모델에 필적하는 성능을 달성했다.

### 역사적 배경

2021년 당시 deep learning 기반 computer vision은 ResNet, ViT 등 강력한 architecture를 보유하고 있었지만, 여전히 'closed-world' 가정 하에 미리 정의된 class label에 종속된 학습 방식에 머물러 있었다. OpenAI는 NLP에서 검증된 large-scale pretraining의 철학을 vision에 이식함으로써, 수작업 annotation 없이도 웹 텍스트를 supervision signal로 활용할 수 있다는 것을 실증적으로 보여주었다.

### 왜 혁신적이었는가

기존의 고정된 softmax classifier와 labeled dataset에 의존하는 supervised learning 방식 대신, image-text pair에 대한 contrastive objective(InfoNCE loss)를 사용해 dual encoder를 학습시킴으로써, 학습 시 본 적 없는 class도 자연어 description만으로 zero-shot 분류할 수 있는 open-vocabulary 능력을 달성했다.

### 이 논문이 만들어낸 변화

CLIP의 등장으로 vision 모델이 자연어를 통해 open-vocabulary 방식으로 임의의 개념을 인식할 수 있게 되었고, 이는 DALL-E, Stable Diffusion, GPT-4V 등 이후 multimodal 모델들의 핵심 backbone으로 자리잡았다. 또한 'natural language supervision'이라는 개념이 vision-language alignment 연구의 표준 접근법으로 확립되어, foundation model 시대의 문을 여는 데 결정적인 역할을 했다.

### 오늘날 배울 수 있는 것

1. **Contrastive learning의 설계 원칙**: CLIP의 핵심은 positive pair(올바른 image-text 쌍)의 cosine similarity는 높이고 negative pair는 낮추는 symmetric contrastive loss다. 실무에서 multimodal 시스템을 설계할 때, 단순한 classification head보다 이러한 embedding space alignment가 훨씬 강력한 generalization을 제공한다는 점을 기억해야 한다.
2. **데이터 규모와 다양성이 곧 capability다**: CLIP은 정교한 curation보다 웹에서 수집한 400M개의 noisy한 (image, text) 쌍을 그대로 활용했다. 이는 실무에서 완벽한 소량 데이터보다 다양하고 대규모인 데이터가 zero-shot generalization에 더 유리할 수 있음을 시사한다.
3. **Prompt engineering은 inference 단계의 핵심 레버다**: CLIP은 'a photo of a {class}' 같은 prompt template 설계만으로 성능이 크게 달라진다. 이는 오늘날 LLM뿐 아니라 vision-language 모델 활용 시에도 prompt 설계가 별도의 fine-tuning 없이 성능을 끌어올리는 실용적인 도구임을 보여준다.

### 한계 및 이후 발전

CLIP은 fine-grained classification이나 counting, spatial reasoning 같은 세밀한 task에서 취약하며, 학습 데이터의 사회적 편향(bias)이 그대로 모델에 반영되는 문제가 있었고, 이후 ALIGN, Florence, SigLIP 등의 연구에서 데이터 품질 개선 및 loss function 변경을 통해 일부 극복되었다.
