## 지금 이 논문을 읽어야 하는 이유

MoCo가 등장한 2019년, computer vision 커뮤니티는 ImageNet supervised pre-training을 사실상 유일한 정답으로 여겼다. 하지만 Kaiming He 팀은 contrastive learning을 'dictionary look-up' 문제로 재해석하며 이 공식을 뒤집었다. queue 기반 dynamic dictionary와 momentum-updated encoder를 결합해, batch 크기에 종속되지 않으면서도 크고 일관된 negative sample pool을 유지하는 방법을 고안한 것이다. 핵심은 단순한 trick이 아니라 '왜 negative sample의 consistency가 학습 안정성을 결정하는가'라는 근본 질문에 대한 구조적 답변이었다.

이 논문이 열어젖힌 문은 생각보다 훨씬 넓었다. SimCLR, BYOL, DINO, MAE로 이어지는 self-supervised visual learning의 계보가 모두 MoCo의 설계 원칙을 계승하거나 반론으로 삼아 성장했다. 오늘날 medical imaging, autonomous driving, satellite imagery처럼 labeled data가 희소한 도메인에서 foundation model을 pre-training할 때 쓰는 self-supervised pipeline의 뿌리가 바로 여기에 있다. 매일 쓰는 HuggingFace의 vision 모델 상당수가 이 패러다임 위에서 학습되었다.

지금 이 논문을 읽으면 두 가지 실무 통찰을 얻는다. 첫째, momentum encoder의 EMA update 원칙은 teacher-student 구조 설계 전반에 그대로 적용된다. 모델을 직접 gradient로 업데이트하는 대신 천천히 갱신하면 representation consistency가 유지된다는 원칙은 knowledge distillation이나 semi-supervised learning 설계 시 즉시 활용 가능하다. 둘째, queue 크기와 momentum 계수의 균형 문제는 'negative sample의 양과 freshness 사이의 trade-off'라는 보편적 설계 문제로 일반화된다. 데이터 효율이 중요한 모든 대조 학습 기반 시스템에서 이 논문의 분석 틀은 여전히 유효한 나침반이다.

## [Momentum Contrast for Unsupervised Visual Representation Learning (MoCo)](https://arxiv.org/abs/1911.05722)

> 2019년  ·  Kaiming He, Haoqi Fan, Yuxin Wu  ·  CVPR 2020  ·  인용 8,000회

### 한 줄 요약

당시 supervised learning에 크게 의존하던 visual representation learning 분야에서, MoCo는 contrastive learning을 'dictionary look-up' 문제로 재해석하여 unsupervised 방식으로 강력한 visual representation을 학습하는 방법을 제안했다. 핵심 아이디어는 queue 기반의 dynamic dictionary와 momentum update로 유지되는 moving-averaged encoder를 결합하여, 크고 일관된 negative sample 집합을 효율적으로 관리하는 것이다. 그 결과 MoCo는 여러 downstream task에서 supervised pre-training에 필적하거나 이를 능가하는 transfer learning 성능을 달성했다.

### 역사적 배경

2019년 발표 당시 computer vision 커뮤니티는 ImageNet supervised pre-training을 transfer learning의 황금 표준으로 여겼으며, unsupervised 방식은 보조적 수단에 불과하다는 인식이 지배적이었다. MoCo는 이러한 supervised 중심 패러다임에 정면으로 도전하며, label 없이 학습한 representation이 downstream task에서 supervised baseline을 넘을 수 있음을 처음으로 설득력 있게 보여주었다.

### 왜 혁신적이었는가

기존의 end-to-end contrastive learning 방식이 batch 크기에 종속되어 충분한 negative sample 확보가 어려웠던 문제를, queue 기반 dynamic dictionary와 momentum-updated encoder를 결합함으로써 메모리 효율을 유지하면서도 크고 일관된 negative sample pool을 구성해 unsupervised visual representation의 품질을 supervised 수준으로 끌어올렸다.

### 이 논문이 만들어낸 변화

MoCo는 large-scale labeled dataset 없이도 경쟁력 있는 visual representation을 학습할 수 있음을 실증함으로써, self-supervised learning이 computer vision의 주류 패러다임으로 자리잡는 전환점을 마련했다. 이후 SimCLR, BYOL, MAE 등 수많은 self-supervised visual learning 연구가 MoCo의 설계 원칙(momentum encoder, large negative queue)을 계승하거나 이에 대한 반론으로 발전하며 분야 전체를 빠르게 성장시켰다.

### 오늘날 배울 수 있는 것

1. dictionary 설계 관점의 전환: contrastive learning을 단순한 positive/negative pair 비교가 아닌 'dictionary look-up'으로 추상화하면, queue·memory bank·large batch 등 다양한 구현 전략을 통일된 프레임워크로 분석하고 개선할 수 있다.
2. momentum update의 안정성 효과: encoder를 gradient로 직접 업데이트하는 대신 exponential moving average로 천천히 갱신하면, queue 내 representation의 일관성(consistency)이 유지되어 학습이 안정화된다는 원칙은 오늘날 teacher-student 구조나 EMA 기반 모델 설계에도 그대로 적용된다.
3. negative sample의 양과 질의 균형: 충분히 많은 negative sample이 contrastive learning 성능에 결정적이지만, 오래된 queue entry는 outdated encoder로 생성된 representation이므로 queue 크기와 momentum 계수를 함께 튜닝해야 한다는 실무적 교훈을 제공한다.

### 한계 및 이후 발전

MoCo는 queue 크기와 momentum 계수에 민감하며, negative sample의 품질 관리가 부족하다는 한계가 있었고, 이는 이후 SimCLR의 large batch 전략, BYOL의 negative-free 접근, MoCo v3의 ViT 통합 등으로 점진적으로 극복되었다.

## [Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer (T5)](https://arxiv.org/abs/1910.10683)

> 2019년  ·  Colin Raffel, Noam Shazeer, Adam Roberts  ·  JMLR 2020  ·  인용 12,000회

### 한 줄 요약

당시 NLP 분야는 task마다 서로 다른 fine-tuning 방식과 output format을 사용해 통일된 비교가 어려웠다. T5는 모든 NLP task를 'text-to-text' format으로 통일하여 하나의 encoder-decoder 모델로 번역, 요약, 분류, 질의응답 등을 동일한 방식으로 처리하는 unified framework를 제안했다. 체계적인 ablation study와 대규모 C4 dataset, 최대 11B parameter 모델을 통해 당시 다수의 NLP benchmark에서 state-of-the-art 성능을 달성했다.

### 역사적 배경

2019년은 BERT가 발표된 지 약 1년이 지난 시점으로, NLP 커뮤니티는 pre-training + fine-tuning 패러다임이 유효함을 확인했지만 수십 가지 변형 방법론이 난립하던 시기였다. T5는 이 혼란 속에서 'pre-training의 무엇이 중요한가'라는 질문에 대규모 controlled experiment로 답하려 했으며, 기존의 task-specific architecture 설계 관행에 정면으로 도전했다.

### 왜 혁신적이었는가

기존의 task마다 별도의 output layer와 fine-tuning 전략을 설계하는 방식 대신, 모든 NLP task의 input과 output을 plain text sequence로 통일하는 text-to-text framework를 사용함으로써, 단일 encoder-decoder 모델이 분류·생성·번역·요약을 동일한 training objective(teacher-forcing cross-entropy)로 학습할 수 있음을 증명했다.

### 이 논문이 만들어낸 변화

T5의 text-to-text 패러다임은 이후 GPT-3, FLAN, InstructGPT 등 instruction-following 모델의 직접적인 선구자가 되었으며, 모든 task를 단일 format으로 처리하는 아이디어는 오늘날 LLM의 범용 assistant 설계 철학의 근간이 되었다. 또한 scale, data, objective를 독립 변수로 분리해 실험하는 방법론적 엄밀함은 이후 scaling law 연구의 방법론적 토대를 마련했다.

### 오늘날 배울 수 있는 것

1. **Unified format의 힘**: task마다 다른 head를 설계하는 대신 text-to-text처럼 공통 interface를 정의하면, 모델 재사용성과 multi-task 학습 효율이 크게 높아진다. 실무에서 여러 NLP task를 동시에 서빙할 때 단일 모델로 통합하는 설계를 고려할 수 있다.
2. **Ablation study의 중요성**: T5는 pre-training objective, model size, dataset 크기, fine-tuning 방법을 각각 독립 변수로 분리해 실험했다. 새로운 시스템을 설계할 때 변수를 통제한 체계적 실험 없이는 어떤 요소가 성능에 기여하는지 알 수 없으며, 이는 재현 가능한 연구와 신뢰할 수 있는 의사결정의 기본이다.
3. **Scale과 data quality의 상호작용**: T5는 단순히 모델을 키우는 것보다 고품질 데이터(C4)와 적절한 objective의 조합이 중요함을 보였다. 실무에서 모델 크기를 늘리기 전에 학습 데이터의 품질과 task alignment를 먼저 점검하는 것이 비용 효율적인 접근이다.

### 한계 및 이후 발전

encoder-decoder 구조 특성상 decoder-only 모델 대비 추론 속도와 generation 효율이 낮고, 이후 GPT-3 계열의 few-shot prompting 방식이 fine-tuning 없이도 높은 성능을 보이면서 T5의 fine-tuning 중심 패러다임은 점차 in-context learning 방식으로 대체되었다.
