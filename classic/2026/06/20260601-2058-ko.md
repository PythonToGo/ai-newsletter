## 지금 이 논문을 읽어야 하는 이유

2013년 Word2Vec이 등장하기 전, NLP는 one-hot encoding이라는 sparse representation의 한계에 갇혀 있었다. Mikolov 팀은 단순한 single hidden layer network와 Negative Sampling, Subsampling이라는 실용적 트릭으로 'King - Man + Woman ≈ Queen'을 가능하게 했다. 이는 단순한 기술적 개선이 아니라, 언어의 의미를 vector 공간에서 다룰 수 있다는 패러다임의 전환이었다.

오늘날 우리가 매일 쓰는 BERT, GPT, LLaMA의 token embedding layer는 Word2Vec의 직계 후손이다. 추천 시스템의 item embedding, 그래프의 node embedding, 심지어 코드 자동완성 모델의 representation까지, Word2Vec의 아이디어는 텍스트를 넘어 ML 전반의 표준 설계 언어가 됐다. Transfer learning과 fine-tuning 기반의 현대 LLM 활용 방식도 이 논문이 제시한 'unlabeled corpus로 사전 학습 후 재사용'이라는 원형에서 출발한다.

지금 이 논문을 읽으면 두 가지 실질적 통찰을 얻는다. 첫째, Negative Sampling의 원리를 이해하면 대규모 분류 문제에서 softmax가 병목이 될 때 어떻게 근사할지 설계 감각이 생긴다. 둘째, 고빈도 저정보 단어를 확률적으로 제거하는 Subsampling 전략은 데이터 불균형과 노이즈 문제를 다룰 때 '더 많은 데이터'보다 '더 나은 데이터'가 답임을 다시 일깨워 준다.

## [Distributed Representations of Words and Phrases (Word2Vec)](https://arxiv.org/abs/1310.4546)

> 2013년  ·  Tomas Mikolov, Ilya Sutskever, Kai Chen  ·  NeurIPS 2013  ·  인용 30,000회

### 한 줄 요약

당시 자연어 처리 분야에서는 단어를 고차원 sparse vector(one-hot encoding)로 표현해 단어 간 의미적 유사성을 포착하지 못하는 문제가 있었다. Tomas Mikolov 등은 단일 hidden layer를 가진 neural network로 대규모 텍스트 corpus를 학습해 단어를 dense한 low-dimensional vector 공간에 표현하는 Word2Vec을 제안했으며, Skip-gram 모델에 Negative Sampling과 Subsampling 기법을 도입해 학습 속도와 vector 품질을 동시에 향상시켰다. 그 결과 'King - Man + Woman ≈ Queen'과 같은 analogy 추론이 가능한 distributed representation을 효율적으로 학습할 수 있음을 입증했다.

### 역사적 배경

2013년 당시 deep learning은 이미지 분야에서 AlexNet(2012)으로 주목받기 시작했지만, NLP 분야는 여전히 count 기반 통계 모델과 sparse representation이 주류였다. Word2Vec은 NLP에서도 neural network 기반 접근이 실용적으로 동작할 수 있음을 보여주며 기존의 symbolic, 통계적 패러다임에 정면으로 도전했다.

### 왜 혁신적이었는가

기존의 full softmax를 사용하는 neural language model 대신 Hierarchical Softmax와 Negative Sampling을 도입하고, 고빈도 단어에 대한 Subsampling을 적용함으로써, 수십억 단어 규모의 corpus에서도 수 시간 내에 고품질 word vector를 학습하는 것을 처음으로 실용적인 수준에서 가능하게 했다.

### 이 논문이 만들어낸 변화

Word2Vec은 이후 GloVe, FastText, 그리고 BERT와 같은 contextual embedding 모델의 직접적인 토대가 되었으며, 단어를 dense vector로 표현하는 패러다임은 현대 NLP 파이프라인의 표준으로 자리잡았다. 또한 텍스트 이외의 도메인(추천 시스템의 item embedding, 그래프의 node embedding 등)에도 동일한 아이디어가 광범위하게 적용되어 representation learning 분야 전체에 영향을 미쳤다.

### 오늘날 배울 수 있는 것

1. Negative Sampling의 교훈: 전체 vocabulary에 대한 정확한 확률 계산 대신 소수의 negative example만 sampling해 근사하는 방식은, 계산 비용이 큰 softmax가 병목이 되는 대규모 분류 문제에서 오늘날에도 유효한 실용적 트릭이다.
2. Subsampling을 통한 데이터 품질 관리: 'the', 'a'처럼 고빈도이지만 의미 정보가 적은 단어를 학습에서 확률적으로 제외하는 Subsampling 전략은, 데이터 불균형 문제를 다룰 때 단순히 데이터를 더 모으는 것보다 노이즈를 줄이는 것이 효과적임을 보여준다.
3. Transfer learning의 원형: 대규모 unlabeled corpus로 사전 학습한 word vector를 downstream task에 재사용하는 방식은, 오늘날 fine-tuning 기반 LLM 활용의 원형으로, 범용 representation을 먼저 학습하고 특정 태스크에 적응시키는 전략의 가치를 실무에서 항상 고려해야 한다.

### 한계 및 이후 발전

Word2Vec은 하나의 단어에 하나의 고정된 vector만 할당하므로 다의어(polysemy)나 문맥에 따른 의미 변화를 포착하지 못했으며, 이 한계는 이후 ELMo와 BERT 같은 contextual embedding 모델이 등장하면서 극복되었다.

## [Mask R-CNN](https://arxiv.org/abs/1703.06870)

> 2017년  ·  Kaiming He, Georgia Gkioxari, Piotr Dollar  ·  ICCV 2017  ·  인용 30,000회

### 한 줄 요약

당시 object detection과 instance segmentation은 별개의 복잡한 파이프라인으로 처리되었는데, Mask R-CNN은 Faster R-CNN에 mask prediction branch를 추가하는 간결한 방식으로 두 작업을 하나의 framework에서 동시에 수행하였다. 핵심 아이디어는 기존 RoIPool의 quantization 오류를 제거한 RoIAlign 연산을 도입하여 spatial alignment를 정확하게 유지하는 것이었다. 그 결과 COCO instance segmentation benchmark에서 당시 최고 성능을 달성하였으며, human pose estimation 등 다양한 task로도 손쉽게 확장 가능함을 보였다.

### 역사적 배경

2017년 당시 deep learning 기반 object detection은 Faster R-CNN이 주도하고 있었고, segmentation 분야는 FCN과 DeepLab 계열이 semantic segmentation에 집중하던 시기였다. Instance segmentation은 detection과 segmentation을 순차적으로 연결하는 방식이 일반적이었으며, 단일 모델로 두 task를 end-to-end로 학습하는 시도는 드물었다.

### 왜 혁신적이었는가

기존의 RoIPool 기반 feature extraction 방식 대신 RoIAlign을 도입하여 spatial misalignment 문제를 해결하고, classification·bounding box regression·mask prediction을 하나의 network에서 병렬로 학습함으로써 추가 연산 비용을 최소화하면서도 instance 단위의 정밀한 segmentation을 달성하였다.

### 이 논문이 만들어낸 변화

Mask R-CNN은 detection, segmentation, pose estimation을 단일 network에서 처리하는 multi-task learning의 표준 template이 되었으며, 이후 Panoptic FPN, PointRend, SOLOv2 등 수많은 후속 연구의 기반 architecture로 자리잡았다. 또한 RoIAlign이라는 개념은 이후 다양한 region-based 모델에서 feature extraction의 기본 연산으로 채택되어 spatial precision에 대한 인식을 업계 전반에 확산시켰다.

### 오늘날 배울 수 있는 것

1. Multi-task learning 설계 원칙: mask branch를 기존 detection head와 독립적으로 분리하여 각 task의 loss가 서로 간섭하지 않도록 설계한 방식은, 오늘날 multi-head 모델을 설계할 때 task 간 gradient 간섭을 최소화하는 실무 지침으로 여전히 유효하다.
2. Spatial precision의 중요성: quantization처럼 사소해 보이는 구현 디테일이 downstream task 성능에 결정적 영향을 미칠 수 있음을 RoIAlign이 증명하였으며, feature alignment와 interpolation 방식을 꼼꼼히 검토하는 습관이 실무에서 중요하다.
3. 단순한 확장의 힘: 복잡한 새 architecture를 설계하는 대신 검증된 backbone(Faster R-CNN)에 최소한의 branch를 추가하는 접근법은, 새로운 task를 다룰 때 기존 강력한 baseline을 최대한 활용하고 변경을 최소화하는 실용적 전략의 모범 사례이다.

### 한계 및 이후 발전

Mask R-CNN은 two-stage detector 구조를 따르기 때문에 real-time inference에 한계가 있었으며, 이는 이후 YOLACT, SOLOv2 같은 one-stage instance segmentation 방법들이 등장하는 계기가 되었다.
