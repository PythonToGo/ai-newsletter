# 📄 신뢰성 위기: AI의 일관성과 정렬 문제

> **리포트 ID**: `20260625-190442`  
> **생성**: 2026-06-25 19:04 UTC  
> **논문 수**: 4편  

## 이번 주 연구 동향

이번 주 논문들은 공통적으로 AI 시스템의 '신뢰성 결함'을 다양한 각도에서 조명한다. MLLM의 order sensitivity 감사, voice AI의 perception-action disconnect, VLA 모델의 RL fine-tuning 불안정성까지—각기 다른 도메인이지만 모두 모델이 겉으로는 올바르게 작동하는 것처럼 보이면서 실제 의사결정에서는 예측 불가능한 실패를 일으킨다는 구조적 문제를 지적한다. GUI grounding 연구인 WinDOM도 소형 모델의 한계를 self-distillation으로 극복하려는 시도로, 신뢰할 수 있는 소형 모델 구축이라는 맥락에서 같은 흐름에 놓인다.

방법론적으로는 self-distillation과 behavioral evaluation framework가 반복 등장한다는 점이 주목할 만하다. FORCE는 Q-function 기반 action filtering과 self-distillation을 결합해 RL 학습의 불안정성을 완화하고, WinDOM은 EMA 기반 self-distillation으로 외부 teacher 없이 cold-start 문제를 해결한다. 한편 Facet-Probe와 voice AI 논문은 Bayesian item-response model, behavioral scenario 설계 등 엄밀한 audit 프레임워크를 통해 모델의 실제 행동을 측정하는 방식을 택했다. 즉, '더 강한 모델 훈련'보다 '현재 모델의 실패 모드를 정밀하게 진단'하는 방향으로 연구 무게중심이 이동하고 있다.

이 논문들이 남긴 과제는 명확하다. Order sensitivity나 vocal delivery 무시 같은 문제는 단순한 버그가 아니라 현재 multimodal 아키텍처의 구조적 한계에서 비롯된다. 따라서 다음 스텝은 이러한 실패 모드를 훈련 목표에 명시적으로 반영하는 것—예컨대 consistency-aware RLHF나 acoustic feature를 decision layer에 직접 연결하는 아키텍처 설계—이 될 것이다.

실무 시사점은 하나로 압축된다. 프로덕션 AI 파이프라인에 일관성 검증 레이어를 반드시 추가해야 한다. 입력 순서를 바꾸거나 modality 간 상충 시나리오를 만들어 동일 쿼리를 복수 실행하고, 답변이 뒤집히는 비율을 모니터링하는 consistency check는 이제 선택이 아닌 필수다.

## 논문 분석

### 1. Same Evidence, Different Answer: Auditing Order Sensitivity in Multimodal Large Language Models

- **출처**: arxiv
- **점수**: 7.0
- **URL**: http://arxiv.org/abs/2606.26079v1

**요약**

이 논문은 multimodal large language model(MLLM)이 동일한 증거를 다른 순서로 제시받았을 때 답변이 바뀌는 'order sensitivity' 문제를 체계적으로 감사(audit)한다. 저자들은 Facet-Probe라는 5가지 facet(option, evidence-chunk, document-rank, image-set, mixed-modality ordering)으로 구성된 평가 프레임워크를 도입하여 18개의 frontier 및 open-weight MLLM을 분석했다. Bayesian item-response model을 활용해 ordering noise와 per-facet bias를 분리하고, 실험 결과 어떤 모델도 order-invariant하지 않으며 flip rate가 24~50%에 달함을 발견했다. 가장 성능이 좋은 모델조차 13.4%의 trial에서 답변이 뒤집히며, training-free prompt 변경만으로는 이 문제를 완전히 해결하지 못했다.

**방법론**

핵심 아이디어는 동일한 증거를 order-irrelevant하게 섞었을 때 모델 답변이 얼마나 뒤집히는지를 5가지 facet으로 세분화하여 측정하는 Facet-Probe audit 프레임워크다. Bayesian item-response model을 사용해 각 문항의 난이도와 모델 능력을 통제하면서 ordering에 의한 noise와 systematic bias를 분리하고, temperature 0에서의 same-ordering control 실험으로 decoder stochasticity에 의한 baseline flip rate를 추정하여 ordering이 실제로 유발하는 초과 flip을 정량화했다. 18개 모델에 대해 option ordering, evidence-chunk ordering, document-rank ordering, image-set ordering, mixed-modality ordering의 5개 facet을 독립적으로 평가하여 facet별 취약성 프로파일을 도출했다.

**주요 기여**

1. 5가지 facet(option, evidence-chunk, document-rank, image-set, mixed-modality)을 포괄하는 최초의 체계적 MLLM order sensitivity audit 프레임워크인 Facet-Probe를 제안했다.
2. Bayesian item-response model과 same-ordering control을 결합하여 decoder stochasticity와 ordering sensitivity를 분리하는 엄밀한 측정 방법론을 제시했다.
3. 18개 frontier 및 open-weight MLLM 모두가 order-invariant하지 않음을 실증하고(flip rate 24~50%), 모델 capability가 높아도 flip이 완전히 제거되지 않으며(최고 모델 13.4%) training-free prompt 변경의 한계를 명확히 규명했다.

**실험 결과**

18개 MLLM 전체에서 per-facet panel-mean flip rate는 24~50% 범위로 측정되었다. 가장 성능이 우수한 모델(Gemini 계열)도 13.4%의 trial에서 답변이 뒤집혔다. Temperature 0에서의 same-ordering control 실험을 통해 decoder noise floor 대비 ordering에 의한 substantial한 초과 flip이 존재함을 확인했으며, training-free prompt mitigation은 flip rate를 일부 감소시키나 완전히 해소하지는 못했다.

**맥락**

현재 MLLM benchmark는 각 문항에 대해 하나의 고정된 canonical ordering으로만 평가하기 때문에, 순서 변경에 따른 모델의 신뢰성 문제를 전혀 측정하지 못한다. 신흥 AI 평가 가이드라인(예: EU AI Act, NIST AI RMF)은 모델이 order-irrelevant 입력 변형에 대해 일관된 답변을 내놓아야 한다는 baseline reliability를 요구하고 있어, 이 문제는 규제 준수 측면에서도 시급하다. 특히 multimodal 환경에서는 텍스트뿐 아니라 이미지 순서, 문서 순위 등 다양한 modality의 ordering이 복합적으로 영향을 미치기 때문에 기존 단일 modality 연구보다 훨씬 복잡한 문제를 다룬다.

**실무 시사점**

ML 엔지니어는 MLLM을 프로덕션에 배포할 때 동일한 입력이라도 evidence나 option의 순서를 다르게 하여 여러 번 쿼리하는 consistency check를 파이프라인에 반드시 포함시켜야 한다. Facet-Probe의 5가지 facet 분류를 참고하여 자신의 use case에서 어떤 ordering 유형이 가장 취약한지 사전에 진단하고, 특히 RAG(Retrieval-Augmented Generation) 시스템에서 document-rank ordering이 답변에 미치는 영향을 별도로 평가해야 한다. Training-free prompt engineering만으로는 flip rate를 충분히 낮추지 못하므로, 중요한 의사결정 시스템에서는 앙상블 또는 다중 순서 샘플링 전략을 고려해야 한다.

**한계**

Gemini 모델에 대한 mitigation 테스트는 제한적인 범위에서만 수행되었으며, training-free 방법의 효과가 모델 아키텍처나 학습 방식에 따라 달라질 수 있어 일반화에 주의가 필요하다. 또한 Bayesian item-response model의 가정이 실제 모델 동작의 복잡성을 완전히 포착하지 못할 수 있으며, 평가에 사용된 데이터셋의 도메인 편향 가능성도 배제할 수 없다.

**관련 링크**

- http://arxiv.org/abs/2606.26079v1

### 2. WinDOM: Self-Family Distillation for Small-Model GUI Grounding

- **출처**: arxiv
- **점수**: 7.0
- **URL**: http://arxiv.org/abs/2606.25964v1

**요약**

WinDOM은 소형(~2B) 모델이 GUI 화면에서 특정 요소의 위치를 찾는 'GUI grounding' 작업을 잘 수행할 수 있도록 설계된 연구다. 핵심 기여는 두 가지로, Windows 11 웹 재구현 환경을 headless Playwright로 자동 구동해 DOM에서 직접 bounding box를 추출한 54,425건의 grounding corpus(WinDOM)와, EMA 기반 self-distillation 또는 동일 계열 대형 모델을 teacher로 사용하는 Self-Family Distillation(SFD) 기법이다. SFD의 cold-start saturation 깊이를 GRPO의 명시적 hyperparameter로 처리함으로써, 외부 annotation이나 대규모 모델 없이도 Qwen3.5-2B 수준의 소형 모델 성능을 끌어올리는 것을 목표로 한다.

**방법론**

핵심 아이디어는 외부 annotation 없이 DOM에서 직접 bounding box를 읽어 grounding corpus를 구축하고, 동일 모델 계열 내에서 teacher-student distillation을 수행하는 Self-Family Distillation(SFD)이다. SFD는 student 모델의 EMA를 teacher로 사용하는 완전 self-contained 경로와, 동일 계열의 더 큰 frozen 모델을 teacher로 사용하는 경로 두 가지를 rejection-sampling 기반 cold-start로 통합한다. 이후 cold-start의 saturation 깊이를 GRPO의 명시적 hyperparameter로 노출해 supervised fine-tuning과 reinforcement learning 단계를 유기적으로 연결한다.

**주요 기여**

1. OCR·인간 annotation 없이 headless Playwright + DOM 파싱으로 자동 구축한 54,425건 규모의 GUI grounding corpus WinDOM 공개
2. EMA self-distillation과 동일 계열 대형 모델 distillation을 단일 rejection-sampling 프레임워크로 통합한 Self-Family Distillation(SFD) 기법 제안
3. SFD cold-start saturation 깊이를 GRPO hyperparameter로 명시화해 소형 모델의 SFT→RL 전환 전략을 체계화

**실험 결과**

Qwen3.5-2B student 모델에 under-saturated cold-start SFD를 적용한 결과가 보고되나, arxiv 제출본(v1) 기준으로 구체적인 수치 비교표는 본문에서 완전히 공개되지 않아 정확한 SOTA 대비 수치 인용이 어렵다.

**맥락**

온디바이스 배포와 저비용 반복 개발에 적합한 소형 GUI agent에 대한 수요가 높아지고 있지만, ~2B 규모 모델은 고품질 bounding box 학습 데이터 확보와 supervised fine-tuning·reinforcement learning의 효과적인 결합이라는 두 가지 미해결 과제를 안고 있다. 기존 접근법은 OCR이나 인간 annotation에 의존해 비용이 높거나, 대형 독점 모델을 teacher로 요구하는 경우가 많아 소형 모델 중심 연구에는 적합하지 않았다.

**실무 시사점**

ML 엔지니어는 WinDOM 데이터 수집 파이프라인을 참고해 headless browser + DOM 파싱 방식으로 annotation 비용 없이 GUI grounding 데이터를 자동 구축할 수 있다. SFD의 EMA self-distillation 경로는 외부 teacher 모델 없이도 cold-start를 수행할 수 있어, 독점 API 의존도를 낮추고 소형 모델 파인튜닝 파이프라인에 바로 통합 가능하다. 또한 SFD saturation 깊이를 GRPO hyperparameter로 명시적으로 제어하는 방식은 RL 학습 안정성 튜닝 전략으로 실무에 적용할 수 있다.

**한계**

논문이 다루는 환경이 Windows 11 웹 재구현에 한정되어 있어 네이티브 앱이나 다른 OS 환경으로의 일반화 가능성은 아직 검증되지 않았다. 또한 under-saturated cold-start 조건에서의 성능 결과가 arxiv 제출 버전 기준으로 완전히 공개되지 않아 재현성 확인이 필요하다.

**관련 링크**

- http://arxiv.org/abs/2606.25964v1

### 3. Real-Time Voice AI Hears but Does Not Listen

- **출처**: arxiv
- **점수**: 6.9
- **URL**: http://arxiv.org/abs/2606.26083v1

**요약**

이 논문은 최신 real-time voice AI 시스템들이 말의 내용(words)은 처리하지만 목소리의 감정적 전달 방식(vocal delivery)은 실질적인 의사결정에 반영하지 못한다는 문제를 다룬다. OpenAI GPT Realtime 2, Google Gemini 3.1 Flash Live, Alibaba Qwen3.5 Omni Plus/Flash 등 4개 주요 production 시스템을 대상으로, 울면서 '괜찮다'고 말하는 발신자 통화 종료, 두려운 목소리로 승인된 송금 처리, 명백히 sarcastic한 동의로 등록 처리 등 3가지 시나리오에서 평가했다. 놀랍게도 이 시스템들은 감정을 '인식'은 하지만 '결정'에는 반영하지 않는 'perception-action disconnect' 현상을 보였다.

**방법론**

핵심 아이디어는 'words와 vocal delivery가 상충하는 시나리오'를 설계하여 voice AI의 실제 의사결정이 어느 modality를 따르는지 측정하는 behavioral evaluation framework이다. 구체적으로 3가지 고위험 시나리오(위기 통화, 금융 승인, 서비스 등록)에서 감정적으로 모순된 음성 입력을 4개 production system에 제공하고, 시스템의 action 결과와 직접 질문 시의 perception 응답을 비교 분석했다. Accent·age 추정 태스크도 추가하여 acoustic property vs. lexical content bias를 교차 검증했다.

**주요 기여**

1. Real-time voice AI에서 'perception-action disconnect' 현상을 최초로 체계적으로 정의하고 실증적으로 입증함 — 시스템이 감정을 인식하면서도 결정에 반영하지 않는 구조적 문제를 명명.
2. OpenAI, Google, Alibaba의 4개 최신 production voice system을 동일한 고위험 시나리오 benchmark로 비교 평가하는 공개 평가 프레임워크 제시.
3. Accent·age 추정에서도 acoustic signal보다 lexical content bias가 우세함을 보여, 문제가 특정 감정 태스크에 국한되지 않는 범용적 현상임을 시사.

**실험 결과**

4개 시스템(OpenAI GPT Realtime 2, Google Gemini 3.1 Flash Live, Alibaba Qwen3.5 Omni Plus, Qwen3.5 Omni Flash) 모두 3개 고위험 시나리오에서 vocal delivery 대신 words를 따르는 결정을 내렸다. 직접 질문 시 4개 중 3개 시스템은 distress·fear·sarcasm을 정확히 식별했으나, 동일 맥락의 action 단계에서는 이를 무시했다. 구체적인 정확도 수치나 성공률 퍼센트는 초록에 명시되지 않았다.

**맥락**

Voice AI가 고객 서비스, 금융 거래, 위기 상담 등 고위험 실무 환경에 빠르게 배포되면서, 단순 speech-to-text를 넘어 화자의 감정·의도·맥락을 정확히 파악하는 능력이 필수적으로 요구되고 있다. 기존 연구는 주로 speech recognition accuracy나 language understanding에 집중했으나, 음성의 acoustic 특성(감정, 억양, 나이 등)이 실제 의사결정 루프에 통합되는지에 대한 체계적 평가는 부족했다.

**실무 시사점**

Production voice AI를 금융·의료·고객지원 등 고위험 도메인에 배포할 때, 시스템이 감정이나 sarcasm을 '말로 설명할 수 있다'고 해서 그것이 실제 action에 반영된다고 가정해서는 안 된다. ML 엔지니어는 voice AI pipeline 설계 시 acoustic feature를 decision-making layer에 명시적으로 연결하는 별도 모듈(예: emotion-aware routing, acoustic signal gating)을 추가하거나, 이 논문의 평가 시나리오를 자체 시스템의 regression test suite에 포함시켜야 한다.

**한계**

논문이 평가한 시나리오가 3가지로 제한적이며, 각 시스템의 내부 아키텍처나 학습 데이터에 접근할 수 없어 perception-action disconnect의 근본 원인(예: instruction tuning bias, RLHF 과정의 text 편향)을 정확히 규명하지 못했다. 또한 accent·age 추정 실험에서의 bias 분석은 초록에서 언급되나 전체 논문의 범위와 깊이가 arxiv 초기 버전 기준으로 제한적일 수 있다.

**관련 링크**

- http://arxiv.org/abs/2606.26083v1

### 4. FORCE: Efficient VLA Reinforcement Fine-Tuning via Value-Calibrated Warm-up and Self-Distillation

- **출처**: arxiv
- **점수**: 6.9
- **URL**: http://arxiv.org/abs/2606.26006v1

**요약**

Vision-Language-Action (VLA) 모델을 Reinforcement Learning (RL)으로 fine-tuning할 때 발생하는 sample inefficiency 문제를 해결하기 위한 FORCE 프레임워크를 제안한다. FORCE는 3단계 구조로, 불안정한 Q-function으로 인한 catastrophic unlearning과 저품질 exploration data로 인한 비효율적인 policy update라는 두 가지 핵심 문제를 동시에 해결한다. Value-Calibrated Warm-Up 단계에서 on-policy rollout을 활용해 Q-function의 distributional shift를 완화하고, 이후 calibrated Q-function을 filter로 사용해 고품질 action만 policy update에 활용한다. 시뮬레이션 및 실제 로봇 태스크에서 기존 방법 대비 우수한 성능과 sample efficiency를 달성했다.

**방법론**

핵심 아이디어는 Q-function을 먼저 안정적으로 calibrate한 뒤, 이를 고품질 action의 filter로 활용해 policy update의 효율을 높이는 것이다. 1단계(Value-Calibrated Warm-Up)에서 on-policy rollout 데이터로 Q-function의 distributional shift를 보정하고, 2단계(online RL)에서 calibrated Q-function이 policy 자체의 action proposal과 expert demonstration 모두를 필터링해 high-value action만 학습에 사용한다. 3단계에서는 self-distillation을 통해 policy가 자신의 개선된 행동을 스스로 학습하며 안정적인 수렴을 유도한다.

**주요 기여**

1. Q-function의 초기 불안정성을 on-policy rollout 기반 Value-Calibrated Warm-Up으로 완화하는 새로운 3단계 RL fine-tuning 프레임워크 FORCE 제안
2. Calibrated Q-function을 action filter로 활용해 policy 자체 proposal과 expert data 모두에서 high-value action만 선별하는 효율적인 policy update 메커니즘 도입
3. Self-distillation을 통해 costly human intervention 없이 sample-efficient한 VLA RL fine-tuning을 시뮬레이션 및 실제 로봇 환경에서 검증

**실험 결과**

시뮬레이션 및 실제 로봇 조작 태스크에서 기존 RL fine-tuning 방법 대비 향상된 성공률과 sample efficiency를 달성했다고 보고되었으나, arXiv 공개본에서 구체적인 수치가 잘려 있어 정확한 SOTA 비교 수치는 확인 불가.

**맥락**

VLA 모델은 sub-optimal demonstration data로 인한 imitation ceiling에 갇혀 있으며, RL fine-tuning이 이를 돌파할 수 있는 유력한 방법으로 주목받고 있다. 그러나 기존 RL fine-tuning은 초기 Q-function 불안정성과 저품질 exploration으로 인해 수렴이 느리고 비용이 많이 드는 human intervention에 의존하는 경향이 있어 실용적 적용이 어렵다. 로봇 조작 등 실세계 응용에서 데이터 효율적인 RL fine-tuning 방법론의 필요성이 높아지고 있는 시점에 이 연구가 등장했다.

**실무 시사점**

ML 엔지니어는 FORCE의 Value-Calibrated Warm-Up 기법을 통해 VLA 모델의 RL fine-tuning 초기 불안정성을 줄이고, Q-function 기반 action filtering을 replay buffer 설계에 바로 적용해 sample efficiency를 높일 수 있다. 또한 self-distillation을 활용한 policy update 방식은 비용이 큰 human intervention 없이도 고품질 학습 데이터를 자동으로 선별하는 실용적인 파이프라인으로 활용 가능하다.

**한계**

논문이 공개한 실험 결과의 일부가 arXiv 버전에서 잘려 있어 전체 benchmark 수치를 확인하기 어렵다. 또한 3단계 프레임워크의 각 단계별 하이퍼파라미터 튜닝 부담과 실제 로봇 환경에서의 일반화 범위에 대한 추가 검증이 필요하다.
