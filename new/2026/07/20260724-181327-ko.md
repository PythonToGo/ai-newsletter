## 이번 주 연구 동향

이번 주 논문들을 관통하는 핵심 키워드는 '고정된 가정의 해체'다. 기존 generative model이 고정 차원을 전제했다면 EFlows는 expanding interpolant로 이를 허물고, 기존 RL 학습 스택이 단일 프로세스 환경을 가정했다면 OpenForgeRL은 harness와 trainer를 완전히 decouple하며 그 경계를 지운다. MIRROR는 VLM이 단일 modality view에서 학습한다는 관행에 의문을 제기하고, DONDO는 영어·고자원 언어 중심의 ASR 생태계 바깥을 정면으로 겨냥한다. 연구자들이 공통적으로 묻고 있는 것은 결국 하나다: 우리가 당연하게 받아들인 설계 제약이 정말 필요한가?

방법론적으로는 '분리(decoupling)'와 'cross-signal 활용'이 반복 등장한다. OpenForgeRL은 proxy를 통해 inference harness와 RL trainer를 분리하고, MIRROR는 text view와 image view의 성공·실패 신호를 cross-modal reinforcement learning으로 교차 활용한다. EFlows 역시 expand operator와 transport map을 분리 설계함으로써 차원 증가와 분포 이동을 독립적으로 다룬다. DONDO의 learning-rate annealing 전략도 multilingual 적응과 monolingual 복원을 단계적으로 분리한 설계다. 복잡한 문제를 하나의 end-to-end 블랙박스로 밀어 넣기보다, 구조적으로 분리하고 각 신호를 재활용하는 방향이 이번 주 논문들의 공통된 설계 철학이다.

남겨진 과제도 선명하다. EFlows는 텍스트·분자 구조에서 가능성을 보였지만 대규모 언어 생성으로의 확장성은 아직 미지수다. MIRROR의 cross-modal reinforcement learning은 geometry 도메인에 집중되어 있어 일반 VLM task로의 전이 가능성이 검증되지 않았다. OpenForgeRL은 Kubernetes 기반 orchestration이 소규모 팀에게 운영 부담이 될 수 있으며, DONDO는 아프리카 6개국 27개 언어를 다루지만 데이터 희소성 문제는 여전히 근본적 병목으로 남는다. 공통적으로, 이 논문들이 제안하는 프레임워크들은 확장성과 일반화 실험이 후속 연구의 핵심 과제가 될 것이다.

ML 엔지니어에게 가장 즉각적인 실무 시사점은 OpenForgeRL의 proxy 기반 decoupling 패턴이다. 자체 inference harness나 tool-use 파이프라인을 이미 운영 중이라면, RL 학습을 위해 harness를 재작성하는 대신 lightweight proxy 레이어를 삽입하는 방식으로 기존 veRL 등의 학습 스택을 그대로 재사용할 수 있다. 시스템 복잡도를 낮추면서 agent 학습 루프를 빠르게 구축하려는 팀에게 즉시 적용 가능한 아키텍처 레퍼런스다.

### 1. Expanding Flow Maps

- **출처**: arxiv
- **점수**: 7.0
- **URL**: http://arxiv.org/abs/2607.21585v1

**요약**

기존 flow-based generative model은 고정된 차원이나 고정된 sequence 길이에서만 동작하는 한계가 있었다. 이 논문은 Expanding Generative Flows(EFlows)를 제안하여 점진적으로 차원이 증가하는 distribution 간의 flow를 정의하고, 이를 효율적인 few-step 생성 모델로 distill하는 Expanding Flow Maps(EFMs)를 소개한다. EFM은 expand operator와 transport map 두 가지 learnable operation으로 구성되어 상태 공간을 확장하면서 동시에 denoising을 수행한다. 이를 통해 연속 및 이산 상태 공간 모두에서 가변 길이 생성이 가능한 새로운 generative modeling 패러다임을 제시한다.

**방법론**

핵심 아이디어는 생성 과정을 '차원이 고정된 transport'가 아닌 '차원이 점진적으로 증가하는 expanding interpolant'로 재정의하는 것이다. EFM은 임의의 두 timestep 사이의 map을 expand operator(현재 상태에 conditional noise로 새로운 좌표/token을 추가)와 transport map(확장된 상태를 interpolant를 따라 전진)으로 분리하여 학습한다. 두 operator를 합성(compose)하면 단일 map이 expansion과 denoising을 동시에 수행하며, 이를 통해 few-step 생성이 가능한 distillation이 이루어진다.

**주요 기여**

1. 차원이 증가하는 distribution 간의 flow를 정의하는 새로운 수학적 프레임워크인 Expanding Generative Flows(EFlows)를 제안하여 고정 차원 제약을 근본적으로 해소.
2. EFlows를 efficient few-step 생성으로 distill하는 Expanding Flow Maps(EFMs)를 도입하고, expand operator와 transport map의 분리 구조로 학습 가능성과 효율성을 동시에 확보.
3. 연속(이미지, 분자 등)과 이산(텍스트 token 등) 상태 공간 모두에 적용 가능한 통합 프레임워크를 제시하여 가변 길이 생성 문제에 대한 새로운 접근법을 확립.

**맥락**

기존 diffusion model 및 flow matching 기반 생성 모델은 입력과 출력의 차원이 동일해야 한다는 근본적인 제약이 있어, 가변 길이 sequence나 점진적으로 구조가 성장하는 데이터(예: 단백질, 텍스트, 트리 구조)를 자연스럽게 모델링하기 어려웠다. 특히 언어 모델처럼 token 수가 동적으로 결정되는 경우, 기존 continuous normalizing flow나 consistency model 계열의 방법론은 직접 적용이 불가능했다. 이 연구는 expanding interpolant라는 새로운 수학적 프레임워크로 이 근본적 제약을 해소하려 한다.

**실무 시사점**

가변 길이 sequence 생성(예: 자동 회귀 없이 텍스트나 분자 구조 생성)을 few-step으로 수행하고 싶은 ML 엔지니어에게 직접적인 대안 아키텍처를 제공한다. 기존 flow matching 또는 consistency model 파이프라인을 expanding 구조로 확장할 때 expand operator와 transport map을 별도 모듈로 설계하는 방식을 실무에 참고할 수 있다. 특히 단백질 서열, 코드 생성, 가변 해상도 이미지 등 출력 크기가 동적인 태스크에서 새로운 모델링 선택지로 활용 가능하다.

**한계**

논문의 내용이 공개된 arxiv 버전 기준으로 실험 결과 및 SOTA 비교 수치가 명시적으로 제공되지 않아 실제 성능 검증이 제한적이며, expand operator의 설계 선택(conditional noise 구조 등)이 도메인마다 달라질 수 있어 범용 적용 시 추가적인 엔지니어링이 필요할 수 있다.

**관련 링크**

- http://arxiv.org/abs/2607.21585v1

### 2. OpenForgeRL: Train Harness-native Agents in Any Environment

- **출처**: arxiv
- **점수**: 6.9
- **URL**: http://arxiv.org/abs/2607.21557v1

**요약**

현대 AI agent들은 Claude Code, Codex 같은 복잡한 inference harness를 통해 multi-turn reasoning과 tool use를 수행하지만, 기존 오픈소스 SFT/RL 학습 스택은 이런 stateful, multi-process harness 환경을 지원하지 못한다. OpenForgeRL은 lightweight proxy를 통해 harness의 model call을 가로채 학습 데이터로 기록하고, Kubernetes orchestrator로 각 rollout을 독립 컨테이너에서 실행함으로써 어떤 harness, 어떤 환경에서도 end-to-end 학습을 가능하게 하는 오픈소스 framework다. 이를 통해 연구자들은 실제 배포 환경과 동일한 harness에서 agent를 직접 학습·연구·개선할 수 있으며, veRL 같은 표준 RL codebase와 호환된다.

**방법론**

핵심 아이디어는 학습 스택과 inference harness를 완전히 분리(decouple)하되, lightweight proxy를 중간에 두어 harness가 model에 보내는 모든 call을 투명하게 가로채 표준 RL 학습 데이터 형식으로 기록하는 것이다. 각 rollout은 Kubernetes가 생성한 독립 원격 컨테이너 안에서 실행되므로, harness와 환경의 종류에 관계없이 동일한 학습 파이프라인을 재사용할 수 있다. 이렇게 수집된 trajectory는 veRL 등 표준 RL codebase에 그대로 전달되어 policy update에 활용된다.

**주요 기여**

1. Harness-native end-to-end training: Claude Code, Codex 등 실제 inference harness를 수정하지 않고 그대로 사용하면서 RL 학습을 가능하게 하는 최초의 오픈소스 framework 제시.
2. Lightweight proxy + Kubernetes orchestration: model call 가로채기와 컨테이너 격리를 결합해 어떤 harness·환경 조합에도 확장 가능한 범용 학습 인프라 설계.
3. 표준 RL codebase 호환성: veRL 등 기존 SFT/RL 스택과 인터페이스를 맞춰, 연구자가 새로운 학습 인프라를 처음부터 구축할 필요 없이 harness 기반 agent 연구를 즉시 시작할 수 있는 생태계 제공.

**맥락**

Claude Code, OpenClaw 등 inference harness 기반 agent가 실용적으로 강력해지면서, 이를 실제 배포 환경 그대로 학습시키려는 수요가 급증하고 있다. 그러나 기존 오픈소스 RL/SFT 학습 인프라는 단일 프로세스 기반 inference를 가정하기 때문에, 복잡한 stateful multi-process harness와 호환되지 않아 학습과 추론 환경 사이의 gap이 발생한다. 이 gap은 학습된 agent가 실제 harness 환경에서 성능이 저하되는 근본 원인이 되어왔다.

**실무 시사점**

ML 엔지니어는 OpenForgeRL을 활용해 veRL 등 기존 RL codebase를 수정 없이 그대로 사용하면서, Claude Code나 자체 inference harness 위에서 agent를 end-to-end로 학습시킬 수 있다. Kubernetes 기반 orchestration 덕분에 각 rollout이 격리된 컨테이너에서 실행되므로, 환경 오염 없이 대규모 병렬 학습이 가능하고 다양한 실제 환경(코드 실행, 웹 브라우징 등)으로 손쉽게 확장할 수 있다.

**한계**

논문이 공개된 시점 기준으로 benchmark 수치나 기존 방법 대비 정량적 성능 비교가 충분히 제시되지 않아, 실제 학습 효율 및 성능 향상 폭을 독립적으로 검증하기 어렵다. 또한 Kubernetes 인프라 의존성으로 인해 소규모 연구 환경에서의 셋업 복잡도가 높을 수 있다.

**관련 링크**

- http://arxiv.org/abs/2607.21557v1
- https://github.com/volcengine/verl

### 3. DONDO: Open w2v-BERT Speech-Recognition Base Models for African Languages

- **출처**: arxiv
- **점수**: 6.8
- **URL**: http://arxiv.org/abs/2607.21540v1

**요약**

DONDO는 아프리카 언어를 위한 오픈소스 automatic speech recognition (ASR) base model 패밀리로, w2v-BERT 2.0 self-supervised speech encoder를 기반으로 구축되었다. 가나, 시에라리온, 나이지리아, 세네갈, 케냐, 짐바브웨 등 6개국의 27개 언어 변종을 지원하며, 21개의 monolingual 모델과 5개의 multilingual 모델로 구성된다. 종교 텍스트에서 추출한 read speech를 주요 fine-tuning 데이터로 활용하여 라이선스가 명확하고 철자가 일관된 학습 데이터를 확보했으며, 2~3단계 learning-rate-annealed fine-tuning 절차를 통해 monolingual baseline을 여러 경우에서 능가하는 성능을 달성했다.

**방법론**

핵심 아이디어는 w2v-BERT 2.0 self-supervised encoder를 기반으로, 먼저 multilingual 모델을 높은 learning rate로 fine-tuning한 뒤 learning rate를 점진적으로 annealing하는 2~3단계 절차를 통해 monolingual 성능을 회복 및 초과하는 것이다. 추가로 one-hot language identity 벡터를 acoustic feature sequence 앞에 prefix frame으로 prepend하는 경량 language-conditioning 메커니즘을 도입하여 multilingual 모델이 언어를 명시적으로 인식하도록 유도한다. 학습 데이터는 라이선스가 명확하고 철자 일관성이 높은 종교 텍스트 기반 read speech를 주로 활용하여 저자원 환경에서의 데이터 확보 문제를 해결했다.

**주요 기여**

1. 아프리카 6개국 27개 언어 변종을 지원하는 21개 monolingual + 5개 multilingual ASR base model을 permissive license로 공개
2. multilingual 모델을 먼저 적응시킨 후 learning rate annealing으로 monolingual baseline을 회복·초과하는 2~3단계 fine-tuning 레시피 제안
3. one-hot language identity를 prefix frame으로 주입하는 경량 language-conditioning 메커니즘 도입으로 추가 파라미터 없이 multilingual 모델 성능 향상

**실험 결과**

여러 아프리카 언어에서 2~3단계 learning-rate-annealed fine-tuning을 적용한 multilingual 모델이 strong monolingual baseline을 여러 경우에서 능가하는 결과를 보고하였으나, 논문 본문 발췌 범위 내에서 구체적인 수치(WER 등)는 제공되지 않았음.

**맥락**

아프리카 언어들은 전 세계 언어의 상당 부분을 차지함에도 불구하고, 전사된 오디오 데이터 부족과 라이선스 문제로 인해 ASR 연구에서 심각하게 소외되어 왔다. 기존의 multilingual ASR 모델들은 주로 고자원 언어에 집중되어 있어, 저자원 아프리카 언어에 대한 실용적인 base model이 거의 존재하지 않는 상황이다. DONDO는 이러한 격차를 해소하기 위해 permissive license 하에 공개된 모델을 제공하며, 데이터 희소성 문제를 종교 텍스트 기반 read speech로 창의적으로 해결하고자 한다.

**실무 시사점**

ML 엔지니어는 DONDO의 2~3단계 learning-rate-annealed fine-tuning 전략을 저자원 언어 ASR 프로젝트에 직접 적용할 수 있으며, multilingual 모델을 먼저 높은 learning rate로 적응시킨 후 annealing하는 방식은 다른 저자원 도메인에도 유효한 레시피가 될 수 있다. 또한 one-hot language identity를 prefix frame으로 주입하는 경량 language-conditioning 메커니즘은 추가 파라미터 없이 multilingual 모델의 언어 구분 능력을 높이는 실용적인 기법으로 활용 가능하다.

**한계**

학습 데이터가 주로 종교 텍스트 기반 read speech에 한정되어 있어, 자연스러운 대화체나 다양한 도메인에서의 일반화 성능이 제한될 수 있다. 또한 27개 언어 변종이 지원되지만, 아프리카 대륙의 수천 개 언어 중 극히 일부만 커버하고 있어 대표성 면에서 한계가 존재한다.

**관련 링크**

- http://arxiv.org/abs/2607.21540v1

### 4. MIRROR: Learning from the Other View for Multi-Modal Reasoning

- **출처**: arxiv
- **점수**: 6.7
- **URL**: http://arxiv.org/abs/2607.21552v1

**요약**

Vision-language model (VLM)은 동일한 기하학 문제를 텍스트로 풀 때와 diagram으로 풀 때 서로 다른 성공/실패 패턴을 보인다. 이 논문은 이러한 modality 간 불일치 현상을 활용하기 위해 동일 문제의 text-dominant, image-dominant, combined 세 가지 view를 포함한 ODA-Data dataset을 구축하고, reinforcement learning 기반의 MIRROR 프레임워크를 제안한다. MIRROR는 한 view에서 성공한 reasoning path를 다른 view 학습의 신호로 활용하는 상호 보완적 학습 방식으로, VLM의 visual reasoning 능력을 전반적으로 향상시킨다.

**방법론**

핵심 아이디어는 동일 문제의 서로 다른 modality view 간 성공/실패 불일치를 cross-view learning signal로 활용하는 것이다. MIRROR는 reinforcement learning 프레임워크 하에서, 한 view(예: text)에서 모델이 올바른 reasoning을 수행했을 때 이를 다른 view(예: diagram)의 학습을 위한 positive reward signal로 사용하는 Modality-Informed Reciprocal Reasoning Optimization을 구현한다. 이를 위해 text-dominant, image-dominant, combined image+text의 세 가지 view로 구성된 ODA-Data를 구축하여 modality별 reasoning behavior를 체계적으로 분석하고 훈련에 활용한다.

**주요 기여**

1. 동일 기하학 문제에 대해 text-dominant, image-dominant, combined view를 포함한 고품질 paired multimodal dataset인 ODA-Data를 구축하고, modality-dependent reasoning 평가를 위한 split을 제공함.
2. 서로 다른 modality view 간의 complementary reasoning signal을 상호 활용하는 reinforcement learning 기반 프레임워크 MIRROR(Modality-Informed Reciprocal Reasoning Optimization)를 제안함.
3. VLM이 동일 문제에서 modality에 따라 서로 다른 성공/실패 패턴을 보인다는 현상을 체계적으로 분석하고, 이를 multimodal post-training에 활용할 수 있음을 실증함.

**실험 결과**

논문 전문이 제공되지 않아 구체적인 수치 결과는 확인되지 않음. ODA-Data 기반 geometry reasoning benchmark에서 MIRROR가 기존 multimodal post-training 대비 향상된 성능을 보인다고 보고하나, 정확한 수치는 원문 확인 필요.

**맥락**

LLM은 강력한 reasoning 능력을 보이지만, VLM은 동일한 내용을 담은 diagram 문제에서 현저히 낮은 성능을 보이는 modality gap 문제가 존재한다. 기존 multimodal post-training 방법들은 각 modality의 complementary한 reasoning path와 failure mode를 충분히 활용하지 못했으며, 이를 체계적으로 분석하고 해결하려는 시도가 부족했다.

**실무 시사점**

ML 엔지니어는 동일 문제의 여러 modality view를 paired data로 구성하고, 한 view에서의 성공 신호를 다른 view 학습에 활용하는 cross-modal reinforcement learning 전략을 실제 VLM fine-tuning 파이프라인에 적용할 수 있다. ODA-Data는 modality-dependent reasoning 평가 benchmark로도 활용 가능하며, 기하학 외 다른 도메인으로의 확장 가능성도 있다.

**한계**

현재 ODA-Data와 MIRROR는 기하학(geometry) 문제 도메인에 집중되어 있어 다른 visual reasoning 도메인으로의 일반화 가능성은 추가 검증이 필요하다. 또한 세 가지 view의 paired data 구축 비용이 높아 대규모 확장에 제약이 있을 수 있다.
