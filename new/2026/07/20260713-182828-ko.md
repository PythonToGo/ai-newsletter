# 📄 VLM의 한계를 해부하다: 효율·정렬·적응의 삼각 과제

> **리포트 ID**: `20260713-182828`  
> **생성**: 2026-07-13 18:28 UTC  
> **논문 수**: 4편  

## 이번 주 연구 동향

이번 주 논문들은 공통적으로 Vision-Language Model(VLM)의 실제 배포 가능성과 신뢰성이라는 두 축을 중심으로 수렴한다. 엣지 디바이스에서의 에너지 효율, 의료 도메인에서의 OOD 적응, 그리고 counting이라는 기초 능력에서의 internal misalignment까지—연구자들은 VLM이 '작동한다'는 사실을 넘어 '왜 실패하는가'와 '어떻게 고칠 수 있는가'를 정밀하게 파고들고 있다. Binary-to-source retrieval 논문 역시 LLM의 reasoning 능력을 실용적 engineering 문제에 접목하려는 같은 맥락에 놓인다.

방법론적으로 주목할 공통점은 training-free 또는 inference-time 개입이 반복 등장한다는 점이다. TCLA는 추가 학습 없이 logit을 post-hoc 보정하고, counting 논문은 nonlinear probe와 causal steering intervention으로 모델 재학습 없이 오류를 교정하며, retrieval pipeline은 fine-tuning 대신 anchor 기반 검색과 LLM re-ranking을 조합한다. 에너지 분석 논문 역시 새로운 모델을 훈련하는 대신 기존 inference 파이프라인의 병목을 실측으로 재정의한다. 이는 대규모 재훈련 비용 없이 현재 모델의 한계를 우회하려는 실용주의적 경향을 반영한다.

이 논문들이 남긴 과제는 명확하다. Training-free 방법들은 support sample의 품질과 수량에 민감하며, internal representation과 verbalized output 사이의 misalignment 문제는 counting을 넘어 VLM의 전반적인 신뢰성 문제로 확장될 수 있다. 엣지 배포에서는 output token 수를 줄이는 전략이 에너지 절감의 핵심으로 부상했지만, 응답 품질을 유지하면서 token efficiency를 높이는 방법은 여전히 열린 문제다.

실무 ML 엔지니어에게 가장 직접적인 시사점은 VLM 배포 시 에너지 프로파일링의 기준점을 바꿔야 한다는 것이다. Visual token 압축에 집중하던 기존 최적화 전략 대신, speculative decoding이나 응답 길이 제어 등 output token 생성 단계를 타깃으로 하는 접근이 실질적인 에너지 절감으로 이어진다는 실증 결과는 엣지 VLM 파이프라인 설계의 우선순위를 재정렬할 근거가 된다.

### 1. Seeing is Free, Speaking is Not: Uncovering the True Energy Bottleneck in Edge VLM Inference

- **출처**: arxiv
- **점수**: 7.3
- **URL**: http://arxiv.org/abs/2607.09520v1

**요약**

Vision-Language Model(VLM)을 엣지 디바이스에서 실행할 때 실제 에너지 병목이 어디에 있는지를 최초로 체계적으로 분석한 논문이다. 기존 연구들은 visual token 처리가 주요 에너지 비용이라고 암묵적으로 가정해왔으나, 본 연구는 이 가정을 뒤집고 output token 생성(텍스트 디코딩)이 진짜 에너지 병목임을 실증적으로 밝혔다. 5개 모델, 3개 architecture family, 4가지 입력 해상도, 2개 하드웨어 플랫폼(NVIDIA RTX 3070, Jetson Orin NX)에 걸친 실험을 통해 output token 하나가 input token 하나보다 11~39배 더 많은 wall-clock time을 소비함을 확인했다. 이 발견은 VLM 효율화 연구의 방향을 visual token 압축에서 텍스트 생성 최적화로 재설정해야 함을 시사한다.

**방법론**

핵심 아이디어는 VLM inference의 에너지 소비를 power draw와 inference time으로 분리하여, 어느 요소가 실제 에너지 변동을 유발하는지를 실측 기반으로 규명하는 것이다. 5개 VLM 모델(3개 architecture family)을 대상으로 4가지 입력 해상도, 다양한 이미지 복잡도·프롬프트 유형 조건에서 NVIDIA RTX 3070과 Jetson Orin NX 두 플랫폼의 실제 전력 및 시간을 측정하는 systematic energy profiling을 수행했다. 특히 input token 처리(prefill, compute-bound)와 output token 생성(decode, memory-bound)의 비대칭적 시간 비용을 정량화하여 에너지 병목의 원인을 구조적으로 분석했다.

**주요 기여**

1. VLM on-device inference에 대한 최초의 체계적 energy profiling 연구로, 기존의 'visual processing이 에너지 병목'이라는 암묵적 가정을 실증적으로 반박함.
2. 평균 inference power가 입력 해상도·이미지 복잡도·프롬프트 유형에 관계없이 모델 고유 상수(5% 이내 변동)임을 발견하여, 에너지 최적화의 핵심이 power가 아닌 inference time임을 규명함.
3. output token 하나가 input token 하나보다 11~39배 더 많은 wall-clock time을 소비한다는 정량적 수치를 제시하여, 텍스트 생성 최적화가 VLM 효율화의 진짜 레버임을 명확히 함.

**실험 결과**

NVIDIA RTX 3070 및 Jetson Orin NX 두 플랫폼에서 5개 VLM 모델 실험 결과: (1) 평균 inference power는 입력 해상도, 이미지 복잡도, 프롬프트 유형 전반에 걸쳐 5% 미만의 변동만 보이며 모델 고유 상수로 동작함. (2) output token 1개의 wall-clock time 비용이 input token 1개 대비 11~39배 높음(모델 및 플랫폼에 따라 상이). 이는 visual token 수 감소가 전체 에너지에 미치는 영향이 미미함을 의미하며, 기존 visual token 압축 기법들의 에너지 절감 효과가 과대평가되었음을 시사함.

**맥락**

embodied AI, 로봇, 모바일 에이전트 등 엣지 환경에서 VLM 추론의 에너지 효율은 실용화의 핵심 과제다. 기존 효율화 연구들은 visual token 수를 줄이는 방향에 집중해왔는데, 이는 visual processing이 에너지를 가장 많이 소비한다는 검증되지 않은 가정에 기반한 것이었다. 본 논문은 이 가정 자체가 잘못되었음을 체계적인 energy profiling으로 처음으로 증명하며, 연구 커뮤니티의 최적화 방향 재설정을 촉구한다.

**실무 시사점**

ML 엔지니어는 엣지 VLM 배포 시 visual token 압축보다 output token 수를 줄이는 전략(응답 길이 제한, speculative decoding, 더 효율적인 autoregressive decoding 기법)에 우선순위를 두어야 한다. 평균 inference power가 입력 해상도나 이미지 복잡도와 무관하게 거의 일정(5% 이내 변동)하다는 발견은, 에너지 최적화의 핵심 레버가 'power 절감'이 아닌 'inference time 단축'임을 의미하므로 latency 최적화 기법이 곧 에너지 최적화임을 실무에서 활용할 수 있다.

**한계**

논문에서 제공된 내용이 일부 잘려 있어 전체 실험 결과와 결론을 완전히 확인하기 어렵다. 또한 테스트된 하드웨어가 NVIDIA RTX 3070과 Jetson Orin NX 두 플랫폼에 한정되어 있어, ARM Mali GPU나 Apple Silicon 등 다른 엣지 칩셋으로의 일반화 가능성은 추가 검증이 필요하다.

**관련 링크**

- http://arxiv.org/abs/2607.09520v1

### 2. Practical Source Code Recovery from Binary Functions Using Anchor-Based Retrieval and LLM Reasoning

- **출처**: arxiv
- **점수**: 6.9
- **URL**: http://arxiv.org/abs/2607.09452v1

**요약**

이 논문은 stripped binary에서 원본 소스 코드를 복원하는 실용적인 pipeline을 제안합니다. 기존의 decompiler가 근사적인 pseudocode를 생성하는 방식과 달리, 이 연구는 소스 코드 database에서 실제 원본 함수를 찾아내는 anchor-based retrieval 접근법을 사용합니다. Ghidra를 통해 string, constant, external call 등의 anchor를 추출하고, inverted-index search와 LLM re-ranking을 결합하여 최종 매칭을 수행하며, 최적화된 tcpdump binary에서 95.2%의 assembly instruction coverage를 달성했습니다.

**방법론**

핵심 아이디어는 decompiler로 코드를 '생성'하는 대신, 대규모 소스 코드 database에서 binary와 가장 유사한 원본 함수를 '검색'하는 것입니다. Ghidra로 binary에서 string, constant, external call, 함수명 등의 anchor를 추출한 뒤 inverted-index로 후보 파일을 좁히고, disassembly·decompiled code·source metadata를 함께 LLM에 입력하여 최종 re-ranking을 수행합니다. 높은 신뢰도의 매칭 결과는 다음 iteration의 anchor로 재사용되어 점진적으로 coverage를 확장합니다.

**주요 기여**

1. Decompiled pseudocode 생성이 아닌 실제 원본 소스 함수 검색에 초점을 맞춘 binary-to-source retrieval pipeline 제안
2. String, constant, external call 등 다양한 anchor 유형을 활용한 inverted-index 기반 후보 검색과 LLM re-ranking의 결합
3. 최적화된 stripped tcpdump binary에서 95.2% assembly instruction coverage라는 높은 실용적 성능 달성 및 GitHub 기반 retrieval dataset을 통한 추가 검증

**실험 결과**

최적화된 stripped tcpdump binary 대상 평가에서 assembly instruction coverage 95.2% 달성. GitHub 기반 retrieval dataset을 활용한 추가 실험도 수행되었으나 논문 발췌본에 구체적인 수치는 포함되지 않음.

**맥락**

Binary reverse engineering은 malware 분석, 취약점 연구, 레거시 소프트웨어 유지보수 등 다양한 보안 분야에서 핵심적인 작업이지만, 기존 decompiler(예: Ghidra, IDA Pro)는 원본 코드와 거리가 먼 근사적 pseudocode만 생성합니다. 최근 LLM 기반 코드 생성 기술이 발전하면서 binary-to-source 복원의 정확도를 높일 수 있는 가능성이 열렸고, 이 연구는 retrieval-augmented 방식으로 그 가능성을 실용적으로 구현하려 합니다.

**실무 시사점**

ML 엔지니어는 이 pipeline의 anchor 추출 → inverted-index retrieval → LLM re-ranking 구조를 코드 검색이나 취약점 분석 도구 개발에 직접 응용할 수 있습니다. 특히 confident match를 다음 pass의 anchor로 재활용하는 iterative 전략은 다른 retrieval-augmented generation(RAG) 시스템 설계에도 참고할 만한 패턴입니다.

**한계**

평가가 주로 tcpdump라는 단일 오픈소스 binary에 집중되어 있어, 다양한 컴파일러 최적화 수준이나 상용 소프트웨어에 대한 일반화 가능성이 충분히 검증되지 않았습니다. 또한 소스 코드 database에 원본 함수가 존재해야 한다는 closed-world 가정이 실제 환경에서는 큰 제약이 될 수 있습니다.

**관련 링크**

- http://arxiv.org/abs/2607.09452v1

### 3. TCLA: Training-Free Class-wise Logit Adaptation for Medical Vision-Language Models

- **출처**: arxiv
- **점수**: 6.7
- **URL**: http://arxiv.org/abs/2607.09562v1

**요약**

Medical Vision-Language Models(VLMs)은 강력한 zero-shot 성능을 보이지만, domain shift와 class bias로 인해 out-of-distribution(OOD) 데이터에서 성능이 저하되는 문제가 있다. 본 논문은 TCLA(Training-Free Class-wise Logit Adaptation)라는 순수하게 학습이 필요 없는 few-shot adaptation 방법을 제안하며, 소수의 support sample을 활용해 inference logit을 보정함으로써 inter-class deconfusion과 domain shift 감소를 동시에 달성한다. X-ray, Ultrasound, MRI, CT, Histopathology 등 9개 medical imaging 데이터셋에서 실험한 결과, TCLA는 기존 training-based adaptation 방법들을 대부분의 경우에서 능가하는 성능을 보였다.

**방법론**

핵심 아이디어는 소수의 support sample로부터 class-wise 통계를 추출하여 VLM의 inference logit을 사후 보정(post-hoc correction)함으로써 inter-class confusion을 줄이고 domain shift를 완화하는 것이다. 구체적으로, 각 class별 support feature를 분석해 class 간 logit 분포의 편향을 추정하고, 이를 기반으로 test sample의 logit을 class-wise로 재조정하는 방식을 취한다. 별도의 gradient 업데이트나 추가 파라미터 없이 순수하게 logit 공간에서의 통계적 보정만으로 작동하므로 빠르고 안정적이다.

**주요 기여**

1. Training-free few-shot adaptation 방법인 TCLA를 제안하여, 추가 학습 없이 Medical VLM의 OOD 성능을 향상시키는 최초의 순수 inference-time 보정 프레임워크를 제시함.
2. Class-wise logit adaptation을 통해 inter-class deconfusion과 domain shift 감소를 동시에 달성하는 메커니즘을 설계하여, 1-shot처럼 극단적으로 데이터가 부족한 환경에서도 안정적인 성능을 보임.
3. X-ray, Ultrasound, MRI, CT, Histopathology를 포함한 9개 diverse medical imaging 데이터셋에서 광범위한 실험을 통해 기존 training-based adaptation 방법들 대비 우수하거나 동등한 성능을 model-agnostic하게 달성함을 실증함.

**실험 결과**

X-ray, Ultrasound, MRI, CT, Histopathology를 포함한 9개 medical imaging 데이터셋에서 실험한 결과, TCLA는 대부분의 경우 기존 training-based few-shot adaptation 방법들을 능가하는 OOD 성능을 기록하였다. 특히 1-shot처럼 극단적으로 데이터가 부족한 환경에서 기존 방법들이 불안정한 반면 TCLA는 일관된 성능 향상을 보였으나, 논문 초록에서 구체적인 수치(예: 정확도 %)는 명시되지 않았다.

**맥락**

Medical VLMs는 대규모 pretraining 덕분에 뛰어난 zero-shot 능력을 갖추지만, 실제 임상 환경에서는 domain shift와 class imbalance로 인한 bias 문제로 OOD 성능이 크게 떨어진다. 기존 few-shot adaptation 방법들은 추가적인 trainable component를 도입하여 1-shot처럼 극단적으로 데이터가 부족한 상황에서 불안정하고 다양한 medical modality에 대한 robustness가 부족하다는 한계가 있었다. 이에 따라 빠르고 model-agnostic하며 추가 학습 없이 적용 가능한 adaptation 방법의 필요성이 대두되었다.

**실무 시사점**

TCLA는 training-free 방식이므로 기존에 배포된 Medical VLM에 추가 학습 없이 즉시 적용할 수 있어, 데이터가 극히 부족한 실제 의료 현장에서 빠르게 활용 가능하다. Model-agnostic 특성 덕분에 특정 아키텍처에 종속되지 않으므로, 다양한 Medical VLM backbone에 plug-and-play 형태로 통합할 수 있다. 또한 class-wise logit 보정 방식은 구현이 단순하여 기존 inference pipeline에 최소한의 수정만으로 OOD robustness를 개선할 수 있다.

**한계**

TCLA의 성능은 logit 보정에 사용되는 support sample의 품질과 대표성에 의존하므로, support set이 실제 데이터 분포를 잘 반영하지 못할 경우 효과가 제한될 수 있다. 또한 논문에서 다룬 9개 데이터셋이 다양한 modality를 포함하지만, 더 희귀한 medical imaging 도메인이나 극단적인 class imbalance 시나리오에서의 일반화 가능성은 추가 검증이 필요하다.

**관련 링크**

- http://arxiv.org/abs/2607.09562v1

### 4. The Count Is There, but Misaligned: Understanding and Correcting Counting Failures in VLMs

- **출처**: arxiv
- **점수**: 6.7
- **URL**: http://arxiv.org/abs/2607.09544v1

**요약**

Vision-language model(VLM)들이 기본적인 객체 counting에서 실패하는 이유를 분석한 논문으로, 모델이 내부적으로는 올바른 count를 인코딩하고 있지만 이를 언어 출력으로 변환하는 과정에서 misalignment가 발생함을 밝혔습니다. Nonlinear probe를 VLM의 activation에 학습시킨 결과, 모델이 틀린 답을 출력할 때도 내부 representation에는 정답 count 정보가 존재함을 확인했습니다. 이를 바탕으로 causal steering intervention과 detector-guided self-correction 방법을 제안하여 별도의 재학습 없이 counting 성능을 개선하는 실용적인 접근법을 제시합니다.

**방법론**

핵심 아이디어는 VLM의 내부 activation에 linear 및 nonlinear probe를 학습시켜 counting 오류가 representation 수준에서 이미 감지 가능한지 검증하는 것입니다. SVCCA(Singular Vector Canonical Correlation Analysis)를 통해 ground-truth count probe와 model output probe의 activation subspace가 부분적으로 겹치지만 readout 방향이 misaligned됨을 분석했습니다. 이를 바탕으로 causal steering으로 올바른 count 방향을 강화하거나, probe가 오류를 감지할 때만 self-correction re-prompting을 트리거하는 두 가지 개입 방법을 제안합니다.

**주요 기여**

1. VLM의 counting 실패가 지식 부재가 아닌 internal representation과 verbalized output 사이의 misalignment에서 비롯됨을 probe 분석과 SVCCA로 최초로 체계적으로 규명
2. Causal steering intervention을 통해 activation 수준에서 count 방향을 강화하면 실제 모델 출력 성능이 향상됨을 인과적으로 검증
3. 재학습 없이 적용 가능한 detector-guided self-correction 방법을 제안하여, counting 오류가 감지된 경우에만 선택적으로 re-prompting하는 경량 실용 솔루션 제시

**실험 결과**

4개의 VLM(모델명 미상)과 5개의 counting dataset에 걸쳐 nonlinear probe가 counting 오류를 높은 신뢰도로 감지함을 확인했으며, causal steering intervention 적용 시 모델의 counting 정확도가 유의미하게 향상되었습니다. 구체적인 수치는 논문 본문에 포함되어 있으나 초록에서는 명시적 수치가 제공되지 않았습니다.

**맥락**

VLM들은 다양한 multimodal task에서 뛰어난 성능을 보이지만, 이미지 내 객체 수를 세는 counting 능력은 여전히 취약한 것으로 알려져 있습니다. 기존 연구들은 이를 모델의 지식 부재로 해석했지만, 이 논문은 내부 representation과 언어 출력 사이의 gap이라는 새로운 관점을 제시합니다. 이 구분은 해결책의 방향을 근본적으로 바꾸며, 재학습 없이도 내부 표현을 활용한 수정이 가능함을 시사합니다.

**실무 시사점**

ML 엔지니어는 VLM의 counting 오류를 감지하기 위해 간단한 nonlinear probe를 activation 위에 학습시키는 방식을 실무에 바로 적용할 수 있으며, 이는 모델 재학습 없이도 오류 감지기로 활용 가능합니다. Detector-guided self-correction 방식은 오류가 감지된 경우에만 선택적으로 re-prompting을 수행하므로, inference 비용을 최소화하면서 counting 정확도를 높이는 실용적인 파이프라인 구성에 활용할 수 있습니다.

**한계**

이 연구는 counting이라는 특정 능력에 초점을 맞추고 있어, 다른 유형의 VLM 오류(예: spatial reasoning, attribute binding)에 동일한 misalignment 가설이 적용되는지는 검증되지 않았습니다. 또한 causal steering intervention의 효과가 모든 모델 아키텍처와 counting 범위에서 일관되게 나타나는지에 대한 추가 검증이 필요합니다.
