## 이번 주 연구 동향

이번 주 논문들은 표면적으로는 로보틱스, 분자 시뮬레이션, planning, 코드 생성이라는 서로 다른 도메인을 다루지만, 그 저변에는 두 가지 공통 문제의식이 흐른다. 첫째는 '데이터 효율성'이다. VLA pretraining 논문(TAP)과 MLIP optimizer 논문 모두, 레이블된 전문가 데이터가 부족한 현실에서 어떻게 더 적은 데이터로 더 나은 성능을 끌어낼 것인가를 핵심 질문으로 삼는다. 둘째는 '문제의 구조적 분해'다. TAP의 Decomposition Hypothesis, ACID의 cycle consistency, DecompRL의 modular decomposition은 모두 복잡한 문제를 독립적으로 다룰 수 있는 하위 구성 요소로 쪼개는 전략을 공유한다.

방법론적으로 주목할 패턴은 inverse dynamics model의 반복 등장이다. TAP은 self-supervised motor prior 학습에, ACID는 world model planning의 transition 검증에 inverse dynamics objective를 활용한다. 이는 단순히 한 논문의 아이디어가 아니라, action-grounded representation을 얻기 위한 범용 기법으로 자리잡고 있음을 시사한다. 한편 SOAP/Muon 논문은 optimizer 선택이 architecture 선택만큼 중요한 설계 축임을 실증하며, 기존 Adam 중심의 관행에 의문을 제기한다는 점에서 방법론적 다양성을 넓히는 흐름으로 읽힌다.

이 논문들이 남긴 과제는 명확하다. 분해(decomposition) 전략들이 각각의 도메인에서 효과를 입증했지만, 분해의 단위와 기준을 어떻게 자동으로 결정할 것인가는 여전히 열린 문제다. TAP의 2단계 fine-tuning, ACID의 scale-invariant weighting, DecompRL의 sub-function 설계 모두 사람의 귀납적 판단에 의존하는 부분이 남아 있으며, 이를 end-to-end로 학습하는 방향이 다음 연구의 자연스러운 스텝이 될 것이다.

실무 시사점은 간단하다. 기존 파이프라인에서 '버려지던 데이터'를 재검토할 시점이다. TAP의 off-task trajectory 활용, MLIP의 partial force supervision 대응, ACID의 plug-in 구조는 모두 추가 데이터 수집 없이 기존 자산을 재활용하는 방향을 가리킨다. ML 엔지니어라면 현재 프로젝트에서 레이블 없이 쌓이고 있는 interaction log나 실패 trajectory가 있는지 먼저 확인해볼 것을 권한다.

## 논문 분석

### 1. Learning to Move Before Learning to Do: Task-Agnostic pretraining for VLAs

- **출처**: arxiv
- **점수**: 6.9
- **URL**: http://arxiv.org/abs/2607.02466v1

**요약**

Vision-Language-Action (VLA) 모델은 전문가 시연 데이터(observations, instructions, actions 삼중쌍)의 부족으로 인해 성능이 제한되는 근본적인 병목 현상을 겪고 있다. 이 논문은 '물리적 운동 능력(how to move)'과 '의미적 정렬(what to do)'을 분리해야 한다는 Decomposition Hypothesis를 제안하며, 언어 감독은 후자에만 필요하다고 주장한다. 이를 바탕으로 Task-Agnostic Pretraining (TAP)이라는 2단계 프레임워크를 제안하는데, 1단계에서는 레이블 없는 저비용 interaction 데이터로 self-supervised Inverse Dynamics objective를 통해 motor prior를 학습하고, 2단계에서는 최소한의 전문가 데이터로 언어와 연결한다. SIMPLER benchmark에서 TAP은 100만 개 이상의 전문가 trajectory로 학습한 모델과 동등한 성능을 보이면서 절대 성능을 10% 향상시켰다.

**방법론**

핵심 아이디어는 언어 감독 없이도 학습 가능한 '운동 능력'과 언어가 필요한 '의미 정렬'을 분리(Decomposition Hypothesis)하는 것이다. 1단계에서는 레이블 없는 interaction 데이터(버려진 off-task trajectory, robot play 포함)에 self-supervised Inverse Dynamics Model을 적용해 연속된 두 상태(state)로부터 행동(action)을 예측하는 방식으로 transferable motor prior를 학습한다. 2단계에서는 이렇게 학습된 motor prior를 고정하거나 초기화로 활용하고, 소량의 전문가 시연 데이터만으로 언어 조건부 policy를 fine-tuning하여 semantic grounding을 완성한다.

**주요 기여**

1. 물리적 운동 능력(motor competence)과 의미적 언어 정렬(semantic alignment)을 분리해야 한다는 Decomposition Hypothesis를 제안하고 이를 이론적·실험적으로 검증함.
2. 레이블 없는 저비용 데이터(off-task trajectory, robot play)를 self-supervised Inverse Dynamics objective로 활용하는 Task-Agnostic Pretraining (TAP) 2단계 프레임워크를 설계함.
3. SIMPLER benchmark에서 100만 개 이상의 전문가 trajectory로 학습한 기존 모델 대비 동등하거나 우수한 성능을 훨씬 적은 레이블 데이터로 달성하며 10% absolute 성능 향상을 입증함.

**실험 결과**

SIMPLER benchmark에서 TAP은 1M개 이상의 전문가 trajectory로 학습된 모델들과 동등한 성능을 달성하면서, 레이블 데이터 사용량을 수 배 이상 줄이고 절대 성능(absolute performance)을 10% 향상시켰다. 이는 orders of magnitude 더 적은 레이블 데이터를 사용한 결과로, 데이터 효율성 측면에서 기존 SOTA 대비 큰 개선을 보여준다.

**맥락**

로봇 학습에서 VLA 모델의 성능을 높이려면 대규모 전문가 시연 데이터가 필요하지만, 이는 수집 비용이 매우 높아 실용적 확장이 어렵다. 기존 접근법들은 언어 지시와 행동을 동시에 학습하려 했기 때문에 모든 데이터에 언어 레이블이 필요했고, 이는 데이터 효율성을 크게 저하시켰다. 이 연구는 운동 능력 학습과 언어 정렬 학습을 분리함으로써 레이블 없는 저비용 데이터를 최대한 활용할 수 있는 새로운 패러다임을 제시한다.

**실무 시사점**

ML 엔지니어는 기존에 버려지던 off-task trajectory나 robot play 데이터를 TAP의 1단계 pretraining에 활용하여 전문가 시연 데이터 수집 비용을 대폭 절감할 수 있다. Inverse Dynamics objective 기반의 motor prior를 먼저 학습한 후 소량의 레이블 데이터로 fine-tuning하는 2단계 구조는 데이터가 제한된 실제 로봇 배포 환경에 직접 적용 가능하다. 이 Decomposition Hypothesis는 새로운 로봇 태스크 도입 시 전체 파이프라인을 재학습하지 않고 2단계만 업데이트하면 되는 효율적인 개발 워크플로우를 가능하게 한다.

**한계**

현재 실험이 SIMPLER benchmark(시뮬레이션 환경)에 집중되어 있어 실제 물리 로봇 환경에서의 일반화 성능은 추가 검증이 필요하다. 또한 1단계에서 학습된 motor prior가 매우 다양한 로봇 형태(morphology)나 완전히 새로운 운동 패턴에도 전이 가능한지에 대한 분석이 제한적이다.

**관련 링크**

- http://arxiv.org/abs/2607.02466v1

### 2. Beyond Adam: SOAP and Muon for Faster, Label-Efficient Training of Machine Learning Interatomic Potentials

- **출처**: arxiv
- **점수**: 6.8
- **URL**: http://arxiv.org/abs/2607.02499v1

**요약**

Machine learning interatomic potentials (MLIPs)는 과학적 시뮬레이션을 위한 AI의 핵심 도구로 자리잡았지만, 훈련에 사용하는 optimizer 선택은 대부분 Adam에 고정되어 있었다. 이 논문은 최근 제안된 matrix-structured optimizer인 Muon, SOAP, SOAP-Muon을 NequIP와 Allegro MLIP 모델 훈련에 체계적으로 적용하고 비교한다. 실험 결과 SOAP와 SOAP-Muon이 Adam 대비 수렴 속도와 최종 정확도 모두에서 일관되게 우수한 성능을 보였으며, 특히 부분적인 force supervision 환경에서 그 차이가 두드러졌다. 이 연구는 optimizer 선택이 MLIP 훈련에서 간과되어 온 중요한 설계 축임을 보여준다.

**방법론**

핵심 아이디어는 기존 Adam의 element-wise second moment 추정 대신 weight matrix의 전체 구조를 활용하는 matrix-structured preconditioning을 MLIP 훈련에 도입하는 것이다. SOAP(Shampoo as Adam Preconditioner)는 Shampoo 스타일의 Kronecker-factored curvature 추정을 Adam과 결합하고, Muon은 Nesterov momentum에 orthogonalization을 적용하며, SOAP-Muon은 두 방법을 hybrid로 결합한다. NequIP와 Allegro 모델에 대해 full force supervision 및 partial force supervision 조건에서 체계적인 ablation study를 수행하여 각 optimizer의 효과를 정량적으로 비교했다.

**주요 기여**

1. MLIP 훈련에 Muon, SOAP, SOAP-Muon을 최초로 체계적으로 적용하고, optimizer 선택이 architecture 선택만큼 중요한 설계 축임을 실증적으로 입증했다.
2. SOAP와 SOAP-Muon이 Adam 대비 수렴 속도와 최종 정확도 모두에서 일관되게 우수함을 NequIP, Allegro 두 모델에 걸쳐 확인하고, partial force supervision 환경에서 그 이점이 더욱 증폭됨을 발견했다.
3. 데이터 효율적인 MLIP 훈련을 위한 실용적 가이드라인을 제시하여, 고비용 원자 시뮬레이션 데이터 수집 부담을 optimizer 개선으로 완화할 수 있는 방향을 제안했다.

**실험 결과**

NequIP와 Allegro 모델을 표준 분자 dynamics benchmark에서 평가한 결과, SOAP와 SOAP-Muon은 Adam 대비 수렴 속도와 최종 energy/force 예측 오차 모두에서 일관된 개선을 보였다. Partial force supervision(일부 구조에만 force label 제공) 조건에서 개선 폭이 특히 두드러졌으며, Muon은 일부 설정에서만 Adam을 능가하는 불일관한 결과를 보였다. 구체적인 수치는 논문 내 각 benchmark 및 supervision 비율별 표에 제시되어 있으나 초록에서는 정량적 수치가 명시되지 않았다.

**맥락**

MLIPs 분야는 새로운 architecture와 대규모 dataset 구축에 집중해 왔으나, optimizer 선택은 거의 논의되지 않고 Adam 계열이 기본값으로 사용되어 왔다. 최근 Muon, SOAP 같은 matrix-structured optimizer들이 언어 모델 등 다른 도메인에서 Adam을 능가하는 결과를 보이기 시작했고, 이를 과학 시뮬레이션 특화 모델에 적용하는 연구가 필요한 시점이었다. 특히 원자 시뮬레이션 데이터 수집 비용이 높아 label-efficient training이 중요한 상황에서 optimizer 개선의 실질적 가치가 크다.

**실무 시사점**

MLIP 훈련 파이프라인에서 Adam을 SOAP 또는 SOAP-Muon으로 교체하는 것만으로도 동일한 데이터로 더 높은 정확도를 달성하거나, 동일한 정확도를 더 적은 데이터로 달성할 수 있어 데이터 수집 비용을 절감할 수 있다. 특히 force label이 부분적으로만 제공되는 현실적인 데이터 부족 상황에서 SOAP 계열 optimizer의 이점이 더욱 극대화되므로, 실험 데이터가 제한적인 연구 환경에서 즉시 적용 가치가 높다.

**한계**

Muon은 Adam 대비 일부 개선만 제공하며 일관성이 부족해 단독 사용에는 한계가 있고, 연구가 NequIP와 Allegro 두 모델에 한정되어 있어 다른 MLIP architecture로의 일반화 여부는 추가 검증이 필요하다. 또한 matrix-structured optimizer는 Adam보다 구현 복잡도와 메모리 오버헤드가 높을 수 있어 대규모 모델에서의 실용성은 별도로 평가해야 한다.

**관련 링크**

- https://arxiv.org/abs/2502.16982
- https://arxiv.org/abs/2409.20325
- https://github.com/mir-group/nequip
- https://github.com/mir-group/allegro

### 3. ACID: Action Consistency via Inverse Dynamics for Planning with World Models

- **출처**: arxiv
- **점수**: 6.8
- **URL**: http://arxiv.org/abs/2607.02403v1

**요약**

ACID는 world model 기반의 decision-time planning에서 발생하는 trajectory 신뢰성 문제를 해결하는 framework입니다. 기존 방법은 예측된 trajectory의 최종 상태만 goal과 비교하여 평가하기 때문에, 중간 transition들이 실제 환경에서 실현 가능한지 검증하지 않는다는 문제가 있습니다. ACID는 inverse dynamics model을 활용한 cycle action consistency를 도입하여, 예측된 transition으로부터 역방향으로 추론한 action이 원래 conditioning된 action과 일치하는지를 per-step으로 검증합니다. 4가지 action-conditioned world model과 6가지 task에서 실험한 결과, ACID는 planning compute를 크게 줄이면서도 baseline과 동등하거나 더 나은 성능을 달성했습니다.

**방법론**

핵심 아이디어는 world model이 예측한 (s_t, a_t, s_{t+1}) transition에 inverse dynamics model을 적용하여 역방향으로 action을 추론하고, 이 추론된 action이 원래 conditioning action a_t와 얼마나 일치하는지를 cycle consistency residual로 정량화하는 것입니다. 이 per-step residual은 scale-invariant adaptive weight를 통해 기존 planning cost에 자연스럽게 통합되며, 별도의 architecture 변경 없이 다양한 world model 위에 적용 가능합니다. 전체 framework는 decision-time에만 작동하므로 world model 재학습 없이 즉시 적용할 수 있습니다.

**주요 기여**

1. Decision-time planning에서 중간 transition의 실현 가능성을 검증하는 cycle action consistency 개념을 제안하여, 기존 terminal-state-only planning cost의 근본적 한계를 지적하고 해결책을 제시함.
2. Scale-invariant adaptive weight를 통해 consistency residual을 planning cost에 통합하는 범용적이고 하이퍼파라미터 robust한 방법론을 설계함.
3. 4가지 서로 다른 action-conditioned world model과 rigid/deformable manipulation, articulated control, visual navigation을 포함한 6가지 task에서 ACID의 일관된 성능 향상 및 compute 효율성을 실증적으로 검증함.

**실험 결과**

4가지 action-conditioned world model(논문에서 구체적 모델명 명시)과 rigid manipulation, deformable manipulation, articulated control, visual navigation을 포함한 6가지 task에서 ACID를 평가한 결과, 모든 설정에서 baseline planning 대비 일관된 성능 향상을 달성했습니다. 특히 baseline과 동등한 task 성공률을 달성하면서 필요한 planning compute를 substantially 감소시켰으며, 구체적인 수치는 논문 본문의 Table 및 Figure에 task별로 상세히 보고되어 있습니다.

**맥락**

Action-conditioned world model을 이용한 decision-time planning은 embodied AI 분야에서 점점 주목받는 패러다임이지만, 예측된 trajectory가 실제 환경 rollout과 괴리되는 문제(compounding error, unrealizable transition)가 고질적인 한계로 지적되어 왔습니다. 기존 planning cost는 terminal state의 goal 근접성만 평가하므로, 중간 transition의 물리적 실현 가능성을 전혀 고려하지 않습니다. 이 연구는 이러한 gap을 inverse dynamics consistency라는 간단하고 범용적인 아이디어로 메우려 합니다.

**실무 시사점**

ML 엔지니어는 기존 action-conditioned world model에 inverse dynamics model을 추가하고, cycle consistency residual을 planning cost에 편입하는 방식으로 ACID를 플러그인처럼 적용할 수 있습니다. Scale-invariant adaptive weight 덕분에 별도의 하이퍼파라미터 튜닝 없이도 다양한 task와 model에 범용적으로 사용 가능하며, 동일한 성능을 더 적은 planning compute로 달성할 수 있어 inference 비용 절감에도 직접적인 이점이 있습니다.

**한계**

Inverse dynamics model 자체의 품질에 성능이 의존하므로, inverse dynamics 학습이 어려운 환경(예: 고차원 연속 action space, 부분 관측 환경)에서는 consistency 신호의 신뢰성이 저하될 수 있습니다. 또한 논문에서 다룬 task들이 주로 manipulation과 navigation에 한정되어 있어, 더 복잡한 long-horizon 또는 open-world 시나리오로의 일반화 여부는 추가 검증이 필요합니다.

**관련 링크**

- http://arxiv.org/abs/2607.02403v1

### 4. DecompRL: Solving Harder Problems by Learning Modular Code Generation

- **출처**: arxiv
- **점수**: 6.7
- **URL**: http://arxiv.org/abs/2607.02390v1

**요약**

LLM이 현재 풀 수 없는 어려운 코딩 문제를 해결하기 위해, DecompRL은 문제를 독립적으로 구현 가능한 작은 sub-function들로 분해한 뒤 이를 재조합하는 방식을 제안한다. k개의 구현과 n개의 모듈을 조합하면 최대 k^n개의 후보 솔루션을 생성할 수 있어, 단순 반복 샘플링 대비 탐색 공간을 기하급수적으로 확장한다. RL을 통해 모듈형 코드 생성을 명시적으로 학습시키는 DecompRL은 기존 방법들이 near-zero probability 문제로 실패하는 어려운 benchmark에서 유의미한 성능 향상을 달성한다.

**방법론**

핵심 아이디어는 하나의 어려운 문제를 n개의 독립적인 sub-function으로 분해하고, 각 sub-function에 대해 k개의 구현을 샘플링한 뒤 재조합하여 최대 k^n개의 후보 솔루션을 생성하는 것이다. DecompRL은 verifiable reward를 기반으로 한 RL 알고리즘으로, LLM이 hierarchical code structure를 명시적으로 decompose하고 구현하는 방식을 학습하도록 훈련된다. 이를 통해 탐색의 bottleneck을 전체 솔루션 공간에서 각 모듈의 구현 공간으로 분산시켜 near-zero probability 문제를 완화한다.

**주요 기여**

1. 어려운 코딩 문제에서 near-zero base policy probability 문제를 decomposition 기반 탐색 공간 확장으로 해결하는 새로운 프레임워크 제안
2. modular code generation을 명시적으로 학습하는 RL 알고리즘 DecompRL 설계 및 구현
3. 반복 샘플링 및 기존 RL fine-tuning 대비 어려운 benchmark에서 더 높은 정확도와 샘플 효율성 달성

**맥락**

LLM 기반 코드 생성에서 test-time compute scaling(반복 샘플링)과 RL fine-tuning은 base policy가 정답을 생성할 확률이 거의 0에 가까운 어려운 문제에서는 모두 한계를 보인다. 샘플링을 늘려도 GPU 비용이 선형적으로 증가하고, RL의 gradient signal도 탐색 공간 자체가 너무 클 때는 효과가 없다. 이 연구는 문제 자체를 더 쉽게 만드는 decomposition 전략으로 이 근본적인 병목을 해결하려 한다.

**실무 시사점**

ML 엔지니어는 DecompRL의 modular decomposition 전략을 어려운 코딩 task에 적용해, 단일 솔루션 생성 대신 sub-function 단위로 분리하여 조합 탐색을 활용할 수 있다. 기존 RL fine-tuning pipeline에 hierarchical code structure 학습을 추가하면 같은 샘플 예산으로 훨씬 더 넓은 후보 공간을 커버할 수 있어 실용적인 비용 효율성을 기대할 수 있다.

**한계**

off-the-shelf 모델이 modular generation에 최적화되어 있지 않아 DecompRL 학습 초기에 decomposition 품질이 불안정할 수 있으며, sub-function 간 interface 설계가 잘못될 경우 재조합 단계에서 오류가 증폭될 수 있다. 또한 k^n 조합 탐색의 실제 비용과 효과는 문제 구조에 따라 크게 달라질 수 있어 일반화 범위에 대한 추가 검증이 필요하다.

**관련 링크**

- http://arxiv.org/abs/2607.02390v1
