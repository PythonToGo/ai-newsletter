## 이번 주 연구 동향

이번 호는 언어모델의 반복 계산 구조와 영상 편집기의 후학습을 함께 읽는다. MoLT는 이전 계산에서 무엇을 기억할지 바꾸고, I2VT는 영상 편집기에 이미지 교사의 능력을 전달한다. 하나는 계산 경로, 다른 하나는 학습 자료와 감독 신호에 관한 연구이므로 단일한 기술 유행으로 묶지는 않는다.

두 연구를 읽을 때 공통으로 조심할 것은 효율의 분모다. 더 적은 토큰으로 같은 손실에 도달해도 GPU 사용량은 늘 수 있다. 새 영상 쌍 없이 후학습해도 기존 영상 사전학습과 이미지 교사의 비용은 남는다. 아래에서는 저자 보고 수치와 공개 코드에서 확인한 사항, 편집상의 적용 제안을 구분한다.

최근 30일 신논문 아카이브 21개 보고서의 제목·URL과 본문을 대조해 두 논문이 미수록임을 확인했다. 지난 호의 번역 평가·로봇 시연 데이터와 다른 문제를 선정했다. 원문·README·구현을 열람했으며 학습·추론·판정 API를 실행하거나 독립 재현하지 않았다. 점수는 측정 성능이 아니라 편집 선정 점수다.

### 1. 반복 층 사이에 숨은 상태 대신 기억을 전달한다 — Mixture-of-Loops Transformer

- **출처**: arXiv 원문 v1·HUST/ByteDance Seed/University of Toronto 저자 저장소
- **점수**: 8.3/10 — 편집 선정 점수
- **URL**: https://arxiv.org/abs/2611.34923

**요약**

Lianghui Zhu 등의 MoLT는 같은 층을 반복 사용하는 Transformer에서 정보 전달 방식을 바꾼다. 핵심은 attention의 키·값(KV)을 재사용 가능한 기억으로 다루는 것이다. U-MoLT는 기억을 만드는 encoder와 예측을 읽어내는 decoder를 분리한다. 같은 파라미터를 반복 쓴다는 사실과 같은 연산량이라는 주장은 다르다.

**방법론**

공개 구현 설명에서 encoder는 반복마다 같은 토큰 임베딩에서 다시 시작한다. Loop KV는 이전 반복의 현재 위치보다 앞선 토큰만 읽도록 제한한다. MoLA는 순서 방향의 KV와 현재 토큰의 층별 KV를 하나의 softmax로 선택한다. Decoder는 encoder 출력에 대한 causal cross-attention을 사용하며, decoder에서 encoder로 되돌리는 피드백은 없다.

이 구분은 캐시를 설계할 때 중요하다. 코드 안내는 고정 횟수 unrolling과 토큰 순서 recurrent 추론이 일반적으로 같은 출력을 내지 않는다고 명시한다. 고정 반복의 prefill 결과를 recurrent 캐시로 그대로 넘기는 것도 금지한다. 서로 다른 실행 스케줄을 같은 함수의 빠른 구현으로 오해하면 안 된다.

**주요 기여**

층 재사용을 단순 반복에서 KV 기억의 선택적 재사용 문제로 확장했다. U-MoLT에서는 이후 예측에 쓰이지 않는 중간 decoder 통과를 생략한다. 공개 범위는 BlaGPT 기반 최소 U-MoLT, MoLA 커널·테스트와 소형 설정이다. MoLT-R·MoLT-KV, MoL-Hybrid 추론, 대규모 학습 레시피는 README의 미완료 항목으로 남아 있다.

**실험 결과**

저자 보고에서 400B 토큰 학습한 3B MoE의 10개 과제 평균 정확도는 OLMo3 60.1%→U-MoLT 62.2%다. 별도의 700M 짝지은 실험에서는 기준 모델의 400B 토큰 검증 CE에 232.8B 토큰으로 도달한다. 이것이 약 1.7배의 토큰 효율이다.

그러나 부록 Table 11의 전체 400B 학습은 64 H20 기준 7,049→14,026 GPU-hours, 이론 FLOPs는 2.01배다. 같은 계산 예산으로 학습률 일정을 끝까지 맞춘 비교는 별도 실험이 필요하다고 저자도 적는다. 즉 토큰 감소만으로 학습비 절감을 결론 내릴 수 없다.

**맥락**

편집 해석: 데이터가 제한된 상황의 효율, 모델 크기당 품질, 실제 계산비는 다른 목적 함수다. 이번 결과는 반복 구조의 가능성을 보여주지만, 같은 비용이면 더 큰 비반복 모델이 나은지까지 해결하지는 않는다. 코드가 공개됐다는 사실도 논문의 모든 실행 경로가 공개됐다는 뜻은 아니다.

**실무 시사점**

언어모델 구조 연구팀은 공개 소형 설정부터 비교 계획을 세우는 편이 좋다. 제공 JSON은 6+6층, 두 반복, 동일한 반복별 손실 가중치와 `detach_loop_memory=false`를 쓴다. 반면 클래스 기본값은 피드백 gradient를 끊고 손실 가중치가 1:2이므로, 기본 생성자만 사용하면 제공 설정과 다른 실험이 된다.

완료 기준은 같은 토큰 수의 CE뿐 아니라 GPU-hours·최대 메모리·동일 예산 최종 품질을 함께 보고하는 것이다. 캐시 테스트는 각 스케줄 내부에서 수행하고, 고정 두 반복과 recurrent 결과의 원소별 동일성을 정답 기준으로 삼지 말자. 이번에는 테스트 코드를 실행하지 않았다.

**한계**

규모 확대는 700M·1.5B dense와 3B MoE까지다. 더 큰 모델의 효과는 미검증이며 소형 추론 지연 결과를 대형 서비스에 확대 해석하지 않는다. 최소 공개판은 MoE·hybrid handoff·기존 연구 checkpoint 변환을 포함하지 않는다. 전체 성능 재현에는 추가 공개물이 필요하다.

### 2. 한 프레임을 가르쳐 영상 편집을 바꾼다 — Improving and Expanding Video Editing Capabilities Without Videos

- **출처**: arXiv 원문 v1·I2VT 저자 프로젝트와 코드
- **점수**: 8.0/10 — 편집 선정 점수
- **URL**: https://arxiv.org/abs/2611.34941

**요약**

Ji Xie 등의 I2VT는 이미 학습된 영상 편집기를 이미지 편집 교사로 후학습한다. 학생은 한 장의 이미지를 한 프레임 영상처럼 편집하고, 자신의 잡음 제거 경로에서 교사의 예측을 따라간다. 추론 때는 교사를 버리고 전체 영상을 편집한다. ‘영상 없이’는 새 후학습 영상 쌍이 필요 없다는 의미이지 영상 사전학습이 필요 없다는 뜻이 아니다.

**방법론**

논문은 학생의 denoising 경로에서 교사의 velocity 예측을 맞춘다. Velocity는 잡음에서 깨끗한 잠재표현으로 이동하는 방향이다. 교사가 미리 만든 완성 이미지 쌍만 학습하는 offline distillation과 비교한다. 공개 `distillation_loss`는 교사 출력을 detach해 gradient를 차단하고, 기본값으로 velocity MSE를 계산한다.

구현은 clean-latent MSE·cosine 대안도 구분한다. 두 모델의 예측 형식과 텐서 크기를 맞추는 검사가 있어, 단순히 교사의 완성 그림을 정답 이미지로 넣는 코드와는 다르다. 세 학생은 Bernini-R-1.3B·14B와 VideoCoF이며, 공개된 결과물은 기반 모델에 얹는 LoRA다.

**주요 기여**

README는 17,227개 source image와 지시문·teacher edit로 된 I2VT-17K, 세 모델, OpenVE++를 안내한다. OpenVE++는 행동 73·표정 42·몸 움직임 42·조명 50개로 총 207개 클립이다. 학습과 평가 source clip을 분리했다고 명시한다. 이번 조회에서는 Hugging Face 데이터 본문이 열리지 않아 실제 파일·다운로드 상태는 검증하지 못했다.

**실험 결과**

공개 README의 공동 학습 결과에서 I2VT-14B는 OpenVE-Bench 3.33→3.58, OpenVE++ 2.30→3.77이다. 전자는 Gemini 2.5 Pro, 후자는 Gemini 3.8 Flash의 1–5점 판정이며 서로 다른 판정기의 숫자를 직접 비교하지 않는다. 별도의 기본 편집 전용 실험 Table 1의 3.68과 공동 학습 3.58도 다른 조건이다.

논문은 모델별 LoRA 후학습 200 step을 사용한다. VBench 시간 일관성 평가는 대체로 비슷하지만 모든 지표가 좋아지지는 않는다. Bernini-R-14B의 flickering 점수는 0.9788→0.9767로 하락한다. 따라서 “이미지 학습이 시간 일관성을 보장한다”는 결론은 과하다.

**맥락**

편집 해석: 비싼 영상 정답 쌍을 늘리는 대신 이미 강한 이미지 편집 능력을 활용하는 전이 학습이다. 기존 영상 모델의 시간적 능력을 유지하면서 편집 지시 준수를 개선하는 것이 목표다. 이미지에 없는 장시간 움직임의 인과관계까지 새로 학습했다는 증거로 보지는 않는다.

**실무 시사점**

영상 편집 연구팀은 같은 source clip·지시문·seed·sampler에서 base와 LoRA를 비교하자. README의 `--base`는 LoRA 없는 기반 모델을 실행하는 구분이다. 수정해야 할 영역뿐 아니라 보존할 배경과 인물 정체성도 사람이 가려서 검토하는 평가표를 만들면 좋다.

완료 기준은 지시 준수 향상과 함께 깜빡임·비대상 영역 훼손이 사전 허용 범위 안에 드는 것이다. 공개 자동 평가 경로는 Gemini 키를 요구한다. 이 뉴스레터에서는 이를 실행하지 않았고, 무과금 재현 계획이라면 로컬 지표·수동 비교를 사용하되 논문의 판정 점수를 재현했다고 주장하지 않아야 한다.

**한계**

세 기반 모델과 공유된 잠재표현을 쓰는 실험이므로 임의의 이미지·영상 모델 쌍에 그대로 적용된다고 단정할 수 없다. 자동 판정은 사람의 정답이 아니며 외부 도메인 검증이 필요하다. 코드의 Apache 2.0과 기반 가중치의 라이선스는 별개다. 저장소는 기반 가중치를 재배포하지 않으며 각 원저자의 조건을 따르도록 안내한다.
