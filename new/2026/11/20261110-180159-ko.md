**요약**

SSD는 문맥에 있는 지식을 모델 가중치에 내재화하는 자기증류 방법이다. 문맥을 받은 교사와 그렇지 않은 학생이 같은 응답을 함께 생성한다. 기본적으로 학생이 쓰고, 두 분포가 크게 다를 때 교사 토큰을 택한다. 공개 README는 Company Memo·Wikipedia·Science Q&A에서 on-policy 자기증류에 근접한 정확도를 더 적은 감독 토큰으로 얻었다고 설명한다.

**방법론**

핵심은 **선택적 감독이 아니라 선택적 생성 경로 교정**이다. 교사 분포와 증류 손실은 모든 응답 위치에서 계산한다. 교사 개입 임계값은 다음 토큰을 어느 모델이 생성할지 결정하며, 대부분 실험은 분포 차이를 재는 Jensen–Shannon divergence를 사용한다.

공개 Science Q&A 설정은 reverse-KL 스위칭, 임계값 1.0, 전체 위치 손실, 1,024토큰 생성 상한과 EMA 교사 갱신을 지정한다. 대표 설명을 임의로 복사하기보다 과제별 설정 파일을 고정해야 한다.

**주요 기여**

학생 자신의 경로만 따라갈 때와 교사 경로만 모방할 때의 절충을 토큰 단위로 조절한다. 구현 측면에서는 수정한 vLLM으로 교사와 학생을 동시 실행한다. 다만 추가 교사 계산을 없앤 방법은 아니다.

**실험 결과**

원문 표 1의 Science Q&A 비교다. 숫자는 저자 보고이며 정확도 구간은 95% 신뢰구간이다.

| 모델·평가 조건 | On-policy 정확도 / 감독 토큰 | SSD 정확도 / 감독 토큰 |
|---|---|---|
| Qwen3-4B, 각각 8·4 epoch, 학습 시드 3개 | 64.6±2.7 / 13.19M | 66.3±2.6 / 5.88M |

이 표의 토큰 감소는 55%다. 초록의 38–69%는 다른 비교 지점에 대한 요약이므로 혼용하지 않는다. 감독 토큰은 손실을 적용한 응답 위치의 누적 수이며 GPU 계산량 자체가 아니다.

**맥락**

README의 요구는 SSD에 80GB급 CUDA GPU 두 장, 기준선에는 한 장이다. 시간 개선을 비용 개선으로 바로 바꾸면 추가 장치를 빠뜨린다. 새 지식의 정확도만 보지 말고 기존 업무의 회귀 시험도 평가 계약에 넣어야 한다는 것이 편집부의 해석이다.

**실무 시사점**

- **대상**: 문서 기반 지식을 로컬 모델에 학습시키는 연구·플랫폼팀
- **방법**: 별도 검증셋에서 임계값을 선택하고 최종 시험셋은 남긴다. 동일 모델·데이터·생성 상한으로 SFT, on-policy, SSD를 비교해 정확도·GPU시간·최대 메모리·기존 업무 성능을 기록한다.
- **완료 기준**: 반복 시드에서 목표 정확도를 만족하고, 전체 GPU시간과 회귀 성능이 사전 예산·허용치 안에 들어오는지 보고한다.

읽기 순서는 원문 3.2 → 표 1·평가 프로토콜 → 부록의 한계 → README → 해당 YAML이다. README는 망각 연구, 14B 실험, 스위칭 제거실험과 신호 분석이 현재 배포에 포함되지 않는다고 명시한다. 기본 설정은 최종 가중치도 저장하지 않으므로 후속 재현 시 옵션을 확인해야 한다.

**한계**

연구의 중심은 비교적 짧은 closed-book QA다. 장기 추론으로의 일반화는 미해결이다. 논문은 held-out 점수로 하이퍼파라미터를 고른다고 명시하므로, 재현에서는 모델 선택용 검증과 최종 시험을 분리하는 것이 바람직하다. 코드 열람은 실행 검증이 아니며, 이번에는 모델·학습 스크립트·유료 API를 실행하지 않았다.
