## 이번 주 연구 동향

이번에는 다국어 번역과 사람 시연 기반 로봇 학습을 함께 읽는다. Hy-MT3는 번역 결과의 누락·오역·지시 위반을 구분하고, RoboCap-10k는 작업 영상에 머리·손의 3차원 좌표와 시간별 설명을 붙인다. 서로 다른 문제지만, 학습·평가에 사용할 라벨이 무엇인지 먼저 살펴야 한다는 편집상의 공통점이 있다.

번역 판정 모델의 점수는 사람의 절대 정답이 아니며, 손 좌표 추정치도 모든 현장에서 직접 측정한 정답은 아니다. 따라서 점수가 좋아졌다는 사실과 실제 시스템이 좋아질 것이라는 기대를 구분한다. 아래 분석은 논문의 조건·수치와 공개 자료를 읽은 결과이며 독립 실행이나 재현은 하지 않았다.

최근 30일 신작 아카이브 20개 보고서를 대조해 두 논문이 미수록임을 확인했다. 지난 호의 세계 모델·과학적 상태 추정과 겹치지 않도록 번역 평가와 로봇 데이터로 범위를 넓혔다. Hy-MT3는 오늘 뉴스 호에서 공개 소식을 다뤘지만, 여기서는 v2 원문의 절대 오류율·판정 조건을 중심으로 분석한다. 점수는 실측 성능이 아닌 편집 선정 점수다.

## 논문 분석

### 1. 유창함보다 충실성 — Hy-MT3: More Accurate, Robust and Practical Multilingual Translation Models in the Wild

- **출처**: arXiv 원문 v2·Tencent Hunyuan 공식 코드
- **점수**: 8.2/10 — 편집 선정 점수
- **URL**: https://arxiv.org/abs/2611.27673

**요약**

Tencent Hunyuan Team의 Hy-MT3는 1.8B·7B·30B-A3B 번역 모델과 TransRubric 평가 체계다. 102개 언어를 지원한다. TransRubric은 표본별 기준표에 따라 오류 유형과 점수를 내는 LLM 판정 방식이다. 핵심적으로 볼 것은 종합 순위보다 오류가 남아 있는 비율이다.

**방법론**

주 평가에는 DeepSeek-V4.1-Flash·Qwen3.5-397B-A17B 두 판정기의 평균을 사용한다. WildMTBench-202611은 10개 분야에 각 500개씩 총 5,000개 사례이며 참조 번역 없이 채점한다. Hy-MT3는 non-thinking 모드로 평가했다.

**주요 기여**

공개 TransRubric 저장소는 기준표 생성·보완·병합과 번역 판정 메시지 생성 코드를 제공한다. 확인한 함수는 입력을 검증하고 메시지를 구성하며, 스스로 판정 모델을 실행하는 엔진은 아니다. 결과에는 오류 유형·심각도와 점수를 구조화하도록 요구한다. 평가 자원을 공개한 것과 무료 판정 모델을 제공한 것은 구별해야 한다.

**실험 결과**

v2 Table 5에서 Hy-MT2-30B-A3B→Hy-MT3-30B-A3B의 평균 판정 점수는 83.62→91.30이다. 오역 포함 표본은 56.0%→31.8%, 누락·추가는 21.2%→5.5%, 지시 위반은 16.5%→9.8%다. 유형은 중복될 수 있다. 빈 출력·미채점도 고정 분모에서 0점 처리하므로, 성공 사례만의 평균으로 읽지 않는다.

**맥락**

편집 해석: “오역 43% 감소”만 읽으면 남은 오류 부담을 놓친다. 해당 평가에서 새 모델에도 오역으로 판정된 표본이 약 3분의 1 남는다. 번역을 사용자에게 바로 보여줄지, 사람이 편집할 초안으로 쓸지에 따라 유용성이 달라진다.

**실무 시사점**

번역·현지화 팀은 우선 의미 오류와 형식 위반을 분리한 평가표를 만들자. 고정된 자사 표본에서 기존 모델과 같은 입력 조건으로 비교하고, 자동 판정과 언어 검토자의 불일치를 따로 모은다. 완료 기준은 평균 점수뿐 아니라 중요 누락·변수 손상·용어 오류의 허용 수준을 충족하는 것이다.

공개 학습 안내에는 전체 미세조정·LoRA와 모델별 설정이 있다. LoRA만 저장한 파일과 기반 가중치를 혼동하지 말고, 데이터·프롬프트·리비전을 함께 기록해야 한다. 이 안내를 읽었다고 원 논문 모델의 모든 사전학습·후학습 과정을 재현한 것으로 보지는 않는다. 이번에는 코드 열람만 수행했다.

**한계**

판정 모델의 편향과 번역 기준의 적절성은 남는다. 같은 모델의 반복 채점이 사람들 사이의 의견보다 일관적이라고 해서 더 정확하다는 뜻은 아니다. 논문은 완전한 학습 레시피·데이터를 재현하는 보고서라기보다 모델·평가 결과 중심으로 읽어야 한다. 한국어 업무 품질은 별도 검증 대상이다.

### 2. 영상의 양보다 좌표 라벨의 의미 — RoboCap-10k: A Metrically Accurate Egocentric Dataset for Robot Learning

- **출처**: arXiv 원문 v1
- **점수**: 7.8/10 — 편집 선정 점수
- **URL**: https://arxiv.org/abs/2611.26916

**요약**

Kheri Hughes 등은 11개국의 실제 작업 중 수집한 10,000시간의 양손 조작 데이터를 제시한다. 같은 장치 모델의 카메라 여섯 대와 IMU 두 개를 사용한다. 보정·SLAM·손 추적으로 미터 단위 머리·손 좌표를 추정한다. 영상 규모뿐 아니라 라벨 품질을 검토할 자료라는 점이 중요하다.

**방법론**

SLAM은 카메라·관성 센서로 위치와 주변 구조를 함께 추정하는 방법이다. 여기에 다중 시점 손 추적과 작업·하위 작업 설명을 결합한다. 논문은 LeRobot v3 형식의 412개 shard와 CC BY 4.0 배포를 안내한다. 데이터 페이지·프로젝트 본문은 이번 조회에서 열리지 않아 실제 파일·현재 접근 조건은 검증하지 못했다.

**주요 기여**

일관된 장치와 보정 절차로 생성한 대규모 시연을 평가 대상으로 제시한다. 다만 데이터 공개와 처리 파이프라인 소스 공개는 같지 않다. 원문은 Grounded API를 사용하며, 이번 확인 범위에서는 그 전체 재현 코드를 확보하지 못했다. 로봇 학습 성능이 이미 입증된 모델 출시로 소개하지 않는다.

**실험 결과**

RoboMoCap의 153.4시간 검증에서 SE(3) 정렬 후 머리 궤적 ATE 중앙값은 3.0mm다. 별도 9.2분 손 검증의 PA-MPJPE는 4.5mm다. 후자는 회전·이동·스케일을 정렬한 관절 오차로, 현장 전체의 절대 손 위치 오차가 아니다. 이 데이터로 학습한 로봇 정책의 성공률 비교는 보고하지 않는다.

**맥락**

편집 해석: 사람 영상의 손 경로를 로봇 행동으로 옮기려면 좌표계뿐 아니라 로봇의 관절·도달 가능 영역도 맞춰야 한다. 따라서 대규모 시연은 정책 학습의 원료이지 곧바로 실행할 로봇 명령이 아니다. 데이터셋 이름의 시간 규모만으로 학습 효과를 예상하기 어렵다.

**실무 시사점**

시연 학습 팀은 접근이 가능해진 뒤 작은 표본에서 영상·좌표·설명의 시간 대응과 좌표 변환을 먼저 검사하자. 이후 동일 정책·동일 데이터 예산으로 기존 데이터와 혼합 효과를 비교하는 계획을 세운다. 완료 기준은 로딩 성공이 아니라 새 환경의 조작 성공·실패 유형·접촉 구간 오류를 함께 기록한 결과다.

데이터 확보를 전제로 일정부터 확정하지 않는 것이 좋다. 이번에는 접근 신청이나 다운로드를 하지 않았고, 가려진 파일 내용을 추정하지 않았다. 원문의 수치와 공개 상태 설명을 구별해 기록했다.

**한계**

좌표는 현장의 직접 측정 정답이 아닌 추정치다. 접촉 시 손가락 가림, 촉각·힘 정보 부재, 사람과 로봇의 형태 차이가 남는다. 설명의 10% 인적 검토는 파이프라인 조정용이지 배포 설명 전체를 사람이 수정했다는 뜻이 아니다.
