## 논문 분석

### 1. HALO — Perceptive Humanoid Motion from Simulation

- **출처**: Apple 연구진, arXiv v1
- **점수**: 8.5/10 (편집 선정 점수)
- **URL**: https://arxiv.org/abs/2611.06908
- **날짜**: 분석한 HTML v1 표기 2026-11-04; 발견 목록은 11월 5일자로 표시. 확인 2026-11-06.
- **발견 경로**: 최신 로보틱스 논문 검색 → 원문·저자 프로젝트
- **상태**: 프리프린트; 학회 채택으로 표시하지 않음

**요약**

HALO는 시뮬레이션에서 영상·언어·전신 동작의 짝을 만들어 휴머노이드를 학습한다. 천 개의 절차적 주택 환경을 사용한다. 고수준 과제 분해, 동작 생성, 저수준 추종을 분리한다. 실제 집을 미리 스캔하지 않는 전이를 평가했다.

**방법론**

동작 생성기는 시각·언어에서 계획을 만들고, 추종기는 깊이와 신체 상태를 이용해 실행한다. 전문가를 학생에게 증류할 때 학생이 방문하는 상태에도 감독을 제공하는 DAgger를 사용한다. 단순 모방 이후 강화학습으로 보정하는 단계가 이어진다.

**주요 기여**

데이터 생성과 물리 실행을 연결한 시스템이라는 점이 중요하다. 다만 ‘사람 없이 데이터 생성’은 과제 설계까지 자동이라는 뜻이 아니다.

**실험 결과**

저자 보고 단일 작업은 미관측 실제 환경 6곳에서 360회 시험해 평균 91%다. 반면 연속 작업은 실제 환경 1곳에서 평균 70%이며, 웅크리기→이동→밀기는 50%다. 단일 성공률을 긴 업무의 성공률로 쓰면 안 된다. 시뮬레이션 앉기 제거실험에서 깊이를 없애면 84%에서 74%로 하락했다. 기존 시스템 비교표는 데이터·환경이 달라 동일 조건 순위로 해석하지 않는다.

**맥락**

좋은 자세를 생성하는 것과 다음 작업에 유리한 위치에서 끝내는 것은 다르다. 로봇 평가팀에는 작업 경계의 상태도 평가 항목으로 삼을 이유가 된다.

**실무 시사점**

재현 담당자는 먼저 표 II의 단일·연속 작업 조건을 읽고, 제거실험과 구현 공개 상태를 확인하자. 향후 시험에서는 전환 시 목표가 시야에 남는지, 실패 후 탐색으로 복구하는지 기록한다. 완료 기준은 미관측 환경에서 전체 작업 성공률과 사람 개입을 함께 보고하는 것이다.

**한계**

과제 추가에는 사람의 프롬프트·키프레임 설계가 남고 접촉·가림에도 취약하다. 프로젝트에는 Code 문구가 있지만 이번 열람에서는 연결된 실행 저장소를 확인하지 못했다. 코드 공개·전체 재현 가능을 단정하지 않으며, 모델이나 로봇을 실행하지 않았다.
