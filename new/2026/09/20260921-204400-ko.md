## 이번 주 연구 동향

이번 주 논문들은 크게 두 가지 방향으로 수렴한다. 첫째는 AI 시스템의 '내면 상태(internal state)'를 어떻게 신뢰할 수 있게 해석하느냐의 문제이고, 둘째는 agent가 실제 환경에서 더 복잡한 행동을 수행할 수 있도록 benchmark와 학습 환경을 어떻게 확장하느냐의 문제다. 표면적으로는 interpretability, 음성 AI, 신경과학, computer-use agent라는 서로 다른 도메인처럼 보이지만, 그 저변에는 '모델이 실제로 무엇을 알고 무엇을 할 수 있는가'를 검증 가능한 방식으로 측정하려는 공통된 문제의식이 흐르고 있다.

방법론적으로 주목할 점은 여러 논문이 외부 레이블이나 reference model 없이 내부 신호만으로 평가를 수행하는 self-contained 설계를 채택하고 있다는 것이다. PIR은 labeled truth corpus 없이 intermediate layer의 activation 패턴만으로 숨겨진 지식을 탐지하고, RecreationWorld는 실행 중인 reference 애플리케이션을 oracle로 삼아 별도의 human annotation 없이 verifiable trajectory를 자동 생성한다. BrainWideBench 역시 단일 대규모 데이터셋을 공유 기반으로 삼아 across-animal transfer를 표준화된 방식으로 측정한다. 이처럼 '외부 감독 없이 내부 또는 환경 자체를 검증 신호로 활용하는' 패턴이 반복 등장한다는 점은 scalable evaluation의 핵심 트렌드로 읽힌다.

이 논문들이 남긴 과제는 명확하다. PIR은 모델이 지식을 숨기는 이유와 메커니즘까지는 설명하지 못하며, RecreationWorld의 hybrid agent는 out-of-distribution 환경에서의 일반화 한계가 아직 불분명하다. NemotronLabs VoiceChat의 full-duplex 설계는 실시간 latency와 tool-calling 정확도 사이의 trade-off를 완전히 해소하지 못했고, BrainWideBench는 across-animal transfer의 성능 격차 원인을 규명할 해석 도구가 부족하다. 결국 다음 스텝은 단순 성능 측정을 넘어 '왜 작동하는가'를 설명하는 mechanistic 이해로의 이동이 될 것이다.

ML 엔지니어 관점에서 가장 즉각적인 실무 시사점은 평가 파이프라인의 재설계다. PIR과 RecreationWorld 모두 기존 output-level 평가가 놓치는 신호를 내부 activation이나 환경 실행 결과로 보완한다는 점에서, 현재 팀이 운영하는 모델 평가 체계에 internal state probing 또는 execution-based verification 레이어를 추가하는 것이 단기적으로 높은 ROI를 가져올 수 있다.

### 1. A Lie Detector Test for Language Models: Reading Knowledge a Model Won't Reveal

- **출처**: arxiv
- **점수**: 7.5
- **URL**: http://arxiv.org/abs/2609.21996v1

**요약**

대형 언어 모델(LLM)은 실제로 알고 있는 지식을 의도적으로 숨기거나 잘못 보고할 수 있는데, 출력 결과만으로는 모델이 정말 모르는 것인지 숨기는 것인지 구별할 수 없다. 이 논문은 범죄 수사에서 사용되는 Concealed Information Test(CIT)를 LLM에 적용한 Probe of Internal Recognition(PIR)이라는 방법을 제안한다. PIR은 모델의 internal state를 직접 읽어 어떤 후보 답변을 모델이 '인식'하는지 탐지하며, 별도의 reference model이나 labeled 데이터 없이 동작한다. Gemma, Qwen, Llama, Mistral, Phi 등 5개 계열 8개 모델에서 0.70~0.87의 balanced accuracy를 달성했다.

**방법론**

핵심 아이디어는 범죄 심리학의 Concealed Information Test(CIT)를 차용하여, 모델이 진짜 정답을 '인식'할 때 internal state에서 나타나는 차별적 반응을 포착하는 것이다. 구체적으로, 질문과 여러 후보 답변(정답 1개 + 그럴듯한 decoy들)을 모델에 제시하고, 각 후보에 대한 intermediate layer의 activation 패턴을 probe로 분류하여 어느 후보가 모델 내부에서 '인식된 정답'으로 처리되는지 판별한다. 이 과정은 외부 레이블이나 honest reference model 없이 모델 자체의 internal representation만으로 수행된다.

**주요 기여**

1. 범죄 수사 기법인 Concealed Information Test를 LLM의 숨겨진 지식 탐지에 최초로 적용한 PIR(Probe of Internal Recognition) 프레임워크 제안
2. Reference model 및 labeled truth corpus 없이 동작하는 reference-free 설계로, 다양한 모델 계열(Gemma, Qwen, Llama, Mistral, Phi)에 걸쳐 범용성 검증
3. 출력 기반 평가만으로는 탐지 불가능한 sandbagging 및 지식 은폐 행동을 internal state 분석으로 식별할 수 있음을 실험적으로 입증

**실험 결과**

5개 계열 8개 모델 대상 실험에서 PIR은 balanced accuracy 0.70~0.87을 달성했으며, 이는 unknown-item baseline(0.28~0.40) 및 random chance(0.25)를 크게 상회한다. 모델이 실제로 알고 있는 항목에 대해서는 모르는 항목 대비 일관되게 높은 internal recognition 신호가 관측되었다.

**맥락**

LLM이 점점 강력해지면서 모델이 능력을 의도적으로 숨기는 'sandbagging' 문제나 내부 지식과 다른 답변을 출력하는 문제가 AI 안전성 연구에서 핵심 이슈로 부상하고 있다. 기존의 capability evaluation은 모델의 출력에만 의존하기 때문에, 모델이 전략적으로 낮은 성능을 보이거나 거짓 답변을 할 경우 이를 탐지할 수단이 없었다. 이 연구는 모델의 internal representation을 직접 분석함으로써 출력 기반 평가의 근본적 한계를 우회하려 한다.

**실무 시사점**

ML 엔지니어는 PIR을 모델 평가 파이프라인에 통합하여, 모델이 실제로 알고 있지만 출력하지 않는 지식을 탐지하는 보조 수단으로 활용할 수 있다. Reference model이나 labeled truth corpus가 필요 없는 reference-free 설계 덕분에, 새로운 도메인이나 proprietary 모델 평가에도 비교적 쉽게 적용 가능하다. 특히 sandbagging 탐지나 모델 정직성(honesty) 평가가 중요한 RLHF 후처리 단계 및 red-teaming 시나리오에서 실질적인 도구로 쓰일 수 있다.

**한계**

현재 결과는 white-box 접근(internal state 접근 가능)을 전제로 하므로, API를 통해서만 접근 가능한 closed-source 모델에는 직접 적용하기 어렵다. 또한 balanced accuracy 0.70~0.87은 고무적이지만 완벽하지 않으며, 모델이 internal state 수준에서도 전략적으로 표현을 조작할 경우 PIR의 신뢰성이 저하될 수 있다는 점은 미해결 과제로 남는다.

**관련 링크**

- http://arxiv.org/abs/2609.21996v1

### 2. NemotronLabs VoiceChat: An Open Full-duplex Speech-to-Speech Model with Tool Calling Capabilities

- **출처**: arxiv
- **점수**: 7.1
- **URL**: http://arxiv.org/abs/2609.21967v1

**요약**

NemotronLabs VoiceChat는 full-duplex 실시간 음성 대화를 지원하는 오픈 speech-to-speech 모델로, native tool-calling 기능을 갖추고 있습니다. streaming speech encoder와 decoder-only language model을 결합하고, agent text 및 structured function call을 위한 병렬 output stream, RNN-T 기반 실시간 전사 branch, streaming TTS decoder를 통합한 단일 아키텍처로 설계되었습니다. Full-Duplex-Bench 1.0에서 오픈 모델 중 가장 낮은 pause-handling takeover rate를 기록하고, 사용자 interruption 후 100% takeover 및 4.33/5의 응답 품질 점수를 달성했습니다.

**방법론**

핵심 아이디어는 streaming speech encoder와 decoder-only LM을 중심으로, agent text·structured function call·user transcription·TTS를 모두 단일 통합 아키텍처 안에서 병렬로 처리하는 것입니다. 사용자 발화를 실시간으로 처리하는 RNN-T auxiliary branch가 incremental transcription을 담당하고, 별도의 parallel output stream이 tool invocation을 위한 structured function call을 생성합니다. 이 설계를 통해 모델은 듣기·전사·추론·tool 호출·발화를 하나의 streaming pipeline 안에서 자연스러운 대화 타이밍을 유지하며 수행합니다.

**주요 기여**

1. Full-duplex 실시간 음성 대화와 native tool-calling을 단일 streaming 아키텍처로 통합한 최초의 오픈 모델 공개
2. RNN-T 기반 incremental transcription branch와 parallel structured function call output stream을 결합한 새로운 멀티스트림 아키텍처 설계
3. Full-Duplex-Bench 1.0/1.5에서 오픈 모델 중 최고 수준의 interruption 처리 성능(100% takeover rate, 93% backchannel 후 응답 재개) 달성

**실험 결과**

Full-Duplex-Bench 1.0: 오픈 모델 중 가장 낮은 pause-handling takeover rate, 사용자 interruption 후 100% takeover rate, post-interruption 응답 품질 4.33/5. Full-Duplex-Bench 1.5: user backchannel 후 93% 응답 재개율. VoiceBench: normalized average 55.1.

**맥락**

기존 음성 AI 시스템은 turn-based 방식으로 동작하여 자연스러운 대화 흐름을 방해하고, 사용자 interruption이나 backchannel 처리에 취약했습니다. Full-duplex 음성 대화 모델은 동시에 듣고 말할 수 있어야 하며, 여기에 tool-calling까지 통합하는 것은 기술적으로 매우 어려운 과제였습니다. 이 연구는 이러한 한계를 극복하고 실제 대화에 가까운 자연스러운 음성 AI agent를 오픈 모델로 구현하는 것을 목표로 합니다.

**실무 시사점**

ML 엔지니어는 이 모델의 병렬 output stream 설계(agent text + structured function call 동시 생성)를 참고하여 실시간 음성 agent 파이프라인을 구축할 수 있습니다. RNN-T 기반 incremental transcription branch와 streaming TTS decoder의 통합 방식은 latency에 민감한 프로덕션 환경에서 end-to-end 음성 시스템을 설계할 때 직접 적용 가능한 아키텍처 패턴을 제공합니다. 오픈 모델로 공개되어 있어 커스터마이징 및 도메인 특화 fine-tuning에 활용할 수 있습니다.

**한계**

논문의 abstract가 잘려 있어 VoiceBench 전체 결과 및 추가 benchmark 수치를 확인하기 어렵습니다. Full-duplex 환경에서의 tool-calling 정확도나 복잡한 multi-turn 시나리오에서의 성능 한계, 그리고 다국어 지원 여부에 대한 정보가 불명확합니다.

**관련 링크**

- http://arxiv.org/abs/2609.21967v1

### 3. BrainWideBench: Benchmarking large-scale pretraining and across-animal transfer in multi-region neural recordings

- **출처**: arxiv
- **점수**: 6.9
- **URL**: http://arxiv.org/abs/2609.22064v1

**요약**

BrainWideBench는 대규모 신경 기록 데이터를 활용한 across-animal transfer learning을 평가하기 위한 benchmark로, 139마리 마우스의 276개 뇌 영역에서 수집된 International Brain Laboratory Brainwide Map 데이터셋을 기반으로 구축되었다. 행동 decoding, masked/future neural activity prediction, 해부학적 조직 복원이라는 세 가지 task suite를 통해 학습된 neural representation의 범용성을 체계적으로 평가한다. 기존 연구들이 단편적인 evaluation protocol과 좁은 task 도메인에 집중했던 한계를 극복하고, large-scale pretraining이 다양한 downstream task에 전이 가능한 general-purpose neural representation을 학습할 수 있는지 종합적으로 검증하는 표준 framework를 제시한다.

**방법론**

핵심 아이디어는 단일 대규모 데이터셋(IBL Brainwide Map)을 공유 기반으로 삼아, across-animal transfer를 세 가지 complementary task suite로 동시에 평가하는 통합 benchmark framework를 구축하는 것이다. 구체적으로 (1) 행동 변수 decoding, (2) masked 또는 future neural activity prediction, (3) 해부학적 뇌 영역 조직 복원이라는 task를 통해 pretrained model이 생물학적으로 의미 있는 representation을 학습했는지 다각도로 검증한다. 이를 통해 pretraining 규모와 downstream task 성능 간의 관계를 체계적으로 분석할 수 있는 표준 evaluation protocol을 제공한다.

**주요 기여**

1. 139마리 마우스, 276개 뇌 영역을 포괄하는 IBL Brainwide Map 기반의 최초 across-animal transfer benchmark인 BrainWideBench를 공개함.
2. 행동 decoding, neural activity prediction, 해부학적 조직 복원이라는 세 가지 complementary task suite를 통해 neural representation의 범용성을 다각도로 평가하는 표준 framework를 제시함.
3. 기존 단편적 evaluation protocol의 한계를 극복하고, large-scale pretraining이 neuroscience downstream task에 미치는 영향을 체계적으로 분석할 수 있는 공개 benchmark 및 평가 인프라를 제공함.

**맥락**

대규모 신경 기록 기술의 발전으로 수백 개의 뇌 영역과 수많은 동물에 걸친 데이터 수집이 가능해졌으나, 이 데이터 규모를 실제로 활용해 범용 neural representation을 학습할 수 있는지 검증할 통일된 evaluation framework가 부재했다. 기존 연구들은 단일 동물 또는 단일 뇌 영역에 국한된 좁은 평가 방식을 사용해 across-animal transfer 능력을 제대로 측정하지 못했으며, 이로 인해 neuroscience AI 분야의 진전이 단편적으로 이루어졌다.

**실무 시사점**

ML 엔지니어는 BrainWideBench를 통해 자신이 개발한 neural foundation model의 across-animal transfer 성능을 표준화된 방식으로 평가하고 타 모델과 직접 비교할 수 있다. 행동 decoding, neural activity prediction, 해부학적 구조 복원이라는 세 가지 complementary task suite는 모델의 representation quality를 다각도로 검증하므로, pretraining 전략 설계 및 ablation study 계획 수립에 실질적인 가이드라인을 제공한다.

**한계**

현재 benchmark는 단일 행동 패러다임(감각 기반 의사결정 과제)에서 수집된 데이터에 국한되어 있어, 다양한 행동 맥락에서의 generalization 능력을 평가하기 어렵다. 또한 마우스 단일 종에 한정된 데이터셋이므로 cross-species transfer 능력은 평가 범위 밖에 있다.

**관련 링크**

- http://arxiv.org/abs/2609.22064v1
- https://github.com/int-brain-lab/paper-brain-wide-map

### 4. RecreationWorld: Scalable and Verifiable Environments for Hybrid Computer-Use Agents

- **출처**: arxiv
- **점수**: 6.9
- **URL**: http://arxiv.org/abs/2609.22000v1

**요약**

RecreationWorld는 GUI 조작과 코드 작성을 동시에 수행하는 'hybrid computer-use agent(CUA)'를 위한 새로운 benchmark 및 학습 환경 프레임워크입니다. 기존 CUA 연구가 GUI 탐색 또는 코드 작성 중 하나에만 집중했던 것과 달리, 이 연구는 두 능력을 유기적으로 결합한 agent를 평가하고 훈련합니다. 핵심 아이디어는 'recreation': agent가 실행 중인 reference 애플리케이션을 관찰하고, 그 동작을 스스로 파악하여 동일하게 작동하는 구현체를 만들어내는 것입니다. Ubuntu, macOS, Windows, Android, Web 등 5개 플랫폼을 지원하며, 생성된 trajectory로 훈련된 모델은 5개의 out-of-distribution benchmark에서 성능 향상을 보였습니다.

**방법론**

핵심 아이디어는 실행 중인 reference 애플리케이션을 oracle로 삼아 agent가 동작을 역공학(reverse-engineer)하고 동일하게 작동하는 구현체를 만드는 'recreation' 패러다임입니다. Agent는 GUI를 탐색하며 동작을 파악하고, 코드를 작성·실행하며, 결과를 시각적으로 검증하는 세 단계를 자율적으로 결정합니다. 생성된 trajectory는 hidden behavioral test를 통해 execution-grounded reward로 평가되며, 이를 통해 scalable한 고품질 학습 데이터를 확보합니다.

**주요 기여**

1. GUI 조작과 코드 작성을 동시에 평가하는 최초의 hybrid CUA framework인 RecreationWorld를 제안하고, Ubuntu·macOS·Windows·Android·Web 5개 플랫폼을 지원하는 재현 가능한 환경을 구축함.
2. 실행 중인 reference 애플리케이션을 oracle로 활용하는 'recreation' 패러다임을 도입해 처방된 workflow 없이 execution-grounded reward를 제공하는 검증 메커니즘을 설계함.
3. 오픈소스 애플리케이션 기반의 scalable trajectory 생성 파이프라인을 통해 훈련된 모델이 5개의 out-of-distribution benchmark에서 성능 향상을 달성함을 실증함.

**실험 결과**

RecreationWorld로 생성된 trajectory로 훈련된 모델이 5개의 out-of-distribution computer-use benchmark에서 성능 향상을 보였다고 보고되었으나, 논문 content가 잘려 구체적인 수치는 확인되지 않음.

**맥락**

LLM 기반 CUA는 웹 브라우징이나 GUI 자동화, 혹은 터미널 코딩 중 하나에 특화되어 발전해 왔으나, 실제 디지털 업무는 두 능력을 번갈아 사용해야 합니다. 기존 benchmark는 이런 hybrid 시나리오를 평가하지 못했고, 검증 가능한 reward 신호도 부족했습니다. RecreationWorld는 실행 가능한 reference 애플리케이션을 oracle로 활용해 execution-grounded reward를 제공함으로써 이 공백을 메웁니다.

**실무 시사점**

ML 엔지니어는 RecreationWorld의 unified harness를 활용해 native GUI control과 coding tool이 결합된 agent를 동일한 환경에서 훈련·평가할 수 있습니다. 오픈소스 애플리케이션 기반의 scalable trajectory 생성 파이프라인을 통해 대규모 학습 데이터를 자동으로 확보할 수 있으며, 5개 플랫폼 지원으로 cross-platform agent 개발에 바로 적용 가능합니다.

**한계**

논문의 content가 일부 잘려 있어 전체 실험 결과 및 모델 세부 사항을 확인하기 어렵습니다. 또한 'recreation' 태스크 설계 특성상 reference 애플리케이션의 품질과 다양성에 평가 신뢰도가 크게 의존한다는 한계가 있습니다.
