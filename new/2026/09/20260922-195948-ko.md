## 이번 주 연구 동향

이번 주 논문들은 표면적으로는 computer-use agent, uncertainty estimation, 로봇 조작, 병리 영상 분석이라는 서로 다른 도메인을 다루지만, 공통적으로 '실전 배포 가능한 AI'를 향한 두 가지 핵심 질문을 던진다. 첫째, 모델이 실제로 얼마나 잘 작동하는가를 어떻게 정확히 측정할 것인가(평가 신뢰성), 둘째, 제한된 자원과 접근 권한 안에서 어떻게 성능을 끌어올릴 것인가(효율과 신뢰)가 그것이다.

방법론적으로는 두 가지 패턴이 반복 등장한다. 하나는 '분해(decomposition)'다. OSWorld-Pro는 long-horizon task를 subgoal 체인으로 분해해 평가하고, SLICEChat은 기가픽셀 이미지를 progressive token pruning으로 단계적으로 압축한다. DexTacWAM 역시 각 손가락의 tactile 신호를 독립적으로 encoding한 뒤 집계하는 구조를 택한다. 다른 하나는 '외부화(externalization)'다. Pinocchio는 black-box LLM의 내부 상태 없이 외부 calibrator만으로 uncertainty를 추정하고, DexTacWAM은 촉각을 단순 conditioning이 아닌 예측 대상 world state로 끌어올려 감각 정보를 모델 외부에서 내부로 통합한다.

이 논문들이 남긴 과제는 명확하다. subgoal 단위 평가가 정교해질수록 annotation 비용과 LLM-Judge의 신뢰도 간 트레이드오프가 커지고, zero-shot transfer를 표방하는 uncertainty calibrator는 도메인 시프트에 얼마나 강건한지 아직 충분히 검증되지 않았다. 또한 tactile world model과 token pruning 기반 multimodal 압축 모두 실제 임상·산업 환경의 노이즈와 분포 변화에 대한 robustness 연구가 뒤따라야 한다.

실무 시사점은 하나로 압축된다. closed-source API를 프로덕션에서 사용하는 팀이라면 Pinocchio 방식의 external uncertainty calibrator를 응답 필터링 레이어로 즉시 도입할 수 있다. log-probability 접근 없이 단일 forward pass로 AUROC 0.86 수준의 신뢰도 점수를 얻는다는 것은, 별도 모델 교체나 fine-tuning 없이 hallucination 리스크를 줄이는 가장 빠른 경로가 될 수 있다.

### 1. OSWorld-Pro: Process-based Evaluation for Computer Use Agents

- **출처**: arxiv
- **점수**: 7.4
- **URL**: http://arxiv.org/abs/2609.24890v1

**요약**

OSWorld-Pro는 Computer-Use Agent(CUA)를 최종 결과물이 아닌 중간 과정(subgoal) 단위로 평가하는 새로운 benchmark이다. 300개 이상의 task와 2,800개 이상의 subgoal, 67,000개 이상의 human annotation을 기반으로 구축되었으며, LLM-Judge를 활용해 각 단계의 달성 여부를 평가한다. 최신 SOTA 모델조차 이 benchmark에서 낮은 성능을 보여, 기존 end-state 평가 방식이 agent의 실제 능력을 과대평가하고 있음을 드러낸다.

**방법론**

핵심 아이디어는 CUA의 long-horizon task를 순차적으로 의존하는 subgoal 체인으로 분해하고, 각 subgoal의 달성 여부를 human annotation과 정렬된 LLM-Judge로 자동 평가하는 것이다. 300개 이상의 task를 2,800개 이상의 subgoal로 세분화하고, 67,000개 이상의 human annotation을 수집해 LLM-Judge의 판단 기준을 calibration하였다. 이를 통해 agent가 전체 task를 완료하지 못하더라도 중간 단계에서의 진척도와 실패 패턴을 정량적으로 측정할 수 있다.

**주요 기여**

1. 300개 이상의 task와 2,800개 이상의 subgoal로 구성된 process-based CUA evaluation benchmark인 OSWorld-Pro를 최초로 제안.
2. 67,000개 이상의 human annotation을 기반으로 human-aligned LLM-Judge를 구축하여 subgoal 단위의 자동화된 평가 파이프라인을 제공.
3. End-state 평가만으로는 드러나지 않는 agent의 단계별 실패 유형(keyboard input 오류, click precision 오류 등)을 체계적으로 분석할 수 있는 진단 프레임워크 제시.

**실험 결과**

SOTA LLM 기반 CUA도 OSWorld-Pro에서 낮은 성능을 기록하며 기존 end-state benchmark 대비 훨씬 도전적인 난이도임을 확인하였으나, 논문 원문이 일부 잘려 구체적인 수치(정확한 성공률 등)는 확인되지 않음.

**맥락**

기존 OSWorld 등의 CUA evaluation은 수백 단계의 작업 끝에 생성된 최종 결과물만을 functional verifier로 평가하여, agent가 어느 단계에서 왜 실패했는지 파악하기 어렵다. 예를 들어 keyboard input 오류와 GUI click 정밀도 오류는 전혀 다른 개선 전략을 필요로 하지만, end-state 평가만으로는 이를 구분할 수 없다. Process-based evaluation에 대한 수요가 높아지는 시점에서, 세밀한 진단 도구의 부재가 CUA 연구의 병목이 되고 있다.

**실무 시사점**

ML 엔지니어는 OSWorld-Pro의 subgoal 단위 평가 체계를 활용해 자사 agent의 실패 지점을 단계별로 진단하고, keyboard input, click precision 등 구체적인 취약 영역에 맞는 targeted fine-tuning 또는 mitigation 전략을 수립할 수 있다. LLM-Judge 기반의 human-aligned 평가 파이프라인은 새로운 CUA 개발 시 자동화된 process-level evaluation 인프라로 바로 참고할 수 있다.

**한계**

논문 본문이 일부 잘려 있어 최종 수치 결과의 전체 범위를 확인하기 어려우며, LLM-Judge의 평가 신뢰도가 task 도메인이나 복잡도에 따라 달라질 수 있다는 점은 주의가 필요하다. 또한 subgoal 설계 자체가 human annotation에 크게 의존하므로, 새로운 task 유형으로의 확장성에 한계가 있을 수 있다.

**관련 링크**

- http://arxiv.org/abs/2609.24890v1
- https://os-world.github.io

### 2. Pinocchio: Fast Uncertainty Estimates for Black-Box Language Models

- **출처**: arxiv
- **점수**: 7.2
- **URL**: http://arxiv.org/abs/2609.24881v1

**요약**

Pinocchio는 black-box LLM API의 응답 정확성을 외부에서 추정하는 uncertainty calibrator입니다. log-probability나 fine-tuning 접근 없이도 단일 forward pass만으로 uncertainty estimate를 생성할 수 있으며, 7개 LLM으로 학습 후 13개의 미공개 모델에 zero-shot transfer가 가능합니다. 핵심 결과로 held-out 모델 응답 정확성 예측에서 0.862 AUROC를 달성했습니다.

**방법론**

핵심 아이디어는 target LLM의 내부 상태에 접근하지 않고 입력 질문과 모델 응답 텍스트만을 이용해 응답 정확성을 예측하는 external calibrator를 학습하는 것입니다. 7개 LLM의 응답 데이터를 joint training에 활용하여 모델 불가지론적(model-agnostic) representation을 학습하며, inference 시에는 단일 forward pass만으로 uncertainty score를 출력합니다. 이를 통해 logit, weight, internal state 접근 없이도 black-box API 환경에서 동작하는 lightweight calibration이 가능합니다.

**주요 기여**

1. Black-box LLM API 환경(log-probability·fine-tuning 접근 불필요)에서 동작하는 최초의 external uncertainty calibrator인 Pinocchio를 제안.
2. 7개 LLM joint training을 통해 8개 기관의 13개 미공개 모델에 대한 zero-shot transfer 능력을 실증(held-out 모델 기준 0.862 AUROC 달성).
3. 단일 forward pass로 uncertainty estimate를 생성하는 lightweight 구조로 실시간 프로덕션 환경에서의 실용성을 확보.

**실험 결과**

held-out 응답 정확성 예측: AUROC 0.862 (7개 LLM joint training 기준). 13개 미공개 모델(8개 기관)에 대한 zero-shot transfer에서도 유효한 성능을 보고.

**맥락**

GPT 계열을 포함한 다수의 산업용 LLM API는 log-probability를 반환하지 않고 fine-tuning도 허용하지 않아, 기존 uncertainty estimation 방법론을 적용할 수 없습니다. 의료·법률·금융 등 high-stakes 도메인에서는 모델 예측의 신뢰도 정량화가 필수적이므로, black-box 환경에서도 동작하는 uncertainty estimation 기법의 필요성이 급증하고 있습니다.

**실무 시사점**

ML 엔지니어는 GPT, Claude 등 closed-source API를 사용하는 프로덕션 파이프라인에 Pinocchio를 plug-in 형태로 추가해 별도 모델 수정 없이 응답 신뢰도 점수를 얻을 수 있습니다. 단일 forward pass로 동작하는 lightweight 구조 덕분에 latency 오버헤드가 최소화되어 실시간 서비스에도 적용 가능하며, zero-shot transfer 특성 덕분에 새로운 모델이 출시되더라도 재학습 없이 바로 활용할 수 있습니다.

**한계**

논문이 공개한 내용이 일부 잘려 있어 전체 architecture 세부 사항과 실패 케이스 분석이 불분명합니다. 또한 7개 LLM으로 학습된 calibrator가 도메인 분포가 크게 다른 태스크나 비영어권 언어에서도 동일한 transfer 성능을 보장하는지는 추가 검증이 필요합니다.

**관련 링크**

- http://arxiv.org/abs/2609.24881v1

### 3. DexTacWAM: A Visuo-Tactile World-Action Model for Dexterous Manipulation

- **출처**: arxiv
- **점수**: 6.9
- **URL**: http://arxiv.org/abs/2609.24976v1

**요약**

DexTacWAM은 시각 정보만으로는 포착하기 어려운 접촉 역학(contact dynamics)을 모델링하기 위해 촉각(tactile) 센서를 통합한 World-Action Model(WAM)입니다. 각 손가락 끝의 촉각 정보를 독립적으로 encoding하고, finger- 및 pose-aware tactile compressor로 집계한 뒤, video diffusion world model에 주입하여 시각-촉각 joint world modeling을 수행합니다. 22-DoF bimanual 플랫폼에서 6가지 contact-rich dexterous manipulation task를 평가한 결과, 평균 성공률 70.6%로 가장 강력한 baseline의 38.0%를 크게 상회하는 SOTA 성능을 달성했습니다.

**방법론**

핵심 아이디어는 촉각 정보를 world model의 conditioning 신호가 아닌 예측 대상 world state의 일부로 통합하는 것입니다. 각 손가락 끝의 tactile 데이터를 독립적으로 encoding한 후, finger identity와 손가락 pose를 인식하는 tactile compressor로 집계하여 tactile latent를 생성합니다. 이 latent를 video diffusion world model에 주입함으로써 시각과 촉각을 jointly 예측하는 visuo-tactile world modeling을 구현하고, 예측된 world state를 기반으로 action을 생성합니다.

**주요 기여**

1. 촉각 정보를 단순 conditioning이 아닌 예측 대상 world state로 통합한 최초의 visuo-tactile World-Action Model(WAM) 제안
2. 손가락별 독립 encoding과 finger- 및 pose-aware tactile compressor를 결합한 새로운 tactile feature aggregation 아키텍처 설계
3. 22-DoF bimanual 플랫폼에서 6가지 contact-rich dexterous manipulation task에 대한 종합 benchmark 구축 및 평균 70.6% vs. baseline 38.0%의 SOTA 성능 달성

**실험 결과**

22-DoF bimanual 플랫폼의 6가지 contact-rich dexterous manipulation task 전체에서 SOTA 달성: DexTacWAM 평균 70.6% vs. 최강 baseline 38.0%. Ablation study에서 tactile world modeling 제거 시 4-task 평균이 74.7%에서 26.6%로 급락하여, tactile world modeling의 기여가 결정적임을 확인.

**맥락**

Dexterous manipulation에서 접촉 정보는 task 성공의 핵심이지만, 기존 vision-centric World-Action Model들은 이를 직접 모델링하지 못해 contact-rich 작업에서 한계를 보였습니다. 최근 video diffusion 기반 world model과 action generation을 결합한 WAM 패러다임이 주목받고 있으나, 촉각 정보를 world state 예측에 통합한 연구는 거의 없었습니다. 이 연구는 촉각 센서를 단순 conditioning 신호가 아닌 예측 대상 world state의 일부로 모델링함으로써 이 공백을 메웁니다.

**실무 시사점**

ML 엔지니어는 tactile 센서 데이터를 video diffusion world model에 통합하는 finger-aware compressor 설계 패턴을 로봇 조작 파이프라인에 바로 참고할 수 있습니다. 특히 촉각을 단순 conditioning이 아닌 예측 대상 world state로 포함시키는 것이 성능에 결정적임을 ablation study가 명확히 보여주므로, 멀티모달 world model 설계 시 이 원칙을 우선 적용할 수 있습니다. 22-DoF bimanual 플랫폼 기반의 6가지 contact-rich benchmark는 향후 dexterous manipulation 연구의 평가 기준으로도 활용 가능합니다.

**한계**

논문은 22-DoF bimanual 플랫폼이라는 특정 하드웨어 환경에서만 검증되어 다른 로봇 플랫폼으로의 일반화 가능성이 불확실합니다. 또한 tactile 센서 노이즈나 실제 배포 환경에서의 센서 신뢰성 문제에 대한 분석이 제한적입니다.

**관련 링크**

- http://arxiv.org/abs/2609.24976v1

### 4. SLICEChat: Progressive In-Encoder Token Pruning for Whole-Slide Pathology Language Models

- **출처**: arxiv
- **점수**: 6.9
- **URL**: http://arxiv.org/abs/2609.24894v1

**요약**

Whole-slide pathology image(WSI)는 기가픽셀 규모의 시각 정보를 담고 있어 slide-level multimodal large language model(MLLM) 적용 시 심각한 연산 부담을 초래한다. SLICEChat은 hybrid Mamba-Transformer slide encoder 내부에 progressive token pruning을 통합하여, multimodal fusion 이전에 compact한 slide representation을 생성하는 새로운 접근법을 제안한다. Language-supervised, region-aware pruning을 통해 공간적으로 연속된 저유용 영역을 단계적으로 제거하며, SlideBench VQA benchmark에서 TCGA 79.84%, BCNB 59.09% 정확도로 기존 slide-level pathology MLLM을 능가하는 성능을 달성했다.

**방법론**

핵심 아이디어는 slide encoder 내부에서 token 수를 단계적으로 줄여 multimodal fusion 전에 이미 compact한 representation을 확보하는 것이다. Mamba layer가 효율적인 long-range 정보 전파를 담당하고, Transformer layer가 줄어든 sequence에서 global attention을 수행하며, 두 stage 사이에 language supervision 신호를 활용한 region-aware pruning이 공간적으로 연속된 저유용 영역을 controlled keep-rate schedule에 따라 제거한다.

**주요 기여**

1. Hybrid Mamba-Transformer slide encoder 내부에 progressive token pruning을 통합한 최초의 slide-level MLLM 아키텍처 SLICEChat 제안
2. Language-supervised, region-aware pruning 메커니즘을 통해 multimodal fusion 이전에 공간적으로 coherent한 저유용 영역을 단계적으로 제거하는 방법론 제시
3. SlideBench VQA benchmark에서 TCGA 및 BCNB cohort 모두에서 기존 slide-level pathology MLLM 대비 SOTA 성능 달성

**실험 결과**

SlideBench VQA benchmark 기준: TCGA cohort 79.84% accuracy, BCNB cohort 59.09% accuracy로 기존 slide-level pathology MLLM 전체를 능가하며 SOTA 달성.

**맥락**

WSI 기반 병리 분석은 수천 개의 patch token을 처리해야 하므로 기존 MLLM의 attention 연산이 극도로 비효율적이며, 대부분의 기존 방법은 slide encoding 이후에만 compression을 적용해 multimodal attention 단계에서 여전히 높은 연산 비용이 발생한다. Mamba 계열 모델이 long-sequence 처리에 강점을 보이면서 병리 이미지처럼 초고해상도 입력을 다루는 분야에서 hybrid architecture에 대한 관심이 높아지고 있으며, token pruning을 encoder 내부에 통합하는 방식이 실질적인 효율화 경로로 주목받고 있다.

**실무 시사점**

ML 엔지니어는 SLICEChat의 in-encoder progressive token pruning 전략을 참고하여, 긴 sequence를 다루는 의료 영상 또는 문서 이해 모델에서 multimodal fusion 이전 단계에 compression을 삽입하는 설계 패턴을 적용할 수 있다. Mamba layer로 long-range dependency를 효율적으로 전파하고 Transformer layer로 global interaction을 보존하는 hybrid 구조는 고해상도 입력을 처리하는 다양한 도메인에서 재사용 가능한 backbone 설계 원칙을 제공한다.

**한계**

논문에서 제시된 keep-rate schedule은 태스크와 데이터셋에 따라 별도 튜닝이 필요할 수 있으며, WSI 외 다른 초고해상도 도메인으로의 일반화 가능성은 추가 검증이 필요하다. 또한 arxiv 버전 기준으로 ablation study의 범위와 다양한 압축률에서의 성능 트레이드오프가 충분히 공개되지 않은 점은 실무 적용 시 주의가 필요하다.
