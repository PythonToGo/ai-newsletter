## 이번 주 연구 동향

이번 주 논문들은 공통적으로 'AI agent가 환경과 어떻게 상호작용하며 행동을 형성하는가'라는 질문을 중심으로 수렴한다. 단일 모델의 성능 개선을 넘어, agent가 shared context, harness, 협업 구조 속에서 어떤 집단적·구조적 행동 패턴을 만들어내는지가 핵심 연구 축으로 부상하고 있다. Copying 메커니즘으로 설명되는 자발적 집단 행동, on-policy correction으로 극복하는 distribution mismatch, 역할 분리로 해결하는 false confidence 문제, 그리고 whole-body navigation의 end-to-end 제어까지—모두 agent가 환경 신호를 어떻게 내면화하고 행동으로 변환하는지를 탐구한다.

방법론적으로는 두 가지 흐름이 반복 등장한다. 첫째는 역할 분리(role decomposition)다. ExecCritic의 Test/Repair agent 분리, TANGO의 planning-generation-editing-tracking 파이프라인, harness evolution과 fine-tuning의 단계적 분리가 모두 이 패턴을 따른다. 둘째는 on-policy 데이터의 중요성이다. Imitation learning이 evolved harness 환경에서 역효과를 낸다는 발견은, 강한 모델의 trajectory를 그대로 따르는 것이 아니라 weaker model 자신의 rollout 기반 correction이 필수임을 실증한다. Shared context가 agent 행동에 직접 편향을 유발한다는 copying 연구 역시 같은 맥락—환경 분포가 학습 분포를 결정한다는 원칙—을 현실 데이터로 뒷받침한다.

이 논문들이 남긴 과제는 명확하다. Agent가 shared environment에서 형성하는 집단 행동은 설계자의 의도를 벗어날 수 있으며, 이를 사전에 감지하거나 제어하는 메커니즘은 아직 미성숙하다. Harness와 모델을 co-evolve시키는 방법론도 초기 단계이며, 어떤 순서와 비율로 진화시켜야 최적인지는 열린 문제로 남는다. Humanoid navigation의 sim-to-real gap 역시 해결되지 않은 핵심 병목이다.

실무 ML 엔지니어에게 가장 즉각적인 시사점은 harness 설계가 모델 학습보다 먼저라는 점이다. Agent 시스템을 구축할 때 harness를 먼저 충분히 진화시킨 뒤 fine-tuning에 진입해야 하며, 이때 반드시 weaker model 자신의 on-policy rollout을 학습 데이터로 활용해야 한다. 강한 모델의 trajectory를 imitation하는 손쉬운 방법은 evolved harness 환경에서 오히려 성능을 크게 저하시킬 수 있다.

### 1. Copying explains the collective behavior of AI agents in the wild

- **출처**: arxiv
- **점수**: 7.6
- **URL**: http://arxiv.org/abs/2609.09150v1

**요약**

2026년 6월, 수천 개의 AI agent들이 외부 지시 없이 자발적으로 공개 wiki를 활용해 서로 협력하는 집단 행동을 보였다. 이 논문은 그 완전한 기록을 분석하여, agent의 세 가지 핵심 결정(어디에 쓸지, 이름을 뭐라 할지, 어떻게 표현할지)이 단 하나의 규칙으로 설명됨을 밝혔다. 그 규칙은 'copying'으로, agent는 자신이 현재 보고 있는 페이지에서 각 선택지가 차지하는 비율에 비례하여 해당 선택지를 선택한다. 단일 free parameter를 가진 세 개의 minimal copying model이 관찰된 집단 행동을 재현하는 데 성공했다.

**방법론**

핵심 아이디어는 agent의 선택 확률이 현재 보이는 페이지 내 해당 선택지의 비율(share)과 일치한다는 'copying' 가설이다. 세 가지 결정(위치, 이름, 표현)에 대해 각각 single free parameter를 가진 minimal copying model을 구성하고, 실제 wiki 편집 기록과의 적합도를 검증했다. 시간적 가중치 분석을 통해 최근 편집 스트림이 오래된 기록보다 훨씬 강하게 행동에 영향을 미침을 확인했다.

**주요 기여**

1. 수천 개의 AI agent가 자발적으로 협력한 최초의 in-the-wild 대규모 집단 행동 데이터셋을 공개하고 분석함.
2. Agent의 다양한 결정이 단일한 copying 규칙으로 통합 설명될 수 있음을 실증적으로 입증함.
3. 각각 single free parameter만을 가진 세 개의 minimal copying model이 관찰된 집단 행동 패턴을 성공적으로 재현함을 보임.

**실험 결과**

세 개의 minimal copying model(각각 single free parameter)이 위치 선택, 이름 선택, 표현 방식 선택에 대한 실제 agent 행동 분포를 재현하는 데 성공했으며, 현재 페이지 내 share가 가장 강한 예측 변수로 확인되었고 오래된 편집 기록의 영향은 미미했음.

**맥락**

AI agent가 대규모로 실제 환경에서 어떻게 집단 행동을 형성하는지에 대한 실증적 데이터는 극히 드물었다. 기존 연구는 주로 통제된 실험실 환경에서 이루어졌으나, 이 사례는 수천 개의 agent가 자연 발생적으로 협력한 유일무이한 in-the-wild 기록을 제공한다. 특히 각 agent가 작성 전 무엇을 보았는지까지 보존된 데이터는 인과적 분석을 가능하게 한다는 점에서 매우 희귀하다.

**실무 시사점**

AI agent 시스템을 설계하거나 배포하는 ML 엔지니어는 agent가 공유 환경(wiki, 메시지 스트림 등)에서 의도치 않은 집단 행동을 형성할 수 있음을 고려해야 한다. Copying 메커니즘은 단순하지만 강력하므로, agent가 접근하는 shared context의 내용이 agent 행동에 직접적인 편향을 유발할 수 있다는 점을 모니터링 및 안전 설계에 반영해야 한다. 또한 단일 free parameter의 minimal model이 복잡한 집단 행동을 설명할 수 있다는 점은 agent 행동 예측 모델링의 단순화 가능성을 시사한다.

**한계**

이 연구는 단일 사건(특정 wiki, 특정 timed test 환경)에서 수집된 데이터에 기반하므로 일반화 가능성이 제한적일 수 있다. 또한 각 agent의 내부 추론 과정이나 model architecture에 대한 정보 없이 행동 패턴만으로 copying을 추론했기 때문에, 메커니즘의 인과적 해석에는 주의가 필요하다.

**관련 링크**

- http://arxiv.org/abs/2609.09150v1

### 2. TANGO: Humanoid Navigation in Cluttered Environments with a Whole-Body Vision-Language-Action Model

- **출처**: arxiv
- **점수**: 7.0
- **URL**: http://arxiv.org/abs/2609.09158v1

**요약**

TANGO는 복잡한 실내 환경에서 휴머노이드 로봇이 자연어 명령을 따라 이동할 수 있도록 설계된 최초의 whole-body vision-language navigation framework입니다. 기존의 2D path planning 방식과 달리, TANGO는 팔 위치, 상체 조정, 보행 변조 등 29-DoF joint-space action을 직접 예측하여 3D 공간에서 충돌 없이 이동합니다. 전적으로 시뮬레이션에서 학습되며, global path planning, kinematic whole-body motion generation, obstacle-aware motion editing, RL-based tracking을 결합한 파이프라인으로 다양한 traversal behavior를 합성합니다. 시뮬레이션에서 학습된 정책이 실제 휴머노이드 로봇에 zero-shot으로 전이되는 성능을 보여줍니다.

**방법론**

핵심 아이디어는 자연어 명령과 egocentric RGB 관측을 입력으로 받아 29-DoF joint-space action을 직접 예측하는 end-to-end vision-language-action model을 구축하는 것입니다. 시뮬레이션에서 global path planning으로 충돌 없는 경로를 생성하고, kinematic whole-body motion generation과 obstacle-aware motion editing으로 다양한 traversal behavior를 합성한 뒤, RL-based tracking으로 동역학적으로 실현 가능한 action supervision을 제공합니다. 이렇게 학습된 정책은 별도의 실제 데이터 없이 zero-shot으로 실제 휴머노이드 로봇에 전이됩니다.

**주요 기여**

1. 자연어 명령 조건부 휴머노이드 whole-body navigation을 위한 최초의 vision-language-action framework인 TANGO를 제안.
2. Global path planning, kinematic motion generation, obstacle-aware motion editing, RL-based tracking을 통합한 시뮬레이션 전용 학습 파이프라인을 설계하여 실제 데이터 없이 다양한 traversal behavior 학습 가능.
3. 학습된 정책의 실제 휴머노이드 로봇으로의 zero-shot sim-to-real transfer를 실증하여 복잡한 실내 환경에서의 whole-body 적응 능력을 검증.

**맥락**

휴머노이드 로봇의 실내 내비게이션은 단순한 2D 경로 계획을 넘어, 좁은 공간과 장애물이 가득한 환경에서 팔·몸통·다리를 통합적으로 제어해야 하는 매우 어려운 문제입니다. 기존 vision-language navigation 연구는 주로 바퀴형 로봇이나 단순화된 이동 모델을 대상으로 했기 때문에, 복잡한 3D 기하 구조에 적응하는 whole-body 제어 능력이 부족했습니다. 대규모 언어·비전 모델의 발전과 함께 자연어 조건부 로봇 제어에 대한 관심이 높아지면서, 휴머노이드에 특화된 통합 framework의 필요성이 대두되었습니다.

**실무 시사점**

ML 엔지니어는 TANGO의 시뮬레이션 전용 학습 파이프라인(global path planning → kinematic motion generation → obstacle-aware editing → RL tracking)을 참고하여 실제 데이터 없이도 복잡한 로봇 제어 정책을 학습하는 방법론을 실무에 적용할 수 있습니다. Vision-language model을 action prediction에 직접 연결하는 구조는 언어 조건부 로봇 제어 시스템 설계 시 유용한 아키텍처 참고 사례가 됩니다. 또한 sim-to-real transfer 전략은 데이터 수집 비용이 높은 휴머노이드 로봇 연구 외에도 다양한 embodied AI 프로젝트에 적용 가능합니다.

**한계**

논문의 학습이 전적으로 시뮬레이션에 의존하기 때문에, 시뮬레이션과 현실 간의 domain gap으로 인한 sim-to-real transfer 성능 저하 가능성이 존재합니다. 또한 29-DoF whole-body 제어의 복잡성으로 인해 매우 동적이거나 예측 불가능한 실제 환경에서의 일반화 능력은 추가 검증이 필요합니다.

**관련 링크**

- http://arxiv.org/abs/2609.09158v1

### 3. Co-Evolving Harnesses and Models: On-Policy Correction Helps Weaker Models Catch Up Where Imitation Fails

- **출처**: arxiv
- **점수**: 6.9
- **URL**: http://arxiv.org/abs/2609.09134v1

**요약**

Agent harness(시스템 프롬프트, 툴셋, 실행 훅, context 관리 scaffold)는 agentic task 성공의 핵심 결정 요소다. 이 논문은 harness evolution과 lightweight fine-tuning을 어떻게 결합해야 하는지를 탐구하며, evolved harness 환경에서 강한 모델의 trajectory를 imitation하면 오히려 성능이 퇴보한다는 역설적 현상을 발견했다. 반면 on-policy correction 방식(weaker model 자신의 rollout에서 expert가 수정한 데이터로 학습)을 사용하면 7개 enterprise agent task 모두에서 성능이 회복되고 향상된다. 이 연구는 harness와 model weight를 함께 co-evolve하는 새로운 패러다임을 제시한다.

**방법론**

핵심 아이디어: evolved harness 환경에서 imitation learning은 distribution mismatch로 인해 역효과를 내며, weaker model 자신의 on-policy rollout에 expert correction을 적용하는 방식이 이를 해결한다. 구체적으로 weaker model로 harness를 먼저 진화시킨 후, weaker model의 실제 rollout trajectory를 수집하고 stronger expert가 이를 수정한 데이터로 fine-tuning하는 on-policy correction 방식을 적용한다. 이 접근법은 imitation이 전달하지 못하는 evolved scaffold와 model behavior 간의 alignment 문제를 해결한다.

**주요 기여**

1. Evolved harness 환경에서 expert trajectory imitation이 7개 task 전체에서 4~30점 성능 퇴보를 유발한다는 역설적 현상을 발견하고 분석함.
2. On-policy correction(weaker model의 rollout 기반 expert 수정 데이터 학습)이 이 퇴보를 극복하고 성능을 회복·향상시킴을 실증함.
3. Harness evolution과 on-policy fine-tuning을 순차적으로 결합하는 co-evolution 프레임워크를 제안하여, smaller model이 frontier 모델 수준에 근접할 수 있는 실용적 경로를 제시함.

**실험 결과**

7개 enterprise agent task에서 evolved harness 위 imitation learning 적용 시 Qwen3-Coder와 Gemma 4 모두 4~30점 성능 퇴보 발생. 반면 on-policy correction 적용 시 동일 7개 task에서 성능 회복 및 향상 확인. Unevolved harness 환경에서는 동일한 imitation 절차가 성능 향상에 기여함을 대조 실험으로 확인.

**맥락**

LLM 기반 agent 시스템에서 frontier 모델 대비 저비용의 smaller model을 domain-specific task에 활용하려는 수요가 급증하고 있다. 기존 접근법은 harness 최적화와 model fine-tuning을 독립적으로 다루었으나, 두 요소가 상호작용하는 방식에 대한 이해가 부족했다. 특히 evolved harness 환경에서 imitation learning이 왜 실패하는지, 그리고 어떤 대안이 효과적인지에 대한 체계적 분석이 없었다.

**실무 시사점**

ML 엔지니어는 evolved harness 위에서 stronger model의 trajectory를 그대로 imitation하는 방식을 피해야 하며, 대신 weaker model 자신의 on-policy rollout을 기반으로 expert correction을 적용하는 방식을 채택해야 한다. Harness를 먼저 진화시킨 후 on-policy correction으로 fine-tuning하는 순차적 co-evolution 파이프라인은 frontier 모델 비용의 일부로 comparable한 성능을 달성하는 실용적 경로가 될 수 있다.

**한계**

실험이 7개의 enterprise agent task에 한정되어 있어 더 광범위한 도메인에서의 일반화 가능성은 검증되지 않았다. 또한 harness evolution 자체의 자동화 방법론과 on-policy correction의 expert 개입 비용에 대한 상세한 분석이 부족하다.

**관련 링크**

- http://arxiv.org/abs/2609.09134v1

### 4. ExecCritic: Learn to Test, Test to Improve for Coding Agents

- **출처**: arxiv
- **점수**: 6.9
- **URL**: http://arxiv.org/abs/2609.09133v1

**요약**

ExecCritic는 코딩 에이전트가 소프트웨어 버그를 수정할 때 발생하는 '테스트와 패치가 함께 틀리는' 문제를 해결하기 위한 프레임워크입니다. Test agent와 Repair agent를 분리하여 각자 독립적으로 학습시키고, test-verify-revise scaffold를 통해 테스트가 올바른 행동을 검증하도록 강제합니다. role-specific reinforcement learning을 적용해 Test agent는 올바른 패치와 잘못된 패치를 구별하는 테스트를 생성하도록, Repair agent는 해당 테스트의 execution feedback을 기반으로 소스 코드를 수정하도록 각각 훈련됩니다. SWE-bench Verified benchmark에서 기존 방법 대비 유의미한 성능 향상을 달성했습니다.

**방법론**

핵심 아이디어는 테스트 생성과 소스 코드 수정을 독립된 두 agent로 역할 분리하여, 테스트가 패치의 오류에 오염되지 않도록 하는 것입니다. Test agent는 repository-native 테스트를 생성하고, fail-closed harness가 이를 검증·동결한 뒤, Repair agent는 동결된 테스트의 execution feedback만을 신호로 소스 코드를 수정합니다. 각 agent는 role-specific reinforcement learning으로 별도 훈련되며, Test agent는 'Learn to Test(올바른 패치와 잘못된 패치를 구별하는 테스트 생성)', Repair agent는 'Test to Improve(execution feedback 기반 코드 수정)' 목표로 최적화됩니다.

**주요 기여**

1. test-verify-revise scaffold: Test agent와 Repair agent를 구조적으로 분리하고 fail-closed harness로 테스트를 검증·동결하여 false confidence 문제를 해결하는 새로운 파이프라인 설계
2. role-specific reinforcement learning 레시피: 'Learn to Test'와 'Test to Improve' 두 가지 독립적인 RL 학습 목표를 정의하여 각 agent를 특화 훈련하는 방법론 제시
3. SWE-bench Verified benchmark에서의 성능 향상: Qwen-3.5-35B-A3B backbone 기반으로 기존 단일 에이전트 방식 대비 코드 수정 정확도를 개선하는 실증적 결과 제공

**실험 결과**

SWE-bench Verified benchmark에서 ExecCritic를 적용한 결과, 기존 단일 에이전트 기반 execution feedback 방식 대비 repository 버그 수정 성공률이 향상되었다고 보고됩니다. 다만 arxiv preprint v1 기준으로 구체적인 수치(예: resolve rate %)는 논문 본문 전체 공개 이후 확인이 필요합니다.

**맥락**

LLM 기반 코딩 에이전트가 GitHub issue를 자동으로 수정하는 연구가 활발하지만, 에이전트가 패치와 테스트를 동시에 생성할 경우 두 결과물이 같은 방향으로 틀려 false confidence를 만드는 구조적 문제가 있습니다. Execution feedback은 강력한 학습 신호이지만, 테스트 자체가 잘못된 behavioral target을 인코딩하면 오히려 에이전트를 잘못된 방향으로 유도합니다. 이 연구는 테스트 생성과 코드 수정을 역할 분리(role separation)함으로써 이 근본적인 신뢰성 문제를 해결하려 합니다.

**실무 시사점**

ML 엔지니어는 단일 에이전트가 테스트와 패치를 모두 생성하는 파이프라인 대신, Test agent와 Repair agent를 분리하고 fail-closed harness로 테스트를 검증·동결하는 scaffold 구조를 실무 코딩 에이전트 시스템에 적용할 수 있습니다. role-specific reinforcement learning 레시피는 Qwen-3.5-35B-A3B 같은 오픈소스 backbone에도 적용 가능하므로, 자체 코드 수정 에이전트를 훈련할 때 참고할 수 있는 실용적인 학습 프레임워크를 제공합니다.

**한계**

논문이 공개한 내용이 arxiv preprint 초기 버전으로, Repair agent의 학습 결과 및 전체 ablation study 세부 수치가 아직 완전히 공개되지 않았을 수 있습니다. 또한 두 agent를 별도로 훈련하는 방식은 inference 비용과 파이프라인 복잡도를 증가시키며, 실제 대규모 repository에서의 일반화 성능은 추가 검증이 필요합니다.
