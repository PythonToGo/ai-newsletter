## 이번 주 연구 동향

이번 주 논문들은 표면적으로 서로 다른 도메인을 다루지만, 공통적으로 '현재 시스템이 실제로 무엇을 이해하고 있는가'라는 근본적 질문을 던진다. embedding retrieval의 surface-form bias 연구는 RAG 파이프라인이 의미적 구조를 진짜로 파악하지 못한다는 사실을 드러내고, SFT-RL annotation budget 연구는 post-training의 최적화 전략이 생각보다 훨씬 robust한 near-optimal 영역 위에 놓여 있음을 보여준다. 두 연구 모두 '정밀한 최적해'보다 '실질적 작동 범위'를 탐구하는 방향으로 수렴한다.

방법론적으로는 controlled benchmark 설계와 surrogate 근사라는 두 가지 접근이 반복 등장한다. retrieval bias 연구는 surface form과 structure를 의도적으로 분리한 benchmark로 모델의 실제 능력을 해부하고, SK-Wasserstein 연구는 Sierpiński-Knopp space-filling curve를 통해 고비용 2D optimal transport를 O(N log N) 1D sorting으로 환원한다. Facet-0 역시 flow matching 기반 joint action-wrench prediction으로 contact-rich 환경을 surrogate wrench signal로 근사하는 구조를 취한다. 각기 다른 문제지만 '복잡한 현실을 다루기 쉬운 공간으로 매핑'하는 전략이 핵심이다.

이 논문들이 남긴 과제는 명확하다. retrieval 시스템의 structural understanding을 높이려면 lexical overlap을 넘어서는 새로운 embedding 학습 패러다임이 필요하고, SFT-RL near-optimal 영역이 task 복잡도나 데이터 분포 변화에도 안정적인지는 아직 검증이 부족하다. 로봇 분야에서는 force/torque 신호를 foundation model 수준으로 일반화하는 데이터 수집 체계가 병목으로 남아 있다.

실무 ML 엔지니어에게 가장 직접적인 시사점은 SFT-RL budget 연구에서 나온다. 대형 모델에 대한 exhaustive ratio 탐색 대신, 소형 proxy 모델로 near-optimal 영역을 먼저 식별한 뒤 대형 모델에 이식하는 전략은 annotation 비용을 즉시 절감할 수 있는 실용적 레시피다. 모델 규모가 커질수록 이 영역이 넓어진다는 empirical 발견은, 리소스가 제한된 팀일수록 더 유리하게 활용할 수 있는 scaling 특성이다.

### 1. Retrieved but not ranked: surface-form bias in structural retrieval, from mathematics to agent trajectories

- **출처**: arxiv
- **점수**: 7.0
- **URL**: http://arxiv.org/abs/2609.01556v1

**요약**

이 논문은 embedding retrieval 시스템이 의미적 구조(structure)가 아닌 표면적 단어 형태(surface form)에 과도하게 의존한다는 문제를 체계적으로 분석합니다. 연구팀은 수학 경시대회 문제(MathNet-Retrieve)와 embodied agent trajectory(ALFWorld 기반) 두 도메인에서, 표면 형태와 의미를 의도적으로 분리한 retrieval benchmark를 구축하여 평가를 수행했습니다. 결과적으로 최신 production embedding 모델들은 수학 도메인에서 가장 어려운 disguise tier 기준 Hit@1 0.0%를 기록했으며, trajectory 도메인에서도 hypergeometric chance 수준 이하의 성능을 보였습니다. 이는 현재 embedding 모델들이 literal token에 anchor되어 있으며 진정한 구조적 이해에 실패하고 있음을 보여줍니다.

**방법론**

핵심 아이디어는 surface form과 underlying structure를 의도적으로 분리한 controlled benchmark를 구축하여, embedding model이 진짜로 구조를 이해하는지 lexical overlap에 의존하는지를 측정하는 것입니다. 수학 도메인에서는 동일한 수학적 구조를 가진 문제를 다른 표현(변수명, 문맥 변경 등)으로 disguise하는 여러 tier를 설계했고, trajectory 도메인에서는 동일한 task 구조를 다른 object/receptacle 조합으로 표현한 ALFWorld trajectory를 활용했습니다. 두 도메인 모두 동일한 평가 protocol 하에서 여러 production embedding 모델과 lexical reranker를 비교 분석했습니다.

**주요 기여**

1. Surface form과 structure를 의도적으로 분리한 두 개의 새로운 retrieval benchmark(MathNet-Retrieve: 500 queries, 117,088-item corpus; ALFWorld-derived: 118 queries, 336 trajectories)를 공개했습니다.
2. 최신 production embedding 모델들이 structural retrieval에서 완전히 실패함을 정량적으로 입증했습니다 — 수학 도메인 최고 난이도 tier에서 Hit@1 0.0%, trajectory 도메인에서 chance 수준 이하.
3. 95% 이상의 오류 케이스에서 모델이 정답보다 lexically similar한 오답을 선택한다는 surface-form bias의 메커니즘을 분석하고, lexical reranker가 이 문제를 오히려 악화시킬 수 있음을 보였습니다.

**실험 결과**

수학 도메인(MathNet-Retrieve): 가장 어려운 disguise tier에서 production embedding 모델들의 strict Hit@1 = 0.0% (bootstrap 95% CI [0.0, 0.0]). 그러나 정답 항목은 거의 항상 top 10 안에 존재함. 오류의 95.2~99.8%에서 모델이 정답보다 lexically similar한 항목을 1위로 선택. Trajectory 도메인(ALFWorld-derived): gold trajectory가 다른 object를 포함해야 할 때 세 embedding 모델 모두 hypergeometric chance 수준에 도달하거나 그 이하로 하락. object와 receptacle 모두 달라야 하는 조건에서는 모든 세 모델이 chance 이하 성능 기록.

**맥락**

RAG(Retrieval-Augmented Generation) 파이프라인과 agent memory 시스템이 널리 사용되면서, retrieval의 품질이 downstream task 성능에 직접적인 영향을 미치게 되었습니다. 기존 embedding retrieval 연구는 주로 paraphrase나 semantic similarity에 초점을 맞췄지만, 표면 형태가 달라도 동일한 구조를 가진 항목을 찾는 structural retrieval 능력은 충분히 평가되지 않았습니다. 이 연구는 surface-form bias가 단순한 성능 저하가 아니라 완전한 실패(complete failure)임을 두 개의 독립적인 도메인에서 동시에 입증함으로써 문제의 심각성을 부각시킵니다.

**실무 시사점**

RAG 파이프라인이나 agent memory 시스템을 구축하는 ML 엔지니어는 현재 production embedding 모델(OpenAI, Cohere 등)이 구조적으로 유사하지만 표현이 다른 항목을 찾는 데 근본적으로 실패할 수 있음을 인지해야 합니다. 특히 수학 문제 풀이, 코드 retrieval, task planning 등 structural similarity가 중요한 도메인에서는 lexical overlap 기반 reranker를 추가해도 문제가 해결되지 않으며 오히려 악화될 수 있습니다. 이 논문의 benchmark를 활용해 자신의 retrieval 시스템이 surface-form bias에 얼마나 취약한지 직접 진단해볼 수 있습니다.

**한계**

이 연구는 두 도메인(수학, embodied agent trajectory)에만 한정되어 있어 다른 structural retrieval 시나리오로의 일반화 가능성이 불분명하며, surface-form bias를 해결하기 위한 구체적인 방법론을 제시하지 않고 문제 진단에 초점을 맞추고 있습니다.

**관련 링크**

- http://arxiv.org/abs/2609.01556v1

### 2. Facet-0: A Robotic Foundation Model for Contact-Rich Precise Manipulation

- **출처**: arxiv
- **점수**: 6.9
- **URL**: http://arxiv.org/abs/2609.01596v1

**요약**

Facet-0는 sub-millimeter 수준의 정밀 조립 작업을 위한 robotic foundation model로, 로봇의 행동이 유발하는 contact(접촉) 결과를 예측하고 평가하는 능력을 핵심으로 한다. action chunk와 미래의 wrist-wrench profile을 동시에 생성하는 joint action-wrench proposal 방식을 사용하며, flow matching과 reinforcement learning(RL) post-training을 결합해 정밀 조립에 필요한 compliant interaction을 학습한다. 실험 결과, 기존 방법 대비 contact-rich 조립 task에서 유의미한 성능 향상을 달성했으며, 새로운 부품에 대한 on-robot adaptation도 경량화된 구조로 지원한다.

**방법론**

핵심 아이디어는 action chunk와 미래 wrist-wrench profile을 함께 예측하는 joint action-wrench proposal로, contact 결과를 policy 학습의 중심에 놓는 것이다. causal wrench history를 vision-language semantics 및 kinematic state와 align한 multimodal representation을 학습하고, flow matching으로 action과 예상 wrench를 동시에 생성한다. 이후 실제 배포 rollout 데이터로 distributional Action-Wrench Critic을 학습하고, phase-aware reward와 contact-selective credit assignment로 RL post-training을 수행하며, 새로운 부품 적응 시에는 frozen representation 위에 lightweight bounded actor만 추가로 학습한다.

**주요 기여**

1. action chunk와 미래 wrist-wrench profile을 동시에 생성하는 joint action-wrench proposal 프레임워크를 제안하여, contact 결과 예측을 robotic foundation model에 통합함.
2. distributional Action-Wrench Critic, phase-aware reward, contact-selective credit assignment를 결합한 RL post-training 방법론을 설계하여 정밀 조립에서의 policy 개선을 집중적으로 달성함.
3. frozen representation을 재활용하는 lightweight bounded actor 구조로, 새로운 부품에 대한 효율적인 on-robot adaptation을 가능하게 함.

**실험 결과**

논문 본문이 일부만 제공되어 구체적인 수치 benchmark 결과는 확인되지 않음. sub-millimeter tolerance 조립 task에서 기존 방법 대비 contact failure robustness 및 task success rate 향상을 보고하나, 정확한 수치는 전문(full paper) 확인 필요.

**맥락**

산업용 로봇 조립은 sub-millimeter 수준의 공차(tolerance)와 복잡한 contact dynamics를 요구하지만, 기존 robotic foundation model들은 시각·언어 정보 위주로 학습되어 force/torque(힘/토크) 피드백을 제대로 활용하지 못했다. 특히 contact failure(접촉 실패) 상황에서의 robustness와 compliant interaction 능력이 부족해 실제 정밀 조립 환경에 적용하기 어려웠다. Facet-0는 이러한 gap을 메우기 위해 wrench(힘·토크) 정보를 foundation model의 핵심 modality로 통합하는 새로운 접근을 제안한다.

**실무 시사점**

ML 엔지니어는 flow matching 기반의 joint action-wrench prediction 구조를 참고해, force/torque sensor 데이터를 기존 vision-language 기반 robot policy에 통합하는 방법론을 실무에 적용할 수 있다. distributional Action-Wrench Critic과 phase-aware reward 설계는 contact-rich task에서의 RL fine-tuning 전략으로 바로 활용 가능하며, frozen representation 위에 lightweight bounded actor를 얹는 구조는 새로운 부품·환경에 대한 효율적인 on-robot adaptation 파이프라인으로 응용할 수 있다.

**한계**

논문의 on-robot adaptation 및 RL post-training 결과가 특정 조립 부품과 환경에 국한되어 있어, 다양한 산업 현장으로의 일반화 가능성은 추가 검증이 필요하다. 또한 causal wrench history 정렬과 flow matching 기반 생성 과정의 계산 비용이 실시간 배포 환경에서 병목이 될 수 있다는 점도 주목해야 한다.

**관련 링크**

### 3. Scaling Near-Optimal SFT-RL Annotation Budget Allocation from Small to Large LLMs

- **출처**: arxiv
- **점수**: 6.9
- **URL**: http://arxiv.org/abs/2609.01573v1

**요약**

LLM post-training 시 고정된 annotation budget을 supervised fine-tuning(SFT)과 reinforcement learning(RL)에 어떻게 배분할지는 아직 해결되지 않은 문제다. 이 논문은 단일 최적 비율 대신 '근사 최적(near-optimal) 영역'—peak performance 대비 일정 tolerance(2~10%) 이내의 allocation 집합—을 특성화하는 새로운 프레임워크를 제안한다. 핵심 발견은 이 near-optimal 영역이 모델 규모가 커질수록 넓어지고, 소형 proxy 모델에서 찾은 영역이 대형 target 모델로 신뢰성 있게 전이된다는 것이다. 이를 통해 소형 모델 실험만으로 대규모 탐색 없이 효율적인 budget allocation 전략을 도출할 수 있다.

**방법론**

핵심 아이디어는 SFT-RL annotation budget 배분 문제를 단일 최적점 탐색이 아닌 'near-optimal 영역' 특성화 문제로 재정의하는 것이다. 소형 proxy 모델에서 다양한 SFT-RL ratio를 실험하여 peak performance 대비 일정 tolerance 이내의 allocation 집합을 식별하고, 이 영역이 대형 target 모델로 전이되는지를 empirical하게 검증한다. 실험은 여러 task, model family, preference-based 및 outcome-based RL 설정에 걸쳐 수행되어 결과의 일반성을 확인한다.

**주요 기여**

1. SFT-RL budget allocation을 near-optimal 영역 관점에서 재정의하는 원칙적 framework 제안
2. Near-optimal 영역이 모델 규모가 커질수록 넓어진다는 empirical 발견—대형 모델일수록 정밀한 ratio 탐색이 덜 필요함
3. 소형 proxy 모델에서 찾은 near-optimal 영역이 대형 target 모델로 신뢰성 있게 전이됨을 다양한 task·model family에서 실증, 대규모 탐색 비용 절감 전략 제시

**실험 결과**

Near-optimal tolerance를 2~10%로 설정했을 때 해당 영역이 충분히 넓어 실용적 적용이 가능함을 여러 task와 model family에서 확인. 소형 proxy 모델에서 식별한 near-optimal 영역을 대형 모델에 적용했을 때 peak performance 대비 tolerance 이내의 성능을 일관되게 달성. 구체적인 절대 수치는 task별로 다르며 논문 본문의 실험 섹션에 상세 기재됨.

**맥락**

LLM post-training에서 SFT와 RL의 annotation budget 배분은 실무적으로 매우 중요하지만, 기존 연구는 'low-data regime에서는 SFT가 유리하다'는 수준의 broad trend만 제시했을 뿐 원칙적인 framework가 없었다. 특히 소형 모델에서 찾은 최적 비율이 대형 모델에도 적용 가능한지는 검토된 바 없어, 대규모 모델마다 비용이 큰 탐색 실험을 반복해야 하는 문제가 있었다.

**실무 시사점**

ML 엔지니어는 대형 모델에 대한 exhaustive SFT-RL ratio 탐색 대신, 소형 proxy 모델 실험으로 near-optimal 영역을 먼저 파악한 뒤 대형 모델에 적용하는 전략으로 annotation 비용을 크게 절감할 수 있다. Near-optimal 영역이 충분히 넓기 때문에 정확한 최적점을 찾지 않아도 실용적으로 충분한 성능을 달성할 수 있으며, 이 전략은 다양한 task와 model family에 걸쳐 일관되게 작동한다.

**한계**

논문이 다루는 near-optimal tolerance(2~10%)의 기준이 task마다 달라질 수 있으며, 극단적으로 대규모 모델(예: 수백B 파라미터)에서의 전이 가능성은 추가 검증이 필요하다. 또한 preference-based RL과 outcome-based RL 모두를 다루지만, 특정 도메인이나 매우 희소한 reward 환경에서의 일반화는 미확인 상태다.

**관련 링크**

- http://arxiv.org/abs/2609.01573v1

### 4. Sierpiński--Knopp Wasserstein Distance for Persistence Diagrams and Applications to 2-Wasserstein Approximation

- **출처**: arxiv
- **점수**: 6.9
- **URL**: http://arxiv.org/abs/2609.01528v1

**요약**

이 논문은 persistence diagram 간의 거리를 빠르게 계산하기 위한 Sierpiński-Knopp (SK) Wasserstein distance를 제안한다. Sierpiński-Knopp space-filling curve를 이용해 2D diagram point들을 1D 구간으로 인코딩한 뒤, O(N log N) 복잡도의 1차원 optimal assignment로 매칭을 수행한다. 이 거리는 고전적인 2-Wasserstein distance를 upper bound하며, Hilbert space로의 isometric embedding과 positive-definite Gaussian kernel을 허용해 kernel 기반 머신러닝 파이프라인과 직접 호환된다. 12개의 과학 데이터셋 실험에서 기존 방법 대비 우수한 속도와 경쟁력 있는 정확도를 보였다.

**방법론**

핵심 아이디어는 persistence diagram의 upper diagonal triangle 위 point들을 Sierpiński-Knopp space-filling curve로 단위 구간 [0,1]에 순서 보존적으로 인코딩하여, 2D 매칭 문제를 1D sorting 기반 optimal assignment로 환원하는 것이다. 인코딩된 1D point set 간의 매칭은 정렬 후 순서대로 대응시키는 방식으로 O(N log N)에 수행되며, diagonal projection(소멸 처리)도 명시적으로 고려된다. 이 assignment를 기반으로 더 정밀한 surrogate dissimilarity W_Γ도 추가로 정의된다.

**주요 기여**

1. Sierpiński-Knopp space-filling curve를 활용한 O(N log N) persistence diagram 거리 d_SK 제안 및 이것이 2-Wasserstein distance를 control함을 이론적으로 증명
2. d_SK가 Hilbert space로의 isometric embedding을 허용하고 positive-definite Gaussian kernel을 유도함을 보여, kernel 기반 머신러닝과의 직접 호환성 확보
3. point assignment를 활용한 tighter surrogate dissimilarity W_Γ 도입 및 12개 과학 데이터셋에서의 실험적 검증

**실험 결과**

12개의 과학 데이터셋(논문에서 'scientific co-' 로 시작하는 컬렉션)에서 실험을 수행하였으며, SK-Wasserstein distance는 기존 Wasserstein 근사 방법 대비 O(N log N)의 계산 효율을 달성하면서 경쟁력 있는 분류/회귀 정확도를 보였다. 구체적인 수치는 논문 전문 접근이 제한되어 확인되지 않았으나, surrogate W_Γ가 d_SK보다 2-Wasserstein에 더 근접한 근사를 제공함이 실험적으로 확인되었다.

**맥락**

Topological Data Analysis(TDA)에서 persistence diagram은 데이터의 위상적 특징을 요약하는 핵심 도구이지만, 두 diagram 간의 Wasserstein distance 계산은 일반적으로 O(N^3) 이상의 복잡도를 요구해 대규모 데이터에 적용하기 어렵다. 또한 기존 근사 방법들은 Hilbert space embedding이나 positive-definite kernel 구조를 보장하지 않아 표준 머신러닝 방법론과의 통합이 제한적이었다. 이 연구는 이러한 계산 병목과 기하학적 비호환성을 동시에 해결하려는 동기에서 출발한다.

**실무 시사점**

SK-Wasserstein distance는 O(N log N) 복잡도와 positive-definite kernel 구조를 동시에 제공하므로, TDA 기반 feature를 SVM, Gaussian Process, kernel PCA 등 표준 kernel 방법에 바로 연결할 수 있다. 실무에서 persistence diagram을 feature로 사용하는 파이프라인에서 기존 Wasserstein 계산을 SK 거리로 대체하면 대규모 데이터셋에서도 실용적인 속도를 기대할 수 있다. 추가로 제안된 surrogate dissimilarity W_Γ는 더 타이트한 근사를 제공해 정밀도가 중요한 응용에 활용 가능하다.

**한계**

SK 거리는 space-filling curve 인코딩 과정에서 2D 위상 정보의 일부가 손실될 수 있으며, 2-Wasserstein distance에 대한 upper bound는 보장하지만 tight한 근사 품질은 diagram의 구조에 따라 달라질 수 있다. 논문에서 다루는 실험이 12개 데이터셋에 한정되어 있어 더 다양한 도메인에서의 일반화 성능은 추가 검증이 필요하다.
