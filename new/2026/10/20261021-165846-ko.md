## 이번 주 연구 동향

이번 호의 두 논문은 에이전트 시스템의 서로 다른 병목을 다룬다. SAPD는 이미 기록된 상호작용을 재사용해 실행 환경을 다시 호출하지 않고 에이전트를 학습시키는 방법을 제안한다. RoboJudge는 로봇 행동 영상을 평가할 때 단순 화질이나 프레임 유사도가 아니라 물리적 타당성과 지시 이행을 사람이 판단하는 방식에 맞추려 한다.

최근 30일의 새 논문 아카이브 18편을 URL·제목 기준으로 대조했으며 두 논문은 미수록이었다. 두 논문 모두 arXiv v1이 2026년 10월 20일 제출됐다. SAPD는 논문에 “코드를 곧 공개한다”고 적었으나 확인 시점에는 연결된 공식 저장소가 없었다. RoboJudge는 코드, 9B 가중치, 800개 평가 세트와 학습 주석을 공개했다. 수량을 채우기 위해 검증이 약한 논문은 추가하지 않았다.

## 논문 분석

### 1. SAPD: 실행 환경을 다시 열지 않고 기록된 에이전트 경험에서 배우기

- 출처: arXiv:2610.27847v1, Meituan LongCat Team·University of Chinese Academy of Sciences
- 점수: 8.4/10 — 편집상 선정 점수이며 논문의 측정 지표가 아님
- URL: https://arxiv.org/abs/2610.27847
- 제출일: 2026-10-20 08:30:30 UTC
- 상태: 사전출판 v1; 동료평가 여부 미확인; 공식 코드 공개 예정
- 확인일: 2026-10-21

**요약**

다중 단계 에이전트의 온라인 학습은 매번 환경을 실행해 행동과 관측을 주고받아야 한다. SAPD(Step-Advantage Policy Distillation)는 과거 궤적의 각 의사결정 시점까지를 접두부로 잘라 고정하고, 학생 모델이 그 시점에서 여러 후보 응답을 생성하게 한다. 교사 모델은 같은 접두부 아래 후보들을 평가하며, SAPD는 후보의 절대 점수보다 그룹 평균 대비 상대적인 단계 이점을 이용한다. 새 관측이나 추가 다중 턴 실행 없이 기록된 경험을 재사용한다는 것이 핵심이다.

**방법론**

각 오프라인 궤적에서 과제 지시, 이전 행동·관측, 현재 관측만 남겨 의사결정 접두부를 만든다. 정답 행동과 이후 관측은 입력에서 제외한다. 학생은 접두부마다 8개 응답을 샘플링하고, 동결된 교사와 학생의 로그확률 차이를 토큰 수준 증류 신호로 사용한다.

단계 신호는 추론 문자열이 아니라 행동 토큰에서 교사–학생 점수 차이를 합산한 뒤, 동일 접두부의 후보 평균을 빼서 만든다. 이렇게 하면 모든 후보에 공통으로 붙는 접두부별 점수 편향은 제거되지만, 후보마다 다른 교사 오류까지 고치는 것은 아니다. 저자들은 잘못된 형식과 직전 행동 반복을 벌점으로 주는 로컬 규칙도 더했다. 이는 환경 성공 보상이 아니라 텍스트와 기록만으로 계산되는 안전장치다.

실험의 학생은 Qwen2.5-1.5B-Instruct, 교사는 SFT 또는 GRPO로 학습한 동결 Qwen2.5-3B-Instruct다. ALFWorld 2,382개 궤적·21,300개 접두부, WebShop 909개·3,384개, 검색 QA 8,146개·22,826개를 사용했으며 학생 학습은 NVIDIA H200 8장에서 수행했다.

**주요 기여**

- 실행 가능한 환경을 재호출하지 않고 기존 다중 턴 궤적을 의사결정 단위로 재사용한다.
- 같은 접두부의 후보끼리 비교해 공통 점수 오프셋에 덜 민감한 단계별 학습 신호를 만든다.
- 연속된 여러 과제를 학습할 때 SFT보다 이전 과제 성능을 크게 보존했다.
- 온라인 OPD와 비교해 긴 상호작용에서 환경 실행 비용을 줄일 가능성을 보였다.

**실험 결과**

GRPO 교사 조건에서 SAPD는 ALFWorld 성공률 69.3%, 검색 QA 정확도 41.3%, WebShop 성공률 53.4%를 기록했다. 동일 표의 OPD+Rule은 각각 62.8%, 41.0%, 49.0%였다. SFT 교사 조건에서는 SAPD가 ALFWorld 96.6%, 검색 QA 38.8%, WebShop 59.4%였고 OPD+Rule은 94.0%, 38.6%, 53.1%였다. 교사 구성에 따라 SFT 자체가 일부 과제에서 더 높거나 비슷하므로 “모든 기준선을 압도했다”로 읽으면 안 된다.

WebShop→ALFWorld→검색 QA 순차 학습 뒤 SAPD는 이전 두 과제에서 50.8%와 90.5%를 유지했지만, 순차 SFT는 2.3%와 7.8%로 떨어졌다. 온라인 OPD 대비 학습 단계 시간은 평가한 구성에서 ALFWorld 12.4배, WebShop 10.9배, 검색 QA 4.7배 빨랐다. 이 비교는 평가와 체크포인트 저장 시간을 제외한 학습 시간이다. 검색 QA에서는 누적 시간 절감에도 최종 정확도가 온라인 OPD보다 약간 낮았다고 저자들이 명시한다.

**맥락**

온라인 에이전트 강화학습의 비용은 모델 계산뿐 아니라 브라우저, 게임, 검색 시스템 같은 환경을 안정적으로 유지하고 반복 실행하는 데서 발생한다. SAPD는 새 경험을 만드는 방법이 아니라 이미 있는 성공 궤적을 더 오래 활용하는 방법이다. 특히 최대 50턴의 ALFWorld처럼 긴 작업에서 온라인 재실행을 피하는 효과가 컸다.

**실무 시사점**

에이전트 로그를 보유한 팀은 “대화 전체를 SFT 데이터로 넣기” 전에 의사결정 접두부, 행동, 다음 관측을 분리해 볼 수 있다. 적용 대상은 명확한 행동 형식과 반복 오류 규칙을 정의할 수 있는 환경이다. 완료 기준은 동일 로그 분할에서 기존 SFT·OPD와 비교해 새 과제 성능뿐 아니라 이전 과제 보존율, 환경 호출 횟수, 총 학습 시간을 함께 기록하는 것이다. 교사 점수만 좋아지고 실제 성공률이 오르지 않는 보상 해킹을 확인하기 위해 독립 환경 평가를 반드시 남겨야 한다.

**한계**

상대 단계 점수는 공통 오프셋은 지우지만 후보별 순위가 잘못된 교사 오류는 고치지 못한다. 행동 길이가 다르면 길이 의존 오차도 남는다. 반복·형식 규칙은 세 과제에 맞춘 로컬 휴리스틱이어서 다른 도구 환경으로 자동 일반화되지 않는다. 결과는 1.5B 학생과 3B 교사, 세 벤치마크에 한정되며 더 큰 모델이나 비정형 GUI 업무의 재현은 확인되지 않았다. 무엇보다 확인 시점에 공식 코드가 공개되지 않아 논문 수치의 독립 실행은 아직 어렵다.

### 2. RoboJudge: 로봇 영상의 ‘그럴듯함’과 ‘지시 성공’을 따로 평가하기

- 출처: arXiv:2610.27782v1, Sphere AI Lab 연구진
- 점수: 8.7/10 — 편집상 선정 점수이며 벤치마크 점수가 아님
- URL: https://arxiv.org/abs/2610.27782
- 제출일: 2026-10-20 07:48:41 UTC
- 상태: 사전출판 v1; 코드·모델·평가 데이터 공개
- 확인일: 2026-10-21

**요약**

로봇 세계모델이 만든 영상은 자연스러워 보여도 손가락이 늘어나거나 물체가 순간 이동할 수 있고, 물리는 맞아도 지시한 물체를 옮기지 않을 수 있다. RoboJudge는 이를 물리 준수도(Physical Adherence, PA)와 지시 정렬도(Instruction Alignment, IA)라는 1~5점의 두 축으로 분리한다. 800개 인간 주석 영상으로 기존 판정 모델을 비교하고, 1만2천개 영상·약 2만5천개 인간 검증 점수로 Qwen3.5-9B 기반 판정기를 학습했다.

**방법론**

평가 세트는 8개 원천 코퍼스와 10개 영상 생성기에서 만든 800개 영상이며 그리퍼, 사람 손, 다관절 손을 포함한다. PA는 행위자 형태, 장면·물체의 시간적 일관성, 접촉과 중력의 현실성을 본다. IA는 첫 프레임의 행위자 유지, 올바른 대상 물체, 최종 목표 달성을 본다.

학습 데이터의 초안 점수는 세 폐쇄형 멀티모달 모델의 평균으로 만들고 사람이 검토·수정했다. 사람이 쓴 근거 메모는 GPT-5.5가 구조화된 추론 형식으로 다시 작성했다. 저자들은 Qwen3.5-9B를 한 epoch 전면 SFT한 뒤 정확한 점수 일치 보상으로 200단계 GRPO를 수행했다. 평가는 4fps, 최대 32개 균등 샘플 프레임으로 통일했다.

**주요 기여**

- 로봇 행동 영상 평가를 물리 타당성과 지시 이행으로 분리한 인간 주석 벤치마크를 제시한다.
- 범용 멀티모달 모델과 로봇 특화 모델, 영상 판정 모델, 비언어적 유사도 지표를 같은 데이터에서 비교한다.
- 코드, Apache-2.0 모델 가중치, 800개 벤치마크와 학습 주석을 공개해 재현 경로를 제공한다.
- 프레임 수를 늘리는 것만으로 판정 일치도가 단조롭게 좋아지지 않는다는 ablation을 제시한다.

**실험 결과**

RoboJudge-9B의 사람 점수와의 전체 Pearson 상관은 0.719, PA는 0.645, IA는 0.775였다. 같은 표에서 가장 높은 폐쇄형 기준의 전체 상관은 Gemini-3.7-Flash 0.630으로, 절대 차이는 0.089였다. 클러스터 부트스트랩 95% 구간은 전체 개선이 [0.061, 0.119], IA 개선이 [0.010, 0.078]이었지만 PA 개선은 [-0.011, 0.078]로 0을 포함했다. 따라서 PA에서 관측값은 가장 높았지만 강한 우위를 통계적으로 확정했다고 말할 수 없다.

전체 정확한 점수 일치율은 0.473, MSE는 0.747이었다. 상관이 높아도 절반이 넘는 항목에서 1~5 정수 점수가 사람과 정확히 같지 않았다는 뜻이다. 비언어적 지표 중 DINO와 V-JEPA paired similarity의 PA 상관은 각각 0.392와 0.370으로 RoboJudge보다 낮았다. GPT-5.5는 2·4·8fps에서 전체 상관이 0.620·0.618·0.620으로 거의 변하지 않았다.

**맥락**

생성 영상의 화질 평가는 로봇 계획의 유효성 평가와 다르다. 물체가 선명하더라도 접촉이 깨지거나 목표 위치가 틀리면 실제 행동 후보로 쓸 수 없다. RoboJudge는 영상 생성 모델의 순위를 만드는 것보다 “어떤 실패를 별도 축으로 측정해야 하는가”를 명확히 했다는 데 실무 가치가 있다.

**실무 시사점**

로봇 세계모델을 평가하는 팀은 하나의 종합 점수 대신 PA와 IA를 분리하고, 실제 실패 유형별 사람 검토 표본을 유지할 수 있다. 시작 방법은 공개 벤치마크에서 inference와 evaluate 스크립트를 재현한 뒤 자사 카메라·그리퍼·과제 영상으로 외부 검증 세트를 만드는 것이다. 완료 기준은 Pearson 상관뿐 아니라 정확 일치율, MSE, 위험한 실패의 누락률을 보고하고, 모델 순위가 사람 평가와 같은지 확인하는 것이다. 안전 관련 행동 선택에서는 이 판정기를 단독 승인자로 사용하지 않아야 한다.

**한계**

학습 점수와 추론 근거 작성에 폐쇄형 모델이 개입해 주석 파이프라인 전체를 로컬 모델만으로 재현하기 어렵다. 공개 벤치마크는 800개이며 원천 코퍼스와 생성 모델의 분포에 영향을 받는다. 최대 32개 샘플 프레임은 짧은 접촉 오류를 놓칠 수 있다. 높은 상관은 개별 영상의 안전성 인증이 아니며, 평가 모델 자체가 생성 모델의 오류를 공유할 수 있다. 벤치마크 데이터는 CC BY-NC 4.0이고 모델·코드는 Apache-2.0이므로 상업 이용 시 구성요소별 조건을 따로 확인해야 한다.

### 카드 2 — SAPD

SAPD는 과거 에이전트 로그를 의사결정 시점별 접두부로 나눕니다. 학생이 같은 상황에서 여러 행동을 만들면 교사가 후보를 비교하고, 평균보다 나은 행동에 상대 점수를 줍니다. 평가한 구성에서 온라인 OPD보다 학습 단계가 4.7~12.4배 빨랐습니다. 단, 교사의 잘못된 후보 순위와 실제 환경 성공은 별개입니다.

### 카드 3 — RoboJudge

RoboJudge는 로봇 영상을 물리 준수도와 지시 정렬도로 나눠 평가합니다. 800개 사람 주석 영상에서 9B 모델의 전체 Pearson 상관은 0.719였습니다. 그러나 정확한 정수 점수 일치율은 0.473이므로 사람 판정을 대체하는 안전 인증기는 아닙니다. 코드·가중치·벤치마크는 공개됐습니다.

### 카드 4 — 실행 체크리스트

- 에이전트 팀 → 로그를 접두부·행동·관측으로 분리 → 이전 과제 보존율과 실제 성공률까지 측정 → SAPD 원문
- 로봇 팀 → 물리와 지시 성공을 별도 평가 → 상관·정확 일치·위험 실패 누락을 보고 → RoboJudge-Bench
- 검증 팀 → 모델 판정 표본을 사람이 재검토 → 단독 자동 승인 금지 기준 문서화 → 논문 한계

### 캡션

좋은 에이전트는 새 경험을 많이 만드는 것만으로 완성되지 않습니다. 이미 모은 경험을 잊지 않고 배우는 방법과, 생성된 행동을 사람의 기준에 맞게 평가하는 방법이 함께 필요합니다. 이번 두 논문은 효율과 검증을 각각 다루지만, 둘 다 모델 점수를 실제 성공으로 착각하지 말라는 같은 경고를 남깁니다.
