## 1. 한 사람 대신 ‘대화 그룹’을 따라가는 EEG 데이터셋

**논문:** A multi-scenario EEG dataset for auditory attention decoding in naturalistic multi-talker environments — Shu Peng 외.
**상태:** arXiv v1 사전공개, 2026-10-07. 학술지 게재·후속 수정일은 확인하지 못했다.

SoundBubble-EEG는 목표 대화 그룹에 집중하는 청자의 EEG를 수집한다. 건강한 중국어 모어 화자 30명의 128채널 기록은 25시간 이상이다. 회의·식당·TV 장면을 공간 음향으로 합성하여, 기존 두 화자 과제보다 복잡한 청각 주의를 다룬다. 실제 식당 현장 녹음 실험으로 해석하면 안 된다.

### 방법·실험·근거

저자들은 개인별 25개 시행에서 하나씩 제외하는 교차검증으로 ridge 기반 backward mTRF를 평가했다. 이는 시간 지연 EEG에서 음성의 진폭 변화인 envelope를 복원하는 선형 모델이다. 장면을 섞어 학습하며, 각 시험 구간은 120초다.

| 원문 결과 | 조건·해석 |
| --- | --- |
| 전체 정확도 0.717 | 목표 음성 상관이 비목표보다 큰 시행 비율 |
| 평균 목표 상관 약 0.026 | 낮은 절대 상관도 함께 공개 |
| 평균 상관 차이 0.0196 | 라벨 교환 50,000회 대조, 보정 p=0.00002 |

**한계:** 고정 장면 순서는 피로·학습과 혼재할 수 있다. 개인 간 전이·미지 장면 전이·짧은 실시간 판단 성능은 이 결과로 입증되지 않는다. 최신 딥러닝 모델과의 우열을 주장하는 연구도 아니다.

### 코드와 실행 전 확인

[저자 코드 README](https://github.com/Mashirops/sound-bubble-eeg-code)는 전처리, 신호 품질 검사, 기존 AAD 기준선과 전체 시행 검증을 구분한다. 로컬 BIDS 데이터 경로 설정이 필요하고 결과·원시 데이터·음성 배열은 코드 저장소에 포함되지 않는다. 원래 분석의 패키지 버전은 고정되지 않았다고 명시한다. [데이터 DOI](https://doi.org/10.5281/zenodo.19610627)는 원문에 있지만 이번 열람은 실패하여 파일·라이선스·다운로드 가능성을 독립 확인하지 못했다.

### 엔지니어의 다음 실험 — 편집 제안

대상은 EEG 디코더 개발자다. 먼저 데이터 접근·이벤트 동기화·전처리 환경을 확인하고 개인별 기준선을 재현한다. 그다음 동일한 분할·채널·판단 구간·튜닝 예산으로 비교 모델을 평가한다. 완료 기준은 참여자별 상관 차이와 정확도, 불확실성, 환경 버전을 담은 표다. 장면 또는 참여자를 완전히 제외하는 별도 실험을 추가해야 전이 주장에 근거가 생긴다. 이번 편집 과정에서는 코드를 실행하지 않았다.
