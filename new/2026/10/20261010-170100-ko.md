## 1. Neural Decoding as Cognitive Inference

- 저자: Yi Guo 외
- 상태: arXiv v1 사전공개
- 제출: 2026-10-08 13:19:57 UTC
- 정규 URL: https://arxiv.org/abs/2610.11923

### 무엇을 제안했나

이 연구는 신경 신호를 외부 라벨에 직접 대응시키는 대신, 관측 신호와 뇌의 구조적 사전정보를 함께 이용해 인지 상태를 추론한다. 저자들이 ‘meta-neural semantic representation’이라 부르는 고수준 표현은 관측 인코더와 대뇌피질 기하학 prior 인코더를 product-of-experts 방식으로 결합해 만든다. EEG·MEG·ECoG·fNIRS·fMRI의 다섯 계측 방식과 운동·지각·내적 사고의 세 영역을 평가했다. 텍스트 생성에는 별도의 임베딩 정렬, Q-Former, Phi-4-mini LoRA가 들어가므로 하나의 순수 디코더 성능으로 단순화하면 안 된다.

### 실험·비교·정량 근거

EEG/MEG 비교에는 공개 가중치의 LaBraM·BrainOmni·CBraMod, 세션 간 비교에는 SPaRCNet, 내부 상태 fMRI에는 NeuroSTORM을 사용했다. 공유 데이터에서는 분할·라벨·테스트 샘플과 최적화 예산을 고정했다고 저자들은 설명한다.

| 조건 | 저자 보고 결과 | 의미 |
| --- | --- | --- |
| ECoG Speech, 208일 | 세션 간 평균 유사도 0.393 → 0.803 | 고수준 표현의 장기 안정성 |
| AJILE12 ECoG, 4일 | 0.459 → 0.819 | 자연스러운 상지 움직임 |
| SHU-MI EEG, 8일 | 0.214 → 0.758 | 비침습 운동상상 EEG |
| 자체 OPM-MEG, 6명 | 의미 상관 중앙값 0.567; 3분류 48% | chance 33%, BrainOmni보다 높다고 보고 |

이 수치들은 서로 다른 데이터셋·과제의 결과다. 특히 SHU-MI는 청각 주의 데이터가 아니며, sAAD 성능으로 읽을 수 없다.

### 한계와 재현성

논문은 광범위한 데이터셋을 다루지만 명시적인 limitations 절과 공식 코드 링크를 확인하지 못했다. 자체 imagined-speech 실험은 6명으로 작고, 생성 단계는 동결 언어·확산 모델의 prior에 영향을 받는다. 대뇌피질 기하학을 얻기 위한 좌표·해부 정보와 계측별 전처리 차이도 실제 이전 비용을 만든다. 학습에는 저자 기준 NVIDIA A800 80GB 두 장이 사용되었다.

### FP/sAAD에서 해볼 것 — 편집 제안

- **대상:** 참여자·세션 변화에 약한 EEG 모델.
- **방법:** 기존 BiSSD/분류 표현과 구조 prior 결합 표현을 동일 subject/session split에서 비교한다.
- **완료 기준:** within-session, cross-session, cross-subject 정확도와 표현 유사도, 파라미터·GPU 비용을 한 표에 기록한다.
- **주의:** 사전정보가 테스트 참여자나 세션 라벨을 누설하지 않는지 ablation으로 확인한다.

**읽는 순서:** Figure 1 개요 → cross-session Figure 4 → Model comparisons/Evaluation protocol → Dataset preprocessing → 내부 상태 결과.
