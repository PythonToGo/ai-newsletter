## 이번 주 연구 동향

이번 호의 세 논문은 서로 다른 영역을 다루지만, 성능을 높이기 위해 모델에 더 많은 지시를 넣는 대신 **환경과 실행 구조를 다시 설계**한다는 공통점이 있다. AlphaNIST는 조립 순서와 중간 보상을 직접 가르치지 않고 다양한 초기 상태와 20개 조립 과제를 함께 학습시킨다. Humanize MLE Agents(HMA)는 한 에이전트의 긴 컨텍스트를 계속 늘리는 대신 두 에이전트가 같은 작업공간을 짧은 세션 단위로 넘겨받게 한다. Wikipedia Game 연구는 정보검색을 정답 생성 문제가 아니라 링크 그래프에서의 순차 선택 문제로 바꿔 모델의 의미적 탐색 능력을 측정한다.

세 연구의 수치는 모두 조건을 함께 읽어야 한다. AlphaNIST의 98.2%는 실제 공장이 아니라 Isaac Lab 시뮬레이션의 학습 분포에서 얻은 성공률이다. HMA의 78.2% any-medal rate는 75개 MLE-bench 과제, 과제당 6시간, 특정 상용·오픈 모델 조합이라는 조건에 묶인다. Wikipedia Game의 최고 모델은 사람과 성공률은 비슷했지만 더 많은 단계와 재시도를 사용했으며, 일부 고비용 모델은 전체 10,000게임이 아니라 제한된 표본만 수행했다.

실무적으로는 “더 긴 컨텍스트·더 복잡한 보상·더 큰 모델”을 기본 답으로 삼기 전에, 데이터 다양성·세션 경계·평가 그래프가 만드는 효과를 분리해 측정해야 한다. 이번 호의 실행 기준은 명확하다. 로봇 정책은 실제 하드웨어 이전에 분포 밖 초기 상태와 안전 실패를 따로 평가하고, 에이전트 워크플로는 단일 세션과 교대 세션을 동일 예산으로 비교하며, 검색 시스템은 성공률과 함께 경로 길이·재시도·도메인 이동 성능을 기록한다.

## 논문 분석

### 1. AlphaNIST: Emergent Assembly Skills from Binary Task Rewards

- **출처**: arXiv (NVIDIA·University of Washington)
- **점수**: 8.6/10 — 편집 선정 점수
- **URL**: https://arxiv.org/abs/2610.13354

**요약**

AlphaNIST는 NIST Assembly Task Board #1의 20개 조립 과제를 하나의 정책으로 학습하는 강화학습 프레임워크다. 시연, 과제별 정책, 조립 진척도 보상이나 고정된 작업 순서를 주지 않고, 조립 완료 여부의 이진 보상과 공통 제어 비용만 사용한다. 저자들은 64K 병렬 환경의 학습 분포에서 전체 성공률 98.2%를 보고하고, 최대 10개 조립 쌍을 정해진 순서 없이 한 에피소드에서 완성하는 정책도 학습했다고 주장한다.

**방법론**

정책은 Franka Emika Panda의 상태와 이동 부품·결합부·로봇의 point cloud를 입력으로 받고, 25Hz에서 7차원 상대 관절 목표와 그리퍼 명령을 출력한다. 핵심은 세 요소의 결합이다. 첫째, 잡기 전 상태부터 부분 조립 상태까지 저장한 reset bank가 탐색 범위를 넓힌다. 둘째, 최근 성공률이 중간인 상태를 더 자주 뽑는 success-guided beta sampling이 학습 가능한 경계에 경험을 배분한다. 셋째, 완전 조립 오차가 1mm 미만일 때만 성공 보상을 주되 큰 동작·관절 속도·토크에는 공통 제어 비용을 부과한다. PPO는 1K~256K 병렬 환경으로 확장되며, 모델과 하이퍼파라미터는 과제별로 바꾸지 않는다.

**주요 기여**

1. 20개 이질적 조립 과제를 별도 전문가 없이 하나의 geometry-conditioned 정책으로 처리했다.
2. 과제 다양성이 희소 보상 탐색을 방해하기보다 정밀 조립 사이의 양의 전이를 만들 수 있음을 단일 과제 정책과의 비교로 제시했다.
3. 명시적 planner 없이 재파지, 주변 형상을 이용한 재정렬, 장애물을 치운 뒤 미완성 과제로 돌아오는 행동이 나타났다고 보고했다.

**실험 결과**

64K 환경·25K iteration의 공유 정책은 학습 분포에서 98.2% 성공률을 기록했다. 평가 성공은 15초 안에 완전 조립하면서 안전 실패가 동시에 발생하지 않는 경우로 정의했다. 저자들은 20개를 따로 학습한 정책보다 공유 정책이 세 정밀 조립 과제에서 특히 강했다고 보고한다. 다중 조립 실험은 최대 10개 쌍이 모두 완성될 때만 보상을 주며, 정책은 순서 지시 없이 조립을 완료했다. 이 결과는 5개 평가 seed와 과제·seed당 32회 시도를 포함한 scaling 평가를 바탕으로 한다.

**맥락**

로봇 조립은 작은 공차, 접촉 역학, 재파지와 실패 복구 때문에 보통 시연·단계별 sub-policy·dense reward에 의존한다. AlphaNIST는 복잡성을 줄이지 않고 여러 형상과 초기 상태를 한 정책에 노출해 재사용 가능한 조작 행동을 얻으려 한다. 이는 과제를 세분화하는 설계와 반대 방향의 실험이며, “다양성 자체가 학습 신호가 될 수 있다”는 가설을 강화한다.

**실무 시사점**

Isaac Lab 기반 조립 정책을 개발한다면 먼저 3종 이상의 형상군과 넓은 초기 상태를 같은 성공 정의로 묶고, uniform reset과 성공률 기반 sampling을 동일 interaction budget에서 비교하라. 완료 기준은 평균 학습 성공률이 아니라 보지 못한 초기 자세·마찰·질량 조건에서의 성공률, 안전 제한 위반률, 실제 로봇 100회 반복 결과를 함께 기록하는 것이다. 정책이 중간 상태를 우연히 암기하지 않는지 확인하려면 reset bank 밖의 조합을 별도 holdout으로 두어야 한다.

**한계**

모든 핵심 결과는 시뮬레이션이며 실제 NIST 보드에서의 sim-to-real 결과가 없다. 최대 256K 병렬 환경은 높은 계산 자원을 요구하고, reset bank 자체가 조립 관련 상태를 사람이 구성한 형태이므로 “이진 보상만으로 처음부터 모든 탐색을 해결했다”는 해석은 과하다. 논문 작성 시점에는 코드 공개를 review·revision 이후로 예고했을 뿐 저장소가 공개되지 않았다. 98.2%는 deployment 성능이 아니라 학습 분포의 시뮬레이션 수치다.

**관련 링크**

- 원문(버전 1, 2026-10-09): https://arxiv.org/html/2610.13354v1
- 정규 논문 URL: https://arxiv.org/abs/2610.13354

- 코드 상태: 2026-10-13 확인 기준 미공개, 논문에 추후 공개 예정으로 기재

### 2. Humanize MLE Agents: Multi-Agent Session Alternation Beyond Single-Agent Limits

- **출처**: arXiv (Tsinghua University·Zhejiang University·NVIDIA·MIT)
- **점수**: 8.4/10 — 편집 선정 점수
- **URL**: https://arxiv.org/abs/2610.13494

**요약**

HMA는 장시간 ML 엔지니어링 과제에서 한 에이전트가 같은 컨텍스트를 계속 유지하는 대신, 서로 다른 두 agent–harness 조합이 동일 작업공간을 번갈아 이어받는 워크플로다. 각 세션은 최대 (k)개의 실험으로 제한되고, 코드·모델·평가 결과는 보존하되 대화 컨텍스트는 초기화한다. 75개 MLE-bench Kaggle 과제에서 가장 좋은 구성은 78.2% any-medal rate를 기록해 저자들의 최강 단일 에이전트 72.4%를 넘었다.

**방법론**

저자들은 세션 교대를 context-reset semi-Markov decision process로 모델링하고, 각 에이전트의 개선 가능성이 남아 있으며 서로 보완적일 때 교대가 단일 에이전트 한계를 넘는 충분조건과 예산 경계를 제시한다. 실제 HMA는 공유 작업공간, 세션당 최대 5개 실험, 총 6시간 예산과 마지막 15분의 상대 에이전트 리뷰를 사용한다. 에이전트 내부 도구와 공식 harness는 바꾸지 않고, handoff 때 새 컨텍스트가 기존 산출물을 읽어 다음 실험을 수행한다.

**주요 기여**

1. 긴 실행에서 응답당 출력 토큰과 점수 개선이 함께 감소하는 현상을 “long-horizon deceleration”로 측정했다.
2. 특정 모델에 맞춘 custom harness 이득이 더 강한 후속 모델에서는 줄거나 역전될 수 있는 “harness staleness”를 비교했다.
3. 모델 내부를 수정하지 않고 세션 경계와 작업공간 지속성만으로 여러 이질적 모델 쌍에서 성능 향상을 보였다.

**실험 결과**

Opus-first HMA는 75개 과제에서 78.2% any-medal rate를 얻었고, 6시간 예산의 최강 단일 baseline은 72.4%였다. 논문이 인용한 최고 공개 workflow baseline은 70.2%였지만 해당 시스템들은 12~24시간과 서로 다른 하드웨어를 사용했으므로 직접적인 효율 비교에는 주의가 필요하다. 여섯 HMA 구성은 구성원 단일 모델 평균보다 any-medal rate를 평균 6.4%p 높였다. 초기 0~2시간 대비 3~5시간의 응답당 평균 출력 토큰 유지율은 HMA 86.4%, matched single-agent 60.7%였지만, 출력 길이는 추론 품질의 간접 지표일 뿐이다.

**맥락**

에이전트 성능 개선은 흔히 긴 컨텍스트, 누적 메모리, 세밀한 AGENTS.md와 task-specific skill을 추가하는 방향으로 진행된다. HMA는 모델 버전이 바뀌면 이런 보조물이 낡을 수 있다는 관찰에서 출발해, 원래 agent–harness를 그대로 두고 workflow의 session boundary만 조절한다. 핵심은 “다중 에이전트 토론”보다 재현 가능한 실험 산출물을 공유 상태로 사용하는 것이다.

**실무 시사점**

반복 실험형 에이전트를 운영한다면 동일 과제 20개 이상에서 단일 세션, 자연 종료 교대, (k=3)·(k=5) 고정 교대를 같은 시간·모델 비용으로 비교하라. handoff에는 설명문보다 실행 가능한 코드, metric 표, 실패 로그, 다음 가설을 남기고 최종 결과는 독립 검증으로 선택한다. 완료 기준은 평균 최고 점수뿐 아니라 재현 성공률, 중복 실험 비율, 잘못된 후보 채택률, 시간당 유효 개선 횟수가 단일 세션보다 좋아지는 것이다.

**한계**

MLE-bench 75개 과제와 특정 2026년 모델·harness 조합에 결과가 묶여 있으며, 일반 소프트웨어 개발이나 연구 자동화로의 전이는 아직 주장 수준이다. 상용 모델을 포함해 비용과 재현 접근성이 제한된다. 공개 workflow와의 비교는 시간·GPU·사전 지식이 일치하지 않는다. 응답 토큰 수를 reasoning intensity의 proxy로 사용한 해석도 직접적인 사고 품질 측정은 아니다.

**관련 링크**

- 정규 논문 URL: https://arxiv.org/abs/2610.13494
- 공식 코드: https://github.com/humanfia/hma
- 확인일: 2026-10-13

### 3. Can Language Models Play the Wikipedia Game?

- **출처**: arXiv (The Alan Turing Institute)
- **점수**: 7.9/10 — 편집 선정 점수
- **URL**: https://arxiv.org/abs/2610.13948

**요약**

이 연구는 시작 문서에서 목표 문서까지 현재 페이지의 링크만 따라가는 Wikipedia Game으로 언어모델의 탐색 능력을 평가한다. 영어 Wikipedia뿐 아니라 다섯 언어의 Wikipedia와 다섯 학술 분야 OpenAlex citation graph를 구축하고, LLM·문장 임베딩·TF-IDF·사람을 비교했다. 최고 LLM들의 성공률은 사람과 통계적으로 유의한 차이가 없었지만, 성공한 경우에도 사람보다 더 많은 단계를 사용했다.

**방법론**

에이전트는 현재 문서의 링크 후보와 목표 문서 정보를 보고 다음 링크 하나를 고른다. 미래 링크를 미리 보거나 목표에서 역방향 탐색할 수 없으며, 같은 페이지 재방문은 방지된다. 100단계 안에 목표에 도달하면 성공이다. 임베딩 baseline은 링크 제목 또는 요약과 목표 요약의 cosine distance가 가장 가까운 후보를 택하고, LLM은 링크 제목 목록에서 하나를 생성한다. 연구팀은 대형 Wikipedia와 OpenAlex 그래프를 로컬에 구축해 외부 검색 API 의존을 줄였다.

**주요 기여**

1. 동일한 순차 탐색 규칙으로 LLM, 임베딩, TF-IDF와 사람의 성공률·경로 효율을 비교했다.
2. 언어와 학술 분야를 바꾸면 모델 순위가 유지되지 않는다는 도메인 이동 결과를 제시했다.
3. 그래프 구축·탐색 코드를 공개해 검색 시스템을 최종 정답뿐 아니라 경로 수준에서 평가할 수 있게 했다.

**실험 결과**

저자들은 GPT-o3 mini, GPT-4o, QwQ-32B, DeepSeek-R1-70B가 사람과 비슷한 성공률 범위에 도달했다고 보고하지만 어느 모델도 사람을 유의하게 앞서지 못했다. 사람은 성공한 게임에서 평균 경로가 더 짧았다. Llama 405B는 영어 Wikipedia 밖의 여러 언어·주제에서 약해졌고 OpenAlex에서는 성공률이 약 3분의 1 감소했다. 전체 후보 게임은 10,000개였지만 자원 제약으로 모든 모델이 전부 수행하지 않았고, GPT-4o는 일부 데이터셋에서 100게임으로 제한됐다.

**맥락**

RAG 평가는 보통 top-k recall이나 최종 답변 정확도에 집중해, 검색기가 어떤 잘못된 분기를 거쳤는지 숨긴다. Wikipedia Game은 각 단계의 후보가 명시된 그래프 탐색으로 바꿔 의미적 연관성을 실제 경로 선택에 사용할 수 있는지 보여준다. 특히 “사실을 알고 있는 것”과 “그 지식을 다음 검색 행동에 쓰는 것”을 분리하는 평가다.

**실무 시사점**

문서 그래프나 citation graph를 탐색하는 에이전트라면 500~1,000개의 고정 출발–목표 쌍을 만들고 TF-IDF, 임베딩, LLM policy를 같은 최대 step에서 비교하라. 성공률과 함께 성공 경로 길이, 재방문, 존재하지 않는 링크 생성, 모델 호출 횟수, 언어·도메인별 편차를 기록한다. 완료 기준은 LLM이 단순 임베딩보다 높은 성공률을 보이면서 호출 비용과 평균 경로 길이까지 허용 범위에 들어오는 것이다.

**한계**

GPT 계열은 최대 500개, 다른 모델은 200개 링크만 prompt에 넣었으므로 후보 truncation이 모델별로 다르다. LLM은 hallucination 때 최대 5회 재시도를 허용해 step 수만으로 실제 호출 비용을 비교하기 어렵다. 고비용 모델의 표본 수와 적용 데이터셋이 제한됐고, Wikipedia가 사전학습 데이터에 포함됐을 가능성이 높아 순수한 미지 그래프 일반화 시험은 아니다. 성공률이 비슷해도 사람보다 긴 경로를 사용한다는 결과를 “인간 수준 검색”으로 확대 해석해서는 안 된다.

### 카드 2 — AlphaNIST

하나의 로봇 정책이 NIST 보드의 20개 조립을 함께 배웠다.  
조립 순서와 중간 진척 보상 없이, 완성 여부와 다양한 reset 상태를 사용했다.  
64K 시뮬레이션 환경의 학습 분포에서 성공률은 98.2%였다.  
단, 실제 로봇 검증과 공개 코드는 아직 없다.

### 카드 3 — HMA

긴 컨텍스트 하나를 붙잡는 대신 두 에이전트가 작업공간을 교대했다.  
75개 MLE-bench 과제에서 최고 구성은 78.2% any-medal, 최강 단일 baseline은 72.4%였다.  
코드·모델·실험 결과는 유지하고 대화 컨텍스트만 초기화한다.  
모델 비용과 비교 자원이 다른 baseline을 단순 순위로 읽으면 안 된다.

### 카드 4 — Wikipedia Game

모델에게 정답을 묻지 않고 현재 문서의 링크 중 다음 한 걸음을 고르게 했다.  
최고 LLM은 사람과 성공률이 비슷했지만 성공 경로는 더 길었다.  
언어와 학술 분야를 바꾸자 모델 순위도 바뀌었다.  
검색 평가는 정답률뿐 아니라 경로 길이·재시도·도메인 이동을 함께 봐야 한다.

### 카드 5 — 실행 체크리스트

- **로봇 팀** → reset 다양성과 sampling을 ablation → 실제 로봇 100회와 안전 실패율로 완료 판단
- **에이전트 팀** → 단일 세션과 (k=3,5) 교대 비교 → 동일 비용에서 유효 개선/시간과 재현율 확인
- **검색 팀** → TF-IDF·임베딩·LLM을 고정 그래프에서 비교 → 성공률·경로·호출 수를 모두 통과
