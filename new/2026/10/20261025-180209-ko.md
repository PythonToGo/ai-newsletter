## 이번 주 연구 동향

이번 호의 공통 질문은 “AI 시스템이 현재 화면이나 프롬프트만 보는 대신, 실제 작업의 상태와 과거 사건을 어떻게 안전하게 이어 붙일 것인가”다. DoorDash의 산업 사례는 라이브 플래그 상태, Jira 맥락, 코드 참조와 테스트를 여러 에이전트가 연결해 사람이 승인할 수 있는 PR로 만든다. WholeBodyMem은 로봇이 행동하기 전에 잠깐 보았던 물체 사건을 제한된 메모리에 남겨, 단서가 사라진 뒤에도 올바른 행동을 고르게 한다.

두 연구 모두 무제한 컨텍스트를 쌓는 대신 필요한 증거를 고르는 구조를 택했다. 다만 50개 플래그를 다룬 단일 기업 평가와 6개 실세계 과제·과제당 10회 시험은 각각 범용성과 강건성을 주장하기에는 아직 좁다. 이번 결과는 완전 자율화의 증거라기보다, 작업별 상태 조회·검증·사람의 승인 지점을 명시한 시스템 설계가 성능을 크게 좌우한다는 실무 신호로 읽는 편이 정확하다.

## 논문 분석

### 1. [멀티에이전트가 오래된 기능 플래그를 PR까지 정리한다](https://arxiv.org/abs/2610.31351)

> **원제**: Automating Feature Flag Cleanup at Scale with Multi-Agent LLM Systems: An Industrial Experience at DoorDash  
> **저자**: Atharv Chandratre, Jai Datar  
> **발표**: arXiv, 2026-10-22 · ICSME 2026 Industry Track 채택  
> **분야**: 소프트웨어 공학 · AI 에이전트 · 코드 유지보수  
> **점수**: 9.0/10  
> **URL**: https://arxiv.org/abs/2610.31351

#### 요약

DoorDash에는 623개 저장소에 5만 6천 개가 넘는 기능 플래그가 있었고, 2026년 5월 기준 1,659개가 오래된 상태였다. 플래그 하나를 사람이 제거하는 데 내부 추정 1~2시간이 걸리는 문제를, 라이브 롤아웃 상태 조회부터 Jira 처리, 코드 수정, 테스트와 PR 생성까지 잇는 멀티에이전트 시스템으로 자동화했다. 50개 실제 플래그 평가에서 45개(90%)의 PR이 엔지니어 승인을 받았고, 플래그당 평균 비용은 4.79달러, 에이전트 실행 시간은 13.8분이었다.

#### 방법론

워크플로는 먼저 MCP를 통해 운영 중인 플래그의 실제 롤아웃 값과 메타데이터를 조회하고, 관련 Jira 티켓과 저장소·코드 참조를 모아 정리 범위와 대체 상수를 제안한다. 사람이 분석 결과를 승인하면 코드 정리 에이전트가 격리된 Git worktree에서 분기와 불필요한 코드를 제거하고 테스트를 수행한 뒤 PR을 만든다. 분석과 코드 변경을 분리하고, 병렬 작업은 worktree로 격리하며, 에이전트별 시간 제한과 변경 라인 테스트 커버리지 기준을 둔 것이 핵심 운영 장치다.

#### 주요 기여

- 규칙 기반 도구가 감당하기 어려웠던 의존성 주입·다중 파일 코드 패턴을 실제 대규모 저장소에서 처리했다.
- 운영 상태를 추측하지 않고 라이브 플래그 서비스에서 조회해, 제거 후 남길 분기 값을 근거와 함께 정했다.
- “분석 → 사람 승인 → 격리된 수정 → 테스트 → PR”이라는 재사용 가능한 에이전트 경계를 제시했다.
- 성공률뿐 아니라 비용과 시간까지 공개해 산업 적용의 경제성을 평가할 수 있게 했다.

#### 실험 결과

실제 오래된 플래그 50개 중 45개가 엔지니어 승인 PR로 이어졌다. 승인률은 90%, 평균 실행 비용은 4.79달러, 평균 에이전트 시간은 13.8분이었다. DoorDash가 공개한 후속 설명에 따르면 평가된 50개 변경에서 프로덕션 회귀는 관찰되지 않았다. 다만 “승인된 PR”은 장기간 운영 후 결함이 없다는 것과 동일한 지표가 아니므로, 성공률의 의미를 구분해야 한다.

#### 맥락

코드 에이전트의 어려움은 코드를 쓰는 능력만이 아니라, 어떤 분기를 남겨야 하는지 운영 사실을 확인하고 변경 범위를 빠짐없이 찾아내는 데 있다. 이 연구는 범용 챗봇에 저장소를 통째로 주는 방식보다, 신뢰할 수 있는 외부 상태와 사람의 판단을 구조화된 체크포인트로 연결하는 패턴이 산업 자동화에 더 적합함을 보여준다.

#### 실무 시사점

도입 시에는 먼저 플래그 서비스·이슈 트래커·코드 검색을 읽기 전용 도구로 묶고, 변경 전 사람이 대체 값과 영향 파일을 승인하게 하는 것이 좋다. PR 단위 격리, 제한 시간, 테스트와 커버리지 게이트, 감사 로그를 기본값으로 두어야 한다. 또한 PR 승인률과 함께 실제 병합률, 재작업률, 롤백·장기 회귀율을 별도로 추적해야 자동화 품질을 제대로 판단할 수 있다.

#### 한계

평가는 한 기업의 내부 코드베이스와 플래그 시스템, 50개 사례에 한정된다. 복잡한 모바일 클라이언트, 외부 소비자, 플래그 외부의 런타임 의존성을 얼마나 포착하는지는 충분히 검증되지 않았다. 분석 에이전트가 영향 파일을 놓치면 다음 단계가 잘못된 범위를 신뢰할 수 있으며, 인간 승인이 안전성의 중요한 일부다. 내부 인프라와 모델 구성에 의존하므로 다른 조직에서 같은 비용·성공률이 재현된다고 단정할 수 없다.

### 2. [행동 전의 장면을 기억하는 휴머노이드: WholeBodyMem](https://arxiv.org/abs/2610.31166)

> **원제**: Memory before Goal: Role of Pre-History Memory for Humanoid Loco-Manipulation  
> **저자**: Chenyuan Chen, Ran Ding, Lechen Zhang, Zewen He, Yoshihiko Nakamura  
> **발표**: arXiv, 2026-10-22 · IEEE RA-L 투고  
> **분야**: 로보틱스 · 비전-언어-행동 · 시각 메모리  
> **점수**: 9.2/10  
> **URL**: https://arxiv.org/abs/2610.31166

#### 요약

휴머노이드가 몸을 돌리거나 물체가 가려지면, 목표 행동에 필요한 단서가 현재 시야에서 사라진다. WholeBodyMem은 목표가 주어지기 전부터 관찰된 물체 사건의 핵심 프레임을 보존해, 로봇이 “어디에 있었는지·무엇이었는지·언제 일어났는지”를 뒤늦게 사용할 수 있게 한다. HuMeGo의 6개 시뮬레이션 과제와 Unitree G1의 6개 실세계 과제에서 메모리 없는 기본 정책 대비 성공률을 각각 29.1%→72.6%, 36.7%→88.3%로 높였다.

#### 방법론

SAM3가 지시와 관련된 물체를 추적하고, 물체의 등장·소실 같은 사건이 제한된 예산 안에서 핵심 프레임을 인과적으로 선택한다. 메모리는 첫·중간·현재 프레임에 최대 4개의 사건 프레임을 더해 3~7장으로 유지된다. 행동 전문가는 이 프레임을 교차 어텐션으로 읽고, 외형·기하·시간을 담은 물체 토큰과 결합한다. 단순히 긴 비디오를 모두 넣는 대신, 행동 결정에 필요한 사건을 좁혀 읽는 설계다.

#### 주요 기여

- 목표 행동 전에 발생한 단서를 명시적으로 다루는 object-guided pre-history memory를 제안했다.
- counting, permanence, reference 기억을 평가하는 HuMeGo 벤치마크를 시뮬레이션과 실세계에 걸쳐 구성했다.
- 동일한 7프레임 예산에서 균등 샘플링보다 사건 기반 선택이 짧은 단서를 더 잘 보존함을 보였다.
- 기억 판단 정확도와 실제 조작 성공률을 분리해, 인지 실패와 제어 실패를 구분했다.

#### 실험 결과

시뮬레이션 기억 과제에서 기본 정책의 평균 성공률은 29.1%, 균등 메모리는 44.4%, 전체 WholeBodyMem은 72.6%였다. 기억 판단 정확도는 약 39%에서 94%로 올랐다. 실세계 Unitree G1의 6개 과제에서는 기본 정책이 60회 중 22회(36.7%), WholeBodyMem이 53회(88.3%) 성공했다. 기존 14개 SIMPLE 과제에서도 평균 성공률이 70.2%에서 86.9%로 상승해, 메모리 추가가 표준 과제를 희생하지 않았다는 근거를 제시했다.

#### 맥락

로봇 VLA 연구는 현재 관찰과 언어 지시를 행동으로 바꾸는 데 집중해 왔지만, 실제 환경은 단서가 잠깐 나타났다 사라지는 비마르코프적 상황이 많다. WholeBodyMem은 “더 많은 프레임”보다 “결정에 필요한 사건 프레임”이 중요하다는 점을 보여준다. 이는 로봇뿐 아니라 장시간 비디오 에이전트와 GUI 에이전트의 메모리 설계에도 연결된다.

#### 실무 시사점

메모리 모듈은 전체 기록을 저장하기보다 물체 상태 변화와 작업 의존성을 기준으로 쓰기 정책을 설계해야 한다. 프레임 예산, 추적 실패율, 결정 지연을 함께 측정하고, 기억 판단과 모터 실행 성능을 분리해 디버깅하는 것이 유용하다. 프로젝트 페이지 기준 실제 배포는 RTX 5090 한 장에서 SAM3를 행동 청크당 약 1.25Hz로 실행하고, 동작은 50Hz로 출력했다.

#### 한계

SAM3가 단서를 처음부터 탐지하지 못하면 메모리는 이를 복구할 수 없고, 온라인 추적 비용도 추가된다. 시뮬레이션 시연은 스크립트 기반이며 렌더링과 현실 사이의 간극이 남는다. 실세계 평가는 과제당 시연 15개, 시험 10회로 작고, 단일 Unitree G1과 정해진 물체·배치에 집중한다. 비교 대상도 주로 메모리 없는 정책과 균등 샘플링이어서 다른 학습형 메모리 구조에 대한 우월성은 아직 확정되지 않았다.
