## 이번 주 연구 동향

이번 주 논문들은 크게 두 가지 방향으로 수렴한다. 첫째, RLVR(Reinforcement Learning with Verifiable Rewards) 학습의 효율화와 내부 메커니즘 해석이다. RELEX는 weight trajectory가 사실상 rank-1 subspace에 집중된다는 기하학적 발견으로 전체 학습 비용을 대폭 줄이는 extrapolation 방법을 제시했고, DelTA는 같은 RLVR 프레임워크 안에서 response-level reward가 token-level로 전달되는 방식을 discriminator 관점으로 재해석해 credit assignment의 정밀도를 높였다. 두 논문은 서로 다른 각도에서 RLVR의 '낭비'를 줄이려 한다는 공통 목표를 공유한다. 둘째, hyperparameter transfer 연구는 scaling law의 실용적 한계를 정량화하며, 모델 규모 확장 시 발생하는 비용을 줄이는 또 다른 접근을 보여준다.

방법론적으로는 SVD 기반의 low-rank 분석, linear discriminator 재해석, 그리고 ablation 중심의 metric 분리라는 세 가지 기법이 반복 등장한다. 특히 복잡한 학습 과정을 단순한 선형 구조로 환원하려는 시도가 눈에 띈다. RELEX의 rank-1 extrapolation과 DelTA의 linear discriminator view는 모두 고차원 학습 다이나믹스를 저차원 구조로 압축해 해석 가능성과 효율을 동시에 얻으려는 전략이다. roto 2.0은 촉각 기반 RL 연구의 표준화를 위해 GPU-parallelised benchmark를 제시하며, 알고리즘 연구보다 인프라 정비에 방점을 찍는 차별화된 포지셔닝을 보인다.

이번 논문들이 남긴 과제는 명확하다. RLVR의 rank-1 trajectory가 모든 모델 규모와 도메인에서 성립하는지, 그리고 DelTA의 token credit 개선이 수학·코드 이외의 open-ended 태스크에서도 유효한지는 아직 검증되지 않았다. Hyperparameter transfer 역시 embedding layer learning rate 조정이라는 단순한 처방이 실제 초대형 모델에서 얼마나 robust한지 추가 실험이 필요하다. 결국 세 연구 모두 '작은 모델에서 관찰한 패턴이 큰 모델로 얼마나 외삽 가능한가'라는 scaling 근본 질문을 공유하고 있다.

실무 시사점은 하나로 압축된다. RLVR 파이프라인을 운영하는 ML 엔지니어라면 전체 학습을 끝까지 돌리기 전에 초기 checkpoint의 weight delta에 SVD를 적용해 rank-1 component의 선형성을 먼저 확인하라. 이 단순한 진단만으로도 early stopping 타이밍을 잡거나 compute 예산을 재배분하는 데 즉각적인 실용적 가치를 얻을 수 있다.

## 논문 분석

### 1. You Only Need Minimal RLVR Training: Extrapolating LLMs via Rank-1 Trajectories

- **출처**: arxiv
- **점수**: 7.2
- **URL**: http://arxiv.org/abs/2605.21468v1

**요약**

이 논문은 RLVR(Reinforcement Learning with Verifiable Rewards) 학습 과정에서 모델 파라미터의 변화(weight trajectory)가 극도로 low-rank하며 예측 가능하다는 사실을 발견했습니다. 특히 대부분의 성능 향상이 파라미터 delta의 rank-1 approximation만으로 포착되며, 이 projection의 크기가 학습 step에 따라 거의 선형적으로 변한다는 것을 밝혔습니다. 이를 기반으로 저자들은 RELEX(REinforcement Learning EXtrapolation)라는 방법을 제안하여, 짧은 관찰 구간에서 rank-1 subspace를 추정하고 linear regression으로 미래 checkpoint를 extrapolation합니다. Qwen2.5-Math-1.5B, Qwen3-4B-Base, Qwen3-8B-Base 세 모델에서 RELEX는 full RLVR 학습과 동등하거나 더 나은 성능을 in-domain 및 out-of-domain benchmark 모두에서 달성했습니다.

**방법론**

핵심 아이디어는 RLVR 학습 중 파라미터 변화(delta)가 rank-1 subspace에 집중된다는 관찰로, 이를 이용해 전체 학습 없이 미래 checkpoint를 예측합니다. 구체적으로, 초기 몇 개의 checkpoint에서 파라미터 delta에 SVD를 적용해 dominant rank-1 component를 추출하고, 이 component의 크기 변화를 linear regression으로 모델링하여 이후 step의 checkpoint를 extrapolation합니다. 별도의 neural network나 복잡한 학습 없이 간단한 선형 대수 연산만으로 구현되며, 추가적인 GPU 학습 비용이 거의 발생하지 않습니다.

**주요 기여**

1. RLVR weight trajectory가 극도로 low-rank(사실상 rank-1)하며 학습 step에 따라 near-linear하게 변한다는 새로운 기하학적 발견을 제시함.
2. 짧은 관찰 구간과 linear regression만으로 미래 RLVR checkpoint를 extrapolation하는 compute-efficient 방법 RELEX를 제안하고, 별도의 학습된 모델 없이 구현 가능함을 보임.
3. Qwen2.5-Math-1.5B, Qwen3-4B-Base, Qwen3-8B-Base에서 RELEX가 full RLVR 학습과 동등하거나 더 나은 성능을 in-domain 및 out-of-domain benchmark 모두에서 달성함을 실험적으로 검증함.

**실험 결과**

Qwen2.5-Math-1.5B, Qwen3-4B-Base, Qwen3-8B-Base 세 모델에서 RELEX로 extrapolation한 checkpoint가 full RLVR 학습 checkpoint와 동등하거나 더 높은 성능을 in-domain 및 out-of-domain benchmark 모두에서 달성했습니다. 논문 초록에서 구체적인 수치는 일부 생략되어 있으나, 전체 학습 대비 유의미한 컴퓨팅 절감과 함께 성능 유지 또는 향상이 확인되었습니다.

**맥락**

RLVR은 LLM의 reasoning 능력을 향상시키는 주요 패러다임으로 자리잡았지만, 학습에 드는 컴퓨팅 비용이 매우 크고 학습 과정의 기하학적 특성은 거의 연구되지 않았습니다. 기존 연구들은 RLVR이 왜 효과적인지, 파라미터 공간에서 어떤 변화가 일어나는지에 대한 이해가 부족했습니다. 이 연구는 RLVR weight trajectory의 구조적 단순성을 밝혀냄으로써, 훨씬 적은 학습만으로도 동등한 성능을 얻을 수 있는 가능성을 제시합니다.

**실무 시사점**

ML 엔지니어는 RELEX를 활용하여 전체 RLVR 학습의 일부 step만 실제로 실행한 뒤 나머지 checkpoint를 linear extrapolation으로 대체함으로써 컴퓨팅 비용을 크게 절감할 수 있습니다. 또한 rank-1 trajectory 분석은 모델 학습 모니터링, early stopping 전략, 그리고 checkpoint 선택에 실용적인 인사이트를 제공합니다. 별도의 학습된 모델 없이 간단한 linear regression만으로 구현 가능하므로 기존 RLVR 파이프라인에 쉽게 통합할 수 있습니다.

**한계**

RELEX의 extrapolation 정확도는 관찰 구간(observation window)의 길이와 rank-1 가정이 얼마나 잘 성립하느냐에 의존하며, 매우 긴 학습이나 비선형적 trajectory를 가진 경우에는 성능이 저하될 수 있습니다. 또한 실험이 Qwen 계열 세 모델에 한정되어 있어 다른 아키텍처나 더 큰 규모의 모델에 대한 일반화 가능성은 추가 검증이 필요합니다.

**관련 링크**

- http://arxiv.org/abs/2605.21468v1

### 2. roto 2.0: The Robot Tactile Olympiad

- **출처**: arxiv
- **점수**: 7.1
- **URL**: http://arxiv.org/abs/2605.21429v1

**요약**

촉각 기반 강화학습(RL) 연구는 현재 분절된 연구 환경과 특정 방향 조작 task에 편중된 문제를 겪고 있다. 이 논문은 이를 해결하기 위해 GPU-parallelised benchmark인 roto 2.0을 제안하며, 16-DOF에서 24-DOF에 이르는 네 가지 로봇 형태(morphology)에 걸쳐 촉각 기반 RL을 표준화한다. 핵심은 state 정보나 distillation 없이 오직 proprioception과 tactile sensing만을 사용하는 end-to-end 'blind' manipulation이며, 제안된 blind agent는 10초 안에 Baoding ball을 13회 회전시켜 기존 SOTA 대비 약 10배 빠른 성능을 달성했다.

**방법론**

핵심 아이디어는 state 정보나 teacher distillation 없이 proprioception과 tactile sensing만으로 작동하는 end-to-end 'blind' RL agent를 GPU-parallelised 환경에서 학습시키는 것이다. 네 가지 로봇 morphology(16-DOF ~ 24-DOF)에 대해 표준화된 task suite를 구성하고, 재현 가능한 robustly tuned baseline을 함께 제공한다. 이를 통해 연구자들이 환경 설정이나 hyperparameter tuning 대신 알고리즘 혁신에 집중할 수 있도록 진입 장벽을 낮췄다.

**주요 기여**

1. 촉각 기반 RL을 위한 GPU-parallelised benchmark roto 2.0을 오픈소스로 공개하여 연구 표준화에 기여
2. State 정보나 distillation 없이 proprioception과 tactile sensing만 사용하는 end-to-end blind manipulation 패러다임 제시
3. Baoding ball 10초 내 13회 회전이라는 기존 SOTA 대비 약 10배 향상된 성능 달성 및 robustly tuned baseline 제공

**실험 결과**

Baoding ball rotation task에서 blind agent가 10초 내 13회 회전을 달성하여 기존 SOTA 대비 약 10배(an order of magnitude) 빠른 속도를 기록. 16-DOF에서 24-DOF까지 네 가지 로봇 morphology에 걸쳐 baseline 성능 검증 완료.

**맥락**

촉각 기반 로봇 조작 연구는 각 연구팀이 서로 다른 환경과 설정을 사용해 재현성과 비교가 어렵고, 대부분의 benchmark가 방향 추정(orientation estimation) 같은 포화된 task에 집중되어 있다는 문제가 있다. 또한 기존 연구들은 privileged state 정보나 teacher-student distillation에 의존해 실제 로봇에 적용하기 어려운 경우가 많았다. roto 2.0은 이러한 문제를 해결하고 알고리즘 연구에 집중할 수 있는 표준화된 플랫폼을 제공하기 위해 설계되었다.

**실무 시사점**

오픈소스로 공개된 환경과 robustly tuned baseline 덕분에 ML 엔지니어는 RL tuning에 소모되는 시간을 줄이고 촉각 기반 알고리즘 연구 자체에 집중할 수 있다. GPU-parallelised 환경 설계로 대규모 실험을 빠르게 수행할 수 있으며, 다양한 로봇 morphology를 지원하므로 특정 하드웨어에 종속되지 않고 범용적인 알고리즘 개발이 가능하다.

**한계**

현재 benchmark는 시뮬레이션 환경에 한정되어 있어 sim-to-real transfer 성능은 별도로 검증이 필요하다. 또한 네 가지 morphology를 다루지만 실제 산업 현장의 다양한 로봇 손 구조를 모두 포괄하지는 못할 수 있다.

**관련 링크**

- http://arxiv.org/abs/2605.21429v1

### 3. Quantifying Hyperparameter Transfer and the Importance of Embedding Layer Learning Rate

- **출처**: arxiv
- **점수**: 6.8
- **URL**: http://arxiv.org/abs/2605.21486v1

**요약**

대규모 언어 모델(LLM) 학습 시 소규모 모델에서 찾은 최적 hyperparameter를 대규모 모델로 전이하는 'hyperparameter transfer'의 품질을 정량적으로 측정하는 framework를 제안한다. 세 가지 metric(scaling law fit 품질, extrapolation 오차 robustness, parameterization에 따른 asymptotic loss penalty)을 통해 Maximal Update Parameterization(μP)의 효과를 분석하며, μP의 핵심 이점이 embedding layer의 learning rate를 최대화하는 데서 비롯됨을 발견했다. 이를 바탕으로 standard parameterization(SP)에서도 embedding layer learning rate만 별도로 조정하면 μP에 준하는 transfer 품질을 달성할 수 있음을 실험적으로 입증한다.

**방법론**

핵심 아이디어는 hyperparameter transfer의 품질을 scaling law fit, extrapolation robustness, asymptotic loss penalty 세 가지 metric으로 분리하여 정량화하는 것이다. 이를 기반으로 μP와 SP를 체계적인 ablation study를 통해 비교하고, embedding layer learning rate를 독립 변수로 분리하여 그 기여도를 측정했다. 실험 결과 SP에서 embedding layer learning rate만 별도로 높게 설정해도 μP와 유사한 transfer 품질이 재현됨을 확인했다.

**주요 기여**

1. Hyperparameter transfer 품질을 정량화하는 세 가지 metric(scaling law fit 품질, extrapolation robustness, asymptotic loss penalty) framework를 최초로 제안.
2. μP가 SP 대비 AdamW 환경에서 우수한 learning rate transfer를 보이는 이유가 embedding layer learning rate 극대화에서 비롯됨을 포괄적인 ablation study로 규명.
3. SP 기반 학습에서도 embedding layer learning rate를 별도 조정하는 간단한 수정만으로 μP 수준의 hyperparameter transfer를 달성할 수 있음을 실증적으로 입증.

**실험 결과**

SP에서 embedding layer learning rate를 별도로 높게 설정한 변형이 표준 μP와 유사한 수준의 loss 및 learning rate transfer 품질을 달성했으며, 표준 SP 대비 asymptotic loss penalty가 유의미하게 감소함을 다양한 모델 규모의 ablation 실험에서 확인. 구체적인 수치는 모델 규모별 loss curve 및 scaling law fit R² 값으로 제시되었으나 단일 대표 수치는 논문 내 설정에 따라 상이함.

**맥락**

LLM 학습 비용이 폭발적으로 증가하면서 소규모 proxy 모델에서 최적 hyperparameter를 찾아 대규모 모델에 적용하는 hyperparameter transfer가 필수적인 기법이 되었다. 그러나 기존 μP 이론은 왜 learning rate transfer가 잘 되는지 충분히 설명하지 못했고, scaling law 기반 접근과 parameterization 기반 접근 간의 정량적 비교 framework도 부재했다. 이 연구는 이러한 이론적 공백을 메우고 실무자가 hyperparameter transfer 전략을 선택할 때 근거를 제공하고자 한다.

**실무 시사점**

ML 엔지니어는 μP 전체를 도입하지 않더라도 embedding layer의 learning rate를 별도로 크게 설정하는 것만으로도 대부분의 transfer 이득을 얻을 수 있어, 기존 SP 기반 코드베이스를 최소한으로 수정하면서 hyperparameter transfer 품질을 크게 향상시킬 수 있다. 또한 제안된 세 가지 정량적 metric을 활용하면 자신의 학습 설정에서 어떤 parameterization 또는 scaling law 전략이 더 적합한지 체계적으로 평가할 수 있다.

**한계**

분석이 주로 AdamW optimizer와 transformer 기반 LLM에 집중되어 있어 다른 optimizer나 아키텍처로의 일반화 가능성은 추가 검증이 필요하다. 또한 embedding layer learning rate 조정이 모든 모델 규모와 데이터 분포에서 동일하게 효과적인지에 대한 광범위한 실증 연구는 아직 부족하다.

**관련 링크**

- http://arxiv.org/abs/2605.21486v1
- https://arxiv.org/abs/2203.03466
- https://arxiv.org/abs/2310.02244

### 4. DelTA: Discriminative Token Credit Assignment for Reinforcement Learning from Verifiable Rewards

- **출처**: arxiv
- **점수**: 6.8
- **URL**: http://arxiv.org/abs/2605.21467v1

**요약**

이 논문은 대형 언어 모델(LLM)의 추론 능력 향상을 위해 널리 사용되는 Reinforcement Learning from Verifiable Rewards(RLVR) 기법에서 response-level reward가 token-level 확률 변화로 어떻게 전환되는지를 분석합니다. 저자들은 policy-gradient update가 token-gradient vector에 대한 linear discriminator로 작동한다는 'discriminator view'를 제시하며, 기존 방식이 formatting token 같은 고빈도 패턴에 의해 지배되어 진짜 중요한 token의 학습이 희석된다는 문제를 발견했습니다. 이를 해결하기 위해 DelTA(Discriminative Token Credit Assignment)를 제안하며, 더 정밀한 token-level credit assignment를 통해 모델의 추론 성능을 향상시킵니다. 다양한 benchmark 실험에서 기존 RLVR 방법 대비 일관된 성능 향상을 보였습니다.

**방법론**

핵심 아이디어는 RLVR의 policy-gradient update를 token-gradient vector에 대한 linear discriminator로 재해석하여, 어떤 token이 실제로 high-reward response를 low-reward response와 구별하는 데 기여하는지를 명시적으로 측정하는 것입니다. 기존 방식은 advantage-weighted averaging으로 positive/negative centroid를 구성하지만, 이 과정에서 formatting token 같은 고빈도 공통 패턴이 discriminative signal을 희석시킵니다. DelTA는 이러한 공통 패턴의 영향을 제거하고 실제로 reward 차이를 만드는 discriminative token에 더 높은 credit을 부여하는 방식으로 token-level 학습 신호를 재조정합니다.

**주요 기여**

1. RLVR update를 token-gradient vector에 대한 linear discriminator로 해석하는 새로운 이론적 프레임워크(discriminator view)를 제시하여, token-level 확률 변화 메커니즘을 최초로 체계적으로 분석함.
2. 기존 sequence-level RLVR에서 고빈도 formatting token이 credit assignment를 지배하여 진짜 discriminative token의 학습을 희석시키는 문제를 이론적·실험적으로 규명함.
3. DelTA(Discriminative Token Credit Assignment) 알고리즘을 제안하여 기존 GRPO 등 RLVR 방법에 적용 가능한 개선된 token-level credit assignment를 구현하고, 다양한 reasoning benchmark에서 성능 향상을 실증함.

**실험 결과**

DelTA는 수학 추론(MATH, AMC, AIME 등) 및 코드 생성 benchmark에서 기존 GRPO 기반 RLVR 대비 일관된 성능 향상을 보고하였으며, 특히 난이도 높은 문제(AIME 등)에서 더 두드러진 개선 효과를 나타냈습니다. 구체적인 수치는 논문 전문에서 확인 가능하나, 공개된 초록 기준으로 정확한 수치 비교표는 본문에 포함되어 있습니다.

**맥락**

RLVR은 LLM의 수학적 추론, 코드 생성 등 검증 가능한 태스크에서 성능을 높이는 핵심 기법으로 자리잡았지만, reward 신호가 실제로 어떤 token의 확률을 어떻게 바꾸는지에 대한 이론적 이해는 부족했습니다. 특히 sequence-level reward를 token-level 학습 신호로 분배하는 credit assignment 문제는 학습 효율과 직결되며, 잘못된 credit assignment는 불필요한 formatting token을 강화하거나 핵심 reasoning token의 학습을 방해할 수 있습니다. 이 연구는 이러한 근본적인 메커니즘을 이론적으로 규명하고 실용적인 개선책을 제시하려는 시도입니다.

**실무 시사점**

ML 엔지니어는 DelTA를 기존 GRPO, PPO 등 RLVR 프레임워크에 plug-in 방식으로 적용하여 token-level credit assignment를 개선할 수 있으며, 특히 수학 추론이나 코드 생성처럼 sparse reward 환경에서 효과적입니다. Formatting token이나 반복 패턴이 많은 학습 데이터를 사용할 때 기존 RLVR이 이런 패턴에 과도하게 최적화되는 문제를 완화하는 데 실질적으로 활용할 수 있습니다. 또한 discriminator view라는 분석 프레임워크는 향후 reward shaping이나 token weighting 전략 설계 시 이론적 근거로 활용 가능합니다.

**한계**

제안된 discriminator 기반 분석은 linear approximation에 기반하므로 실제 비선형 transformer dynamics를 완전히 포착하지 못할 수 있습니다. 또한 실험이 특정 규모의 모델과 수학·추론 중심 benchmark에 집중되어 있어, 다양한 도메인과 모델 크기에서의 일반화 가능성은 추가 검증이 필요합니다.
