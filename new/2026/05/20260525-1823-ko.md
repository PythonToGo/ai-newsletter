## 이번 주 연구 동향

이번 주 논문들은 표면적으로는 게임 AI, 지정학적 편향, 인간 지각 정렬, attention 효율화라는 서로 다른 주제를 다루지만, 그 저변에는 하나의 공통된 질문이 흐른다. 바로 'AI 시스템이 인간의 의도와 얼마나 정확하게 정렬되어 있는가'이다. RLHF와 post-training이 LLM에 개발사 국적 편향을 최대 18배 odds shift 수준으로 주입한다는 발견, 그리고 hybrid generative-discriminative 학습 목표가 순수 discriminative 모델보다 인간 지각에 더 잘 정렬된다는 결과는 모두 alignment의 본질적 메커니즘을 해부하려는 시도다.

방법론적으로 주목할 점은 '통제된 비교 실험'이 반복적으로 등장한다는 것이다. 지정학적 편향 연구는 base model과 chat model 쌍을 비교해 post-training의 순수 효과를 분리했고, JEM 연구는 architecture와 데이터를 고정한 채 mixing coefficient만 변화시켜 학습 목표의 영향을 isolate했다. PCSP는 frozen LLM embedding과 low-rank persona projection을 조합해 수천 개의 NPC를 단일 policy로 제어하는 효율적 설계를 택했으며, approximate attention 연구는 I/O complexity lower bound 증명을 통해 알고리즘의 이론적 최적성을 보장했다. 이처럼 이번 주 논문들은 실험 변수를 엄밀하게 통제하거나 이론적 하한을 증명하는 방식으로 주장의 신뢰성을 높이는 경향을 공유한다.

이 연구들이 남긴 과제는 명확하다. post-training 단계의 편향 감사(bias audit)를 어떻게 표준화할 것인가, hybrid 학습 목표의 sweet spot은 도메인마다 다를 수 있는가, 그리고 approximate attention의 이론적 I/O 이득이 실제 하드웨어 환경에서 얼마나 실현 가능한가가 다음 연구의 핵심 질문으로 남는다. 특히 long-context 모델이 보편화되는 흐름에서 attention의 I/O 최적화는 이론과 시스템 구현 사이의 간극을 좁히는 것이 시급하다.

ML 엔지니어에게 가장 직접적인 실무 시사점은 post-training 파이프라인에 대한 경각심이다. fine-tuning, RLHF, DPO 등 alignment 단계는 모델 성능을 높이는 동시에 의도치 않은 편향을 증폭시킬 수 있으며, 그 효과는 프롬프트 언어에 따라서도 달라진다. 프로덕션 모델을 배포하기 전 다국어·다문화 시나리오에서의 bias audit을 체크리스트에 반드시 포함해야 한다.

## 논문 분석

### 1. One Policy, Infinite NPCs: Persona-Traceable Shared RL Policies for Scalable Game Agents

- **출처**: arxiv
- **점수**: 7.0
- **URL**: http://arxiv.org/abs/2605.23652v1

**요약**

이 논문은 수백~수천 명의 NPC가 등장하는 라이프 시뮬레이션 게임에서 각 캐릭터가 고유한 성격을 일관되게 유지하면서도 실시간으로 동작해야 하는 문제를 다룬다. 저자들은 PCSP(Persona Conditioned Shared Policy)라는 단일 reinforcement learning policy를 제안하며, 이는 frozen LLM embedding으로 인코딩된 자연어 persona 설명을 조건으로 받아 모든 NPC를 하나의 policy로 제어한다. 300개의 persona로 구성된 life-simulation benchmark에서 compositional zero-shot persona 식별 정확도가 우연 대비 최대 17배, Spearman rho 약 0.73의 semantic-behavioral alignment를 달성했으며, LLM-as-policy 대비 22배 빠른 inference 속도를 보였다.

**방법론**

핵심 아이디어는 모든 NPC를 단일 reinforcement learning policy로 제어하되, 각 NPC의 자연어 persona 설명을 frozen LLM으로 한 번만 인코딩하여 policy의 조건 입력으로 사용하는 것이다. Low-rank persona projection을 통해 고차원 LLM embedding을 policy network에 효율적으로 주입하고, PPO를 기본 RL objective로 삼으면서 InfoNCE 기반 trajectory-consistency loss로 행동 일관성을, KL diversity loss로 persona 간 행동 다양성을 동시에 학습한다. 이를 통해 새로운 persona가 추가되어도 재학습 없이 zero-shot으로 대응 가능한 compositional generalization을 달성한다.

**주요 기여**

1. 단일 shared RL policy로 수천 개의 NPC를 자연어 persona 조건만으로 제어하는 PCSP 프레임워크 제안으로, NPC 수 증가에 따른 학습 비용 문제를 해결함.
2. PPO + InfoNCE trajectory-consistency + KL diversity로 구성된 복합 training objective를 통해 persona 일관성과 행동 다양성을 동시에 최적화하는 방법론 제시.
3. 300-persona life-simulation benchmark를 구축하고, compositional zero-shot persona 식별(우연 대비 17배), Spearman rho 0.73의 semantic-behavioral alignment, LLM-as-policy 대비 22배 빠른 inference를 실증적으로 검증함.

**실험 결과**

300-persona life-simulation benchmark 기준: compositional zero-shot persona 식별 정확도 우연(chance) 대비 최대 17배 향상, semantic-behavioral alignment Spearman rho ≈ 0.73 달성, LLM-as-policy baseline 대비 inference 속도 22배 향상. Ablation study에서 InfoNCE trajectory-consistency objective가 성능에 가장 핵심적인 기여를 하는 것으로 확인됨.

**맥락**

라이프 시뮬레이션 게임에서 수천 명의 NPC 각각에 별도 policy를 학습시키는 것은 계산 비용 면에서 현실적으로 불가능하며, LLM을 직접 policy로 사용하면 실시간 inference 요구사항을 충족하기 어렵다. 기존 방법들은 persona 일관성, 디자이너 제어 가능성, 실시간 inference 세 가지 요구사항을 동시에 만족하지 못했다. 따라서 하나의 shared policy가 자연어로 기술된 다양한 persona를 조건으로 받아 각 캐릭터의 개성을 유지하면서도 빠르게 동작하는 scalable한 접근법이 필요했다.

**실무 시사점**

ML 엔지니어는 PCSP의 핵심 구조인 low-rank persona projection과 frozen LLM embedding 조합을 게임 AI 외에도 다중 에이전트 시뮬레이션이나 persona-conditioned 대화 시스템에 적용할 수 있다. PPO + InfoNCE consistency + KL diversity로 구성된 복합 training objective는 행동 일관성과 다양성을 동시에 확보하는 실용적인 레시피로, 유사한 조건부 policy 학습 문제에 바로 참고할 수 있다. 또한 NPC 추가 시 추가 학습 없이 새로운 자연어 persona 설명만으로 zero-shot 일반화가 가능하므로, 콘텐츠 확장 비용을 크게 줄일 수 있다.

**한계**

논문의 benchmark가 300개 persona의 life-simulation 도메인에 한정되어 있어, 액션 게임이나 전략 게임 등 다른 장르로의 일반화 가능성은 아직 검증되지 않았다. 또한 frozen LLM embedding에 의존하기 때문에 embedding 품질이 낮거나 persona 설명이 모호할 경우 성능 저하가 발생할 수 있다는 점도 주목해야 한다.

**관련 링크**

- http://arxiv.org/abs/2605.23652v1

### 2. It's the humans, not the data: Geopolitical bias in LLMs originates in post-training, amplified by the language of the prompt

- **출처**: arxiv
- **점수**: 6.9
- **URL**: http://arxiv.org/abs/2605.23825v1

**요약**

이 논문은 LLM의 지정학적 편향(geopolitical bias)이 pre-training 데이터가 아니라 post-training(RLHF, instruction tuning 등 인간 개입 단계)에서 발생한다는 것을 실증적으로 밝혔습니다. 7개 AI 연구소의 base model과 chat model 쌍을 28개 국가 쌍에 대해 영어·프랑스어·중국어로 테스트한 결과, 6개 연구소의 모델이 post-training 후 해당 개발사의 국가·지역에 유리한 방향으로 편향이 강화되었습니다. 특히 Alibaba의 Qwen 2.5는 base model에서 중립적(-0.15 log-odds)이었으나 chat variant에서 +2.91 log-odds로 약 18배의 odds shift가 관찰되었습니다. 또한 프롬프트 언어에 따라 편향의 크기가 달라지는 현상도 확인되었습니다.

**방법론**

핵심 아이디어는 동일 아키텍처의 base model(pre-training만 수행)과 chat model(post-training 포함) 쌍을 비교함으로써 post-training의 순수한 편향 기여분을 분리하는 것입니다. 28개 국가 쌍에 대해 지정학적 선호를 유도하는 paired-scenario forced-choice probe를 설계하고, 영어·프랑스어·중국어 세 언어로 각각 테스트하여 log-odds 기반으로 편향의 방향과 크기를 정량화했습니다. 7개 AI 연구소(Alibaba, Meta 등)의 open-weight 모델을 대상으로 하여 결과의 일반성을 확보했습니다.

**주요 기여**

1. LLM의 지정학적 편향이 pre-training 데이터가 아닌 post-training 단계에서 주로 발생한다는 것을 7개 연구소, 7쌍의 모델로 실증적으로 입증함.
2. 개발사의 국적·지역과 일치하는 방향으로 post-training 후 편향이 강화되는 패턴을 정량적으로 측정하고, Qwen 2.5에서 18배 odds shift라는 극단적 사례를 제시함.
3. 프롬프트 언어(영어, 프랑스어, 중국어)가 편향의 크기와 방향에 영향을 미친다는 것을 발견하여, 다국어 편향 평가의 필요성을 제기함.

**실험 결과**

Alibaba Qwen 2.5: base model 중국 선호도 -0.15 log-odds (p=0.15, 통계적 비유의), chat model +2.91 log-odds (p<10^-4), odds 기준 약 18배 shift. 7개 연구소 중 6개에서 post-training 후 자국·자지역 편향 방향으로의 유의미한 shift 관찰됨. 프롬프트 언어에 따라 편향 크기가 달라지며, 프랑스어 프롬프트 조건에서 특정 모델의 편향이 가장 두드러지게 나타남.

**맥락**

기존에는 LLM의 편향이 주로 pre-training 데이터의 구성(서구 중심 텍스트 과다 등)에서 비롯된다고 가정되어 왔으며, 이에 따라 데이터 다양성 확보가 주요 해결책으로 제시되었습니다. 그러나 이 연구는 실제 편향의 주요 원인이 인간이 설계하는 post-training 단계(RLHF, instruction tuning, alignment)에 있음을 보여줌으로써, 데이터 중심 접근만으로는 편향 문제를 해결할 수 없다는 점을 시사합니다. AI 모델의 지정학적 편향은 국제 정치·외교적 맥락에서 심각한 영향을 미칠 수 있어, 현재 AI 거버넌스 논의에서 매우 중요한 주제입니다.

**실무 시사점**

ML 엔지니어는 post-training(fine-tuning, RLHF, DPO 등) 파이프라인이 모델에 의도치 않은 지정학적 편향을 주입할 수 있음을 인지하고, alignment 단계에서 편향 감사(bias audit)를 반드시 수행해야 합니다. 또한 동일 모델이라도 프롬프트 언어(영어, 프랑스어, 중국어 등)에 따라 편향의 방향과 크기가 달라지므로, 다국어 서비스 배포 시 언어별 편향 평가를 별도로 진행하는 것이 중요합니다.

**한계**

이 연구는 forced-choice probe 방식의 paired-scenario 설계에 의존하므로, 실제 open-ended 생성 환경에서의 편향 측정과 차이가 있을 수 있습니다. 또한 post-training 데이터와 프로세스의 내부 세부 사항이 공개되지 않아 편향 발생의 정확한 메커니즘을 특정하기 어렵다는 한계가 있습니다.

**관련 링크**

- http://arxiv.org/abs/2605.23825v1

### 3. Not Too Generative, Not Too Discriminative: The Human Alignment Sweet Spot

- **출처**: arxiv
- **점수**: 6.9
- **URL**: http://arxiv.org/abs/2605.23819v1

**요약**

이 연구는 인간의 시각적 표현이 discriminative 학습과 generative 학습 중 어느 쪽에 더 가까운지를 묻는 오래된 질문에 답하려 한다. Joint Energy-Based Models(JEMs)를 활용해 단일 architecture 내에서 두 학습 목표를 연속적으로 interpolate하는 방식으로, 학습 목표 자체의 효과를 다른 변수(architecture, scale, 데이터)와 분리해 측정했다. 6가지 human-alignment benchmark에서 실험한 결과, 순수 discriminative 또는 순수 generative 모델보다 두 목표를 혼합한 hybrid JEM이 인간 지각과의 정렬(alignment)을 일관되게 극대화했다. 이는 인간의 시각 시스템이 '중간 지점'의 학습 목표에 해당하는 표현을 사용할 가능성을 시사한다.

**방법론**

핵심 아이디어는 Joint Energy-Based Models(JEMs)의 단일 mixing coefficient(λ)를 0(순수 discriminative)에서 1(순수 generative) 사이로 변화시켜, architecture·데이터·scale을 고정한 채 학습 목표의 효과만을 isolate하는 것이다. 각 λ 값에서 학습된 모델을 perceptual similarity, gloss perception, human response uncertainty, robustness, shape-texture cue conflict, diagnostic feature attribution 등 6가지 human-alignment benchmark로 평가했다. 이를 통해 generative-discriminative continuum 위에서 human alignment가 최대화되는 지점을 체계적으로 탐색했다.

**주요 기여**

1. Architecture, scale, 데이터를 고정하고 학습 목표만 변화시키는 통제된 실험 설계를 통해, 학습 목표 자체가 human alignment에 미치는 순수한 영향을 최초로 분리·정량화했다.
2. 6가지 다양한 human-alignment benchmark에 걸쳐 hybrid(중간 지점) 학습 목표가 순수 discriminative 및 generative endpoint보다 일관되게 우수함을 실증했다.
3. JEM의 mixing coefficient라는 단일 scalar로 generative-discriminative continuum을 탐색하는 실용적인 프레임워크를 제시해, 향후 human-aligned representation learning 연구의 방법론적 기준을 제공했다.

**실험 결과**

6가지 human-alignment benchmark(perceptual similarity, gloss perception, human response uncertainty, robustness, shape-texture cue conflict, diagnostic feature attribution) 전반에서 hybrid JEM(중간 mixing coefficient)이 순수 discriminative(λ=0) 및 순수 generative(λ=1) endpoint 모두를 일관되게 상회했다. 구체적인 수치는 논문 전문에서 확인 필요(초록에서 수치 미공개).

**맥락**

컴퓨터 비전 분야에서 discriminative 모델(예: 분류기)과 generative 모델(예: diffusion, VAE) 중 어느 쪽이 인간 지각에 더 가까운 표현을 학습하는지는 오랫동안 논쟁거리였다. 그러나 기존 비교 연구들은 학습 목표 외에도 architecture, 데이터 규모, 학습 데이터 등이 달라 학습 목표 자체의 순수한 영향을 분리하기 어려웠다. 이 연구는 이 confound 문제를 JEM을 통해 통제된 방식으로 해결하려 한다.

**실무 시사점**

ML 엔지니어는 인간 지각과의 정렬이 중요한 태스크(perceptual similarity, robustness, feature attribution 등)에서 순수 discriminative 또는 generative 모델 대신 hybrid JEM 방식의 학습 목표를 고려할 수 있다. 단일 mixing coefficient 하나만 조정하면 동일한 architecture로 generative-discriminative continuum 위의 최적 지점을 탐색할 수 있어 실험 비용이 상대적으로 낮다. 또한 이 결과는 foundation model fine-tuning 시 auxiliary generative loss를 추가하는 전략의 이론적 근거로 활용될 수 있다.

**한계**

실험이 JEM이라는 특정 framework에 국한되어 있어, 결론이 다른 hybrid 학습 방식(예: diffusion classifier, masked autoencoder 등)에도 일반화되는지는 추가 검증이 필요하다. 또한 논문에서 다루는 benchmark들이 주로 저수준 지각(perceptual similarity, texture/shape bias 등)에 집중되어 있어 고수준 인지 태스크에서의 alignment는 미검증 상태이다.

### 4. Approaching I/O-optimality for Approximate Attention

- **출처**: arxiv
- **점수**: 6.9
- **URL**: http://arxiv.org/abs/2605.23751v1

**요약**

이 논문은 대형 언어 모델의 attention 연산에서 발생하는 I/O complexity 문제를 재검토합니다. 기존 FlashAttention 등의 방법은 시퀀스 길이 n에 대해 quadratic한 I/O 비용을 가지지만, 이 연구는 approximate attention framework를 활용하여 n에 대해 거의 linear한 I/O 비용을 달성하는 알고리즘을 제시합니다. 또한 각 parameter regime에서 lower bound를 증명하여 제안된 알고리즘이 I/O-optimal에 근접함을 이론적으로 보입니다.

**방법론**

핵심 아이디어는 Alman과 Song의 polynomial approximation 기반 approximate attention framework를 I/O-efficient하게 재설계하는 것입니다. Query, key, value matrix를 fast memory 크기 M에 맞게 tile 단위로 분할하고, polynomial kernel approximation을 활용하여 softmax attention을 근사함으로써 slow memory 접근 횟수를 줄입니다. 각 parameter regime(n, d, M의 상대적 크기)에 따라 알고리즘을 달리 적용하고, 대응하는 lower bound 증명을 통해 near-optimality를 확립합니다.

**주요 기여**

1. 시퀀스 길이 n에 대해 거의 linear한 I/O 비용을 달성하는 approximate attention 알고리즘 제시 — 기존 FlashAttention의 quadratic I/O 비용을 이론적으로 크게 개선
2. 각 parameter regime별 I/O complexity lower bound 증명 — 제안 알고리즘이 I/O-optimal에 근접함을 엄밀히 보임
3. Alman-Song approximate attention framework를 I/O complexity 관점에서 재해석하고 확장 — 이론적 알고리즘 설계와 하드웨어 메모리 계층 구조를 연결하는 새로운 분석 프레임워크 제공

**맥락**

FlashAttention과 그 변형들은 GPU의 fast memory(SRAM)와 slow memory(HBM) 간의 데이터 전송을 최소화하여 실용적인 속도 향상을 이루었지만, 여전히 I/O 비용이 n²에 비례하는 한계가 있습니다. 시퀀스 길이가 길어질수록 이 quadratic bottleneck은 더욱 심각해지며, 이론적 하한인 Ω(nd)와의 격차가 큽니다. 이 연구는 Alman과 Song의 approximate attention framework에서 영감을 받아 이 격차를 좁히는 것을 목표로 합니다.

**실무 시사점**

ML 엔지니어는 이 연구를 통해 긴 context를 처리하는 모델에서 attention의 I/O 비용을 이론적으로 거의 linear하게 줄일 수 있는 가능성을 확인할 수 있으며, 향후 long-context inference 최적화 시스템 설계에 참고할 수 있습니다. 또한 각 parameter regime(n, d, M의 관계)별로 tight한 lower bound가 제시되어 있어, 특정 하드웨어 메모리 구성에서 최적 알고리즘 선택의 이론적 근거로 활용할 수 있습니다.

**한계**

이 연구는 approximate attention을 기반으로 하므로 exact attention 대비 정확도 손실이 존재하며, 이론적 분석 중심이라 실제 GPU 하드웨어에서의 구현 및 실용적 성능 검증이 아직 충분하지 않습니다. 또한 제안된 알고리즘이 실제 시스템에서 FlashAttention 대비 얼마나 빠른지에 대한 empirical benchmark가 부재합니다.
