## 트렌드 분석

최근 일주일 아카이브는 에이전트 실행 환경, 모델 출시, 산업 동향 등을 다뤘다. 이번 호는 일반 AI/ML 범위에서 새로 확인한 Mercury 3 한 건을 분석한다. 모델의 처리 속도뿐 아니라 기존 모델 접근 조건과 추론 설정의 기본값이 함께 바뀌었다는 점에 초점을 맞췄다. 이를 업계 전체의 추세로 일반화하지는 않는다.

최근 14일 범위의 저장된 기사 15편과 URL·사건을 대조했으며, Mercury 3 출시의 기존 보도는 없었다. 수집 기준은 최근 24시간이다. 다만 이번 발표는 공식 목록에서 10월 19일이라는 날짜만 확인되어, 정확히 24시간 경계 안인지는 확정할 수 없다. 이 시간 정밀도 한계를 명시하고, 이용 종료 일정이 있는 미보도 소식으로 선별했다. 수량을 채우기 위한 과거 기사나 반복 항목은 추가하지 않았다.

**요약**

Inception은 확산 기반 언어 모델 Mercury 3를 소개하고, 한 요청에서 다룰 수 있는 문맥 길이를 Mercury 2.5의 26만 토큰에서 100만 토큰으로 늘렸다고 밝혔다. 공식 발표의 NVIDIA GPU 기준 초당 1,068토큰은 공급자 측 수치이지 독립 검증 결과는 아니다. 모델 안내에는 Mercury 2·2.5의 신규 이용자 접근이 종료됐으며, 2026년 10월 19일 이전 사용 이력이 있는 기존 고객은 11월 15일까지 접근할 수 있다고 적혀 있다. 기업 고객은 각 계약에 따라 지원되므로 모든 고객의 종료일이 같다고 해석하면 안 된다. 또한 추론 강도를 생략했을 때 Mercury 3는 `low`, Mercury 2·2.5는 `medium`을 쓰므로 모델 이름만 교체해도 비교 조건이 달라진다.

**맥락**

확산 기반 언어 모델은 텍스트 생성에 확산 방식의 접근을 사용하는 모델 계열이다. 이번 발표에서 검토할 변화는 새 모델의 속도 주장과 별개로 운영 환경의 전환 조건이 구체화됐다는 것이다. 편집상 판단으로는 기존 Mercury 이용자에게 접근 기한과 기본 설정 변화가 즉시 점검할 정보다. 다른 모델 이용자에게는 아직 교체 권고가 아니라 평가 후보의 등장이다.

공식 플랫폼 문서의 Mercury 3 요금은 아래와 같다. 단위는 미화 달러/100만 토큰이며, 다른 중개 서비스나 기업 계약에 그대로 적용된다고 가정하지 않는다.

| 구분 | 정상 표시 가격 | 출시 할인 표시 가격 |
| --- | ---: | ---: |
| 일반 입력 | $0.20 | $0.10 |
| 캐시 입력 | $0.02 | $0.01 |
| 출력 | $0.70 | $0.35 |

캐시 가격은 실제 접두부 캐시에서 제공된 입력에 해당한다. FAQ에 따르면 캐싱은 자동이지만 공개된 보존 시간 보장은 없다. 따라서 반복 프롬프트 전부에 캐시 단가를 적용해서는 안 된다. 출력 토큰에는 추론 토큰도 포함되며, 사용량의 세부 항목은 전체에 이미 포함되어 있어 다시 더하면 이중 계산이 된다. 출시 할인 종료일은 확인한 페이지에 명시되지 않았다.

**실무 시사점**

다음은 편집부가 제안하는 점검 절차이며 이번 작성 과정에서 실행한 테스트가 아니다.

1. **기존 Mercury 운영팀 → 사용 모델과 계약 분류 확인 → 영향 목록 완성.** 설정과 배포 문서에서 `mercury-2`·`mercury-2.5` 의존성을 찾아 담당자를 지정한다. 완료 기준은 각 서비스의 사용 이력, 기업 계약 여부, 전환 기한 확인 책임자가 기록된 것이다. 근거: 아래 모델 안내.
2. **모델 교체 검토팀 → 추론 강도를 명시한 회귀 평가 설계 → 비교표 완성.** 동일한 대표 입력으로 정답성, 도구 호출 인자, JSON 형식 준수 여부를 비교하고 `reasoning_effort`를 기록한다. 완료 기준은 기존·신규 설정의 품질 기준과 복구 조건이 명문화된 것이다. 기본값 차이를 모델 품질 차이로 오인하지 않는다. 근거: 추론 설정 문서.
3. **성능·비용 담당자 → 전체 응답 시간과 토큰 구성을 분리 → 운영 예산 검토 완료.** 첫 응답 대기와 작업 완료 시간의 중앙값·상위 지연을 구분하고, 일반 입력·캐시 입력·출력으로 비용표를 나눈다. 완료 기준은 캐시 적중률 가정과 정상가 복귀 시 예산이 함께 적힌 것이다. 근거: 요금표·FAQ. 토큰 생성 속도를 업무 완료 시간으로 환산하지 않는다.

**한계 및 의문**

공급자가 제시한 토큰 속도만으로 실제 서비스의 동시 요청 처리, 네트워크 지연, 도구 실행을 포함한 성능은 알 수 없다. 경쟁 모델 대비 우위도 이번 호에서 독립 검증하지 않았으므로 확정적인 순위로 싣지 않았다. 긴 문맥 지원이 긴 문서의 모든 사실을 정확히 회수한다는 보장도 아니다.

출시 할인 종료일과 구버전 접근 종료의 정확한 시각·시간대는 미확인이다. 기업 계약의 예외도 개별 확인이 필요하다. 발표일만 있는 자료라 최근 24시간 충족 여부는 시간 단위로 검증할 수 없다는 한계가 남는다. 문서는 변경될 수 있으므로 실제 전환 전 다시 확인해야 한다.
