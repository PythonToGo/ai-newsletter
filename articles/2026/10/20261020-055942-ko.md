## 아이템 분석

### 1. MiniMax M3.1 Flash 출시 — 요금 인하와 기본 추론 설정을 함께 확인하자

- **출처**: MiniMax 공식 발표·호출 문서·가격표·캐시 가이드
- **점수**: 7.8/10 — 편집 선정 점수이며 모델 성능 측정값이 아님
- **URL**: https://www.minimax.io/blog/minimax-m31f

**요약**

MiniMax는 10월 19일 M3.1 Flash를 공식 출시하고 API·M Plan·MiniMax Code에서 제공한다고 밝혔다. 회사는 이전 모델 대비 온라인 추론이 거의 3배 빠르고 agent 작업 사용 비용이 70% 낮다고 주장한다. 발표문은 가중치를 나중에 공개하겠다고 적어, 서비스 접근과 가중치 공개 완료를 구분해야 한다. 호출 문서는 모델 ID를 `MiniMax-M3.1-Flash`, context window를 1,000,000토큰으로 안내한다. [1][2]

**맥락**

공식 발표의 DeepSWE v1.1 73.7%는 공급자 보고이며 독립적인 운영 품질 검증이 아니다. “70% 비용 절감”도 모든 입력과 출력 길이에 적용되는 요금 할인율로 읽으면 안 된다. 작업별 토큰 사용과 비교 조건을 확인해야 한다. [1]

현재 가격표의 모델 행은 다음과 같다. 금액은 USD, 100만 토큰당 요금이며 플랜 구독료나 전체 작업 비용이 아니다. [3]

| 구분 | 요금 | 적용 시 구분 |
| --- | --- | --- |
| 새 입력 | $0.15 | 캐시에 적중하지 않은 입력 |
| 출력 | $0.60 | 생성된 출력 토큰 |
| 캐시 읽기 | $0.015 | 실제 캐시 적중 입력에만 적용 |

캐시 문서는 입력 512토큰 이상에서 prefix matching을 사용한다고 설명한다. 도구 목록·system prompt·메시지 앞부분 변경은 적중에 영향을 줄 수 있다. 캐시가 있다고 모든 입력에 할인 단가를 적용할 수는 없다. [4]

호출 문서에서 특히 중요한 제약은 추론을 끌 수 없다는 점이다. `effort`는 low·medium·high·xhigh·max를 지원하며 생략 시 max다. `thinking: disabled` 또는 `effort: none`은 400 오류로 안내한다. 높은 effort는 토큰 수와 지연을 늘릴 수 있다. [2]

**실무 시사점**

다음은 도입을 검토하는 통합·운영팀을 위한 편집 제안이다. 이번 뉴스레터에서 API를 호출하거나 유료 시험을 수행한 것은 아니다.

1. **대상 → 기존 모델 통합 담당자:** 실제 업무의 비기밀 표본을 선정하고 모델 ID·프로토콜·effort·출력 한도를 명시한다. 완료 기준은 기존의 추론 비활성화 설정이 새 모델에 잘못 전달되지 않고, thinking과 최종 답변을 올바르게 분리하는 것이다.
2. **대상 → 비용 담당자:** 새 입력·캐시 적중 입력·출력을 별도 집계한다. 완료 기준은 단가표가 아니라 재시도까지 포함한 성공 작업당 비용과 지연 비교표다. 모든 입력을 캐시 가격으로 계산하지 않는다.
3. **대상 → 품질 담당자:** 동일 과제에서 effort별 완료율과 도구 호출 실패를 비교한다. 완료 기준은 비용을 낮춘 설정에서도 필요한 품질을 충족하고, 실패 시 기존 경로로 복귀할 수 있는 상태다.

캐시 usage 필드도 프로토콜마다 의미가 다르다. 공식 가이드는 Anthropic 호환의 `input_tokens`를 새 입력으로, OpenAI 호환의 `prompt_tokens`를 전체 입력으로 설명한다. 후자에서는 cached_tokens를 빼고 새 입력량을 계산해야 이중 청구 추정을 피할 수 있다. [4] 여기서 “호환”은 요청 형식 설명이지 이 뉴스레터가 해당 API를 사용했다는 뜻이 아니다.

**한계 및 의문**

공식 호출 문서와 릴리스 노트는 open-weight라는 표현을 쓰지만, 출시 글은 가중치 공개를 미래형으로 적는다. 이번에는 다운로드 가능한 가중치와 라이선스를 별도로 검증하지 않았으므로 공개 완료나 자체 배포 가능 여부를 확정하지 않는다. 서드파티가 보도한 구체적인 공개 예정일도 확정 사실로 추가하지 않았다.

TPS는 토큰 생성 속도이고 사용자 요청 전체 지연은 아니다. 공급자의 속도·비용 주장만으로 다른 모델보다 모든 작업에서 빠르고 저렴하다고 결론낼 수 없다. 가격표의 다른 모델용 Standard/Priority 조건을 Flash에 임의로 적용하지도 않는다. 이번에 확인한 Flash 모델 행에 한정한 요금이며 계정·서비스 티어의 실제 청구는 도입 전에 재확인해야 한다.

캐시 유지 시간·적중률을 이번 문서만으로 보장하지 않는다. 공개 문서 검토만 수행했으며 실제 계정 접근·품질·청구 검증은 하지 않았다.
