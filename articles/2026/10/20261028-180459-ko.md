## 트렌드 분석

오늘의 두 발표는 생성형 AI가 텍스트 중심의 단일 모델 경쟁에서 벗어나고 있음을 서로 다른 방향으로 보여준다. Google DeepMind의 Genie 4는 사용자가 움직이고 수정할 수 있는 세계를 영상·음향과 함께 실시간으로 생성하는 연구 프리뷰다. Liquid AI의 LFM3는 약 2B급 모델들을 하나의 공통 백본에서 텍스트·비전·오디오·옴니·의사결정 작업으로 분화하고, 로컬 실행과 도메인 특화를 전면에 내세운다.

그러나 두 제품의 현재 상태는 크게 다르다. Genie 4는 신뢰할 수 있는 테스터에게만 먼저 제공되며, 일반 개발자는 아직 직접 재현하거나 지연시간·일관성·물리 정확도를 독립 검증하기 어렵다. 반면 LFM3의 텍스트 체크포인트는 이미 Hugging Face에서 내려받을 수 있고 llama.cpp·MLX·vLLM 지원도 발표됐지만, 공개된 성능 수치는 대부분 공급사 자체 평가다. ‘공개 발표’와 ‘검증 가능한 배포’를 같은 단계로 취급하면 안 된다.

최근 7일 아카이브는 대형 모델 출시, 에이전트 안전 평가, 샌드박스 사고와 신약개발 협업에 집중됐다. 이번 판은 실시간 세계 시뮬레이션과 온디바이스 멀티모달 모델이라는 다른 축을 보완한다. 두 항목 모두 최근 14일 기사에서 동일 URL이나 동일 출시 사건을 다루지 않았으며, 10월 27일 공식 발표를 원문과 모델 카드·독립 보도로 재확인했다.

실무적으로는 ‘가장 새 모델’을 바로 도입하는 것보다 접근 상태에 맞는 평가 계획을 세우는 편이 중요하다. Genie 4는 대기 명단과 연구 프리뷰의 한계를 기록한 탐색 대상으로, LFM3는 라이선스와 메모리·지연시간·정확도를 직접 측정할 수 있는 프로토타입 대상으로 분리해야 한다.

### 1. Genie 4 — 음향과 실시간 편집을 결합한 월드 모델 연구 프리뷰

- **출처**: Google DeepMind 공식 발표 / The Verge 독립 보도
- **점수**: 8.7/10 *(편집부 선정 점수)*
- **URL**: https://deepmind.google/blog/genie-4-a-new-generation-of-world-simulation/
- **원 게시자**: Google DeepMind
- **발견 경로**: 당일 AI 발표 모니터링 후 Google DeepMind 원문·모델 페이지와 독립 보도를 교차 확인
- **공개일**: 2026-10-27
- **사건 상태**: 신뢰할 수 있는 테스터 대상 연구 프리뷰; Project Genie·Gemini API·Google AI Studio의 광범위한 이용은 예정 단계
- **확인일**: 2026-10-28

**요약**

Google DeepMind가 텍스트나 이미지에서 실시간 상호작용 환경을 만드는 Genie 4를 발표했다. 사용자는 키보드로 이동하거나 카메라를 조작하면서 자연어로 날씨·객체·인물을 바꿀 수 있고, 모델은 영상과 함께 음악·환경음·대화를 생성한다. Google은 Gemini 계열 모델이 장면의 외관·행동과 연속성 유지를 보조한다고 설명하지만, 모델 구조·학습 데이터·정량 벤치마크의 전체 세부사항은 공개하지 않았다.

독립 보도에 따르면 연속 상호작용은 약 2분 수준으로 이전 세대보다 늘었지만, 기자가 직접 모델을 시험하거나 Genie 3와 동일 조건에서 비교한 결과는 아니다. Google 공식 모델 페이지도 지원 시간을 ‘수 분’으로 표현한다. 따라서 현재 확인 가능한 것은 공급사가 제공한 데모와 제한 공개 상태이지, 범용 물리 시뮬레이터의 독립 검증이 아니다.

**맥락**

월드 모델은 행동에 따라 다음 관측이 어떻게 변할지를 생성하거나 예측하는 모델이다. 게임·영상 제작뿐 아니라 로봇과 에이전트가 실제 환경에 들어가기 전 다양한 상황을 경험하는 훈련 공간으로 활용될 수 있다. Genie 4의 차별점은 사전에 완성된 동영상 생성이 아니라 사용자의 입력에 반응하는 환경, 실시간 자연어 수정, 영상과 함께 생성되는 음향을 하나의 경험으로 묶었다는 데 있다.

이 발표는 아직 제품 출시보다 연구 프리뷰에 가깝다. 신뢰할 수 있는 테스터에게 먼저 제공되고, Google AI Ultra의 Project Genie와 Gemini API·AI Studio 조기 접근 파트너에게 추후 확대될 예정이다. 생성된 영상과 오디오에는 Google의 SynthID 워터마크가 포함된다고 회사는 밝혔다.

**실무 시사점**

- **대상**: 로봇 시뮬레이션, 게임 프로토타이핑, 영상 사전시각화 팀
- **방법**: 접근 권한을 얻으면 ‘멋진 장면’보다 상태 일관성을 먼저 평가한다. 동일한 객체를 여러 번 가리고 다시 보이게 하고, 날씨·카메라·인물 편집을 연속으로 적용하며 객체 속성·공간 관계·음향 동기화가 유지되는지 프레임별로 기록한다.
- **완료 기준**: 사전에 정한 20개 시나리오에서 객체 영속성, 텍스트 가독성, 공간 정확성, 명령 반영 지연, 오디오 동기화 실패율을 산출하고, 실제 훈련이나 제작에 허용할 임계값을 통과해야 한다.

아직 접근할 수 없는 팀은 데모 영상으로 성능을 추정하지 말고, 요구사항과 실패 사례 목록을 먼저 준비하는 것이 합리적이다. 특히 로봇 학습에 쓰려면 생성 세계에서 잘 작동하는 정책이 실제 환경에서도 작동하는지 별도의 sim-to-real 검증이 필요하다.

**한계 및 의문**

Genie 4는 시간이 길어지거나 복잡한 편집을 반복하면 시각 세부사항과 객체 영속성이 변할 수 있다. 복잡한 물리 상호작용, 다중 에이전트, 실제 장소의 정확한 재현, 읽을 수 있는 텍스트, 공간 정확성, 실시간 오디오와 장기 일관성도 미해결 과제로 명시됐다. 공개된 안전 평가는 Google 내부 평가이며 외부 연구자가 검증할 자료는 제한적이다. 제한 공개이므로 가격, API 처리량, 하드웨어 요구량과 개발자 사용 조건도 아직 확정된 일반 제공 정보로 볼 수 없다.

### 2. LFM3 — 약 2B급 공통 백본에서 텍스트·비전·오디오·의사결정 모델로 분화

- **출처**: Liquid AI 공식 발표 / Hugging Face 모델 카드·라이선스
- **점수**: 8.4/10 *(편집부 선정 점수)*
- **URL**: https://www.liquid.ai/blog/lfm3
- **원 게시자**: Liquid AI, Inc.
- **발견 경로**: 당일 모델 출시 목록에서 후보를 확인한 뒤 공식 발표, 배포된 모델 카드와 라이선스 원문을 검증
- **공개일**: 2026-10-27
- **사건 상태**: 기본·후학습 체크포인트 공개, 일부 특화 모델과 런타임 지원 제공; 독립 성능 평가는 초기 단계
- **확인일**: 2026-10-28

**요약**

Liquid AI가 LFM3 모델군을 공개했다. 첫 출시는 약 2B급에서 텍스트, 비전, 오디오, 옴니와 의사결정 모델 등 여섯 가지 변형을 공통 LFM3-1.7B-Base에서 만들며, 텍스트 모델은 1.73B 파라미터와 입력·출력 합산 256K context를 지원한다. 공식 설명에 따르면 24개 층은 gated short convolution 13개, 256-token sliding-window attention 5개, global attention 6개를 결합한다.

텍스트 모델은 4-bit 양자화 시 약 1GB에 들어간다고 회사는 주장하며, Hugging Face 모델 카드에는 로컬 에이전트·도구 호출·구조화 출력·도메인 파인튜닝 용도로 설계됐다고 적혀 있다. 동시에 작은 모델이므로 복잡한 다단계 추론이나 agentic coding에는 권장하지 않고, 지식 집약 작업에는 검색이나 retrieval을 사용하라고 명시한다. 공급사 발표와 모델 카드가 강점뿐 아니라 용도 경계도 함께 제시한다는 점이 중요하다.

**맥락**

LFM3는 모든 작업을 하나의 대형 범용 모델로 처리하는 대신, 비교적 작은 공통 백본을 여러 감각·행동 모델로 특화하는 전략이다. 아키텍처는 짧은 convolution으로 지역적 패턴을 처리하고, sliding-window와 global attention을 섞어 긴 문맥 비용과 전역 정보 접근의 균형을 노린다. Liquid AI는 총 22T token 학습과 마지막 3.5T token의 고품질·도구 사용 중심 mid-training을 설명하지만, 이는 회사가 공개한 학습 기록이며 데이터 구성 전체와 독립 재현 결과는 제공되지 않았다.

공식 표에서 LFM3-VL-2B는 62개 평가의 범주별 단순 평균 71.4를 기록했다. 그러나 서로 다른 벤치마크를 단순 평균한 공급사 집계이며, 더 큰 모델과 폐쇄형 API까지 함께 비교한다. 같은 날 확인 가능한 제3자 종합 평가는 아직 없어 이 숫자를 독립 순위로 해석하면 안 된다.

**실무 시사점**

- **대상**: 모바일·엣지 장치 또는 사내 전용 소형 모델을 검토하는 ML 엔지니어
- **방법**: Hugging Face 체크포인트를 로컬에서 실행하고, 실제 장치의 4-bit 모델 크기·첫 토큰 지연·초당 토큰·메모리·배터리 사용량을 측정한다. 동시에 업무별 정답률, 도구 호출 형식 준수율과 긴 문맥에서의 정보 회수율을 기존 1~3B 기준 모델과 동일 프롬프트로 비교한다.
- **완료 기준**: 목표 장치의 메모리와 지연 예산을 충족하고, 최소 100개 내부 검증 사례에서 기존 모델 대비 정해진 품질 하한을 넘으며, 실패 시 검색·서버 모델로 넘기는 fallback이 동작해야 한다.

상용 도입 전에는 라이선스 검토가 필수다. LFM Open License v1.0은 연구·비영리 이용과 일정 범위의 상업 사용을 허용하지만, 조직의 연간 매출이 1,000만 달러를 넘으면 무료 상업 사용 권리가 종료되고 별도 상업 라이선스가 필요하다. ‘오픈웨이트’가 모든 기업에 무조건 무료라는 뜻은 아니다.

**한계 및 의문**

현재 공개 성능은 대부분 Liquid AI 자체 평가이며, 같은 체크포인트를 동일 조건에서 재실행한 독립 결과가 부족하다. 256K context 지원은 최대 입력 창을 뜻할 뿐 전체 구간에서 균일한 정보 회수 성능을 보장하지 않는다. 4-bit 약 1GB도 가중치 중심 수치로, KV cache·런타임·비전 또는 오디오 인코더와 실제 앱 메모리를 포함한 총 사용량과 다를 수 있다. 모델 카드가 복잡한 추론과 agentic coding을 비권장하므로 작은 크기만 보고 범용 에이전트의 대체재로 간주해서는 안 된다.
