## 1. Firebase 개발 사례: AI가 만든 앱의 핵심 기능은 직접 고쳤다

- 원문: https://firebase.blog/posts/2026/09/build-ios-app-firebase-antigravity

### 설명과 변화

저자들은 Firebase와 Antigravity로 음악 링크 공유용 iOS 앱을 약 6시간에 만들었다고 설명했습니다. 그러나 최초 버전은 핵심인 음악 서비스 간 링크 변환에 실패했습니다. 모델과 프롬프트를 바꿔도 해결되지 않아 Spotify·Apple Music API로 메타데이터 조회와 검색을 구현했습니다. Firebase MCP와 Agent Skills를 사용한 뒤에도 사람이 코드를 검토하고 기능을 반복 시험했습니다.

### 근거·실무 적용·한계

6시간은 두 저자의 경험담이며 비교 실험 결과가 아닙니다. 개발자는 외부 조회 기능에 실패·권한 오류·잘못된 결과 테스트를 붙이세요. 완료 기준은 실제 서비스에서 결과가 맞고 실패를 명시적으로 처리하는 것입니다. 편집자의 판단으로, 이 사례는 도구 연결과 검증을 먼저 설계할 이유를 제공합니다. 모든 모델이 해당 문제를 해결할 수 없다는 일반적 결론은 내리지 않습니다.

## 2. CaixaBank, Google Cloud 협력을 2033년까지 확대

- 출처: Google Cloud Press Corner / CaixaBank 협력 발표
- 발견: 웹 검색 / 공식 보도자료 확인
- 발표일: 2026-10-09; 수정일: 별도 표시 없음
- 사건 시점: 협력 확대 발표 2026-10-09; 실제 배포 일정 미공개
- 확인일: 2026-10-09
- 원문: https://www.googlecloudpresscorner.com/2026-10-09-CaixaBank-Expands-Strategic-Collaboration-with-Google-Cloud-to-Accelerate-AI-and-Data-Capabilities

### 설명과 변화

CaixaBank는 2023년 시작한 Google Cloud 협력을 2033년까지 연장한다고 발표했습니다. Gemini Enterprise를 도입해 문서 관리·분류·복잡한 금융 정보 요약을 지원할 계획입니다. 발표는 데이터 분석, 하이브리드 인프라·보안, 직원 교육을 세 축으로 제시했습니다. 기존 은행 내부 환경과 클라우드를 결합한다는 방향도 포함했습니다.

### 근거·실무 적용·한계

이는 계약과 배포 계획으로, 정확도·시간 절감·ROI 실측치는 공개되지 않았습니다. 기업 AI 담당자는 문서 분류 과제에 담당자·데이터 범위·검토 기준을 지정하세요. 완료 기준은 작은 표본의 오분류율과 수동 검토 시간을 기존 방식과 비교하는 것입니다. 편집자의 제안이며 이 은행의 효과를 추정한 수치가 아닙니다.
