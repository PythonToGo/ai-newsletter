## 트렌드 분석

Google은 Gemini 4 Argon 공개 약 2주 만에 코딩·장기 에이전트 작업·사이버 보안을 강화한 Gemini 4 Carbon을 발표했다. 발표 시점의 Artificial Analysis Intelligence Index v5에서 Carbon은 59점으로 1위를 기록했고, Google은 취약점 발견·검증·패치 벤치마크에서도 높은 수치를 제시했다. 그러나 성능표보다 먼저 확인해야 할 사실은 일반 개발자가 아직 이 모델을 사용할 수 없다는 점이다.

Carbon은 이번 주 일부 사이버 방어자에게 먼저 제공되고, Fairwind Program의 추가 신뢰 파트너로 순차 확대된다. 개발자·기업·소비자용 제품 제공은 “곧”이라는 표현만 있을 뿐 확정 날짜가 없다. 따라서 오늘의 뉴스는 범용 API 출시라기보다 고위험 사이버 능력을 제한된 집단에서 먼저 검증하는 단계적 배포에 가깝다.

증거의 출처도 분리해야 한다. 일반 지능 지수 59점은 Artificial Analysis가 독립 실행한 9개 평가의 복합 점수다. 반면 SEC-bench Pro 88.2%, ExploitGym 54.8%, CWE-bench 71.0%와 대부분의 안전성 개선 수치는 Google이 외부 벤치마크 또는 내부 환경에서 실행해 발표한 결과다. 외부 이름이 붙은 벤치마크라고 해서 실행과 보고까지 독립적이었다는 뜻은 아니다.

최근 7일 아카이브는 모델 출시, 샌드박스·종료 회피 평가, 과학 워크플로, 월드 모델과 엣지 모델을 다뤘다. Carbon은 기존 Argon 보도와 같은 제품군이지만 별도의 모델, 신규 독립 평가, 사이버 전용 제한 배포와 새로운 가격 정보를 포함하므로 실질적인 후속 변화로 판단했다. 이를 명확히 하기 위해 이번 항목을 `업데이트`로 표시한다.

**요약**

Google이 Gemini 4 Carbon을 코딩, 장기 에이전트 작업과 사이버 보안에 초점을 둔 차세대 frontier 모델로 발표했다. Artificial Analysis가 독립 실행한 Intelligence Index v5에서 high reasoning 설정의 Carbon은 59점으로 Claude Opus 5.5의 58점보다 1점 높았다. 다만 이 지수는 지식 작업·코딩·과학·일반 지식을 아홉 평가로 합친 복합 점수이며, 모든 개별 영역에서 1위라는 의미는 아니다. Artificial Analysis도 Carbon이 코딩 에이전트 지수에서는 Claude Opus 5.5에 이어 2위이고, 일부 지식 작업 평가에서는 다른 모델들보다 낮다고 설명한다.

Google이 보고한 사이버 수치는 취약점 발견 SEC-bench Pro 88.2%, 공격 가능성 검증 ExploitGym 54.8%, 패치 생성 CWE-bench 71.0%다. 세 평가는 안전 가드레일을 끈 조건에서 수행됐다고 Google은 명시했다. 이는 모델의 원시 능력을 비교하는 조건이지, 실제 제품에서 동일한 공격 기능이 그대로 허용되거나 같은 성공률이 나온다는 뜻은 아니다.

**맥락**

Carbon은 2주 전에 출시된 Gemini 4 Argon의 후속이다. Google은 내부 팀에서 모델이 며칠 동안 대형 코드베이스의 원인을 추적하고 패치를 시도하는 장기 작업을 수행했다고 주장한다. 그러나 작업별 성공률, 중단 기준, 인간 개입량과 실제 총비용은 공개 발표만으로 충분히 재현할 수 없다.

사이버 성능은 양면적이다. 취약점 발견과 패치는 방어에 유용하지만, exploit 생성 능력은 오용 위험을 함께 높인다. Google은 미국 정부의 자발적 사전 모델 테스트 절차에 참여하고 일부 방어자에게만 먼저 제공한 뒤 Fairwind Program으로 확대한다고 밝혔다. 일반 개발자 제공 전에 가드레일과 피드백을 보완한다는 단계적 배포 전략이다.

가격은 접근 상태와 분리해서 읽어야 한다. Google이 발표한 **도입 할인 가격**은 100만 token당 입력 2달러, 출력 10달러다. cached input은 입력 단가의 95% 할인으로, 도입 기간에는 100만 token당 0.10달러에 해당한다. 도입 기간 종료 후 **표준 가격**은 입력 4달러, 출력 20달러, cached input 0.20달러다. 할인 종료 날짜는 확인 시점에 공개되지 않았고, 현재는 선택된 사이버 방어자 중심이라 모든 개발자가 이 가격으로 즉시 구매할 수 있는 상태가 아니다.

**실무 시사점**

- **대상**: 보안 운영, 취약점 관리와 자동 패치 시스템을 설계하는 팀
- **방법**: 접근 권한을 얻더라도 모델에 운영망 자격증명을 바로 제공하지 않는다. 읽기 전용 코드 복제본, 네트워크 차단 샌드박스와 합성 취약점에서 발견→재현→패치→회귀 테스트의 네 단계를 각각 기록한다. 모델이 만든 exploit과 패치는 서로 다른 승인자가 검토하게 한다.
- **완료 기준**: 최소 100개 내부 사례에서 취약점 재현 정확도, 잘못된 경보, 패치 테스트 통과율, 새 취약점 유입률과 인간 검토 시간을 기준 모델과 비교하고, 운영 코드 반영 전 모든 변경이 독립 테스트와 사람 승인을 통과해야 한다.

- **대상**: 일반 코딩 에이전트 도입을 검토하는 ML 플랫폼팀
- **방법**: Carbon의 59점 종합 지수를 구매 근거로 쓰지 말고, 자사 저장소의 장기 이슈 20~50개에서 완료율·비용·중단 회복·근거 없는 주장·권한 초과 행동을 측정한다. 입력, cached input, 출력 token을 별도 로그로 남겨 할인 종료 후 표준 가격까지 비용을 계산한다.
- **완료 기준**: 기존 모델 대비 성공률 향상이 재현되고, 표준 가격 기준 총작업비용과 검토 시간이 예산 안에 있으며, 권한 초과·테스트 우회·근거 없는 완료 보고가 허용 임계값 아래여야 한다.

**한계 및 의문**

첫째, Carbon은 아직 공개 API가 아니다. Artificial Analysis가 사전 접근 모델을 독립 평가했지만, 일반 사용자는 같은 설정·도구·reasoning effort를 직접 재현하기 어렵다. 공개 후 제품 시스템 프롬프트와 가드레일이 추가되면 벤치마크 결과와 차이가 날 수 있다.

둘째, 사이버 벤치마크 수치는 Google이 실행해 보고했다. 외부 벤치마크를 사용했어도 평가 harness, timeout, 시도 횟수와 도구 구성이 결과에 영향을 준다. 특히 exploit 평가는 가드레일을 끈 조건이므로 실제 제공 모델과 직접 비교할 수 없다.

셋째, 안전성 수치 대부분은 내부 평가다. Google은 Terminal-Bench 4.0의 성공적 cheating 0.0%, cheating 시도 0.4%, 내부 고위험 misalignment alert 약 80% 감소, Argon 대비 근거 없는 주장 약 절반 감소를 보고했다. 이는 유의미한 공급사 증거지만, 표본 수·탐지기 오차·비교 환경 전체가 공개되지 않아 독립적인 안전성 보증으로 볼 수 없다.

넷째, Gray Swan 간접 prompt injection 평가에서 공격 성공률 0.0%라는 결과도 유한한 평가셋에서 관측된 값이다. 모든 prompt injection을 차단한다는 뜻이 아니며, 검색·브라우저·코드 실행 도구를 연결한 실제 환경에서는 새로운 공격면이 생긴다.

다섯째, 1점 차이의 종합 지수는 절대적 우위를 뜻하지 않는다. Artificial Analysis 결과에서도 상위 모델 점수가 가깝고, Carbon은 코딩·지식 작업의 모든 하위 평가를 주도하지 않는다. 모델 선택은 실제 작업과 비용, 접근성, 안전 제약을 함께 측정해야 한다.
