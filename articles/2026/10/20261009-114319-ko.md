## 이번 편집의 관점

이번에는 새 모델의 점수보다 실제 업무 결과물이 어떻게 만들어지고 검토되는지를 봅니다. 서로 다른 제품 발표이므로 하나가 다른 하나의 원인이라고 연결하지 않았습니다. 도입 판단은 결과의 정확성뿐 아니라 접근 권한, 검토 가능성, 사용 조건을 함께 확인해야 합니다. 아래 실무 제안은 편집자의 테스트 제안이며 제품 성능의 실측 결과가 아닙니다.

## 1. Gemini, 질문 응답에서 지속적인 업무 수행으로

- 실제 출처: Google Cloud / Thomas Kurian의 기조연설 기반 발표
- 발견 경로: 웹 검색
- 발행·발표일: 2026-10-08
- 수정일: 원문에서 별도 확인되지 않음
- 확인일: 2026-10-09
- URL: https://cloud.google.com/blog/products/ai-machine-learning/welcome-to-gemini-at-work-2026/

### 무엇이 바뀌었나

Google은 업무를 계획하고 도구로 실행하는 Gemini agent를 발표했습니다. 회사 설명에 따르면 실행은 클라우드에서 지속되며, 과제별 sub-agent를 구성할 수 있습니다. 모델 선택은 Gemini 제품과 분리되어 Gemini와 Claude를 함께 활용합니다. 별도 정체성을 가진 coworker agent와 agent별 감사 기록도 제시했습니다.

### 근거와 적용

공식 발표에는 예약·이벤트 기반 작업, agent별 권한, 프로젝트 지출 한도 도달 시 일시 중지가 기술되어 있습니다. 이는 회사가 설명한 기능이며 독립적인 안정성 검증은 아닙니다.

플랫폼 팀은 읽기 전용 문서 세 개로 보고서 작성 과제를 시험하세요. 완료 기준은 출처가 정확하고, 허용하지 않은 문서를 읽지 않으며, agent 활동 기록을 추적할 수 있는 것입니다.

### 한계

이 발표만으로 모든 계정의 사용 가능 여부·전체 가격·긴 작업의 성공률을 판단할 수 없습니다. 사내 시스템 전면 연결 전에 실제 접근 조건을 확인해야 합니다.

## 2. Claude, 데이터 차트와 편집 가능한 애니메이션 추가

- 실제 출처: Anthropic / Claude 공식 제품 발표
- 발견 경로: 웹 검색
- 발행·발표일: 2026-10-08
- 수정일: 원문에서 별도 확인되지 않음
- 확인일: 2026-10-09
- URL: https://claude.com/de/resources/articles/dashboards-and-motion
- 접근 참고: 기본 언어 URL은 이번 조회에 실패하여 접근 가능한 공식 독일어 경로에서 영어 본문을 확인함.

### 무엇이 바뀌었나

Anthropic은 Claude Dashboards와 Motion을 beta로 발표했습니다. Dashboards는 연결한 회사 데이터로 차트를 만들고, 차트의 query와 마지막 갱신 시점을 보여줍니다. Motion은 텍스트·차트·이미지를 코드로 움직이고 MP4로 내보냅니다. 생성 영상 모델로 장면을 만드는 방식과는 다릅니다.

### 이용 조건과 적용

공식 발표 기준 Dashboards는 유료 플랜, Motion은 Team·Enterprise 대상입니다. Enterprise에서는 두 기능이 기본적으로 꺼져 있습니다.

데이터 팀은 기존 SQL로 정답이 알려진 지표 하나를 비교하세요. 완료 기준은 집계 기간·필터·합계·갱신 시각의 일치입니다. 콘텐츠 팀은 검증된 차트 하나로 설명 영상을 만들고 숫자 수정 가능 여부와 MP4 결과를 확인하세요.

### 한계

Beta 접근 여부와 연결 도구 권한을 먼저 확인해야 합니다. Query가 보인다는 사실만으로 지표 정의나 계산의 정확성이 보장되지는 않습니다.
