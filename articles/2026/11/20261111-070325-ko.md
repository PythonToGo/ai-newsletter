**요약**

ElevenLabs가 녹음 전사용 Scribe v3와 실시간용 v3 Live를 출시했다. 회사는 내부 FLEURS 평가에서 v3의 단어 오류율이 v2 대비 27% 줄었다고 보고한다. Live는 v2 Realtime 대비 semantic WER 43%, 일반 WER 31% 감소를 제시한다. 화자 구분과 대화 문맥 기반 발언 종료 판단도 강조한다.

**맥락**

평가는 102개 언어 점수를 각각 구한 뒤 평균하므로, 모든 음성을 합쳐 계산한 점수와 직접 비교할 수 없다. FLEURS는 짧고 깨끗한 낭독 음성이며 화자 구분 평가는 별도 16개 언어 실환경 데이터로 수행했다. 실시간 화자 평가는 전사를 정답에 정렬하는 별도 절차를 쓰므로 녹음 모델의 화자 점수와 같은 척도로 읽으면 안 된다.

**실무 시사점**

음성 제품팀은 실제 사용자의 동의를 받은 고정 평가셋에서 녹음·실시간 경로를 따로 비교하자. 숫자·고유명사 오류, 화자 배정, 발언 중단과 응답 지연을 기록한다. 완료 기준은 사전에 정한 오류 비용과 지연 한계를 모두 충족하는 것이며, 전체 평균 개선만으로 배포를 승인하지 않는 것이다. 공급사 예제는 모델 ID 변경으로 전환할 수 있다고 안내하지만, 운영에서는 이전 버전으로 되돌릴 수 있는 시험 배포가 바람직하다.

**한계 및 의문**

수치는 공급사 평가이며 독립 재현 결과가 아니다. 내부 실환경 데이터는 공개 예정으로 설명돼, 발표만으로 전체 비교를 재현하기 어렵다. 상대 오류 감소를 정확도 퍼센트포인트 상승으로 바꾸지 않는다. 이번에는 문서만 검토했으며 유료 API를 호출하거나 음성을 전송하지 않았다.
