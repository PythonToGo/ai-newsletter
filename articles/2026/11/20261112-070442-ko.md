## 트렌드 분석

이번 호는 과학 ML과 자율주행의 서로 다른 발전을 다룬다. AlphaGenome 2는 DNA 효과를 세포 조건별로 예측하고, AutoE2E는 공개된 작은 주행 모델을 평가·통합할 기반을 제공한다. 두 발표를 하나의 성능 순위로 묶기보다 ‘어떤 조건에서 나온 예측인가’를 확인하는 사례로 읽는 편이 유용하다.

편집부의 해석은 조건부 성능을 평균 점수 하나로 대체하지 말자는 것이다. 세포 상태가 바뀌면 유전 변이의 효과 해석이 달라지고, 주행 모델은 센서·지도·경로 입력과 시험 분할에 따라 비교 결과가 달라진다. 모델의 공개와 실제 사용 허가, 연구 평가와 현장 검증도 각각 분리해야 한다.

최근 14일 뉴스 아카이브의 제목·URL·사건을 대조해 미수록 두 건을 선정했다. 최근 7일의 모델·로보틱스·음성·이미지 보도와 균형을 고려해 과학 ML을 포함했다. 이미 수록한 H3-Image와 Scribe는 반복하지 않았고, 확인 근거가 약한 후보로 세 번째 자리를 채우지 않았다.

### 1. AlphaGenome 2: 조직 평균에서 세포 유형·상태별 변이 예측으로

- **출처**: Google DeepMind 공식 연구 발표
- **점수**: 8.8/10 *(편집 선정 점수; 실측 벤치마크 아님)*
- **URL**: https://deepmind.google/blog/alphagenome-2-deciphering-how-cells-read-dna-to-better-understand-disease/
- **원 게시자**: Google DeepMind / Adam Gayoso 외
- **발견 경로**: 과학 ML 최신 뉴스 검색 → 공식 발표 본문
- **게시·발표일**: 2026-11-11
- **수정일**: 별도 표시 확인 안 됨
- **확인일**: 2026-11-12
- **상태**: 비상업 연구용 API 제공; 상업 연구는 비공개 프리뷰; 임상·진단 검증 아님

**요약**

Google DeepMind가 DNA 변이의 영향을 세포 유형과 상태별로 예측하는 AlphaGenome 2를 발표했다. 기존의 광범위한 조직 출력 대신 DNA 서열과 생물학적 조건을 함께 입력하는 조건부 모델이다. 회사는 68개 조직의 1억 개 이상 단일세포 프로필을 활용했다고 설명한다. 연구 접근은 확대됐지만 진단 도구로 승인되거나 검증된 것은 아니다.

**맥락**

공식 발표의 TenK10K 평가에는 28개 일차 면역세포 유형이 포함된다. 회사는 원인 변이 식별 30% 대 16%, 방향성 유전자 효과 43% 대 23%를 제시한다. 이는 해당 비교 조건의 공급사 결과이며 모든 질병의 진단 정확도를 뜻하지 않는다. 세포 맥락을 입력받는 구조는 같은 서열이 다른 상태에서 다르게 작동하는 현상을 다루려는 변화다.

**실무 시사점**

유전체 분석팀은 기존에 실험 근거가 있는 변이·세포 조합을 보류 평가셋으로 정하고, 조직 평균 모델과 세포 조건 모델을 비교하자. 효과 방향, 순위와 세포 특이성을 나눠 기록한다. 완료 기준은 미관측 조합에서도 사전 기준을 만족하고, 후속 실험 후보 선정에 도움이 되는지 확인하는 것이다. 예측만으로 환자 판단을 내리지 않는다.

**한계 및 의문**

발표는 독립 재현 결과가 아니다. 새 세포 상태에 대한 일반화를 모든 상태로 확장할 수 없고, 후보 변이의 계산적 재현은 실험적 인과 입증과 다르다. 이번에는 API를 호출하거나 생물학 데이터를 업로드하지 않았다.

### 2. AutoE2E: 작은 공개 주행 모델, 코드와 체크포인트의 조건은 다르다

- **출처**: Autoware Foundation 공식 발표 / 공식 저장소
- **점수**: 8.4/10 *(편집 선정 점수; 실측 벤치마크 아님)*
- **URL**: https://autoware.org/autoware-foundation-and-tier-iv-join-forces-to-releases-autoe2e-an-open-source-ai-model-for-end-to-end-autonomy/
- **원 게시자**: Autoware Foundation / Joanna Tang
- **발견 경로**: 자율주행 최신 발표 검색 → 공식 본문·저장소·모델 카드
- **게시·공개 발표일**: 2026-11-11
- **수정일**: 별도 표시 확인 안 됨; 저장소는 확인 시점 내용
- **확인일**: 2026-11-12
- **상태**: Reactive 모델 공개·Autoware 오픈루프 통합; 실차 폐루프 검증 진행 중

**요약**

Autoware Foundation이 TIER IV 후원으로 개발한 7,990만 파라미터 AutoE2E를 공개했다. v1.0에 포함된 것은 빠르게 궤적을 계획하는 Reactive 모델이며, 월드 모델과 추론 계층은 개발 중이다. KITScenes-Multimodal 검증에서 미세조정 모델의 3초 평균 위치 오차는 0.744m로 보고됐다. L4 무인주행은 달성된 제품 성능이 아니라 개발 목표다.

**맥락**

오픈루프 평가는 기록된 영상에서 미래 경로를 예측하고 사람의 실제 경로와 비교한다. 모델 행동이 다음 관측과 다른 차량 반응을 바꾸는 폐루프 시험과 다르다. 공식 README에서 미세조정 결과는 202개 키프레임 기준이며, 표의 일부 다른 구성은 11,035개 샘플을 사용한다. AutoE2E는 비교 시 지도와 경로도 받으므로 ‘카메라만으로 동일 조건 2위’라고 요약하면 부정확하다.

**실무 시사점**

주행 연구팀은 먼저 코드와 모델 자산의 허용 범위를 나누자. 코드가 Apache 2.0인 것과 달리 체크포인트는 README상 CC BY-NC-SA 4.0 비상업 조건이다. 공식 발표의 상업 활용 표현만으로 가중치 사용까지 승인됐다고 판단하지 않는다.

평가는 같은 장면·프레임·지도·경로 정보로 맞추고 ADE와 종점 오차를 함께 측정하자. 완료 기준은 공통 분할의 재현 결과와 폐루프 실패·개입 기록을 분리해 보고하는 것이다. 공개 모델을 곧바로 공도 제어에 연결하지 않는다.

**한계 및 의문**

작은 파라미터 수는 차량용 장치의 지연·전력 요구 충족을 보증하지 않는다. 입력과 샘플 수가 다른 비교표는 순위의 조건을 함께 읽어야 한다. 실제 폐루프 시험은 진행 중이며, 이번 검토에서는 코드·차량·모델을 실행하지 않았다.
