**요약**

XLANG Lab이 로봇 사용 능력을 평가하는 RoboWild 코드와 실행 안내를 공개했다. 공식 저장소의 초기 릴리스 커밋은 2026-11-20 20:50:20 UTC로, 이번 확인 시점에서 24시간 이내다. Isaac Lab 기반 시뮬레이션에 38개 장면, 239개 기본 작업 설정을 제공하고, 그중 34개를 다른 세 로봇에 각각 재사용해 총 341개 작업–본체 조합을 구성한다. 실제 하드웨어 실험이 아니라 시뮬레이션 평가 환경이며, 시뮬레이터와 에이전트 실행 도구의 역할을 분리한다.

**맥락**

기본 239개 설정은 Dexmate Vega-1에 대응한다. 별도의 34개 설정을 Mobile ALOHA, Franka Mobile, Dex3 손을 장착한 Unitree G1에 각각 적용하므로 총합은 **239 + 34 × 3 = 341**이다. 여기서 본체는 팔·손·카메라·이동 방식이 다른 로봇 하드웨어 구성을 뜻한다.

기본 ReAct 평가에서는 관측을 받고 도구를 호출하는 과정을 반복한다. README는 RGB 카메라 관측, 행동 사이에 멈추는 시뮬레이션, 한 차례에 도구 하나를 고르는 `react_move` 설정을 설명한다. 이동 명령은 경로 계획과 실행을 함께 수행하므로, 이는 모델이 모터를 매 순간 직접 제어하는 평가와도 다르다.

평가 예산은 짧은 과제에 100회, 긴 과제에 200회의 Robot API 호출이다. 문서상 종료 호출 `done()`은 예산을 쓰지 않는다. 이 횟수를 모델 추론 토큰이나 물리 제어 주기와 같은 단위로 취급하면 안 된다. 새로운 소식은 이 조건을 점검할 코드·문서가 배포됐다는 것이며, 이번 호는 재현하지 못한 모델 순위 수치를 싣지 않는다.

**실무 시사점**

로봇·멀티모달 평가팀은 우선 동일 모델·관측·도구 프로필·호출 예산을 고정한 시험 계획을 작성하자. 기본 장면에서의 성능과 34개 공유 설정의 본체별 성능을 따로 보고, 실패를 인식·명령 선택·경로 계획·접촉 실행 단계로 나눠 기록할 수 있다. 완료 기준은 설정과 버전, 성공 판정, 실패 로그를 남겨 다른 담당자가 같은 조건으로 다시 평가할 수 있는 것이다.

공유 설정을 시험하기 전에는 각 로봇의 시작 자세와 프로필이 실제로 포함됐는지도 확인해야 한다. 공식 평가 안내는 CSV에 작업 이름이 있다는 사실만으로 로봇 자세가 준비된 것은 아니라고 경고한다. 누락된 프로필을 임의로 생성한 결과를 공식 설정의 재현으로 보고하지 않는 것이 중요하다.

이번 뉴스레터는 문서와 배포 기록을 검토했으며, 설치 스크립트·시뮬레이터·모델 API·GitHub Actions를 실행하지 않았다. 공개 환경을 소개하는 것과 전체 평가를 직접 재현한 것은 구분한다.
