## 트렌드 분석

이번 판은 모델을 만드는 출발점과 전문 작업을 맡기는 완성품이라는 서로 다른 방향을 살핀다. Baidu는 추가 학습 전의 ERNIE 가중치를 공개했고, OpenAI는 취약점 연구에 특화한 GPT-6 Cyber를 발표했다. 두 소식을 같은 성능 순위로 묶기보다, 무엇을 직접 바꿀 수 있고 어떤 조건에서 접근할 수 있는지를 구분해야 한다.

편집 관점에서 공통 질문은 ‘높은 점수를 실제 사용 권한과 혼동하지 않는가’다. 가중치가 보인다고 모든 지역에서 자유롭게 쓸 수 있는 것은 아니고, 전문 평가에서 앞선다고 일반 제품으로 즉시 제공되는 것도 아니다. 자체 학습팀에는 데이터·메모리·라이선스가, 보안 운영팀에는 승인된 범위와 결과 검증이 서로 다른 도입 관문이다.

최근 14일 기사와 제목·URL·사건을 대조했으며, 최근 7일의 음성·확산 언어모델·생활 평가·물류 로봇 보도도 고려했다. AI·ML·딥러닝·로보틱스를 폭넓게 검색했지만 재보도와 구체적 근거가 약한 미래 계획은 제외했다. 이번에는 11월 5일 공개된 두 사건을 선정했다. 정확한 게시 시각을 확인하지 못한 자료는 엄밀한 24시간 경계가 확정되지 않는다.

### 1. ERNIE 5.5 Flash Base: 후속 학습용 가중치 공개, 지역 제한도 확인해야

- **출처**: Baidu ERNIE 공식 기술 블로그·모델 카드·LICENSE
- **점수**: 8.4/10 *(편집 선정 점수, 성능 측정값 아님)*
- **URL**: https://huggingface.co/baidu/ERNIE-5.5-Flash-Base
- **발견 경로**: 신규 모델 웹 검색 → Baidu 원문·공식 배포
- **공개일**: 2026-11-05 (LICENSE의 release date)
- **수정일**: LICENSE 부속 사용정책은 2026-11-06 개정으로 표시
- **확인일**: 2026-11-06
- **상태**: 사전학습 종료 체크포인트 공개; 지시 학습을 마친 챗봇이 아님

**요약**

Baidu가 텍스트 전용 ERNIE-5.5-Flash-Base 가중치를 공개했다. 여러 전문가 모듈 중 일부를 선택하는 MoE 구조로, 전체 280B 파라미터 중 토큰당 14B를 활성화한다. 33.5T 토큰으로 사전학습했으며, 학습 문맥은 최대 128K, 미세조정·추론 지원 문맥은 1M으로 구분된다. 중간·후속 학습 이전 모델이므로 도메인 적응과 지시 학습 실험의 출발점이다.

**맥락**

대부분의 층에서 과거 토큰을 압축해 보관하고 일부 층에서 세밀하게 참조하는 설계는 긴 문맥의 메모리 부담을 줄이려는 접근이다. 공급사는 유사 규모의 공개 base 모델들을 동일한 평가 도구·프롬프트·few-shot 예제로 비교했다고 설명한다. 완성된 대화 모델과의 직접적인 우열을 뜻하지 않는다.

**실무 시사점**

모델 도입팀은 성능 시험보다 먼저 지역·재배포·상업 조건을 검토하자. 현재 LICENSE 1.11·2조는 허용 지역에서 EU·영국·한국을 제외하고, 5.3조는 해당 지역 밖의 모델·파생물·출력 사용 등을 허가 범위 밖으로 둔다. 다운로드 가능 여부를 사용 허가로 간주하지 않는 것이 첫 통과 기준이다. 허용 조건을 확인한 팀만 별도 환경에서 자체 데이터 품질과 GPU 메모리·지연을 측정하고, 기존 모델 대비 학습 효과를 비교하자.

**한계 및 의문**

활성 14B는 전체 가중치 저장량이 14B 모델과 같다는 뜻이 아니다. 긴 문맥을 지원한다는 설정도 실제 업무 정확도나 비용을 보장하지 않는다. 독립 재현은 확인하지 않았고, 표준 Apache/MIT가 아닌 전용 라이선스이므로 ‘무제한 오픈소스’로 소개해서는 안 된다. 위 조건은 확인 시점 원문 요약이며 개별 이용의 법적 판단을 대신하지 않는다.

### 2. GPT-6 Cyber: 취약점 연구 특화 모델, 일반 공개와는 구분

- **출처**: OpenAI 공식 제품·보안 발표
- **점수**: 8.2/10 *(편집 선정 점수, 성능 측정값 아님)*
- **URL**: https://openai.com/index/introducing-gpt-6-cyber/
- **발견 경로**: 최신 AI 발표 검색 → 공식 원문
- **게시·발표일**: 2026-11-05 · 별도 수정일 미표시
- **확인일**: 2026-11-06
- **상태**: Daybreak를 통한 검증된 방어자 대상 접근; 무제한 일반 공개로 해석하지 않음

**요약**

OpenAI가 취약점을 찾고 실제 악용 가능성을 검증하는 GPT-6 Cyber를 발표했다. 회사 자체 ExploitGym 평가에서 기존 GPT-5.6 Cyber의 32.1% 대비 48.5%를 기록했다. 차이는 16.4%포인트이며, 모든 보안 업무의 성공률이 아니라 지정된 취약점의 악용 가능성을 시험하는 과제 점수다. 허용된 작업 범위를 지키도록 별도 학습했다는 설명도 함께 제시했다.

**맥락**

새 소식은 이전 아카이브의 격리 사고 자체가 아니라 전문 모델의 발표와 이전 세대 대비 평가다. 방어 도구가 경고를 생성하는 단계에서 재현 가능한 증거를 만드는 단계로 옮겨갈 가능성이 있지만, 이는 편집적 해석이며 운영 효과가 독립 입증됐다는 뜻은 아니다.

**실무 시사점**

보안팀은 접근 자격부터 확인하고, 이후 승인된 시험 환경에서만 기존 검토 절차와 비교하자. 완료 기준은 발견 수가 아니라 사람이 재현한 유효 결과, 오탐 검토 시간, 수정 후 회귀 테스트 통과, 범위 밖 작업 차단을 함께 충족하는 것이다. 실서비스 접근이나 자동 수정 권한을 평가 점수만으로 확대해서는 안 된다.

**한계 및 의문**

수치는 공급사 평가이며 별도 독립 재현으로 확인하지 않았다. 제한된 시험에서 경계를 지켰다는 결과는 새로운 환경의 안전 보장이 아니다. OpenAI의 ‘Critical’ 분류는 자체 Preparedness Framework의 사이버 역량·위험 분류로, 안전 인증을 뜻하지 않는다. 접근 제한과 공개 정보만으로는 일반 조직의 비용 대비 효과도 판단할 수 없다.
