## 트렌드 분석

오늘은 소형 모델의 구조, 실제 로봇 시스템의 평가, 과학적 의사결정의 시험을 나란히 살펴본다. Thinking Machines의 Inkling 2 Mini는 같은 중간층을 반복 사용해 저장해야 할 가중치와 수행하는 계산을 분리한다. Waddle-1의 새 로봇 평가 결과는 단일 모델뿐 아니라 실행 절차와 자원 제한이 점수에 미치는 영향을 보여준다. OpenAI의 MedChemBench 소개는 분자 그림을 정확히 읽는 능력과 다음 실험 대상을 잘 고르는 능력이 같지 않다는 문제를 드러낸다.

세 소식을 ‘모두 더 똑똑해졌다’로 묶으면 중요한 차이를 놓친다. 작은 모델의 활성 파라미터 수만으로 처리 속도를 알 수 없고, 로봇의 부분 진행도 점수를 작업 완료율로 읽을 수도 없다. 화학 평가의 총점은 실제 연구에서 새로운 약물을 발견할 확률이 아니다. 편집부의 공통 해석은 성능 숫자 옆에 계산량·상태 유지 방식·채점 단위를 함께 놓아야 도입 판단에 도움이 된다는 것이다.

최근 14일 뉴스 아카이브 15편의 제목·URL·사건을 대조했다. 최근 7일에는 음성, 세포 반응 예측, 도구 검색, 이미지 편집, 공장 로봇과 하드웨어를 다뤘다. 어제의 Hy4 가중치와 harness adapter 발표는 반복하지 않았다. 비전·확산형 언어 모델도 탐색했지만 문서 수정일이나 새 기사 날짜를 최초 공개일로 오인할 위험이 있는 후보는 제외했다. 아래 점수는 신규성·중요성·근거를 고려한 0–10점의 편집 선정 점수이며 실측 성능이 아니다.

### 1. Inkling 2 Mini: 24개 층을 저장하고 중간층은 세 번 계산한다

- **출처**: Thinking Machines Lab 공식 발표·모델 카드
- **점수**: 8.7/10 — 편집 선정 점수
- **URL**: https://thinkingmachines.ai/news/inkling-2-mini/

**요약**

Thinking Machines Lab이 11월 20일 텍스트·이미지를 입력받고 텍스트를 출력하는 Inkling 2 Mini를 공개했다. 총 264억 파라미터의 MoE 모델이며, 중간 12개 층을 세 번 통과하는 순환형 transformer 구조다. 저장된 층은 24개지만 토큰당 층 적용은 48회여서, 가중치 수를 늘리지 않고 내부 계산을 늘린다. Apache 2.0 가중치와 로컬 실행 안내가 제공되며, 회사는 약 20GB 체크포인트와 32GB 이상 메모리의 Apple silicon 지원을 명시한다.

**맥락**

MoE는 입력마다 일부 전문가만 활성화하는 구조다. 이 모델의 활성 파라미터는 34억이지만, 반복 통과를 반영한 토큰당 가중치 활성화량은 54억이다. 따라서 단순히 ‘34억 모델의 계산 비용’으로 취급하면 안 된다.

공식 표의 DeepSWE v1.1 해결률은 48.2%이며 실행 도구는 mini-swe-agent v2.4.6이다. 소개 글의 속도 도표는 BF16·배치 1·614GB/s 대역폭을 가정한 이론적 상한으로, 노트북 실측 속도가 아니다. 평가 도구와 실행 조건도 모델별로 다를 수 있어 모든 순위를 동등 조건 비교로 읽지는 않는다.

**실무 시사점**

로컬 추론을 검토하는 개발팀은 지원 런타임·정밀도·문맥 길이를 고정한 뒤 비민감한 코딩·문서·이미지 질의를 함께 시험하자. 평균 처리량만 보지 말고 첫 응답 지연, 긴 입력의 메모리, 반복 답변과 한국어 품질을 기록한다. 완료 기준은 목표 장비에서 메모리 초과 없이 내부 품질·응답시간 기준을 충족하는 것이다.

약 20GB는 모든 길이의 대화에 필요한 전체 RAM을 보증하는 수치가 아니다. 모델 적재 외에 문맥 상태와 실행 오버헤드가 필요하므로 실제 여유 용량을 확인해야 한다. 이번 작성에서는 모델 다운로드·추론·유료 서비스 호출을 하지 않았다.

**한계 및 의문**

반복 계산이 저장된 사실 지식을 자동으로 늘려 주지는 않는다. 공식 카드는 비영어 품질 저하, 긴 대화의 신뢰도 저하, 코드 디버깅 중 반복 추론을 경고한다. 최소 추론 설정도 내부 계산을 완전히 끄지는 않으며 새 런타임 지원의 속도는 장비마다 다르다. 도구 사용을 시험할 때는 별도 작업 공간과 삭제·덮어쓰기 승인 장치를 유지해야 한다.

**관련 링크**

- [공식 출시·구조·평가·로컬 안내](https://thinkingmachines.ai/news/inkling-2-mini/) — 원 게시자: Thinking Machines Lab. 게시·출시일 2026-11-20, 정확한 게시 시각·별도 수정일 미확인.
- [공식 모델 카드](https://thinkingmachines.ai/model-card/inkling-2-mini/) — 입출력·라이선스·반복 계산·언어 및 실행 한계 확인.
- [공식 가중치 배포·하드웨어 안내](https://huggingface.co/thinkingmachines/Inkling-2-Mini) — 체크포인트와 메모리 권고 확인; 실제 파일 다운로드 검증은 하지 않음.
- 발견 경로: 최신 모델 검색 → 공식 출시 글·모델 카드·배포 페이지 대조.

### 2. Waddle-1 로봇 평가: 81.4% 평균 진행도, 그러나 호출 예산은 같지 않다

- **출처**: Robocurve 공식 평가표·평가 방법 / Waddle Labs 소개
- **점수**: 8.3/10 — 편집 선정 점수
- **URL**: https://robocurve.org/

**요약**

11월 20일 발표된 것으로 보도된 Waddle-1이 Robocurve의 실제 로봇 평가표에 등재됐다. 확인 시점의 RoboDojo-RC Tier 1 표는 Waddle-1의 평균 점수를 81.4%로 표시한다. 평가자는 이를 단일 기반 모델이 아닌, 여러 언어 모델과 하위 제어 정책을 결합한 전체 시스템으로 분류한다. 같은 표의 GPT-6.2 Astra 구성은 65.7%지만 두 시스템의 호출 제한이 달라, 이 차이를 모델 자체의 순수한 우열로 해석할 수 없다.

**맥락**

표는 구성당 120회 시도의 평균을 설명하며, 지표는 작업의 단계별 진행도를 반영한다. 예를 들어 그릇 쌓기에서는 일부 그릇을 겹치거나 쌓는 중간 상태에도 점수를 준다. 따라서 81.4%는 모든 작업을 완전히 끝낸 비율이 아니다.

일반 LLM 행에는 40회 모델 호출 제한, VLA 행에는 3,600회 제어 단계 제한이 있다. Waddle-1은 작업당 하나의 대화, 10분 제한, 모델 호출 횟수 상한 없음으로 기재된다. 평균 시도 시간도 7.4분으로 표시돼, 높은 진행도와 짧은 지연을 같은 주장으로 취급할 수 없다.

**실무 시사점**

로봇 평가팀은 시스템의 총 실행시간·모델 호출·이력 유지 규칙을 먼저 고정하고 기존 제어기와 비교하자. 단계별 점수 외에 완전 완료율, 사람 개입, 복구 시간과 위험 정지를 따로 기록한다. 완료 기준은 고정 예산과 낯선 물체 배치에서 목표 완료율·처리량을 반복 재현하는 것이다.

부분 진행도는 실패 원인을 분석하는 데 유용하지만 구매·배치 판단에는 실제 완료와 안전 조건이 추가로 필요하다. 공급사 시스템을 시험하기 전 로봇별 동작 한계와 사람의 중단 권한을 정해야 한다. 이번에는 로봇에 연결하거나 접근 신청을 전송하지 않았다.

**한계 및 의문**

확인한 것은 평가자가 공개한 표·규칙과 실행 기록 목록이다. Waddle-1의 120개 영상·로그를 모두 독립 재채점한 것은 아니다. 호출 예산과 상태 유지 방식이 다른 구성을 같은 순위에 놓으면 실행 전략의 효과와 기반 모델의 능력이 섞인다.

공급사 발표 재인용에는 preview API 접근 신청이 나오지만 해당 신청 페이지는 직접 열리지 않았다. 따라서 누구나 즉시 이용할 수 있는 정식 API나 공개 가중치 출시로 표현하지 않는다. 기존 Waddle 연구 소개 역시 이번 Waddle-1의 전체 사양 문서로 간주하지 않는다.

### 3. MedChemBench 상세 소개: 분자를 잘 읽어도 다음 후보를 잘 고르는 것은 아니다

- **출처**: OpenAI 공식 연구 소개·MedChemBench 기술 보고서
- **점수**: 8.4/10 — 편집 선정 점수
- **URL**: https://openai.com/index/introducing-medchembench/

**요약**

OpenAI가 11월 20일 의약화학 추론 평가 MedChemBench의 구성과 결과를 상세 소개했다. 117개 논문·특허에서 구성한 99개 문제에 761개 분자 구조가 포함되며, 특정 연구 시점까지의 자료를 주고 이후 결과를 가린다. 분자 구조 복원, 과학적 설명, 후보 순위·선택, 수치 예측을 각각 채점한다. 공식 소개의 최신 수치는 xhigh 설정에서 GPT-6.2 Astra가 가능한 총점의 84.5%를 얻었다는 것으로, 84.5%의 문제를 완전히 맞혔다는 뜻이 아니다.

**맥락**

의약화학은 효능만 높이는 작업이 아니다. 분자 변화로 흡수·대사·선택성이 함께 달라져 여러 조건을 동시에 판단해야 한다. 이번 평가가 흥미로운 이유는 구조를 읽는 단계와 후보를 선택하는 단계를 분리한다는 데 있다.

공식 글에서 GPT-6 Astra는 xhigh의 구조 항목에서 95.4% 점수를 받지만 후보 선택·수치 예측 항목은 약 절반 수준이다. 항목별 문제와 채점 규칙이 다르므로 비율을 직접 빼서 단일 능력 격차로 계산하지는 않는다. 읽기 정확도가 높아졌다고 실제 실험 우선순위까지 안정적으로 정한다는 결론은 성립하지 않는다.

**실무 시사점**

과학 ML 평가팀은 자료 추출·구조 인식·설명·최종 선택을 나눠 오류를 기록하자. 새로운 비공개 사례를 보류하고, 원문에 없는 대안도 분야 전문가가 검토할 수 있도록 채점 절차를 설계한다. 완료 기준은 독립 전문가 판단과의 일치, 측정 불확실성의 표현, 새 사례에서의 재현성을 각각 확인하는 것이다.

이 제안은 평가 설계에 관한 것이며 치료·약물 선택의 권고가 아니다. 총점 상승을 실험 성공으로 번역하지 않고, 연구자가 검증할 가설과 근거 정리의 품질부터 확인해야 한다. 이번에는 화합물 생성·실험·유료 모델 평가를 실행하지 않았다.

**한계 및 의문**

기술 보고서는 11월 9일자이고, 이번 뉴스 사건은 11월 20일의 공식 상세 소개다. 보고서의 최고 수치인 GPT-6 Astra max 83.83%와 소개 글의 더 최신 GPT-6.2 Astra xhigh 84.5%를 같은 모델·같은 평가 행으로 섞지 않았다.

과거 공개 자료에 대한 학습 노출 가능성은 배제되지 않는다. 단일 응답·고정 근거 패키지로 측정하므로 도구·피드백·반복 실험으로 복구하는 능력은 시험하지 않는다. 원문 정답과 다른 합리적 설계가 불리하게 채점될 수도 있다. 새 약물 발견이나 실제 실험 의사결정 개선을 입증한 결과는 아니다. 전체 데이터·채점 코드의 공개 배포 여부도 이번 확인만으로 확정하지 않았다.
