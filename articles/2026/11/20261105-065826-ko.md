## 트렌드 분석

전날에는 Kimi K3.1 Pro의 공식 파일과 라이선스를 직접 확인하지 못해 수록하지 않았다. 이번에는 공식 저장소에서 두 자료를 모두 확인했다. 기존 모델 출시 기사를 반복하는 것이 아니라, 자체 운영을 검토할 수 있게 된 배포 상태의 변화다. 다른 모델·로보틱스 후보도 탐색했지만 오래된 발표와 구체성이 부족한 소식으로 수를 채우지 않았다.

- **날짜 한계**: 기존 블로그의 11월 4일 공개 약속과 실제 파일의 존재를 구분했다. 최초 업로드 시각은 확정하지 못했다.

**요약**

Moonshot AI의 공식 계정에서 Kimi K3.1 Pro 가중치 분할 파일, 설정과 추론 관련 코드를 확인했다. 파일 목록의 전체 크기는 1.56TB로 표시된다. 이는 단순히 API로 접근할 수 있는 상태와 다르지만, 내려받아 실행하는 데 필요한 GPU 메모리나 실제 처리속도를 뜻하지는 않는다. 라이선스는 표준 MIT가 아닌 Kimi K3.1-Pro 전용 조건이다.

**맥락**

10월 25일 아카이브는 모델 성능과 공개 예정 상태를 다뤘다. 이번에는 다운로드 가능한 공식 배포물이 있다는 점과 재사용 조건이 새 확인 사항이다. 활성 파라미터만으로 저장량과 운영비를 계산하면 안 되며, 모델 카드의 실행 예시가 곧 검증된 인프라 사양은 아니다.

**실무 시사점**

자체 호스팅 담당자는 먼저 저장 용량·배포 방식·실행 코드 검토 계획을 작성하자. 완료 기준은 실제 작업에서 품질과 지연을 측정하고, 다운로드·캐시·메모리 예산이 승인된 상태다. 이번 뉴스레터에서는 다운로드나 모델 실행을 하지 않았다.

상업 서비스 담당자는 원문 라이선스 2~4조를 별도 확인해야 한다. 제3자에게 추론·미세조정 제어권을 주는 Model as a Service 사업을 운영하고, 관계사 합산 매출이 연속 12개월 동안 2천만 달러를 초과하면 상업적 사용 전 별도 계약이 요구된다. 특정 기능에만 모델을 내장한 최종 사용자 제품과 단순 요청 중계는 이 정의에서 제외된다.

**한계 및 의문**

별도의 표시 의무도 있다. 제품·서비스의 월간 활성 사용자가 1억 명 초과이거나 월매출이 2천만 달러 초과이면 UI에 모델명을 눈에 띄게 표시해야 한다. 내부 사용과 공식 제품·인증 추론 파트너를 통한 사용에는 2·3조의 예외가 명시된다. 경계 사례는 원문과 공급자 확인이 필요하다. 공개 가중치는 무조건적인 사용 허가나 독립 성능 검증을 뜻하지 않는다.
