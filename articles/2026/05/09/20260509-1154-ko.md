# 모듈화·제어 가능성: AI 설계 패러다임이 바뀐다

## 트렌드 분석

오늘 24시간 동안 발표된 연구들을 관통하는 핵심 테마는 두 가지다. 첫째는 '모듈화(modularity)'—모델을 기능 단위로 분해하고 재조합하는 방향으로의 수렴. 둘째는 '제어 가능성(controllability)'—학습된 행동과 생성 결과를 사후에도 정밀하게 조작할 수 있어야 한다는 요구다. 이 두 흐름은 각기 다른 도메인에서 동시에 터져나오고 있다.

모듈화 측면에서는 UniPool과 EMO가 같은 방향을 가리킨다. UniPool은 MoE 아키텍처에서 레이어별 전문가 집합을 허물고 전역 공유 풀로 통합하며, EMO는 사전학습만으로 도메인별 전문가 클러스터가 자연스럽게 창발함을 보인다. 두 연구 모두 '파라미터를 어떻게 쪼개고 재활용할 것인가'라는 같은 질문에 답하고 있다. 흥미로운 점은 이 둘이 상호 보완적이라는 것—EMO의 창발적 모듈성 위에 UniPool의 공유 풀 구조를 얹으면 경량 배포와 파라미터 효율이라는 두 마리 토끼를 동시에 잡을 수 있는 설계가 그려진다.

제어 가능성 측면에서는 ActCam, SFT-Eraser, ReActor가 삼각형을 이룬다. ActCam은 영상 생성에서 카메라와 캐릭터 모션을 동시에 제어하고, SFT-Eraser는 학습된 LLM 행동을 재훈련 없이 추론 시 제거하며, ReActor는 인간 동작을 로봇 형태에 맞게 물리적으로 정합한다. 세 연구 모두 '이미 학습된 시스템에 사후 개입이 가능한가'를 탐구한다는 점에서 일치한다. 특히 SFT-Eraser는 모델 배포 후 기능 단위 행동 제어를 가능하게 한다는 점에서, 규제 대응이나 안전성 요구가 높아지는 현 시점에 전략적 의미가 크다. VHG의 검증자 기반 문제 생성 역시 '데이터 품질의 사후 보장'이라는 맥락에서 같은 흐름에 속한다.

실무자에게 주는 시사점은 명확하다. 지금 모델을 설계하거나 배포 파이프라인을 구축한다면, '나중에 고칠 수 없는 구조'는 이미 기술 부채다. 모듈화된 전문가 구조, 격리된 행동 서브네트워크, 사후 개입 가능한 제어 레이어—이 세 가지를 처음부터 아키텍처 요구사항에 넣어야 할 시점이 왔다.

## 아이템 분석

### 1. ActCam: Zero-Shot Joint Camera and 3D Motion Control for Video Generation

- **출처**: arxiv
- **점수**: 7.0
- **URL**: http://arxiv.org/abs/2605.06667v1

**요약**

ActCam은 사전 학습된 이미지-비디오 확산 모델 위에서 제로샷으로 캐릭터 모션과 카메라 궤적을 동시에 제어하는 영상 생성 방법이다. 포즈와 깊이 조건을 2단계 스케줄로 적용해 기하학적 일관성과 세부 품질을 모두 확보한다.

**맥락**

Sora, Runway, Kling 등 영상 생성 모델이 급속히 발전하면서 단순 생성을 넘어 촬영 연출 수준의 세밀한 제어 수요가 커지고 있다. 기존 방법들은 카메라 제어 또는 캐릭터 모션 중 하나만 다루거나 파인튜닝이 필요했는데, ActCam은 추가 학습 없이 두 가지를 동시에 해결한다.

**실무 시사점**

기존 이미지-비디오 확산 모델(예: SVD 계열)을 보유한 팀이라면 ActCam의 2단계 컨디셔닝 스케줄을 플러그인 방식으로 적용해 카메라 경로와 배우 동작을 동시에 제어하는 파이프라인을 구축할 수 있다. 광고·영화 프리비즈·게임 컷씬 등 촬영 연출이 중요한 도메인에서 즉시 활용 가능성을 검토할 만하다.

**한계 및 의문**

논문 본문이 일부만 공개되어 정량 평가 결과와 비교 베이스라인의 전체 범위를 확인하기 어렵다. 또한 제로샷 특성상 복잡한 장면이나 빠른 카메라 이동에서 기하학적 일관성이 얼마나 유지되는지는 추가 검증이 필요하다.

**관련 링크**

- http://arxiv.org/abs/2605.06667v1

### 2. UniPool: A Globally Shared Expert Pool for Mixture-of-Experts

- **출처**: arxiv
- **점수**: 7.0
- **URL**: http://arxiv.org/abs/2605.06665v1

**요약**

UniPool은 MoE 아키텍처에서 레이어별 독립 전문가 집합 대신 전역 공유 전문가 풀을 도입해 파라미터 효율을 높이는 새로운 구조다. 깊은 레이어에서 랜덤 라우팅으로 교체해도 정확도 손실이 1~1.6점에 불과하다는 분석을 근거로 한다.

**맥락**

GPT-4, Mixtral 등 대형 MoE 모델이 주류가 되면서 전문가 수 증가에 따른 파라미터 폭증이 실질적 문제로 부상했다. 레이어마다 전문가를 따로 두는 기존 설계가 정말 필요한지에 대한 의문이 커지는 시점에 이 연구가 나왔다.

**실무 시사점**

MoE 모델 설계 시 레이어별 전문가 할당 대신 전역 풀 공유 방식을 검토하면 동일 파라미터 예산으로 더 많은 전문가를 활용하거나 모델 크기를 줄일 수 있다. pool-level auxiliary loss와 NormRouter 조합은 공유 풀의 학습 불안정성을 완화하는 실용적 기법으로 참고할 만하다.

**한계 및 의문**

논문 본문이 잘려 있어 실제 벤치마크 결과와 기존 MoE 대비 정량적 성능 비교를 확인하기 어렵다. 또한 전역 풀 공유 시 통신 오버헤드나 분산 학습 환경에서의 확장성 문제가 충분히 검증됐는지 불명확하다.

**관련 링크**

- http://arxiv.org/abs/2605.06665v1

### 3. EMO: Pretraining Mixture of Experts for Emergent Modularity

- **출처**: arxiv
- **점수**: 7.0
- **URL**: http://arxiv.org/abs/2605.06663v1

**요약**

EMO는 사람이 정의한 사전 지식 없이도 도메인별 전문가 그룹이 자연스럽게 형성되는 MoE 사전학습 방식으로, 특정 도메인 추론 시 전체 모델 없이 전문가 서브셋만으로 성능 저하를 최소화한다.

**맥락**

LLM이 대형화·희소화될수록 메모리 제약 환경에서의 배포 비용이 급증하고 있으며, 기존 MoE 모델은 일부 전문가만 활성화해도 도메인 특화 추론 시 성능이 크게 떨어지는 한계가 있었다. Mixtral, DeepSeek-MoE 등 MoE 기반 모델이 주류로 부상하면서 모듈식 배포 가능성에 대한 관심이 높아진 시점에 나온 연구다.

**실무 시사점**

코드, 수학, 도메인 특화 등 특정 용도로만 모델을 배포해야 하는 엔지니어라면 EMO 방식의 전문가 서브셋 추출을 통해 메모리 사용량을 줄이면서도 성능을 유지하는 경량 배포 전략을 검토할 수 있다. 또한 사전학습 단계에서 도메인 일관성 제약을 추가하는 것만으로 모듈성이 창발한다는 점은 커스텀 MoE 설계 시 라우팅 전략 재고의 실마리를 제공한다.

**한계 및 의문**

논문 본문이 일부만 공개되어 실제 벤치마크 성능 수치와 기존 MoE 대비 정량적 비교 결과를 확인하기 어렵고, 전문가 서브셋만으로 추론할 때의 성능 저하가 어느 수준까지 허용 가능한지에 대한 실용적 기준이 아직 불명확하다.

**관련 링크**

- http://arxiv.org/abs/2605.06663v1

### 4. Verifier-Backed Hard Problem Generation for Mathematical Reasoning

- **출처**: arxiv
- **점수**: 7.0
- **URL**: http://arxiv.org/abs/2605.06660v1

**요약**

VHG는 검증자(Verifier)를 포함한 3자 셀프플레이로 LLM이 유효하고 어려운 수학 문제를 자동 생성하는 프레임워크로, 리워드 해킹 없이 고품질 문제를 생성한다.

**맥락**

LLM의 수학적 추론 능력 향상을 위해 고품질 훈련 데이터가 필수적이지만, 인간 전문가 의존 방식은 비용이 크고 단순 셀프플레이는 무효 문제를 양산하는 문제가 있었다. OpenAI o1/o3, DeepSeek-R1 등 추론 특화 모델 경쟁이 심화되면서 자동화된 고난도 문제 생성 기술의 중요성이 급부상하고 있다.

**실무 시사점**

ML 엔지니어는 수학 추론 모델 훈련 시 VHG처럼 독립 검증자를 파이프라인에 통합해 데이터 품질을 자동 보장하는 방식을 고려해야 한다. 심볼릭 검증자(Hard)와 LLM 기반 검증자(Soft) 두 가지 변형을 상황에 맞게 선택할 수 있으므로, 도메인별 검증 가능성을 먼저 평가한 후 적용 전략을 수립하는 것이 실용적이다.

**한계 및 의문**

부정적분 등 특정 수학 태스크 중심으로 평가되어 범용 수학 전 영역에 대한 일반화 성능이 검증되지 않았으며, LLM 기반 소프트 검증자의 신뢰도 자체가 모델 품질에 의존하는 순환 문제가 남아 있다.

**관련 링크**

- http://arxiv.org/abs/2605.06660v1

### 5. Crafting Reversible SFT Behaviors in Large Language Models

- **출처**: arxiv
- **점수**: 7.0
- **URL**: http://arxiv.org/abs/2605.06632v1

**요약**

SFT로 학습된 LLM 행동을 인과적으로 필요한 희소 서브네트워크(carrier)에 압축하는 LCDD 기법과, 가중치 수정 없이 해당 행동을 추론 시 제거하는 SFT-Eraser를 제안한다.

**맥락**

LLM의 파인튜닝 후 특정 행동을 선택적으로 제어하거나 되돌리는 것은 안전성과 모델 편집 측면에서 핵심 과제다. 기존 서킷 분석 등 사후 해석 방법은 상관관계만 파악할 뿐 인과적 제어가 불가능해, 실제 배포 환경에서의 행동 조정에 한계가 있었다.

**실무 시사점**

ML 엔지니어는 LCDD를 활용해 SFT 단계에서부터 특정 행동을 격리된 서브네트워크에 의도적으로 압축할 수 있으며, SFT-Eraser로 가중치 재학습 없이 소프트 프롬프트만으로 해당 행동을 추론 시 비활성화할 수 있다. 이는 모델 재배포 비용 없이 기능 단위의 행동 제어 파이프라인 설계에 직접 응용 가능하다.

**한계 및 의문**

논문 본문이 잘려 SFT-Eraser의 성능 검증 범위와 carrier 추출의 확장성이 불명확하며, 복잡한 다중 행동 시나리오에서의 carrier 간 간섭 문제는 아직 열린 질문으로 남아 있다.

**관련 링크**

- http://arxiv.org/abs/2605.06632v1

### 6. ReActor: Reinforcement Learning for Physics-Aware Motion Retargeting

- **출처**: arxiv
- **점수**: 6.9
- **URL**: http://arxiv.org/abs/2605.06593v1

**요약**

ReActor는 인간 동작을 로봇 형태에 맞게 재타겟팅할 때 발생하는 물리적 불일치를 해결하는 이중 레벨 최적화 프레임워크로, RL 기반 추적 정책과 동작 재타겟팅을 동시에 학습한다.

**맥락**

휴머노이드 로봇과 모방 학습 연구가 급증하면서 인간 동작 데이터를 로봇에 직접 활용하려는 수요가 높아졌다. 기존 방법들은 발 미끄러짐, 자기 충돌 등 물리적으로 불가능한 동작을 생성해 하위 모방 학습의 품질을 저하시키는 문제가 있었다.

**실무 시사점**

로봇 모방 학습 파이프라인을 구축하는 엔지니어라면 수동 튜닝 없이 희소한 강체 대응점만으로 재타겟팅이 가능한 이 접근법을 참고할 만하다. 물리 시뮬레이터와 재타겟팅을 통합하는 설계 패턴은 데이터 품질 향상에 직접 적용 가능하며, 상위 레벨 손실의 근사 그래디언트 도출 방식도 주목할 필요가 있다.

**한계 및 의문**

논문 내용이 시뮬레이션 및 일부 하드웨어 검증에 그치며, 다양한 로봇 형태나 복잡한 접촉 동작에 대한 일반화 성능은 아직 불명확하다. 이중 레벨 최적화의 계산 비용과 실제 배포 시 실시간 적용 가능성도 추가 검토가 필요하다.
