## 트렌드 분석

오늘의 뉴스를 관통하는 핵심 테마는 하나다: frontier model이 단순한 텍스트 생성 도구를 넘어, 인간 전문가도 수십 년간 풀지 못한 고난도 문제를 실질적으로 해결하는 단계에 진입했다는 것이다. GPT-5.6의 convex optimization gap 해소, Claude Fable의 Jacobian Conjecture 반례 생성, 그리고 $25짜리 WordPress RCE 발견은 표면적으로는 서로 다른 도메인의 이야기처럼 보이지만, 깊이 들여다보면 같은 방향을 가리키고 있다.

수학 분야의 두 사례는 특히 강한 연결고리를 가진다. GPT-5.6이 prompt engineering만으로 30년 묵은 optimization 문제에 접근했고, Claude Fable은 연구자와의 협업을 통해 세기급 난제인 Jacobian Conjecture에 반례를 제시했다. 두 사례 모두 LLM이 symbolic reasoning과 결합될 때 기존 수학 연구 워크플로우를 근본적으로 바꿀 수 있음을 시사한다. 아직 peer review가 완료되지 않아 결과의 신뢰성은 유보적이지만, 이 방향성 자체는 부정하기 어렵다.

보안 사례는 이 흐름의 이면을 날카롭게 드러낸다. $25라는 비용으로 $500,000 가치의 exploit을 찾아낸 사실은, AI의 문제 해결 능력이 방어자와 공격자 모두에게 동등하게 열려 있음을 의미한다. 수학 난제를 푸는 reasoning 능력과 취약점을 탐색하는 능력은 본질적으로 같은 엔진에서 나온다. 즉, capability가 올라갈수록 활용의 양면성도 함께 커진다는 구조적 긴장이 이번 뉴스 묶음 전체에 흐르고 있다.

실무자에게 주는 핵심 시사점은 명확하다: LLM을 보조 도구로만 볼 것인지, 아니면 연구와 보안 파이프라인의 핵심 구성 요소로 재설계할 것인지를 지금 결정해야 한다. 수학 연구자라면 symbolic computation과 LLM을 결합한 hybrid workflow를, 보안 엔지니어라면 LLM 기반 code auditing 자동화를 실험할 시점이다. 경쟁자들은 이미 $25로 시작하고 있다.

### 1. GPT-5.6 used a prompt to close a 30-year gap in convex optimization

- **출처**: hackernews
- **점수**: 7.8
- **URL**: https://old.reddit.com/r/math/comments/1uxj3cy/after_openais_cdc_proof_announcement_gpt56_used_a/

**요약**

GPT-5.6이 prompt를 활용해 convex optimization 분야에서 30년간 미해결이던 gap을 좁히는 수학적 증명을 생성했다는 주장이 Reddit과 HackerNews에서 화제가 됐다. OpenAI의 CDC proof 발표 이후 AI의 수학적 추론 능력에 대한 관심이 급증하고 있다.

**맥락**

OpenAI가 최근 CDC proof 관련 발표를 한 직후 나온 소식으로, LLM의 formal mathematics 및 optimization theory 적용 가능성에 대한 논의가 활발해진 시점이다. convex optimization은 machine learning, operations research 등 다양한 분야의 핵심 이론으로, 30년간의 gap이란 표현은 해당 분야 연구자들에게 매우 큰 의미를 가진다.

**실무 시사점**

ML 엔지니어와 연구자들은 GPT-5.6 같은 frontier model을 단순 코드 생성 도구가 아닌 수학적 추론 보조 도구로 활용하는 실험을 시작할 필요가 있다. 특히 optimization 관련 연구에서 prompt engineering을 통해 새로운 증명 아이디어나 반례를 탐색하는 워크플로우 구축을 고려해볼 만하다.

**한계 및 의문**

Reddit 게시물 기반의 미검증 주장으로, peer review나 공식 논문 발표가 없는 상태다. 'gap을 좁혔다'는 표현의 정확한 의미와 수학적 엄밀성이 검증되지 않았으며, GPT-5.6이라는 모델명 자체도 공식 확인이 필요하다.

### 2. Claude Fable produced a counterexample to the Jacobian Conjecture

- **출처**: hackernews
- **점수**: 7.7
- **URL**: https://xcancel.com/__alpoge__/status/2079028340955197566

**요약**

Claude의 'Fable' 모델이 수학계 난제인 Jacobian Conjecture의 반례를 생성했다는 주장이 제기됐다. 연구자 Levent Alpoge가 AI의 도움으로 C^3에서 C^3로의 polynomial map 반례를 발견했다고 발표했다.

**맥락**

Jacobian Conjecture는 1939년 Ott-Heinrich Keller가 제시한 미해결 난제로, 'Jacobian determinant가 상수인 polynomial map은 반드시 invertible하다'는 명제다. 80년 이상 수많은 수학자가 도전했으나 증명도 반증도 되지 않았으며, Smale의 '21세기 수학 난제 목록'에도 포함된 문제다. 최근 LLM이 IMO 금메달 수준 문제를 풀고 FrontierMath 벤치마크에서 성과를 내는 등 AI의 수학적 추론 능력이 급격히 향상되는 시점에 이 발표가 나왔다.

**실무 시사점**

이 결과가 peer review를 통과한다면 AI가 세기급 수학 난제를 실질적으로 해결하는 첫 사례가 될 수 있으므로, ML 엔지니어는 symbolic computation과 LLM을 결합한 연구 워크플로우에 주목해야 한다. 실무적으로는 Wolfram Alpha 같은 symbolic verification 도구와 LLM을 함께 사용하는 hybrid 검증 파이프라인이 수학·과학 연구에서 표준이 될 가능성이 높다.

**한계 및 의문**

현재 이 반례는 Twitter 게시물 수준으로 공개됐을 뿐 formal peer review나 arXiv preprint가 존재하지 않는다. Jacobian Conjecture는 과거에도 수차례 '증명' 또는 '반증' 주장이 나왔다가 오류로 판명된 역사가 있어, 독립적인 수학자들의 검증이 완료되기 전까지는 신중하게 받아들여야 한다.

**관련 링크**

### 3. I found a WordPress RCEs with GPT5.6 and $25

- **출처**: hackernews
- **점수**: 7.2
- **URL**: https://slcyber.io/research-center/exploit-brokers-pay-500000-for-a-wordpress-rce-i-found-one-with-gpt5-6/

**요약**

보안 연구자가 GPT를 활용해 단 $25의 비용으로 WordPress RCE(원격 코드 실행) 취약점을 발견했으며, 해당 exploit은 브로커 시장에서 $500,000 이상의 가치를 지닌다.

**맥락**

WordPress RCE 취약점은 exploit 브로커 시장에서 최고가 거래 품목 중 하나로, 전통적으로 숙련된 보안 연구자가 수주~수개월을 투자해야 발견 가능했다. 최근 GPT-4/5 계열 LLM의 코드 분석 및 reasoning 능력이 급격히 향상되면서, AI를 활용한 vulnerability research가 현실화되고 있는 시점에 이 사례가 등장했다.

**실무 시사점**

ML 엔지니어와 보안 실무자 모두 LLM을 code auditing 및 vulnerability scanning 파이프라인에 통합하는 것을 진지하게 검토해야 한다. $25라는 극히 낮은 비용 장벽은 공격자도 동일한 방법론을 활용할 수 있음을 의미하므로, WordPress 플러그인/테마를 운영 중인 팀은 즉시 dependency audit과 WAF 설정을 점검해야 한다.

**한계 및 의문**

기사 원문 접근이 제한적이어서 사용된 정확한 prompt engineering 기법, GPT 버전("GPT5.6"이 공식 명칭인지 불명확), 그리고 취약점의 실제 재현 가능성이 독립적으로 검증되지 않았다. AI가 취약점 발견을 보조했더라도 최종 exploit 개발에는 여전히 인간 전문가의 개입이 필요했을 가능성이 높다.
