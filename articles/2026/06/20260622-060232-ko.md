# 오픈소스의 반격: Closed 모델 시대에 균열이 생겼다

## 트렌드 분석

오늘의 뉴스를 관통하는 핵심 테마는 두 가지다. 첫째, closed proprietary 모델의 절대적 우위가 흔들리고 있다는 것. 둘째, frontier model에 대한 접근 자체가 정치적·규제적 리스크 변수로 부상했다는 것이다. 이 두 흐름은 표면적으로 별개처럼 보이지만, 실은 같은 방향을 가리키고 있다 — 단일 closed 모델에 의존하는 구조의 취약성.

GLM-5.2를 둘러싼 두 건의 뉴스는 사실상 하나의 이야기다. Z.ai의 GLM-5.2는 Artificial Analysis Intelligence Index에서 오픈 웨이트 모델 1위를 기록했을 뿐 아니라, GPT-5.5 대비 hallucination rate가 3배 낮다는 충격적인 결과를 보여줬다. benchmark 점수 차이는 불과 4점에 불과하다. 753B 파라미터 규모의 이 모델이 MIT 라이선스로 공개되어 있고, 비용은 GPT-5.5의 일부 수준이라는 점을 감안하면, 'closed 모델 = 고성능'이라는 공식이 더 이상 자동으로 성립하지 않는다는 신호다. 특히 hallucination은 단순한 품질 지표가 아니라 프로덕션 환경에서의 신뢰성과 직결되기 때문에, benchmark 점수만으로 모델을 평가하던 관행 자체를 재검토해야 할 시점이다.

여기에 Anthropic의 Claude Mythos 사태가 더해지면서 그림은 더 복잡해진다. 트럼프 행정부의 export control 부과로 Anthropic은 모델 전체를 비활성화하는 결정을 내렸다. SKT의 중국 연계 의혹과 guardrail 우회 취약점이 규제 트리거가 됐다는 점에서, 이는 단순한 보안 이슈가 아니라 frontier model API 접근이 언제든 정치적 이유로 차단될 수 있다는 현실을 보여주는 사례다. GLM-5.2가 중국 기업 Z.ai의 모델이라는 점도 아이러니하다 — 지정학적 긴장이 고조되는 시대에, 오픈 웨이트 모델의 '오픈'함이 오히려 특정 맥락에서는 리스크 헤지 수단이 될 수 있다.

실무자에게 주는 핵심 시사점은 명확하다. 지금 당장 fallback 전략을 설계해야 한다. 단일 proprietary model API에 의존하는 파이프라인은 규제·정치·보안 이슈로 인한 서비스 중단 앞에 무방비 상태다. GLM-5.2처럼 성능과 비용 경쟁력을 갖춘 오픈 웨이트 모델이 등장한 지금, 멀티 벤더 아키텍처 또는 온프레미스 오픈소스 모델을 포함한 redundancy 설계는 선택이 아닌 필수가 됐다.

### 1. GPT-5.5 hallucinates 3x more than MIT-licensed GLM-5.2

- **출처**: hackernews
- **점수**: 10.0
- **URL**: https://arrowtsx.dev/bigger-models/

**요약**

Z.ai의 오픈소스 GLM-5.2(753B params)가 GPT-5.5 대비 hallucination이 3배 낮으면서 벤치마크 점수는 4점 차이에 불과해, 대형 closed 모델의 우위가 흔들리고 있다.

**맥락**

2026년 현재 AI 업계는 무한한 parameter scaling의 한계에 직면했다. Claude Fable 5가 보안 취약점으로 미국 정부에 의해 출시 3일 만에 사용 금지된 사건은 '크면 클수록 좋다'는 패러다임에 근본적인 의문을 제기했고, DeepSeek V4 Pro의 94% hallucination rate는 대규모 학습 데이터가 오히려 모델의 불확실성 인식 능력을 저해할 수 있음을 보여준다.

**실무 시사점**

ML 엔지니어는 모델 선택 시 benchmark 점수뿐 아니라 hallucination rate와 'I don't know' 응답 비율을 핵심 지표로 평가해야 한다. MIT 라이선스 오픈웨이트 모델인 GLM-5.2가 closed 모델과 경쟁 가능한 수준에 도달했으므로, 비용·보안·커스터마이징 측면에서 오픈웨이트 모델로의 전환을 적극 검토할 시점이다.

**한계 및 의문**

이 기사는 특정 벤치마크(AA Intelligence Index, AA-Omniscience)에만 의존하며, 해당 벤치마크의 신뢰성과 독립성이 검증되지 않았다. 또한 GPT-5.5와 Fable 5의 parameter 수는 추정치에 불과해 직접 비교의 정확성에 한계가 있다.

### 2. GLM-5.2 is the new leading open weights model on Artificial Analysis

- **출처**: hackernews
- **점수**: 7.7
- **URL**: https://artificialanalysis.ai/articles/glm-5-2-is-the-new-leading-open-weights-model-on-the-artificial-analysis-intelligence-index

**요약**

중국 Z.ai의 GLM-5.2가 Artificial Analysis Intelligence Index에서 오픈 웨이트 모델 1위(51점)를 기록했다. 744B total / 40B active parameters 구조로 GLM-5.1 대비 11점 상승하며 MiniMax-M3, DeepSeek V4 Pro를 앞질렀다.

**맥락**

2025~2026년 오픈 웨이트 LLM 경쟁이 중국 기업들 주도로 급격히 심화되고 있다. DeepSeek, MiniMax, Kimi 등이 연이어 고성능 모델을 출시하는 가운데, GLM-5.2는 동일한 MoE 아키텍처(744B total / 40B active)를 유지하면서도 scientific reasoning과 coding 벤치마크에서 큰 폭의 개선을 달성해 '아키텍처 확장 없는 성능 도약'이 가능함을 보여줬다.

**실무 시사점**

GLM-5.2는 $1.4/$4.4 per 1M input/output tokens로 GPT-5.5 수준의 성능을 제공하므로, cost-sensitive한 프로덕션 파이프라인에서 proprietary 모델 대체 옵션으로 즉시 평가해볼 가치가 있다. 특히 scientific reasoning(HLE 40%, GPQA Diamond 89%)과 terminal/coding 태스크(TerminalBench 78%, SciCode 50%)가 강점이므로, 해당 도메인 fine-tuning이나 RAG 파이프라인 구축 시 base model로 우선 검토를 권장한다.

**한계 및 의문**

Artificial Analysis의 Intelligence Index는 자체 가중 집계 방식으로, 특정 벤치마크 편향 가능성이 있다. 또한 오픈 웨이트라고 하나 744B 규모 모델의 자체 inference 인프라 구축 비용은 여전히 높으며, first-party API 의존 시 중국 서비스 접근성·규제 리스크를 별도로 고려해야 한다.

### 3. The Korean telecom giant at the center of Anthropic's Mythos controversy

- **출처**: hackernews
- **점수**: 7.4
- **URL**: https://www.wired.com/story/sk-telecom-anthropic-mythos-export-controls/

**요약**

트럼프 행정부가 SK텔레콤의 중국 연계 의혹과 Amazon의 guardrail 우회 취약점 보고를 계기로 Anthropic의 Claude Mythos 및 Fable 5 모델에 export control을 부과했고, Anthropic은 외국인 접근 차단 대신 모델 전체를 비활성화하는 결정을 내렸다.

**맥락**

미국 정부는 첨단 AI 모델을 반도체와 유사한 국가안보 자산으로 취급하는 방향으로 정책을 전환 중이다. SK텔레콤의 Claude Mythos 접근 허용이 중국 연계 우려를 촉발했고, Amazon 연구진의 Fable 5 guardrail 우회 취약점 보고가 이를 증폭시켜 행정부가 Anthropic의 자체 safeguard 능력을 신뢰하지 못하게 된 배경이다.

**실무 시사점**

ML 엔지니어와 기업은 frontier model API 접근이 언제든 정치적·규제적 이유로 중단될 수 있음을 전제로 fallback 전략(오픈소스 모델 또는 멀티 벤더 아키텍처)을 설계해야 한다. 또한 guardrail 우회 취약점이 규제 트리거가 될 수 있으므로, red-teaming과 adversarial testing 결과를 내부에서만 관리하는 거버넌스 프로세스가 중요해졌다.

**한계 및 의문**

Anthropic과 외부 사이버보안 전문가들은 Fable 5의 취약점이 Claude에만 고유한 문제가 아니라고 반박하고 있어, export control의 기술적 근거가 과장됐을 가능성이 있다. SK텔레콤의 실제 중국 연계 여부도 공개적으로 검증되지 않은 상태다.
